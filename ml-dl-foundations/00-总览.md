## 🎬 一句话故事：你的"倒挂式"学习路径

```
正常路径（教科书顺序）:
  Python → 线代/微积分 → 经典 ML → 神经网络 → CNN/RNN → Transformer → LLM → Agent → RL

你的实际路径:
  Python → LLM 概念 → Transformer → SFT/RLHF/Agent/RL
  ─────────────────────────────────────────────────
  ↑↑↑ 你能"用" loss / 梯度 / optimizer / AdamW / LoRA
      但底下的"为什么"是悬空的

这套笔记做的事:
  把你已经在用的概念"倒着补回去"
       ↓
  最终目标 = 看 LLM/Agent/RL 代码时，每一行都知道在做什么
```

> **不是把你拉回大一基础课。** 是把你"会用"的东西，**反向锚定到原理**。
> 这套笔记每一节都会回扣"你之前在 Happy-LLM / Hello-Agents / agentic-rl 哪一节用过这个概念但没真懂"。

---

## 🎯 这套笔记想让你掌握什么

读完整本笔记书，你应该能回答（直接对应 [04-自测题汇总-是否需要这本书](%E9%99%84%E5%BD%95/04-%E8%87%AA%E6%B5%8B%E9%A2%98%E6%B1%87%E6%80%BB-%E6%98%AF%E5%90%A6%E9%9C%80%E8%A6%81%E8%BF%99%E6%9C%AC%E4%B9%A6.md)）：

1. **loss 是什么？** 为什么 loss 要最小化？SFT loss、CE loss、MSE loss 的区别？
2. **梯度是什么？** 为什么沿梯度反方向走就是下降？反向传播在做什么？
3. **`optimizer.step()` 干了什么？** SGD / Momentum / AdamW 一步一步在更新什么？
4. **`model.parameters()` 是什么？** 神经元、权重、偏置在 PyTorch 里怎么存？
5. **`loss.backward()` 是什么？** 自动微分 / 计算图是怎么运作的？
6. **过拟合怎么诊断？** 训练集和验证集为什么要分？
7. **激活函数为啥要有？** Sigmoid / ReLU / GELU / SwiGLU 选哪个？
8. **学习率为啥要 warmup？** 为啥不能一直用 1e-3？
9. **混合精度（fp16/bf16）省了啥？** GradScaler 是什么？
10. **LayerNorm 和 BatchNorm 区别？** 为什么 NLP 用 LayerNorm？

→ 如果上面**有 ≥5 题答不出来**，这本书是写给你的。

## 🚦 三条阅读路径（按你的时间）

### 🅐 完整深入（4-6 周，推荐）

```
W1: 第 1 章心智模型（3天） + 第 2 章数学（2天） + 第 3 章经典 ML（2天）
W2: 第 4 章神经网络（核心！）—— 全周
W3: 第 4 章 §05-09 + 第 5 章 CNN/RNN
W4: 第 6 章训练实践 + 第 7 章桥接
W5-6: D2L 1-3 章 + 1 个真实小项目（MNIST / Boston Housing）
```

→ 配套主教材：**D2L 中文版** https://zh.d2l.ai

### 🅑 急用版（2 周，目标"读懂 LLM 训练代码"）

```
Day 1-2: 第 1 章 + 第 2 章数学（速读）
Day 3-5: 第 4 章 §01-06（神经元→反向传播→Adam）
Day 6-7: 第 4 章 §07-09 + PyTorch 跑通 MNIST（D2L §3）
Day 8-10: 第 5 章 RNN + Transformer 回顾
Day 11-14: 第 7 章桥接全章（关键）
```

### 🅒 极简版（3-5 天，"能看懂论文公式"）

```
Day 1: 第 1 章 + 第 2 章数学
Day 2: 第 4 章 §01-05（神经元/MLP/loss/反向传播）
Day 3: 第 4 章 §06-09（优化器/初始化/Dropout）
Day 4: 第 7 章 §03 §04（直击 PPO/RM/DPO 的数学根）
Day 5: 自测 + 回头补盲点
```

抓住 5 件事就够：

1. **神经元 = 一个加权求和 + 激活**
2. **MLP = 多层神经元堆叠**
3. **loss = 模型预测 vs 真实的差距，是一个可微的数**
4. **梯度下降 = 用 loss 对参数求导 → 沿反方向更新参数**
5. **优化器 = 这个"更新参数"的具体规则**（SGD/Adam 等）

## ⚠️ 学习前避坑

| 坑 | 怎么避 |
|---|---|
| 想从大一基础课读起 | **不要**！你已经有应用驱动，按本书"倒挂式"路径走更快 |
| 一上来就读 Bishop《PRML》或 Goodfellow《深度学习》 | **不要**！太理论，对你太重 |
| 试图把所有数学推导都搞懂 | 第 2 章只要"看到能认"，不要求"会推导" |
| 跳过第 1 章直接看第 4 章 | 第 1 章 30 分钟，**给你坐标系**，省后面无数困惑 |
| 不写代码全看概念 | 至少第 4 章 §09 那个 30 行 PyTorch demo 要看懂 |
