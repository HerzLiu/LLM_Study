## 🎬 一句话故事：从"会跑模型"到"会调模型"

```
你已经在 Happy-LLM 第 5 章跑过 SFT，可能遇到过：

  - loss 不下降 → 怎么办？
  - OOM → 减啥？
  - 训练突然 NaN → 改啥？
  - 多卡训练快不起来 → 哪里瓶颈？

第 4 章告诉你"每个组件是什么"。
第 6 章告诉你"实际训练时怎么调"。
```

> 这章对你**特别有用**——很多你已经在 Happy-LLM / agentic-rl 笔记里看到过的工程技巧（AMP、ZeRO、梯度累积），在这里**系统讲一遍底层逻辑**。

- [ ] 知道 batch_size / lr / epoch 怎么联动调
- [ ] 能解释 fp16 / bf16 / fp32 区别、为什么要混合精度
- [ ] 知道 DataParallel / DDP / FSDP / ZeRO 区别
- [ ] 能诊断梯度爆炸 / 消失 / NaN
- [ ] 能查训练诊断手册定位问题

## 📝 本章一句话小结

> **第 4 章教你"算法"，第 6 章教你"工程"。**
> 没有工程，再好的算法都跑不出来；
> 没有诊断能力，遇到问题只能瞎试参数。
>
> 本章是 Happy-LLM §5.9 + §6.2 + agentic-rl §A.5 的**理论根**。
