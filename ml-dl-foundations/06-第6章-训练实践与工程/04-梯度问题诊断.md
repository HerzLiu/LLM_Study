# 6.4 梯度问题诊断

⬅ [03-分布式与显存优化](03-%E5%88%86%E5%B8%83%E5%BC%8F%E4%B8%8E%E6%98%BE%E5%AD%98%E4%BC%98%E5%8C%96.md) | ➡ [05-训练诊断手册](05-%E8%AE%AD%E7%BB%83%E8%AF%8A%E6%96%AD%E6%89%8B%E5%86%8C.md)

---

## 🎬 故事比喻：训练曲线的"心电图"

```
正常训练:
  loss     ─────╲___________
            \____  __        ← 平滑下降
                 \/  \_____

异常 1 - 梯度爆炸:
  loss     ──╲__________
              ↑↑↑↑       NaN
              突然飙升 → 直接崩

异常 2 - 梯度消失:
  loss     ─────────────────  ← 一直不动
                              (模型学不到东西)

异常 3 - 反复横跳:
  loss     ─╲╱╲╱╲╱╲╱      ← lr 太大
                              (loss 上下震荡)
```

> 这一节告诉你**看到异常 loss 曲线时怎么诊断**——救你训练命的小手册。

---

## 🔥 6.4.1 梯度爆炸（Exploding Gradient）

### 症状

- Loss 突然飙升 → NaN
- 模型权重变 NaN / inf
- 一般在训练前 100-1000 步出现

### 原因

反向传播时梯度**沿链连乘**（[§4.5](../04-%E7%AC%AC4%E7%AB%A0-%E7%A5%9E%E7%BB%8F%E7%BD%91%E7%BB%9C%E4%B8%8E%E6%B7%B1%E5%BA%A6%E5%AD%A6%E4%B9%A0%E6%A0%B8%E5%BF%83/05-%E6%A2%AF%E5%BA%A6%E4%B8%8B%E9%99%8D-%E5%8F%8D%E5%90%91%E4%BC%A0%E6%92%AD%E5%AE%8C%E6%95%B4%E6%8E%A8%E5%AF%BC.md)）：

$$\nabla \mathcal{L} = \prod_l \frac{\partial \mathcal{L}}{\partial \theta_l}$$

每节梯度 > 1 时，连乘到天文数字。

**触发场景**：
- lr 太大
- 初始化太大（权重 std 太高）
- 数据有异常（极大值、NaN）
- 没用 LayerNorm
- 没用残差连接

### 解决

#### A. 梯度裁剪（Gradient Clipping）⭐ 必装

```python
loss.backward()
torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)   # ← 这一行
optimizer.step()
```

**意义**：把所有梯度的 L2 范数限制在 max_norm（如 1.0）以内。

**典型 max_norm**：
- 一般 DL: 1.0 或 5.0
- LLM: **1.0**（标配）

#### B. 减小学习率

如果训练前期就崩，**lr 减半**再试。

#### C. 加 warmup

让 lr 从 0 慢慢涨起来，避免前几步崩。

#### D. 用 bf16 而非 fp16

bf16 数值范围大，不易溢出。

## 💀 6.4.2 梯度消失（Vanishing Gradient）

### 症状

- Train loss 几乎不动（一直在初始值附近）
- 浅层参数梯度极小（< 1e-7）
- 深层有变化，浅层没变化

### 原因

反向传播链式连乘**每节 < 1**，深网中浅层梯度 → 0。

**触发场景**：
- **Sigmoid / Tanh 激活**（导数最大 0.25）—— 现代 DL 用 ReLU 解决
- 没用残差连接（梯度直通路）
- 没用 LayerNorm
- 初始化太小

### 解决

| 方法 | 效果 |
|---|---|
| **ReLU / GELU / SwiGLU** 激活 | 正区间导数 = 1，不消失 |
| **残差连接** | 给反向传播"高速公路"（§5.1 ResNet，见下方延伸） |
| **LayerNorm / BatchNorm** | 让每层激活稳定 |
| **Kaiming / Xavier 初始化** | 让每层方差稳定 |
| **加大学习率** | 治标，不治本 |

→ 残差连接详见 [§5.1 CNN](../05-%E7%AC%AC5%E7%AB%A0-%E5%85%B8%E5%9E%8B%E6%9E%B6%E6%9E%84%E4%B8%B2%E8%AE%B2/01-CNN%E5%8D%B7%E7%A7%AF%E7%A5%9E%E7%BB%8F%E7%BD%91%E7%BB%9C.md)。

→ 现代 LLM（Transformer + ReLU/GELU + LayerNorm + 残差）**基本不会梯度消失**。

## 🌊 6.4.3 Loss 反复横跳（震荡）

### 症状

```
loss: 2.0 → 0.5 → 2.5 → 0.3 → 3.0 → ...
```

### 原因

- **lr 太大**（最常见）
- batch_size 太小（梯度噪声大）
- 数据没 shuffle
- 数据分布不均

### 解决

- **lr 减半**（最有效）
- 加大 batch_size
- 检查数据是否 shuffle

---

## 🐌 6.4.4 Loss 下降太慢

### 症状

100 epoch 还在初始 loss 附近徘徊。

### 原因

- **lr 太小**
- 模型太小（欠拟合）
- 数据有 bug（如全 0 标签）
- 优化器选错（如用 SGD 没 momentum 训 LLM）

### 解决

- lr 加大 10 倍试
- 检查数据
- 换 AdamW

---

## 💣 6.4.5 Loss = NaN

### 症状

某一步 loss 突然变 NaN，之后全 NaN。

### 排查顺序

```
1. 检查数据是否含 NaN/Inf:
   torch.isnan(x).any()
   torch.isinf(x).any()

2. 检查梯度范数:
   for p in model.parameters():
       if p.grad is not None:
           print(p.grad.norm())

3. 检查激活范围:
   是否有 1e20 这种数？

4. 检查 loss 公式:
   是否有 log(0)? sqrt(负数)? 除以 0?

5. fp16 训练 → 换 bf16

6. lr 减半重试

7. 加梯度裁剪 max_norm=1.0
```

---

## 🛠 6.4.6 必装组合（防大多数问题）

```python
# LLM 训练标配
optimizer = AdamW(model.parameters(), lr=5e-5, weight_decay=0.01)
scheduler = get_cosine_schedule_with_warmup(
    optimizer, num_warmup_steps=200, num_training_steps=10000
)

for step in range(total_steps):
    optimizer.zero_grad()

    with autocast(dtype=torch.bfloat16):              # ← 用 bf16
        loss = model(batch)

    loss.backward()
    torch.nn.utils.clip_grad_norm_(                   # ← 梯度裁剪
        model.parameters(), max_norm=1.0
    )
    optimizer.step()
    scheduler.step()                                   # ← lr 调度
```

→ 这 5 行组合（AdamW + warmup+cosine + bf16 + grad clip + scheduler）能防 90% 训练问题。

## 📊 6.4.7 必监控的 4 个指标

用 wandb / tensorboard 监控：

| 指标 | 健康范围 | 异常含义 |
|---|---|---|
| **train_loss** | 平滑下降 | 上升=lr太大；不动=lr太小 |
| **val_loss** | 跟随 train 下降 | 反弹=过拟合 |
| **gradient_norm** | 0.1 - 10 | >100 爆炸；<0.001 消失 |
| **learning_rate** | warmup 涨 → cosine 降 | 检查 scheduler 配置 |

```python
import wandb
wandb.init(project="my_llm_sft")

for step in range(total_steps):
    loss = ...
    loss.backward()

    # 算梯度范数
    grad_norm = 0
    for p in model.parameters():
        if p.grad is not None:
            grad_norm += p.grad.norm() ** 2
    grad_norm = grad_norm ** 0.5

    wandb.log({
        "loss": loss.item(),
        "gradient_norm": grad_norm.item(),
        "lr": optimizer.param_groups[0]["lr"],
    }, step=step)
```

## ⚠️ 6.4.8 常见误解

| 误解 | 真相 |
|---|---|
| "梯度爆炸 = lr 太大" | 大多数是。但也可能初始化差 / 数据异常 |
| "梯度裁剪 max_norm=1 太小" | LLM 训练就是 1.0，是经验值 |
| "梯度消失现代 DL 没了" | Transformer 时代基本没了，**但 LSTM 仍有** |
| "loss 反弹 = 过拟合" | 也可能只是 lr 突变（如 restart） |
| "NaN 是模型问题" | 大多是**数据**问题 |
| "梯度裁剪让训练变慢" | 不会，裁剪几乎瞬间 |

---

## 📌 6.4 节要点

| 问题 | 解 |
|---|---|
| 梯度爆炸 / NaN | **梯度裁剪 + 减 lr + warmup + bf16** |
| 梯度消失 | ReLU + 残差 + LayerNorm + Kaiming 初始化 |
| Loss 反复震荡 | **减 lr** |
| Loss 下降慢 | 加 lr / 检查数据 / 换 AdamW |

**必装组合**（LLM 训练）：
AdamW + warmup+cosine + bf16 + grad clip 1.0

**必监控指标**：train_loss / val_loss / gradient_norm / lr
