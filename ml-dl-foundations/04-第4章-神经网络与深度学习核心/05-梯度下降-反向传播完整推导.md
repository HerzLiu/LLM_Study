# 4.5 梯度下降 + 反向传播完整推导 ⭐

⬅ [04-损失函数大全](04-%E6%8D%9F%E5%A4%B1%E5%87%BD%E6%95%B0%E5%A4%A7%E5%85%A8.md) | ➡ [06-优化器进化-SGD到AdamW](06-%E4%BC%98%E5%8C%96%E5%99%A8%E8%BF%9B%E5%8C%96-SGD%E5%88%B0AdamW.md)

## 🎬 故事比喻：盲人下山

```
你在山上（参数空间）某点，loss 是"海拔"。
你蒙着眼，但能用脚感觉"地面坡度"。

  - 海拔 = loss
  - 坡度方向 = 梯度
  - 沿坡度反方向走一小步 = 梯度下降

每走一步:
  1. 摸坡度（计算梯度）
  2. 反方向迈一小步（更新参数）
  3. 重复

走够多步 → 到山谷（loss 局部最小）
```

> 这一节是**整本书最核心的一节**。
> 你 SFT 训练时跑的 `loss.backward(); optimizer.step()` 在做的，就是本节的内容。
> 读完后**所有 LLM 训练代码不再黑盒**。

---

## 📐 4.5.1 梯度下降（Gradient Descent）

**目标**：找到参数 $\theta$ 让 loss $\mathcal{L}(\theta)$ 最小：

$$\theta^* = \arg\min_\theta \mathcal{L}(\theta)$$

**思路**：从初始 $\theta_0$ 开始，每步沿**梯度反方向**走一小步：

$$\boxed{\theta_{t+1} = \theta_t - \eta \cdot \nabla_\theta \mathcal{L}(\theta_t)}$$

**逐项解读**：

| 符号 | 含义 | 形状 |
|---|---|---|
| $\theta_t$ | 第 t 步的参数 | 和 $\theta$ 同形状 |
| $\nabla_\theta \mathcal{L}$ | loss 对参数的**梯度** | 和 $\theta$ 同形状 |
| $\eta$ | **学习率**（learning rate） | 标量 |
| $-\eta \nabla_\theta \mathcal{L}$ | 更新步 | 和 $\theta$ 同形状 |

**为什么沿梯度反方向？**

梯度 $\nabla_\theta \mathcal{L}$ 的几何意义：**loss 在当前点上升最快的方向**。

→ 反方向 = **下降最快**的方向。

**类比**：你在 3D 地形图上，梯度指向"最陡上坡"，反方向就是"最陡下坡"。

---

## 🔢 4.5.2 数值例子（一维）

目标：最小化 $\mathcal{L}(\theta) = (\theta - 3)^2$（最小值在 $\theta = 3$）

**梯度**：$\nabla \mathcal{L} = 2(\theta - 3)$

**初始**：$\theta_0 = 0$, **学习率** $\eta = 0.1$

| 步 t | $\theta_t$ | $\mathcal{L}(\theta_t)$ | $\nabla \mathcal{L}$ | $\theta_{t+1} = \theta_t - 0.1 \nabla$ |
|---|---|---|---|---|
| 0 | 0.0 | 9.00 | -6.0 | 0.0 - 0.1·(-6) = **0.6** |
| 1 | 0.6 | 5.76 | -4.8 | 0.6 + 0.48 = **1.08** |
| 2 | 1.08 | 3.69 | -3.84 | 1.08 + 0.384 = **1.46** |
| 3 | 1.46 | 2.36 | -3.07 | 1.46 + 0.307 = **1.77** |
| ... | ... | ... | ... | ... |
| 30 | ≈ 2.99 | ≈ 0 | ≈ 0 | 收敛到 3.0 |

→ 每步都让 loss 下降，最终收敛到最优。

**如果 $\eta$ 太大（如 1.5）**：

| 步 | $\theta$ | $\mathcal{L}$ |
|---|---|---|
| 0 | 0 | 9 |
| 1 | 0 - 1.5·(-6) = 9 | 36 ← **跳过最优点，loss 爆涨** |
| 2 | 9 - 1.5·12 = -9 | 144 |
| 3 | -9 - 1.5·(-24) = 27 | ... ← **发散** |

→ **学习率太大会发散**。这就是为啥 SFT 用 lr=5e-5（很小）。

**如果 $\eta$ 太小（如 0.001）**：收敛慢得令人发指（要几千步才到）。

## 📐 4.5.3 多维情况

设参数有 n 个：$\theta = (\theta_1, \dots, \theta_n)$

梯度是 n 维向量：

$$\nabla_\theta \mathcal{L} = \left(\frac{\partial \mathcal{L}}{\partial \theta_1}, \frac{\partial \mathcal{L}}{\partial \theta_2}, \dots, \frac{\partial \mathcal{L}}{\partial \theta_n}\right)$$

每个 $\frac{\partial \mathcal{L}}{\partial \theta_i}$ 叫**偏导数**——固定其它参数，只看 $\mathcal{L}$ 怎么依赖 $\theta_i$。

→ [§2.2 偏导](../02-%E7%AC%AC2%E7%AB%A0-%E6%95%B0%E5%AD%A6%E6%9C%80%E5%B0%8F%E5%BF%85%E8%A6%81%E5%9F%BA%E7%A1%80/02-%E5%BE%AE%E7%A7%AF%E5%88%863%E4%BB%B6%E5%A5%97-%E5%AF%BC%E6%95%B0%E5%81%8F%E5%AF%BC%E9%93%BE%E5%BC%8F%E6%B3%95%E5%88%99.md) 详讲。

**更新公式相同**：

$$\theta_{i, t+1} = \theta_{i, t} - \eta \cdot \frac{\partial \mathcal{L}}{\partial \theta_i}$$

向量化：

$$\boldsymbol{\theta}_{t+1} = \boldsymbol{\theta}_t - \eta \nabla_\theta \mathcal{L}$$

**问题**：神经网络有**百万到千亿**个参数。
**怎么高效算 $\nabla_\theta \mathcal{L}$？**
**答案**：**反向传播（Backpropagation）**。

---

## 🔄 4.5.4 反向传播：链式法则的应用

### 链式法则回顾

$$\frac{dz}{dx} = \frac{dz}{dy} \cdot \frac{dy}{dx}$$

如果 $z = f(y)$, $y = g(x)$，那 $z$ 对 $x$ 的导数 = 中间链节的导数相乘。

→ [§2.2 链式法则](../02-%E7%AC%AC2%E7%AB%A0-%E6%95%B0%E5%AD%A6%E6%9C%80%E5%B0%8F%E5%BF%85%E8%A6%81%E5%9F%BA%E7%A1%80/02-%E5%BE%AE%E7%A7%AF%E5%88%863%E4%BB%B6%E5%A5%97-%E5%AF%BC%E6%95%B0%E5%81%8F%E5%AF%BC%E9%93%BE%E5%BC%8F%E6%B3%95%E5%88%99.md)。

### 最小例子：2 层 MLP 的反向传播

设网络：

$$
\begin{aligned}
z_1 &= w_1 \cdot x + b_1 \\
a_1 &= \sigma(z_1) \\
z_2 &= w_2 \cdot a_1 + b_2 \\
\hat{y} &= z_2 \\
\mathcal{L} &= (\hat{y} - y)^2
\end{aligned}
$$

（一维输入、一维隐藏、一维输出，全部用标量；$\sigma$ = sigmoid）

**目标**：算出 $\frac{\partial \mathcal{L}}{\partial w_1}, \frac{\partial \mathcal{L}}{\partial b_1}, \frac{\partial \mathcal{L}}{\partial w_2}, \frac{\partial \mathcal{L}}{\partial b_2}$。

**链式法则从外往内**：

**Step 1**: $\frac{\partial \mathcal{L}}{\partial \hat{y}}$
$$\mathcal{L} = (\hat{y} - y)^2 \implies \frac{\partial \mathcal{L}}{\partial \hat{y}} = 2(\hat{y} - y)$$

**Step 2**: $\frac{\partial \mathcal{L}}{\partial z_2}$（$\hat{y} = z_2$，所以 $\partial \hat{y} / \partial z_2 = 1$）
$$\frac{\partial \mathcal{L}}{\partial z_2} = \frac{\partial \mathcal{L}}{\partial \hat{y}} \cdot \frac{\partial \hat{y}}{\partial z_2} = 2(\hat{y} - y) \cdot 1 = 2(\hat{y} - y)$$

**Step 3**: 输出层参数 $w_2, b_2$（$z_2 = w_2 a_1 + b_2$）
$$\frac{\partial \mathcal{L}}{\partial w_2} = \frac{\partial \mathcal{L}}{\partial z_2} \cdot \frac{\partial z_2}{\partial w_2} = 2(\hat{y}-y) \cdot a_1$$
$$\frac{\partial \mathcal{L}}{\partial b_2} = \frac{\partial \mathcal{L}}{\partial z_2} \cdot \frac{\partial z_2}{\partial b_2} = 2(\hat{y}-y) \cdot 1$$

**Step 4**: 传到 $a_1$
$$\frac{\partial \mathcal{L}}{\partial a_1} = \frac{\partial \mathcal{L}}{\partial z_2} \cdot \frac{\partial z_2}{\partial a_1} = 2(\hat{y}-y) \cdot w_2$$

**Step 5**: 传到 $z_1$（$a_1 = \sigma(z_1)$, $\sigma'(z_1) = \sigma(z_1)(1-\sigma(z_1)) = a_1(1-a_1)$）
$$\frac{\partial \mathcal{L}}{\partial z_1} = \frac{\partial \mathcal{L}}{\partial a_1} \cdot \frac{\partial a_1}{\partial z_1} = 2(\hat{y}-y) \cdot w_2 \cdot a_1(1-a_1)$$

**Step 6**: 第 1 层参数 $w_1, b_1$（$z_1 = w_1 x + b_1$）
$$\frac{\partial \mathcal{L}}{\partial w_1} = \frac{\partial \mathcal{L}}{\partial z_1} \cdot x = 2(\hat{y}-y) \cdot w_2 \cdot a_1(1-a_1) \cdot x$$
$$\frac{\partial \mathcal{L}}{\partial b_1} = \frac{\partial \mathcal{L}}{\partial z_1} \cdot 1 = 2(\hat{y}-y) \cdot w_2 \cdot a_1(1-a_1)$$

---

## 🧭 4.5.5 关键观察：反向传播 = 从后往前传梯度

```
正向传播 (forward):
   x ───→ z_1 ───→ a_1 ───→ z_2 ───→ ŷ ───→ L

反向传播 (backward):
   x ←─── z_1 ←─── a_1 ←─── z_2 ←─── ŷ ←─── L
                                              │
                                       从这开始算
                                       (∂L/∂ŷ)
```

**核心思想**：

1. **前向**：算 loss
2. **后向**：从 loss 出发，**反向**用链式法则把梯度传到每个参数
3. **每个参数的梯度** = "loss 对它的偏导" = 把链上每节的导数相乘

**复杂度**：反向传播只需要 **1 次正向 + 1 次反向** = **2 倍正向**的时间。
**对比**：如果对每个参数单独算偏导（数值微分），要 N 次正向 → **慢 N 倍**（N 可以是几十亿）。

→ **反向传播让 DL 训练成为可能**。Hinton 等 1986 普及，2012 AlexNet 引爆。

---

## 🎯 4.5.6 梯度消失 / 梯度爆炸

反向传播时**梯度沿链连乘**：

$$\frac{\partial \mathcal{L}}{\partial w_1} = \frac{\partial \mathcal{L}}{\partial \hat{y}} \cdot \frac{\partial \hat{y}}{\partial z_2} \cdot \frac{\partial z_2}{\partial a_1} \cdot \frac{\partial a_1}{\partial z_1} \cdot \frac{\partial z_1}{\partial w_1}$$

**梯度消失（vanishing gradient）**：
- 如果每节梯度 $< 1$（如 sigmoid 的 $\sigma' \le 0.25$），10 层后梯度 $\le 0.25^{10} \approx 10^{-6}$ → 浅层学不动
- → **现代解法**：用 ReLU/GELU（正区间导数=1）、残差连接、LayerNorm

**梯度爆炸（exploding gradient）**：
- 如果每节梯度 $> 1$，连乘会变天文数字 → NaN
- → **现代解法**：梯度裁剪（gradient clipping）、好的初始化、LayerNorm

→ 这就是为什么 [§6.4 梯度问题诊断](../06-%E7%AC%AC6%E7%AB%A0-%E8%AE%AD%E7%BB%83%E5%AE%9E%E8%B7%B5%E4%B8%8E%E5%B7%A5%E7%A8%8B/04-%E6%A2%AF%E5%BA%A6%E9%97%AE%E9%A2%98%E8%AF%8A%E6%96%AD.md) 是必读章节。
→ 也解释了 [Happy-LLM §2.8 残差连接](../../Happy-LLM/02-%E7%AC%AC2%E7%AB%A0-Transformer%E6%9E%B6%E6%9E%84/08-%E6%AE%8B%E5%B7%AE%E8%BF%9E%E6%8E%A5.md)为什么重要（它给反向传播加了"高速公路"）。

## 🤖 4.5.7 PyTorch 自动微分（autograd）

**手动推导反向传播很烦**——百万参数你推不动。
**PyTorch 自动帮你**：

```python
import torch

# 1. 设置参数（requires_grad=True 才会被追踪）
w1 = torch.tensor(0.5, requires_grad=True)
b1 = torch.tensor(0.1, requires_grad=True)
w2 = torch.tensor(2.0, requires_grad=True)
b2 = torch.tensor(0.3, requires_grad=True)

# 2. 前向计算（PyTorch 同时构建"计算图"）
x = torch.tensor(1.0)
y = torch.tensor(4.0)
z1 = w1 * x + b1
a1 = torch.sigmoid(z1)
z2 = w2 * a1 + b2
loss = (z2 - y) ** 2

# 3. 反向传播（一行代码！）
loss.backward()

# 4. 看每个参数的梯度
print(w1.grad)  # ∂L/∂w1
print(b1.grad)  # ∂L/∂b1
print(w2.grad)  # ∂L/∂w2
print(b2.grad)  # ∂L/∂b2
```

→ **`.backward()` 一行**做完上面 §4.5.4 的全部链式法则。
→ 这就是为什么 Happy-LLM 训练代码里有 `loss.backward()`——**它在反向传播**。

**关键概念**：

| 概念 | 含义 |
|---|---|
| **计算图 (computational graph)** | 每个张量记录"我是谁算出来的"——前向时自动建 |
| **autograd** | PyTorch 的自动微分引擎，沿计算图反向传梯度 |
| **`.grad`** | 每个 `requires_grad=True` 的张量的梯度存这里 |
| **`.backward()`** | 触发反向传播，填充所有 `.grad` |
| **`.zero_grad()`** | 把所有 grad 清零（不清会累加！） |

## 💻 4.5.8 完整训练步（概念示意，未严格验证）

```python
# 一步训练 = 前向 + 反向 + 更新
import torch
import torch.nn as nn
import torch.optim as optim

model = nn.Linear(10, 1)
optimizer = optim.SGD(model.parameters(), lr=0.01)
loss_fn = nn.MSELoss()

x = torch.randn(32, 10)              # batch=32
y = torch.randn(32, 1)

# === 标准 4 步 ===
optimizer.zero_grad()                 # 1. 清零旧梯度
y_pred = model(x)                     # 2. 前向算预测
loss = loss_fn(y_pred, y)             # 3. 算 loss
loss.backward()                       # 4. 反向算梯度
optimizer.step()                      # 5. 用梯度更新参数
```

→ **5 行就是 ML 训练的"心脏"**。
→ Happy-LLM SFT、agentic-rl 的 PPO/GRPO，本质上都是这 5 步的变形。

## ⚠️ 4.5.9 常见误解

| 误解 | 真相 |
|---|---|
| "梯度下降一定收敛到全局最优" | **不**。神经网络是非凸的，只能找**局部最优**。但实践效果很好 |
| "梯度告诉我们最优值在哪" | **不**。只告诉**当前点**最快下降方向，要走多步才知道 |
| "学习率越大越快" | 太大会发散，**太小**也慢——见 §4.7 学习率调度 |
| "`backward()` 一调，参数自动更新" | **不**！`backward()` 只填 `.grad`，**`optimizer.step()` 才更新参数** |
| "梯度可以一直累积" | 不！每步必须 `optimizer.zero_grad()` 清零，否则**和**了上一步 |
| "反向传播 = 链式法则" | 反向传播**是**链式法则在神经网络上的高效实现 |

## 📌 4.5 节要点

| 概念 | 一句话 |
|---|---|
| **梯度下降** | $\theta_{t+1} = \theta_t - \eta \nabla \mathcal{L}$ |
| **梯度** | loss 在参数空间上升最快的方向，反方向 = 下降 |
| **学习率** $\eta$ | 太大发散，太小慢 |
| **反向传播** | 用链式法则**从后往前**传梯度，一次正向 + 一次反向 |
| **梯度消失** | 链式连乘把梯度连到 0（用 ReLU + 残差解） |
| **梯度爆炸** | 链式连乘到天文数字（用裁剪解） |
| **PyTorch autograd** | `loss.backward()` 自动完成反向传播 |
| **训练 5 步** | zero_grad → forward → loss → backward → step |
