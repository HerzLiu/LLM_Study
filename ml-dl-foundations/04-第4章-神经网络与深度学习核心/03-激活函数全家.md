# 4.3 激活函数全家

⬅ [02-MLP前馈神经网络](02-MLP%E5%89%8D%E9%A6%88%E7%A5%9E%E7%BB%8F%E7%BD%91%E7%BB%9C.md) | ➡ [04-损失函数大全](04-%E6%8D%9F%E5%A4%B1%E5%87%BD%E6%95%B0%E5%A4%A7%E5%85%A8.md)

---

## 🎬 故事比喻：神经元的"决策风格"

```
神经元加权求和得到一个分数 z，
怎么把它变成"输出"？

  Sigmoid: "S 形软判官" - 把分数压到 0-1 之间，像概率
  Tanh:    "对称软判官" - 压到 -1 到 1
  ReLU:    "暴脾气" - 负数全砍，正数原样
  GELU:    "ReLU 的优雅版" - 负数也保留一点点
  SwiGLU:  "聪明的门卫" - 一边算分，一边算门控
```

> **激活函数 = 神经元的"非线性变换"**。
> [§4.2.4](02-MLP%E5%89%8D%E9%A6%88%E7%A5%9E%E7%BB%8F%E7%BD%91%E7%BB%9C.md#%EF%B8%8F-424-%E5%85%B3%E9%94%AE%E9%97%AE%E9%A2%98%E4%B8%BA%E4%BB%80%E4%B9%88%E5%BF%85%E9%A1%BB%E6%9C%89%E6%BF%80%E6%B4%BB%E5%87%BD%E6%95%B0-f) 已经证明：**没有激活函数，深度学习 = 线性回归**。
> 本节讲 5 类常见激活函数 + 各自适用场景。

---

## 🪪 4.3.1 Sigmoid（古典派）

$$\sigma(z) = \frac{1}{1 + e^{-z}}$$

**图像**：

```
   1.0 ┤        ╱─────
       │       ╱
   0.5 ┤      ╱
       │    ╱
   0.0 ┤───╱
       └─────────────→
       -5    0    5
```

**性质**：

| 性质 | 值 |
|---|---|
| 输出范围 | $(0, 1)$ |
| $\sigma(0)$ | 0.5 |
| $\sigma'(z) = \sigma(z)(1-\sigma(z))$ | 导数最大 0.25（z=0 时） |
| 单调递增 | ✓ |
| 平滑可导 | ✓ |

**用在哪**：
- ✅ **二分类输出层**（输出 0-1 的概率）
- ✅ LSTM / GRU 的**门控**（也是 0-1 控制）
- ❌ **隐藏层很少用**（见下方"梯度消失"）

**致命问题：梯度消失（Vanishing Gradient）**

当 $|z|$ 很大时（如 z=10），$\sigma'(z) \approx 0$。深层网络反向传播时梯度连乘（[§4.5](05-%E6%A2%AF%E5%BA%A6%E4%B8%8B%E9%99%8D-%E5%8F%8D%E5%90%91%E4%BC%A0%E6%92%AD%E5%AE%8C%E6%95%B4%E6%8E%A8%E5%AF%BC.md) 链式法则），**0.001 × 0.001 × ... → 0**，梯度消失，浅层学不动。

→ **这就是 2010 年前 DL 没火的主因之一**（深网络训不起来）。

---

## 🪪 4.3.2 Tanh（双曲正切）

$$\tanh(z) = \frac{e^z - e^{-z}}{e^z + e^{-z}} = 2\sigma(2z) - 1$$

**图像**：

```
   1.0 ┤        ╱─────
       │       ╱
   0.0 ┤──────╱──────
       │    ╱
  -1.0 ┤───╱
       └─────────────→
       -5    0    5
```

**性质**：

| 性质 | 值 |
|---|---|
| 输出范围 | $(-1, 1)$ |
| 零均值 | ✓（Sigmoid 不是） |
| 导数 | $1 - \tanh^2(z)$，最大 1 |

**用在哪**：
- ✅ RNN / LSTM 的隐藏状态
- ⚠️ 仍有梯度消失问题（虽比 Sigmoid 好）

---

## 🪪 4.3.3 ReLU（深度学习标配，2010+ 革命）

$$\text{ReLU}(z) = \max(0, z) = \begin{cases} z & \text{if } z > 0 \\ 0 & \text{if } z \le 0 \end{cases}$$

**图像**：

```
        ╱
       ╱
      ╱
─────╱─────────→
0  5
```

**性质**：

| 性质 | 值 |
|---|---|
| 输出范围 | $[0, +\infty)$ |
| 导数 | $\begin{cases} 1 & z > 0 \\ 0 & z \le 0 \end{cases}$ |
| 计算极快 | 只是 $\max$，无 $\exp$ |

**优势**：
- ✅ **彻底解决梯度消失**（正区间导数恒为 1）
- ✅ **稀疏激活**（负的全为 0，约一半神经元不激活，类似生物大脑）
- ✅ 计算超快

**问题**：
- ❌ **Dying ReLU**：如果某神经元 $z$ 一直为负，梯度永远 0，神经元"死亡"，再也学不到
- ❌ 负数信息全丢

**变体**：
- **Leaky ReLU**: $\text{LReLU}(z) = \max(0.01 z, z)$（负数保留一点）
- **PReLU**: 负斜率可训练
- **ELU**: 负区间用 $\alpha(e^z - 1)$

**用在哪**：
- ✅ **所有 CNN**（ResNet/VGG/AlexNet 全用 ReLU）
- ✅ 早期 Transformer（原始论文用 ReLU）
- ⚠️ 现代 LLM 已被 GELU/SwiGLU 取代

---

## 🪪 4.3.4 GELU（BERT/GPT 用的）

$$\text{GELU}(z) = z \cdot \Phi(z) \approx 0.5 z \left(1 + \tanh\left(\sqrt{2/\pi}(z + 0.044715 z^3)\right)\right)$$

其中 $\Phi(z)$ 是标准正态分布的 CDF。

**直觉**：可以理解为"**ReLU 的光滑版**"——负数不全砍掉，按"被激活的概率"保留一部分。

**图像（和 ReLU 对比）**：

```
ReLU:           GELU:
   ╱               ╱
  ╱               ╱
 ╱               ╱
──╱─────        ─╱╲─────  ← 负小值轻微保留
0              0
```

**性质**：

| 性质 | 值 |
|---|---|
| 输出范围 | $\approx [-0.17, +\infty)$（负小值轻微保留） |
| 平滑可导 | ✓（处处可导，ReLU 在 0 不可导） |
| 计算稍慢 | 需要 tanh 或 erf |

**用在哪**：
- ✅ **BERT、GPT-2/3、原始 Transformer 改进版**

---

## 🪪 4.3.5 Swish / SiLU（LLM 的当红明星）

$$\text{Swish}(z) = z \cdot \sigma(z) = \frac{z}{1 + e^{-z}}$$

**注意**：Swish 和 SiLU 是**同一个函数的不同名字**。

**图像**：类似 GELU，光滑、负区间小幅保留。

**用在哪**：
- ✅ EfficientNet、LLaMA / Qwen / DeepSeek 的 SwiGLU 内部

---

## 🪪 4.3.6 SwiGLU（当今 LLM 标配）

不只是激活函数，是一个**带门控的 FFN 子结构**：

$$\text{SwiGLU}(x) = (\text{Swish}(\mathbf{W}_1 x)) \otimes (\mathbf{W}_3 x)$$

其中 $\otimes$ 是逐元素乘（Hadamard product）。

**完整 FFN 块**（LLaMA 风格）：

$$\text{FFN}(x) = \mathbf{W}_2 \cdot \big(\text{Swish}(\mathbf{W}_1 x) \otimes (\mathbf{W}_3 x)\big)$$

**逐项解读**：

| 部分 | 作用 |
|---|---|
| $\mathbf{W}_1 x$ | 主路径，准备过激活 |
| $\text{Swish}(\mathbf{W}_1 x)$ | 主路径激活后的"特征" |
| $\mathbf{W}_3 x$ | **门控路径**，决定每个特征通过多少 |
| $\otimes$ | 逐元素相乘 = 门控 |
| $\mathbf{W}_2$ | 输出投影 |

**比 ReLU/GELU 强在哪**：
- ✅ 门控让模型学会"哪些特征该被强调，哪些该被抑制"
- ✅ 实验上 LLM 训练 loss 显著更低

**代价**：
- ⚠️ 需要 **3 个权重矩阵**（而 ReLU/GELU 只要 2 个）
- ⚠️ 参数量增加 50%

**用在哪**：
- ✅ **LLaMA / Qwen / DeepSeek / Mistral**（现代主流 LLM）

→ 详见 [Happy-LLM §5.4 SwiGLU-MLP](../../Happy-LLM/05-%E7%AC%AC5%E7%AB%A0-%E5%8A%A8%E6%89%8B%E6%90%AD%E5%BB%BA%E5%A4%A7%E6%A8%A1%E5%9E%8B/04-SwiGLU-MLP.md)（你跑过的代码）。

## 🪪 4.3.7 Softmax（输出层用，不算"激活函数"严格意义但常一起讲）

$$\text{softmax}(\mathbf{z})_i = \frac{e^{z_i}}{\sum_j e^{z_j}}$$

**作用**：把任意实数向量**归一化为概率分布**（每项 0-1 且和为 1）。

**数值例子**：

| $\mathbf{z}$ | $e^{z_i}$ | softmax |
|---|---|---|
| (1.0, 2.0, 3.0) | (2.72, 7.39, 20.09) | (0.09, 0.24, 0.67) |
| (3.0, 1.0, 2.0) | (20.09, 2.72, 7.39) | (0.67, 0.09, 0.24) |

**用在哪**：
- ✅ **分类输出层**（多分类）
- ✅ **Attention** 把 $QK^T$ 归一化为注意力权重
- ✅ LLM 输出 token 概率分布

→ 详见 [§2.3 概率5件套](../02-%E7%AC%AC2%E7%AB%A0-%E6%95%B0%E5%AD%A6%E6%9C%80%E5%B0%8F%E5%BF%85%E8%A6%81%E5%9F%BA%E7%A1%80/03-%E6%A6%82%E7%8E%875%E4%BB%B6%E5%A5%97-%E5%88%86%E5%B8%83%E6%9C%9F%E6%9C%9BKL.md)。

## 📊 4.3.8 全家对比表（一图速查）

| 名字 | 公式 | 输出范围 | 解决梯度消失？ | 用在哪 |
|---|---|---|---|---|
| **Sigmoid** | $1/(1+e^{-z})$ | $(0, 1)$ | ❌ | 二分类输出、LSTM 门 |
| **Tanh** | $(e^z-e^{-z})/(e^z+e^{-z})$ | $(-1, 1)$ | ⚠️ 部分 | RNN 隐藏态 |
| **ReLU** | $\max(0, z)$ | $[0, +\infty)$ | ✅ | CNN、早期 Transformer |
| **Leaky ReLU** | $\max(0.01z, z)$ | $\mathbb{R}$ | ✅ | 改进 ReLU、GAN |
| **GELU** | $z \cdot \Phi(z)$ | $\approx [-0.17, +\infty)$ | ✅ | BERT、GPT |
| **Swish / SiLU** | $z \cdot \sigma(z)$ | 类似 GELU | ✅ | EfficientNet |
| **SwiGLU** | $\text{Swish}(W_1 x) \otimes (W_3 x)$ | 任意 | ✅ | **LLaMA/Qwen** |
| **Softmax**（输出归一化） | $e^{z_i}/\sum e^{z_j}$ | 概率分布 | — | 分类输出、Attention |

## ⚠️ 4.3.9 常见误解

| 误解 | 真相 |
|---|---|
| "Sigmoid 比 ReLU 老所以差" | Sigmoid 仍**用在二分类输出和门控**，没被淘汰；只是隐藏层不再用 |
| "ReLU 比 Sigmoid 一定好" | 看场景。门控仍用 Sigmoid。回归任务有时 Tanh 更稳 |
| "SwiGLU 是新激活函数" | 严格说**是一种 FFN 结构**（带门控），核心激活仍是 Swish |
| "Softmax 是激活函数" | 严格说不是逐元素函数，是**归一化**。但常和激活一起讲 |

---

## 📌 4.3 节要点

| 场景 | 推荐 |
|---|---|
| 隐藏层（一般 DL） | **ReLU** 或 Leaky ReLU |
| Transformer FFN（BERT/GPT 时代） | **GELU** |
| LLM FFN（LLaMA 后） | **SwiGLU** |
| 二分类输出 | **Sigmoid** |
| 多分类输出 | **Softmax** |
| LSTM / GRU 门控 | **Sigmoid**（值要 0-1） |
| 回归输出 | **无激活**（线性输出） |

**演化历史一句话**：
> Sigmoid (1990) → Tanh (1990s) → **ReLU (2012)** → GELU (2016) → **SwiGLU (2020)**
