# 4.4 损失函数大全

⬅ [03-激活函数全家](03-%E6%BF%80%E6%B4%BB%E5%87%BD%E6%95%B0%E5%85%A8%E5%AE%B6.md) | ➡ [05-梯度下降-反向传播完整推导](05-%E6%A2%AF%E5%BA%A6%E4%B8%8B%E9%99%8D-%E5%8F%8D%E5%90%91%E4%BC%A0%E6%92%AD%E5%AE%8C%E6%95%B4%E6%8E%A8%E5%AF%BC.md)

---

## 🎬 故事比喻：模型考试的"扣分规则"

```
模型预测 = 学生答题
真实标签 = 标准答案
损失函数 = 扣分规则

  - 选择题答错 → 扣固定分（0-1 loss，但没法求导，不用）
  - 答案离正确多远 → 按距离扣分（MSE, 回归）
  - 答案是分类预测 → 按"对正确选项给的概率有多低"扣分（CE, 分类）

训练 = "调参数让总扣分最小"
```

> 这一节看完，你就能解释 Happy-LLM 全书出现过的所有 loss：
>
> - SFT 用的 `CrossEntropyLoss` 是啥
> - RM 用的 pairwise loss 是啥
> - GRPO 的 $L^{GRPO}$ 是啥
> - DPO 的 $\mathcal{L}_{DPO}$ 是啥
>
> **本质都是 MSE / BCE / CE / NLL 的变形**。

---

## 📐 4.4.1 什么是"损失函数"？精确定义

**损失函数** $\mathcal{L}: \mathcal{Y} \times \mathcal{Y} \to \mathbb{R}_{\ge 0}$

输入：预测值 $\hat{y}$ 和真实值 $y$
输出：一个非负数，**越小越好**（0 = 完美预测）

**要满足**：

| 性质 | 含义 | 为什么 |
|---|---|---|
| 非负 | $\mathcal{L} \ge 0$ | 0 才是完美 |
| 单调（粗略） | 预测越偏离真实，loss 越大 | 让梯度有意义 |
| **可微** | $\nabla_\theta \mathcal{L}$ 存在 | 才能反向传播 |

最后一条**最关键**——很多直觉上好的"评估指标"（如准确率）**不可微**，所以**不能直接当 loss**。

→ 这就是为什么分类任务的 loss 是 CE（可微），而**评估指标**才是准确率（不可微但人类直觉）。

---

## 🪪 4.4.2 MSE（均方误差，回归任务）

$$\mathcal{L}_{\text{MSE}}(\hat{y}, y) = (\hat{y} - y)^2$$

batch 版本：

$$\mathcal{L}_{\text{MSE}} = \frac{1}{N} \sum_{i=1}^{N} (\hat{y}_i - y_i)^2$$

**特点**：
- 对**大错误**惩罚更重（平方放大）
- 对 outlier 敏感
- 等价于"假设噪声是**高斯分布**"下的 MLE（[§2.3](../02-%E7%AC%AC2%E7%AB%A0-%E6%95%B0%E5%AD%A6%E6%9C%80%E5%B0%8F%E5%BF%85%E8%A6%81%E5%9F%BA%E7%A1%80/03-%E6%A6%82%E7%8E%875%E4%BB%B6%E5%A5%97-%E5%88%86%E5%B8%83%E6%9C%9F%E6%9C%9BKL.md)）

**用在哪**：
- ✅ 回归任务（预测房价、温度、年龄）
- ✅ Value Network 的训练（PPO/GRPO 的 critic）—— [agentic-rl §1.4](../../agentic-rl-knowledge-base/01-%E7%AC%AC1%E7%AB%A0-RL%E6%9C%80%E5%B0%8F%E5%BF%85%E8%A6%81%E5%9F%BA%E7%A1%80/04-PPO%E4%B8%8EKL%E7%BA%A6%E6%9D%9F.md)

**数值小例子**：

| $\hat{y}$ | $y$ | $(\hat{y}-y)^2$ |
|---|---|---|
| 3.0 | 3.0 | 0 |
| 3.0 | 4.0 | 1 |
| 3.0 | 5.0 | 4 |
| 3.0 | 10.0 | **49** ← 大错被严惩 |

---

## 🪪 4.4.3 MAE（平均绝对误差，回归备选）

$$\mathcal{L}_{\text{MAE}} = \frac{1}{N} \sum_{i=1}^{N} |\hat{y}_i - y_i|$$

**vs MSE**：
- 对 outlier **不敏感**（不平方）
- 但在 0 处不可导（虽然实用中 subgradient 也能用）
- 等价于"假设噪声是 **Laplace 分布**"下的 MLE

---

## 🪪 4.4.4 BCE（二分类交叉熵）

二分类标签 $y \in \{0, 1\}$，预测 $\hat{y} = \sigma(z) \in (0, 1)$：

$$\mathcal{L}_{\text{BCE}}(\hat{y}, y) = -[y \log \hat{y} + (1-y) \log (1-\hat{y})]$$

**逐项解读**：

| 真实 $y$ | 公式简化为 | 含义 |
|---|---|---|
| $y = 1$ | $-\log \hat{y}$ | 模型给正例的概率越低 loss 越大 |
| $y = 0$ | $-\log (1 - \hat{y})$ | 模型给反例的概率越低 loss 越大 |

**数值例子**（$y = 1$）：

| $\hat{y}$ | $-\log \hat{y}$ |
|---|---|
| 0.99 | 0.01 ← 几乎答对，loss 极小 |
| 0.5 | 0.69 ← 模型摇摆 |
| 0.1 | 2.30 ← 答错了，loss 大 |
| 0.01 | 4.61 ← 严重错误，loss 极大 |

→ **错误越离谱，惩罚越重**（$\log$ 的特性）。

**用在哪**：
- ✅ 二分类（点击率预测、垃圾邮件检测）
- ✅ **多标签分类**（每个标签独立 BCE）
- ✅ **DPO loss 的核心**（[agentic-rl §2.2](../../agentic-rl-knowledge-base/02-%E7%AC%AC2%E7%AB%A0-%E4%BB%8ERLHF%E5%88%B0Agentic-RL/02-DPO%EF%BC%88%E5%81%8F%E5%A5%BD%E7%9B%B4%E6%8E%A5%E4%BC%98%E5%8C%96%EF%BC%89.md)）：
  $$\mathcal{L}_{DPO} = -\log \sigma(\text{隐式 reward 差}) \text{ ← 这就是 BCE}$$

---

## 🪪 4.4.5 CrossEntropy（多分类交叉熵）⭐ LLM 训练的核心

多分类标签 $y \in \{1, 2, \dots, C\}$（C 类），预测 $\hat{\mathbf{p}} = \text{softmax}(\mathbf{z}) \in \Delta^{C-1}$（概率分布）：

$$\mathcal{L}_{\text{CE}}(\hat{\mathbf{p}}, y) = -\log \hat{p}_y = -\log \frac{e^{z_y}}{\sum_j e^{z_j}}$$

**逐项解读**：

| 符号 | 含义 |
|---|---|
| $C$ | 类别数 |
| $\mathbf{z} \in \mathbb{R}^C$ | 模型最后一层 logits（**未归一化**）|
| $\hat{\mathbf{p}} = \text{softmax}(\mathbf{z})$ | 归一化后的概率分布 |
| $y$ | 真实类别（一个整数 1-C） |
| $\hat{p}_y$ | 模型对**真实类别** $y$ 给出的概率 |
| $-\log$ | "对真实类别预测概率越低，惩罚越大" |

**人话**：「**模型对正确答案有多大信心？信心越低，扣越多分**」

**数值例子**（4 类分类，真实类别 = 第 2 类）：

| 模型输出 logits $\mathbf{z}$ | softmax $\hat{\mathbf{p}}$ | $\hat{p}_2$（真实类） | loss $-\log \hat{p}_2$ |
|---|---|---|---|
| (1, 4, 0, 0) | (0.04, 0.93, 0.01, 0.02) | 0.93 | **0.07** ← 模型很确定，loss 小 |
| (1, 1, 1, 1) | (0.25, 0.25, 0.25, 0.25) | 0.25 | **1.39** ← 完全摇摆 |
| (4, 0, 0, 0) | (0.93, 0.04, 0.01, 0.02) | 0.04 | **3.22** ← 模型选错了 |

**用在哪**：
- ✅ **几乎所有分类任务**
- ✅ **LLM next-token prediction**：词表大小 = C（5万到20万），真实下一个 token 的 ID 是 $y$
  - → Happy-LLM SFT 的 `CrossEntropyLoss` 就是这个
  - → 详见 [§7.2](../07-%E7%AC%AC7%E7%AB%A0-%E6%A1%A5%E6%8E%A5%E5%88%B0%E4%BD%A0%E5%B7%B2%E5%AD%A6%E7%9A%84%E4%B8%96%E7%95%8C/02-%E4%BB%8E%E4%BA%A4%E5%8F%89%E7%86%B5%E5%88%B0next-token-loss.md)

## 🪪 4.4.6 NLL（负对数似然 Negative Log-Likelihood）

$$\mathcal{L}_{\text{NLL}}(\hat{\mathbf{p}}, y) = -\log \hat{p}_y$$

**和 CE 关系**：
- 数学上**完全相同**
- 区别只在**输入**：
  - `nn.CrossEntropyLoss` 接受 logits（自带 softmax）
  - `nn.NLLLoss` 接受 **log-probabilities**（你需要先调 `F.log_softmax`）

**PyTorch 等价写法**：

```python
# 写法 1
loss = F.cross_entropy(logits, y)

# 写法 2（数学等价）
log_probs = F.log_softmax(logits, dim=-1)
loss = F.nll_loss(log_probs, y)
```

→ 实际写代码用 `cross_entropy`（少一步，数值更稳）。

## 🪪 4.4.7 Contrastive Loss（对比损失）

用于"**让相似的近、不相似的远**"的任务（embedding、检索、对比学习）。

**InfoNCE**（CLIP / Sentence-BERT 用的）：

$$\mathcal{L}_{\text{InfoNCE}} = -\log \frac{e^{\text{sim}(\mathbf{q}, \mathbf{k}^+)/\tau}}{\sum_{\mathbf{k} \in \{\mathbf{k}^+, \mathbf{k}^-_1, \dots\}} e^{\text{sim}(\mathbf{q}, \mathbf{k})/\tau}}$$

**逐项解读**：

| 符号 | 含义 |
|---|---|
| $\mathbf{q}$ | query（如一张图） |
| $\mathbf{k}^+$ | positive key（如这张图的描述） |
| $\mathbf{k}^-_i$ | negative keys（其它无关样本） |
| $\text{sim}$ | 相似度（如点积或 cosine） |
| $\tau$ | 温度系数 |

**直觉**：分母是"所有 key 的相似度求和"，分子只有"对的那个 key"——长得像**多分类 CE**，"对的 key" = 正确类别。

**用在哪**：
- ✅ CLIP 训练
- ✅ Sentence Embedding
- ✅ RAG 检索器
- ⚠️ **可看成 CE 的特殊形式**（"哪一个是匹配的"是分类问题）

---

## 🪪 4.4.8 Pairwise Ranking Loss（RM 用的）

用于"**让 A 排名比 B 高**"。

**Bradley-Terry**（RLHF 的 RM 训练用的）：

$$\mathcal{L}_{\text{BT}}(\theta) = -\log \sigma(r_\theta(x, y_w) - r_\theta(x, y_l))$$

| 符号 | 含义 |
|---|---|
| $x$ | prompt |
| $y_w$ | chosen（好答案） |
| $y_l$ | rejected（差答案） |
| $r_\theta(\cdot, \cdot)$ | reward model 输出的标量分数 |
| $\sigma$ | sigmoid |

**直觉**：让 reward model **给好答案的分数 > 差答案的分数**（差距越大越好）。
**形式**：长得像 **BCE 的变形**（"正例 = chosen 比 rejected 好"）。

→ 详见 [agentic-rl §2.1](../../agentic-rl-knowledge-base/02-%E7%AC%AC2%E7%AB%A0-%E4%BB%8ERLHF%E5%88%B0Agentic-RL/01-RLHF%E4%B8%89%E9%98%B6%E6%AE%B5%EF%BC%88SFT-RM-PPO%EF%BC%89.md)。

## 🪪 4.4.9 KL Divergence（不是 loss 但和 loss 紧密相关）

$$\text{KL}(P \| Q) = \sum_x P(x) \log \frac{P(x)}{Q(x)}$$

**严格说不是"损失函数"**（衡量分布差异），但常**当作 loss 项**用：

- ✅ **RLHF KL penalty**：$L = L_{PPO} - \beta \cdot \text{KL}(\pi_\theta \| \pi_{ref})$
- ✅ **变分自编码器（VAE）**
- ✅ **知识蒸馏**：让 student 的分布接近 teacher

→ 详见 [§2.3](../02-%E7%AC%AC2%E7%AB%A0-%E6%95%B0%E5%AD%A6%E6%9C%80%E5%B0%8F%E5%BF%85%E8%A6%81%E5%9F%BA%E7%A1%80/03-%E6%A6%82%E7%8E%875%E4%BB%B6%E5%A5%97-%E5%88%86%E5%B8%83%E6%9C%9F%E6%9C%9BKL.md)。

**和 CE 关系**：

$$\text{CE}(P, Q) = -\sum_x P(x) \log Q(x) = H(P) + \text{KL}(P \| Q)$$

→ **当 $P$ 固定（如 one-hot 真实标签）时，最小化 CE = 最小化 KL**。
→ 这就是为什么 CE 是"分类标配 loss"。

## 📊 4.4.10 损失函数全家速查表

| 任务 | Loss | 公式 | PyTorch |
|---|---|---|---|
| 回归 | MSE | $(\hat{y}-y)^2$ | `F.mse_loss` |
| 回归（防 outlier） | MAE | $\lvert \hat{y}-y \rvert$ | `F.l1_loss` |
| 二分类 | BCE | $-y\log\hat{y} - (1-y)\log(1-\hat{y})$ | `F.binary_cross_entropy` |
| 多分类 | CE | $-\log \hat{p}_y$ | `F.cross_entropy` |
| 多分类（输入是 log-prob） | NLL | $-\log \hat{p}_y$ | `F.nll_loss` |
| 对比学习 | InfoNCE | 见 §4.4.7 | 自己实现 |
| RM 训练 | Pairwise BT | $-\log \sigma(r_w - r_l)$ | 自己实现 |
| 分布匹配 | KL | $\sum P \log(P/Q)$ | `F.kl_div` |

## ⚠️ 4.4.11 常见误解

| 误解 | 真相 |
|---|---|
| "loss 越小越好" | 训练集 loss 越小可能**过拟合**——看**验证集** loss |
| "loss = 准确率" | 完全不同。loss 可微，准确率不可微 |
| "CE 和 NLL 是两个 loss" | 数学相同，输入格式不同（logits vs log-prob） |
| "PyTorch 的 `CrossEntropyLoss` 接受概率" | **不！** 接受 logits（**未归一化**）。它内部做 softmax |
| "BCE 只能用二分类" | 也可用于**多标签**（每个标签独立 BCE） |
| "DPO loss 是新东西" | **就是 BCE 的变形**（chosen 和 rejected 的隐式 reward 差当 logit） |

## 📌 4.4 节要点

| 任务 | 用什么 Loss |
|---|---|
| 回归 | MSE |
| 二分类 | BCE |
| **多分类（含 LLM next-token）** | **CrossEntropy** |
| 对比学习（embedding） | InfoNCE |
| RM 训练 | Pairwise Bradley-Terry |
| 分布对齐（KL penalty / 蒸馏） | KL Divergence |

**最重要的一条**：
> **LLM 训练 99% 的 loss 都是 CrossEntropy 的变形**（next-token CE / SFT CE / RM BT-as-BCE / DPO sigmoid-CE）。
> 你懂了 CE，就懂了一大半。
