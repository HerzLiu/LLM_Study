# 4.7 学习率调度

⬅ [06-优化器进化-SGD到AdamW](06-%E4%BC%98%E5%8C%96%E5%99%A8%E8%BF%9B%E5%8C%96-SGD%E5%88%B0AdamW.md) | ➡ [08-初始化-归一化-Dropout](08-%E5%88%9D%E5%A7%8B%E5%8C%96-%E5%BD%92%E4%B8%80%E5%8C%96-Dropout.md)

---

## 🎬 故事比喻：下山的速度策略

```
你在山顶（高 loss），目标山谷（低 loss）：

  - 刚开始: 不熟地形，先慢慢走（warmup，避免一脚踩空）
  - 中间:   熟悉了，迈大步飞奔（高 lr）
  - 接近底: 怕越过最低点，开始小步走（decay）

固定 lr = 全程同一速度（要么太慢要么后期来回横跳）
学习率调度 = 全程速度自适应
```

> 这一节解释 Happy-LLM SFT 训练里 `lr_scheduler.cosine_with_warmup(...)` 在干什么，以及为什么 LLM 训练**必须**用调度器。

---

## ❓ 4.7.1 为什么需要 lr 调度？

回忆 [§4.5](05-%E6%A2%AF%E5%BA%A6%E4%B8%8B%E9%99%8D-%E5%8F%8D%E5%90%91%E4%BC%A0%E6%92%AD%E5%AE%8C%E6%95%B4%E6%8E%A8%E5%AF%BC.md) 数值例子：

- $\eta$ 太大 → 发散
- $\eta$ 太小 → 收敛慢

**但**：**最优 $\eta$ 在训练不同阶段是不同的**！

| 阶段 | 最优 lr |
|---|---|
| 初期（参数随机） | **小** → 防止初始大梯度乱搞 |
| 中期（loss 在快速下降） | **大** → 飞速进展 |
| 后期（接近最优） | **小** → 精细调整 |

→ **固定 lr 是 suboptimal**。**调度器** = 动态调整 lr 的策略。

---

## 🌅 4.7.2 Warmup：开头慢慢来

**问题**：训练刚开始时，参数随机、梯度可能很大、梯度统计量（Adam 的 m, v）也没建立好。
**直接用大 lr** → 容易把模型推到很差的初始位置，甚至 NaN。

**Warmup**：前 N 步 lr 从 0 线性涨到 base_lr。

$$\eta_t = \eta_{\text{base}} \cdot \min\left(1, \frac{t}{T_{\text{warmup}}}\right)$$

**典型值**：$T_{\text{warmup}}$ = 总训练步数的 1-10%。

**图示**：

```
lr
 │       _______________________
 │      /
 │     /
 │    /
 │   /
 │  /
 │ /
 │/_______________________________→ step
 0   warmup        后期
```

**为什么对 LLM 特别重要？**

- LLM 参数量大、初始随机
- 没 warmup 经常**前 100 步就发散**
- LayerNorm/Attention 的统计量需要时间稳定

→ **基本所有 LLM 训练都必有 warmup**。

---

## 📉 4.7.3 衰减策略（Decay Schedules）

Warmup 之后，lr 应该**逐渐降低**。常见 4 种：

### 1. Step Decay（阶梯式）

每 N 个 epoch 把 lr 砍半：

$$\eta_t = \eta_{\text{base}} \cdot 0.5^{\lfloor t / T_{\text{step}} \rfloor}$$

**图示**：

```
lr
 │██████
 │      ███
 │         ██
 │           █
 │            █
 │             █
 └──────────────→ step
```

**用在哪**：传统 CV（ResNet 训 ImageNet 经典做法）。

### 2. Exponential Decay（指数衰减）

$$\eta_t = \eta_{\text{base}} \cdot \gamma^t, \quad \gamma < 1$$

**图示**：光滑下降，但末期接近 0 太快。

### 3. **Cosine Decay**（余弦衰减）⭐ LLM 标配

$$\eta_t = \eta_{\min} + \frac{1}{2}(\eta_{\text{base}} - \eta_{\min}) \left(1 + \cos\left(\pi \cdot \frac{t - T_{\text{warmup}}}{T_{\text{total}} - T_{\text{warmup}}}\right)\right)$$

**图示**：

```
lr
 │      _____
 │     /     \____
 │    /          \____
 │   /                \___
 │  /                     \__
 │ /                         \_
 │/                            \____→ step
 0  warmup        cosine 衰减   end
```

**特点**：
- 衰减**前快后慢**（最后期保留一些 lr）
- 平滑、无突变
- 实验上比 step / exp 好

**用在哪**：**几乎所有 LLM 训练**（GPT/LLaMA/Qwen）。

### 4. Linear Decay（线性衰减）

$$\eta_t = \eta_{\text{base}} \cdot \left(1 - \frac{t - T_{\text{warmup}}}{T_{\text{total}} - T_{\text{warmup}}}\right)$$

简单直接，BERT 原始训练用的。

---

## ⭐ 4.7.4 现代 LLM 标准方案：Warmup + Cosine

```
lr
 │         _____
 │        /     \____
 │       /          \____
 │      /                \____
 │     /                      \___
 │    /                          \__
 │   /                              \____→ step
 │  /
 │ /  ← Warmup（线性涨）
 │/
 0   warmup       cosine decay     end
   (1-10% steps)
```

**完整公式**：

$$\eta_t = \begin{cases}
\eta_{\text{base}} \cdot \dfrac{t}{T_{\text{warmup}}} & t \le T_{\text{warmup}} \\
\eta_{\min} + \dfrac{1}{2}(\eta_{\text{base}} - \eta_{\min}) \left(1 + \cos\left(\pi \cdot \dfrac{t - T_{\text{warmup}}}{T_{\text{total}} - T_{\text{warmup}}}\right)\right) & t > T_{\text{warmup}}
\end{cases}$$

**典型超参**：

| 参数 | 典型值 |
|---|---|
| $\eta_{\text{base}}$ | SFT: 5e-5 / Pretrain: 1e-4 ~ 3e-4 |
| $\eta_{\min}$ | $\eta_{\text{base}}$ 的 10%（如 5e-6） |
| $T_{\text{warmup}}$ | 总步数的 1-3% |
| $T_{\text{total}}$ | 总训练步数 |

## 💻 4.7.5 PyTorch 代码（概念示意，未严格验证）

### 方法 1：原生 PyTorch

```python
from torch.optim.lr_scheduler import CosineAnnealingLR, LambdaLR

optimizer = torch.optim.AdamW(model.parameters(), lr=5e-5)
total_steps = 10000
warmup_steps = 200

def lr_lambda(step):
    if step < warmup_steps:
        return step / warmup_steps                    # 线性涨
    else:
        progress = (step - warmup_steps) / (total_steps - warmup_steps)
        return 0.5 * (1 + math.cos(math.pi * progress))  # cosine

scheduler = LambdaLR(optimizer, lr_lambda)

# 训练循环
for step in range(total_steps):
    train_one_step()
    optimizer.step()
    scheduler.step()        # ← 每步更新 lr
    optimizer.zero_grad()
```

### 方法 2：Hugging Face 一键

```python
from transformers import get_cosine_schedule_with_warmup

scheduler = get_cosine_schedule_with_warmup(
    optimizer,
    num_warmup_steps=200,
    num_training_steps=10000,
)
```

→ 这就是 Happy-LLM 训练代码用的。

## 📊 4.7.6 lr 选择经验值

| 场景 | base_lr | 备注 |
|---|---|---|
| ResNet (CNN) + SGD | 0.1 | 经典 |
| BERT pretrain + AdamW | 1e-4 | 原始论文 |
| GPT-3 pretrain + AdamW | 6e-4 | 大模型 lr 可大一些 |
| **LLM SFT + AdamW** | **5e-5 ~ 1e-4** | Happy-LLM 用 5e-5 |
| LLM LoRA + AdamW | 1e-4 ~ 5e-4 | LoRA 参数少，lr 可大 |
| LLM RLHF (PPO) + AdamW | 1e-6 ~ 1e-5 | **比 SFT 小 10 倍**（怕崩） |
| **LLM GRPO + AdamW** | **1e-6 ~ 5e-6** | 同 PPO |

→ RL 阶段 lr 要小很多——因为模型已经训得比较好，怕"一脚踩空"破坏已学好的能力。

---

## 🎯 4.7.7 别的策略（速览）

### Cyclical LR / OneCycle（Smith 2017）

让 lr 在低-高之间"震荡"，反直觉但实践效果好。

```
lr
 │      ___
 │     /   \
 │    /     \
 │   /       \____
 │  /             \___
 └────────────────────→ step
```

### ReduceLROnPlateau（按验证指标降）

如果验证 loss 多步不降 → 自动砍 lr。

### Adafactor schedule

Adafactor 优化器自带 lr 调度（不需要外部 warmup）。

---

## ⚠️ 4.7.8 常见误解

| 误解 | 真相 |
|---|---|
| "lr 调度是可选的" | LLM 训练**必选**——固定 lr 几乎一定崩或不收敛 |
| "warmup 步数越长越好" | 太长浪费训练；典型 1-10% |
| "cosine 衰减比 linear 一定好" | 实践上 cosine 略好但差距不大 |
| "scheduler.step() 在 optimizer.step() 之前调" | **错！** 顺序：`optimizer.step()` → `scheduler.step()` |
| "调度器改的是 optimizer.lr 这个变量" | 是。`scheduler.step()` 内部更新 `optimizer.param_groups[0]['lr']` |
| "训练完后 lr 应该是 0" | 通常衰到 base_lr 的 1-10%，不到 0 |

---

## 📌 4.7 节要点

| 阶段 | lr 策略 |
|---|---|
| 训练开始 (前 1-10%) | **Warmup**：线性从 0 涨到 base_lr |
| 中后期 | **Cosine** 衰减到 base_lr 的 10% |
| LLM 训练 | 几乎都用 **Warmup + Cosine** |
| RL 阶段（PPO/GRPO） | lr 比 SFT **小 10 倍** |

**最重要的一条**：
> **lr 是 DL 最重要的超参数**。比起换优化器，**调好 lr 调度** 更能改善训练效果。
