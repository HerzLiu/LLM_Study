# 1.1 AI / ML / DL 是什么关系

⬅ [00-章节总览](00-%E7%AB%A0%E8%8A%82%E6%80%BB%E8%A7%88.md) | ➡ [02-监督-无监督-强化学习三大范式](02-%E7%9B%91%E7%9D%A3-%E6%97%A0%E7%9B%91%E7%9D%A3-%E5%BC%BA%E5%8C%96%E5%AD%A6%E4%B9%A0%E4%B8%89%E5%A4%A7%E8%8C%83%E5%BC%8F.md)

## 🎬 故事比喻：套娃关系

```
你之前学的概念散落各地：

  AI / 人工智能          ← 最大的盒子，泛指"让机器有智能"
  ML / 机器学习          ← AI 里的一种方法："从数据中学"
  DL / 深度学习          ← ML 里的一种方法："用深层神经网络学"
  NLP / 自然语言处理     ← AI 的一个应用领域
  CV / 计算机视觉        ← AI 的另一个应用领域
  LLM / 大语言模型       ← DL × NLP 的现代产物
  Agent / 智能体         ← AI 的高阶形态：会决策行动
  RL / 强化学习          ← ML 的一个范式：从交互学习

关系：套娃 + 交叉
```

> 这一节给你一张**关系图**，让"漂浮的术语"全部落位。

## 📐 1.1.2 每层各自的定义

### AI（Artificial Intelligence）

> 让机器表现出**人类智能**的行为：感知、推理、决策、学习、行动。

**包括**：
- 早期 AI：**符号主义**（规则、专家系统）—— Hello-Agents §2.1-§2.2 讲过
- 现代 AI：**联结主义**（神经网络）—— Hello-Agents §2.4
- AI Agent：**会规划、调工具、行动**的系统 —— Hello-Agents 全书

→ **AI 是个大伞**，啥都装。

### ML（Machine Learning）

> 不显式编程，让机器**从数据中学**模式。

**核心思想**：
```
传统编程:    规则 + 输入 → 输出
机器学习:    输入 + 输出 → 规则（自动学）
```

**包括**：
- 监督学习、无监督学习、强化学习（§1.2 详）
- 传统 ML：决策树、SVM、贝叶斯
- 深度学习（DL）：神经网络

### DL（Deep Learning）

> **用层数多的神经网络（"深"）做 ML 的方法**。

**"Deep" = 多少层？**
- 早期定义：≥ 3 层隐藏层
- 现在：LLM 动辄几十到几百层

**为什么 DL 这 10 年爆发？**
1. 大数据（互联网海量数据）
2. 算力（GPU）
3. 算法改进（ReLU、Adam、Transformer）

→ 详见 §3.5 传统 ML 到 DL 的转折。

## 🔀 1.1.3 横向：领域 vs 方法

**领域**（task domain）：

| 领域                 | 任务             |
| ------------------ | -------------- |
| NLP（自然语言处理）        | 翻译、问答、对话、文本生成  |
| CV（计算机视觉）          | 图像分类、目标检测、人脸识别 |
| Speech（语音）         | 语音识别、TTS       |
| Recommendation（推荐） | 推送商品/视频        |
| Robotics（机器人）      | 控制、规划、导航       |

**方法**（method）：

| 方法 | 用在哪些领域 |
|---|---|
| 监督学习 | NLP、CV、Speech、Rec |
| 无监督学习 | 聚类、降维、anomaly |
| **强化学习** | Robotics、游戏 AI、RLHF |
| **深度学习** | 现在几乎全部 |

→ **领域和方法正交**：CV 可以用 DL 也可以用传统 ML；DL 可以用监督也可以用 RL。

## ⚠️ 1.1.6 常见误解

| 误解 | 真相 |
|---|---|
| "AI = LLM" | LLM 只是 AI 现在最火的部分，AI ⊋ ML ⊋ DL ⊋ LLM |
| "ML 就是 DL" | DL 是 ML 的子集，传统 ML 还有决策树/SVM 等 |
| "Agent 是新 AI" | Agent 是 AI 的**形态**，不是方法。可以用 ML / DL / 规则等做 Agent |
| "深度学习一定要很深" | "深"是相对的；本质是"多层神经网络" |
| "DL 必然比传统 ML 强" | **不一定**！表格数据上 XGBoost 常比 DNN 强 |
| "RL 不属于 ML" | **属于**！RL 是 ML 的三大范式之一（§1.2） |
| "LLM 是 Agent" | LLM 是模型，Agent 是系统形态。LLM + 工具 + 循环 = Agent |

## 📌 1.1 节要点

| 概念 | 一句话 |
|---|---|
| **AI** | 让机器有智能（最大的盒子） |
| **ML** | 从数据中学（AI 的方法之一） |
| **DL** | 用多层神经网络（ML 的方法之一） |
| **NLP/CV/...** | AI 应用领域 |
| **LLM** | DL 在 NLP 上的现代产物 |
| **Agent** | AI 的形态（不一定用 ML） |
| **RL** | ML 的范式之一（不是 DL 的对立） |

**最重要的一句**：
> **DL ⊂ ML ⊂ AI**，**RL ⊂ ML**，**LLM ⊂ DL ⊂ ML**，**Agent 是形态不是方法**。
