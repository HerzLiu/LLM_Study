## 🎬 一句话故事：给你一个坐标系

你之前学了 Happy-LLM、Hello-Agents、agentic-rl，但脑子里这些概念是**漂浮**的：

> "RLHF 是 LLM 训练阶段，那它和监督学习什么关系？"
> "loss 一直在跑，那它和'模型评估'是一回事吗？"
> "过拟合是什么？我做 SFT 时也算过拟合吗？"
> "reward hacking 和过拟合是不是一回事？"

本章给你一个**坐标系**，让你以后看任何 AI 概念都能"放对位置"。
本章**不讲技术细节**，只讲**关系和定位**。30 分钟读完。

---

## 🎯 本章学完你将拥有

- [ ] 能说清楚 AI / ML / DL / NLP / RL / LLM / Agent 的关系（一张图）
- [ ] 能区分**监督学习 / 无监督学习 / 强化学习**三大范式
- [ ] 知道为什么要**分训练集 / 验证集 / 测试集**
- [ ] 能解释**过拟合 / 欠拟合 / 正则化**（并和 reward hacking 区分）
- [ ] 能列出**评估指标全家桶**：准确率/召回/F1/AUC/pass@k
