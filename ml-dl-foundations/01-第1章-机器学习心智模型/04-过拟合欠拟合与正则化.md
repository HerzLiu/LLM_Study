# 1.4 过拟合 / 欠拟合 / 正则化

⬅ [03-训练验证测试集](03-%E8%AE%AD%E7%BB%83%E9%AA%8C%E8%AF%81%E6%B5%8B%E8%AF%95%E9%9B%86.md) | ➡ [05-评估指标全家桶](05-%E8%AF%84%E4%BC%B0%E6%8C%87%E6%A0%87%E5%85%A8%E5%AE%B6%E6%A1%B6.md)

---

## 🎬 故事比喻：3 个学生

```
学生 A（欠拟合, Underfitting）:
  - 背了 10 道题，但每道都没真懂
  - 训练题做对 60%, 考试 50%
  - 模型太简单 / 训练不够 → 啥都没学到

学生 B（刚好, Just Right）:
  - 背了 1000 道题，理解了原理
  - 训练 95%, 考试 92%
  - 模型容量合适 + 正则化得当

学生 C（过拟合, Overfitting）:
  - 背了 1000 道题，每道死记答案
  - 训练 100%, 考试 60%
  - 模型太复杂 / 训练过头 → 记答案不懂原理
```

> 这一节告诉你如何**诊断**过拟合，以及**用什么手段防**。
> 也是为什么 [reward hacking](../../agentic-rl-knowledge-base/04-%E7%AC%AC4%E7%AB%A0-Code-Agentic-RL%E4%B8%93%E9%A2%98/08-Reward-Hacking%E4%B8%8ESandbox%E5%AE%89%E5%85%A8.md) 在 RL 里这么常见——它本质是 RL 版的过拟合。

---

## 📐 1.4.1 三种状态的诊断

观察 **train loss** vs **val loss**：

| 状态 | train loss | val loss | 间隙 | 诊断 |
|---|---|---|---|---|
| **欠拟合** | 高 | 高 | 小 | 模型学不动 |
| **刚好** | 低 | 低 | 小 | ✅ |
| **过拟合** | 极低 | 高 | **大** | 模型死记 |

### 训练曲线对照

```
loss
 │
 │\                       ← train loss
 │ \                      ── val loss
 │  \________________
 │   \___
 │       \___          欠拟合: 两条都高，且都不再降
 │           \________
 └──────────────────────→ step (epoch)


loss
 │\
 │ \
 │  \___                  ← train
 │      \___      _ _ _   ← val
 │          \___/         过拟合:
 │              ↘         train 一直降，val 在某点开始反弹
 │                ↘
 └──────────────────────→ step


loss
 │\
 │ \
 │  \                     ← train
 │   \____ _ _ _ _ _ _   ← val
 │       \_____           刚好: 两条都降到低位且接近
 │           \____
 └──────────────────────→ step
```

## 🤔 1.4.2 为什么会过拟合？

**根本原因**：**模型容量 >> 数据信息**。

模型有"参数自由度"去**记住**每个训练样本，而不是**学习**通用规律。

**类比**：用 100 个变量解 10 个方程——解有无穷多个，模型选了**任意一个**能完美拟合训练数据的，但这个解对新数据无意义。

### 容易过拟合的场景

1. **小数据 + 大模型**：参数比数据多
2. **训练 epoch 太多**：模型反复刷训练集死记
3. **没有正则化**：模型自由度过大
4. **特征过多**（含噪声）：模型学到噪声而不是信号
5. **数据有噪声/错误标签**：模型死记错误

### 容易欠拟合的场景

1. **模型太小**：容量不够（如用线性回归学非线性数据）
2. **训练太短**：还没收敛
3. **学习率太小**：进展太慢
4. **正则化太强**：参数被压死

---

## 🛡 1.4.3 防过拟合"七种武器"

### 1. 加数据（最有效）

```
数据 ×10 → 过拟合显著减轻
```

实在没数据 → **数据增强**：

| 领域  | 增强方法                       |
| --- | -------------------------- |
| CV  | 旋转/裁剪/翻转/MixUp             |
| NLP | 同义词替换/back-translation/MLM |
| 语音  | 加噪/变速/SpecAugment          |

LLM 几乎不用数据增强（数据本身海量）。

### 2. 减模型容量

- 减层数 / 减神经元数
- 用更简单的架构
- 适用：你确定**数据少**的情况

### 3. Weight Decay（L2 正则化）

在 loss 上加参数大小的惩罚：

$$\mathcal{L}_{\text{total}} = \mathcal{L} + \lambda \sum_i \theta_i^2$$

→ AdamW 的 `weight_decay` 参数（[§4.6.6](../04-%E7%AC%AC4%E7%AB%A0-%E7%A5%9E%E7%BB%8F%E7%BD%91%E7%BB%9C%E4%B8%8E%E6%B7%B1%E5%BA%A6%E5%AD%A6%E4%B9%A0%E6%A0%B8%E5%BF%83/06-%E4%BC%98%E5%8C%96%E5%99%A8%E8%BF%9B%E5%8C%96-SGD%E5%88%B0AdamW.md)）。

### 4. Dropout

训练时随机丢神经元（[§4.8.3](../04-%E7%AC%AC4%E7%AB%A0-%E7%A5%9E%E7%BB%8F%E7%BD%91%E7%BB%9C%E4%B8%8E%E6%B7%B1%E5%BA%A6%E5%AD%A6%E4%B9%A0%E6%A0%B8%E5%BF%83/08-%E5%88%9D%E5%A7%8B%E5%8C%96-%E5%BD%92%E4%B8%80%E5%8C%96-Dropout.md)）。

### 5. Early Stopping

```
监控 val loss
↓
连续 N 个 epoch 不降 → 停训
↓
保存"val loss 最低"那个 checkpoint
```

简单暴力但极有效。

### 6. Batch Normalization / Layer Normalization

副作用是**轻度正则化**（[§4.8.2](../04-%E7%AC%AC4%E7%AB%A0-%E7%A5%9E%E7%BB%8F%E7%BD%91%E7%BB%9C%E4%B8%8E%E6%B7%B1%E5%BA%A6%E5%AD%A6%E4%B9%A0%E6%A0%B8%E5%BF%83/08-%E5%88%9D%E5%A7%8B%E5%8C%96-%E5%BD%92%E4%B8%80%E5%8C%96-Dropout.md)）。

### 7. 集成（Ensemble）

训多个模型，预测时投票。
代价：N 倍训练+推理成本。

## 🐌 1.4.4 防欠拟合"四种武器"

| 武器 | 做法 |
|---|---|
| 加模型容量 | 加层、加 hidden_dim |
| 训更久 | 加 epoch（但小心过拟合） |
| 加大学习率 | lr 太小时收敛慢 |
| 减少正则化 | weight_decay / dropout 调小 |

---

## 🆚 1.4.5 偏差-方差权衡（Bias-Variance Tradeoff）

**经典 ML 理论**：

$$\text{Error} = \text{Bias}^2 + \text{Variance} + \text{Noise}$$

| | 高偏差 (Bias) | 高方差 (Variance) |
|---|---|---|
| 含义 | 模型预测**系统性偏离**真实 | 模型预测**随训练数据剧烈变化** |
| 现象 | **欠拟合** | **过拟合** |
| 应对 | 加容量 | 加数据 / 加正则化 |

**图示**（飞镖靶）：

```
高 bias / 低 variance:        低 bias / 低 variance:
  ●●●                              ●●
  ●●●                              ●●●
                                   ●

(全偏一边, 但稳定)            (聚集在靶心)
                                   ↑ 理想

高 bias / 高 variance:        低 bias / 高 variance:
  ●                                  ●
       ●                        ●     ●
   ●                                       ●
                                     ●
(到处乱+偏)                   (围绕靶心散得很开)
```

---

## 🎯 1.4.6 现代 DL 时代的反常识：**"双下降"现象**

**经典理论**：模型容量增加 → 先**好**（解决欠拟合）→ 然后**变差**（过拟合）。

**现代 DL 发现（2019+）**：模型再继续增大 → **反而变好**！

```
test error
 │
 │  传统理论        现代 DL 发现
 │  ──────────     ─────────────
 │       /\                     ___
 │      /  \                  /
 │     /    \________  ▲     /
 │    /              ↘ │    /
 │   /                ↘│___/
 │  /                  ↑
 │ /             过参数化区域反而好
 └───────────────────────────→ 模型容量
```

→ 这就是为什么 LLM **越大越强**（GPT-3 175B 比 GPT-2 1.5B 好得多）。
→ 现代理论尚未完全解释清楚（**需进一步确认理论细节**）。

## 🪤 1.4.7 reward hacking = RL 版过拟合

[agentic-rl §4.8](../../agentic-rl-knowledge-base/04-%E7%AC%AC4%E7%AB%A0-Code-Agentic-RL%E4%B8%93%E9%A2%98/08-Reward-Hacking%E4%B8%8ESandbox%E5%AE%89%E5%85%A8.md) 的 reward hacking 本质上是**对 reward 函数的过拟合**：

| 监督学习过拟合 | RL reward hacking |
|---|---|
| 模型 overfit 到训练数据 | 模型 overfit 到 reward 函数 |
| 训练 acc 99%、test 50% | 训练 reward 0.95、实际任务效果 0.2 |
| 解：加数据/正则化 | 解：多 reward 联合/hidden tests/抽查 |

**两者数学上同源**：都是 **Goodhart's Law 的具体表现**（一旦把度量当作目标，度量就失效）。

→ 详见 [reward hacking 形式化](../../agentic-rl-knowledge-base/04-%E7%AC%AC4%E7%AB%A0-Code-Agentic-RL%E4%B8%93%E9%A2%98/08-Reward-Hacking%E4%B8%8ESandbox%E5%AE%89%E5%85%A8.md#reward-hacking-%E7%9A%84%E5%BD%A2%E5%BC%8F%E5%8C%96%E5%AE%9A%E4%B9%89)。

## ⚠️ 1.4.8 常见误解

| 误解 | 真相 |
|---|---|
| "train loss 越低越好" | 单看 train 是错——**必须看 val**！ |
| "过拟合 = 模型太大" | 不一定。**模型大 + 数据少 + 无正则化**才过拟合 |
| "Dropout 一定防过拟合" | 太大反而欠拟合；LLM 大数据训练几乎不用 |
| "validation loss 反弹 → 立刻停" | 可能只是噪声波动，看 N 个 epoch 的趋势 |
| "LLM 训出 99% 准确率必有问题" | 看任务。简单任务确实能 99%；复杂任务 99% 几乎一定有泄漏 |
| "防过拟合 = 限制模型能力" | 也可以**加数据**——这是更优雅的解 |

---

## 📌 1.4 节要点

| 状态 | 表现 | 应对 |
|---|---|---|
| **欠拟合** | train/val 都高 | 加容量、训更久、减正则化 |
| **过拟合** | train 低 val 高 | 加数据、加正则化、early stop |
| **刚好** | train 和 val 都低且接近 | ✅ |

**最重要的诊断动作**：**画 train/val loss 曲线**。

**最常用的防过拟合武器**（按效果排序）：
1. **加数据**（最有效）
2. **Weight Decay**（AdamW 自带）
3. **Early Stopping**
4. Dropout
5. 减小模型
