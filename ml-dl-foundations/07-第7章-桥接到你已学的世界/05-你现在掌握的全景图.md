## 💡 7.5.5 给未来的你的话

你 6 周前的"心智模型"是这样的：

```
LLM = 一个魔盒, 调 API 就行
训练 = 跑代码, loss 下降就好
RLHF = 黑魔法, 看不懂公式
Agent = LLM 加一些 prompt 技巧
```

你现在的心智模型应该是：

```
LLM = Transformer × N，每个 block = MLP + Attention + Norm + 残差
训练 = 5 步循环（zero_grad → forward → loss → backward → step）
       loss 来自 MLE 假设（CE/BCE/MSE 是同一族的化身）
       优化器是 AdamW（动量 + 自适应 lr + weight decay）
RLHF = 用 reward 代替 label 的反向传播
       PPO clip 防止 π 跑太远，KL 防止偏离 SFT
GRPO = PPO 省 critic 版（用组内统计）
RLVR = 用 verifier 代替 RM
Agent = LLM + tool + planning + memory
Agentic RL = 训练 Agent 的方法（RL + verifier reward + trajectory）
```

→ **从"调 API"到"懂内部"**，这就是这 6 周做的事。
