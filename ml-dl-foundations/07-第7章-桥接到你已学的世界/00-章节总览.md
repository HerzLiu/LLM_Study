## 🎬 一句话故事：让"补完"真正闭环

```
前 6 章把 ML/DL 基础补给你。
但你最关心的不是"我会做 MNIST 了"，
而是：

  "这些基础到底怎么 → LLM / Agent / RL 的？"

这章就把"补完"和"已学"对上号。

读完这章你应该说：
  "原来 Transformer 的 FFN 就是 MLP！"
  "原来 next-token loss 就是 softmax + CE！"
  "原来 PPO 就是 PG + clip + KL！"
  "原来 GRPO 的 advantage 就是 baseline 减出来的！"
  "原来 reward hacking 就是 ML 里的 Goodhart 法则！"
```

> **优先级 ⭐⭐⭐⭐⭐**。
> 这章是本书的**收官**——前 6 章不读这章相当于"学了没串起来"。

- [ ] 能从 MLP 出发，画图推导到 Transformer 的 FFN/Attention
- [ ] 能从 CE loss 推导到 next-token loss + SFT loss + RM loss
- [ ] 能从 SGD 推导到 PPO / GRPO 的更新公式
- [ ] 能从损失函数概念串起 RM / DPO / RLVR / PRM 的全部 loss
- [ ] 拥有一张"**ML→DL→Transformer→LLM→Agent→RL 全景图**"
