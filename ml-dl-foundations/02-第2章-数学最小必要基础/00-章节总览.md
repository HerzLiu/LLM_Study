## 🎬 一句话故事：你不是要重学高数

你已经在 Happy-LLM 看到过：

```
Attention(Q, K, V) = softmax(QK^T / √d_k) V        ← 矩阵乘
KL(P || Q) = Σ P(x) log P(x)/Q(x)                  ← 概率 + log
∇_θ J = E[∇ log π_θ(a|s) · A(s,a)]                 ← 梯度
```

你大学学过线代、微积分、概论，但都"还给老师了"。

> **本章不让你重学**。
> 只补"**看 LLM/RL 论文时必须认得的那 12 件东西**"。
> 每个概念配可视化 + 数值例子 + 在 LLM 哪里用过。

---

## 🎯 本章学完你将拥有

- [ ] 看到 $W \in \mathbb{R}^{d \times d}$ 知道是 d×d 矩阵
- [ ] 知道 $\mathbf{q} \cdot \mathbf{k}$（内积）算的是什么、几何上代表什么
- [ ] 知道 $\nabla_\theta L$ 是什么形状、为什么沿反方向走能下降
- [ ] 看到 $\text{KL}(P \| Q)$ 知道含义、为什么是非对称的
- [ ] 看到 softmax 知道在做什么、为什么概率会"塌缩"
- [ ] 知道为什么 cross-entropy loss 长成 $-\sum y \log \hat{y}$
