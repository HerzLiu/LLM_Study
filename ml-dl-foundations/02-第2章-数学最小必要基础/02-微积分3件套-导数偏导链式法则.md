# 2.2 微积分 3 件套：导数 / 偏导 / 链式法则

⬅ [01-线性代数4件套-向量矩阵](01-%E7%BA%BF%E6%80%A7%E4%BB%A3%E6%95%B04%E4%BB%B6%E5%A5%97-%E5%90%91%E9%87%8F%E7%9F%A9%E9%98%B5.md) | ➡ [03-概率5件套-分布期望KL](03-%E6%A6%82%E7%8E%875%E4%BB%B6%E5%A5%97-%E5%88%86%E5%B8%83%E6%9C%9F%E6%9C%9BKL.md)

## 🎬 故事比喻：地形图上找下坡

```
你在山上想下山:

  导数 = "我面前 1m 内，海拔变化多少？"
         f'(x) = lim_{h→0} (f(x+h) - f(x))/h

  偏导 = "向北走 1m，海拔变化多少？"（只看一个方向）
         ∂f/∂x = 固定其它变量，对 x 求导

  梯度 = "所有方向中，最陡上坡是哪个方向？"
         ∇f = (∂f/∂x, ∂f/∂y, ...)

  链式法则 = "海拔依赖你脚下温度，温度依赖你纬度"
            → "海拔对纬度的变化 = 海拔对温度 × 温度对纬度"
```

> 这一节是 [§4.5 反向传播](../04-%E7%AC%AC4%E7%AB%A0-%E7%A5%9E%E7%BB%8F%E7%BD%91%E7%BB%9C%E4%B8%8E%E6%B7%B1%E5%BA%A6%E5%AD%A6%E4%B9%A0%E6%A0%B8%E5%BF%83/05-%E6%A2%AF%E5%BA%A6%E4%B8%8B%E9%99%8D-%E5%8F%8D%E5%90%91%E4%BC%A0%E6%92%AD%E5%AE%8C%E6%95%B4%E6%8E%A8%E5%AF%BC.md) 的数学根。
> 你大学学过，本节只复习"能看懂神经网络公式"的部分。

## 🪪 2.2.1 导数（Derivative）

### 一元函数

$f: \mathbb{R} \to \mathbb{R}$，导数定义：

$$f'(x) = \frac{df}{dx} = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h}$$

**几何**：函数图像在点 $x$ 的**切线斜率**。

**直观**：$f'(x) > 0 \Rightarrow$ 函数在 $x$ 处**上升**；$f'(x) < 0 \Rightarrow$ **下降**。

### 常用导数表（记住能秒认）

| $f(x)$ | $f'(x)$ |
|---|---|
| $c$（常数） | 0 |
| $x$ | 1 |
| $x^n$ | $n x^{n-1}$ |
| $e^x$ | $e^x$ |
| $\ln x$ | $1/x$ |
| $\sin x$ | $\cos x$ |
| $\sigma(x) = 1/(1+e^{-x})$ | $\sigma(x)(1-\sigma(x))$ |
| $\tanh x$ | $1 - \tanh^2 x$ |
| $\text{ReLU}(x) = \max(0, x)$ | $\begin{cases}1 & x>0 \\ 0 & x<0\end{cases}$ |
| $f + g$ | $f' + g'$ |
| $c \cdot f$ | $c \cdot f'$ |
| $f \cdot g$ | $f'g + fg'$（乘积法则） |

## 🪪 2.2.2 偏导（Partial Derivative）

**多元函数** $f: \mathbb{R}^n \to \mathbb{R}$，对其中一个变量求导，**其它当常数**：

$$\frac{\partial f}{\partial x_i}(x_1, \dots, x_n) = \text{固定其它 } x_j \neq x_i \text{, 把 } f \text{ 当一元函数对 } x_i \text{ 求导}$$

### 数值例子

$f(x, y) = x^2 + 3xy + y^3$

$$\frac{\partial f}{\partial x} = 2x + 3y \quad \text{（y 当常数）}$$

$$\frac{\partial f}{\partial y} = 3x + 3y^2 \quad \text{（x 当常数）}$$

### 梯度（Gradient）= 偏导组成的向量

$$\nabla f = \left(\frac{\partial f}{\partial x_1}, \frac{\partial f}{\partial x_2}, \dots, \frac{\partial f}{\partial x_n}\right)$$

**关键性质**：
- $\nabla f$ 指向 **f 上升最快**的方向
- $-\nabla f$ 指向 **f 下降最快**的方向（**梯度下降**用这个）

→ 详见 [§4.5](../04-%E7%AC%AC4%E7%AB%A0-%E7%A5%9E%E7%BB%8F%E7%BD%91%E7%BB%9C%E4%B8%8E%E6%B7%B1%E5%BA%A6%E5%AD%A6%E4%B9%A0%E6%A0%B8%E5%BF%83/05-%E6%A2%AF%E5%BA%A6%E4%B8%8B%E9%99%8D-%E5%8F%8D%E5%90%91%E4%BC%A0%E6%92%AD%E5%AE%8C%E6%95%B4%E6%8E%A8%E5%AF%BC.md)。

### 在神经网络里

参数 $\theta$ 可能有几百亿个：$\theta = (\theta_1, \dots, \theta_N)$。
**loss 对参数的梯度**：

$$\nabla_\theta \mathcal{L} = \left(\frac{\partial \mathcal{L}}{\partial \theta_1}, \dots, \frac{\partial \mathcal{L}}{\partial \theta_N}\right) \in \mathbb{R}^N$$

→ 形状和 $\theta$ 一样。

## 🪪 2.2.3 链式法则（Chain Rule）⭐ 反向传播的根

### 一元链式法则

如果 $z = f(y), y = g(x)$，则：

$$\frac{dz}{dx} = \frac{dz}{dy} \cdot \frac{dy}{dx}$$

### 数值例子

$z = (3x + 1)^2$。设 $y = 3x + 1$，则 $z = y^2$：

$$\frac{dy}{dx} = 3, \quad \frac{dz}{dy} = 2y = 2(3x+1)$$

$$\frac{dz}{dx} = 2(3x+1) \cdot 3 = 6(3x+1)$$

### 多元链式法则（最常用）

$z = f(y_1, y_2, \dots, y_k)$, 每个 $y_i = g_i(x)$，则：

$$\frac{dz}{dx} = \sum_{i=1}^k \frac{\partial z}{\partial y_i} \cdot \frac{dy_i}{dx}$$

**人话**：「$z$ 对 $x$ 的变化 = 沿**每条 $y_i$ 路径**的影响加和」

### 在神经网络里

3 层网络 $z_1 \to a_1 \to z_2 \to \hat{y} \to \mathcal{L}$，对最早的参数 $w_1$ 求梯度：

$$\frac{\partial \mathcal{L}}{\partial w_1} = \frac{\partial \mathcal{L}}{\partial \hat{y}} \cdot \frac{\partial \hat{y}}{\partial z_2} \cdot \frac{\partial z_2}{\partial a_1} \cdot \frac{\partial a_1}{\partial z_1} \cdot \frac{\partial z_1}{\partial w_1}$$

→ **5 节链式连乘**。这就是反向传播的核心。
→ 详细推导见 [§4.5.4](../04-%E7%AC%AC4%E7%AB%A0-%E7%A5%9E%E7%BB%8F%E7%BD%91%E7%BB%9C%E4%B8%8E%E6%B7%B1%E5%BA%A6%E5%AD%A6%E4%B9%A0%E6%A0%B8%E5%BF%83/05-%E6%A2%AF%E5%BA%A6%E4%B8%8B%E9%99%8D-%E5%8F%8D%E5%90%91%E4%BC%A0%E6%92%AD%E5%AE%8C%E6%95%B4%E6%8E%A8%E5%AF%BC.md)。

## 🆘 2.2.4 速查表

看到下面这些符号秒认：

| 符号 | 含义 |
|---|---|
| $f'(x)$ 或 $\frac{df}{dx}$ | 一元导数 |
| $\frac{\partial f}{\partial x}$ | 偏导（多元函数对 x 求） |
| $\nabla f$ 或 $\nabla_x f$ | 梯度（偏导组成的向量） |
| $\nabla_\theta \mathcal{L}$ | loss 对参数 θ 的梯度（DL 最常见） |
| $\frac{d}{dt}, \frac{\partial}{\partial t}$ | "对 t 求导" |
| $f \circ g$ | 函数复合 $f(g(\cdot))$（链式法则的前提） |

## 🧠 2.2.5 高阶概念（看到了能认就够）

### Jacobian 矩阵

向量函数 $\mathbf{f}: \mathbb{R}^n \to \mathbb{R}^m$ 的"梯度推广"：

$$\mathbf{J} = \begin{pmatrix} \frac{\partial f_1}{\partial x_1} & \cdots & \frac{\partial f_1}{\partial x_n} \\ \vdots & & \vdots \\ \frac{\partial f_m}{\partial x_1} & \cdots & \frac{\partial f_m}{\partial x_n} \end{pmatrix} \in \mathbb{R}^{m \times n}$$

→ 神经网络反向传播本质是 Jacobian 连乘。**PyTorch autograd 自动处理**。

### Hessian 矩阵

二阶偏导组成的矩阵，$\mathbf{H} \in \mathbb{R}^{n \times n}$。

**用在哪**：
- ✅ 二阶优化器（Newton's method）
- ⚠️ DL 几乎不用（H 太大，存不下）

→ 这就是为什么 Adam 等"自适应学习率"是**一阶方法的近似二阶**——回避 Hessian。

## ⚠️ 2.2.6 常见误解

| 误解 | 真相 |
|---|---|
| "梯度是数" | **不！** 梯度是和参数同形状的**向量**（或张量） |
| "导数 = 斜率" | 一元情况下对，多元情况下要看**方向** |
| "链式法则反方向相乘" | **是正方向**——从外往内拆，连乘 |
| "求偏导时其它变量是 0" | **不！** 是**常数**（不变化），不是 0 |
| "ReLU 在 0 点不可导，PyTorch 会崩" | PyTorch 默认在 $x = 0$ 处取 $\partial \text{ReLU}/\partial x = 0$（subgradient），不崩 |

---

## 📌 2.2 节要点

| 概念 | 一句话 | 在 DL 中 |
|---|---|---|
| **导数** | 函数变化率 | 一元情况，少 |
| **偏导** | 对一个变量求导，其它当常数 | 处处 |
| **梯度** $\nabla f$ | 所有偏导组成的向量 | 反方向 = 下降最快 |
| **链式法则** | $\frac{dz}{dx} = \frac{dz}{dy} \cdot \frac{dy}{dx}$ | **反向传播** |

**最重要的一句**：
> **梯度下降 + 反向传播 = 偏导 + 链式法则的高效实现**。
> 你已经在用，本节让你**理解为什么能这样用**。
