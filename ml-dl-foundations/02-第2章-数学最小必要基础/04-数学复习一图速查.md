## 🧮 全速查表

### 符号约定

| 符号 | 含义 |
|---|---|
| $x$ | 标量 |
| $\mathbf{x}$ | 向量 |
| $\mathbf{X}$ | 矩阵 |
| $\mathbb{R}^n$ | n 维实数向量空间 |
| $\mathbb{R}^{m \times n}$ | m×n 实数矩阵 |
| $\sim$ | "服从" 分布 |

### 线性代数（§2.1）

| 操作 | 公式 | 形状 | PyTorch |
|---|---|---|---|
| 内积 | $\mathbf{a} \cdot \mathbf{b} = \sum a_i b_i$ | 标量 | `torch.dot(a, b)` 或 `a @ b` |
| 矩阵乘 | $[m,k] \times [k,n] = [m,n]$ | 矩阵 | `A @ B` |
| 转置 | $A^T_{ij} = A_{ji}$ | $[n,m]$ | `A.T` |
| L2 范数 | $\lVert \mathbf{x} \rVert = \sqrt{\sum x_i^2}$ | 标量 | `torch.norm(x)` |
| 余弦相似 | $\frac{\mathbf{a} \cdot \mathbf{b}}{\lVert \mathbf{a} \rVert \, \lVert \mathbf{b} \rVert}$ | 标量 ∈[-1,1] | `F.cosine_similarity` |
| 逐元素乘 | $(\mathbf{a} \odot \mathbf{b})_i = a_i b_i$ | 同形状 | `a * b` |

### 微积分（§2.2）

| 操作 | 公式 | PyTorch |
|---|---|---|
| 一元导数 | $f'(x) = \frac{df}{dx}$ | 自动微分 |
| 偏导 | $\frac{\partial f}{\partial x_i}$ | 自动微分 |
| 梯度 | $\nabla f = (\frac{\partial f}{\partial x_1}, \dots)$ | `tensor.grad` 自动算 |
| 链式 | $\frac{dz}{dx} = \frac{dz}{dy} \frac{dy}{dx}$ | autograd 反向传播 |
| Jacobian | $\mathbf{J}_{ij} = \frac{\partial f_i}{\partial x_j}$ | `torch.autograd.functional.jacobian` |

**常见导数表**：

| $f$ | $f'$ |
|---|---|
| $x^n$ | $n x^{n-1}$ |
| $e^x$ | $e^x$ |
| $\ln x$ | $1/x$ |
| $\sigma(x) = 1/(1+e^{-x})$ | $\sigma(1-\sigma)$ |
| $\text{ReLU}(x)$ | $\mathbb{1}[x > 0]$ |
| $\tanh x$ | $1 - \tanh^2 x$ |

### 概率（§2.3）

| 操作 | 公式 | 用途 |
|---|---|---|
| 期望 | $\mathbb{E}_{x \sim P}[f] = \sum P(x) f(x)$ | RL return |
| Softmax | $\text{softmax}(\mathbf{z})_i = \frac{e^{z_i}}{\sum e^{z_j}}$ | 归一化为分布 |
| Sigmoid | $\sigma(z) = \frac{1}{1+e^{-z}}$ | 二分类 |
| KL 散度 | $\text{KL}(P \,\Vert\, Q) = \sum P \log \frac{P}{Q}$ | 分布差距（非对称） |
| 熵 | $H(P) = -\sum P \log P$ | 不确定性 |
| 交叉熵 | $\text{CE}(P, Q) = -\sum P \log Q = H(P) + \text{KL}(P \,\Vert\, Q)$ | 分类 loss |
| 高斯分布 | $\mathcal{N}(\mu, \sigma^2)$，pdf 含 $e^{-(x-\mu)^2/2\sigma^2}$ | 初始化 / 噪声假设 |
| MLE | $\theta^* = \arg\max \prod_i p_\theta(x_i)$ | 监督 loss 的根 |

## 🎯 公式 → 代码 映射

看到论文公式 → 立刻能写 PyTorch：

| 公式 | 含义 | PyTorch |
|---|---|---|
| $\mathbf{y} = \mathbf{W}\mathbf{x} + \mathbf{b}$ | 全连接 | `nn.Linear(in, out)(x)` |
| $\sigma(z)$ | sigmoid | `torch.sigmoid(z)` 或 `F.sigmoid` |
| $\text{softmax}(\mathbf{z})$ | softmax | `F.softmax(z, dim=-1)` |
| $-\sum y \log \hat{p}$ | CE loss | `F.cross_entropy(logits, y)` |
| $(\hat{y}-y)^2$ | MSE | `F.mse_loss(y_pred, y)` |
| $\text{ReLU}(\mathbf{z})$ | ReLU | `F.relu(z)` |
| $\nabla_\theta \mathcal{L}$ | 梯度 | `loss.backward()` + `theta.grad` |
| $\theta \leftarrow \theta - \eta \nabla$ | SGD 更新 | `optimizer.step()` |
| $\text{KL}(\pi_\theta \,\Vert\, \pi_{ref})$ | KL 散度 | `F.kl_div(log_p, log_q, log_target=True)` |
| $\mathbb{E}_{a \sim \pi}[\cdot]$ | 期望 | 用 N 个采样平均 |

## 📐 神经网络一层的形状追踪

**Linear 层**：

```python
nn.Linear(in_features=4, out_features=3)
```

| 张量 | 形状 | 含义 |
|---|---|---|
| 输入 x | $[B, 4]$ | B 个样本，每个 4 维 |
| 权重 W | $[3, 4]$ | 3 个神经元，每个 4 维输入 |
| 偏置 b | $[3]$ | 每个神经元 1 个偏置 |
| 输出 $W^T x^T$ 或 $xW^T$ | $[B, 3]$ | B 个样本，每个 3 维输出 |

**Attention（简化版）**：

```python
Q.shape = [B, h, T, d_k]    # B批, h头, T长, 每头 d_k 维
K.shape = [B, h, T, d_k]
V.shape = [B, h, T, d_v]

scores = Q @ K.transpose(-2, -1)    # [B, h, T, T]
attn = F.softmax(scores / sqrt(d_k), dim=-1)  # [B, h, T, T]
out = attn @ V                       # [B, h, T, d_v]
```

→ 你能追踪这些形状变化 = 你看懂了 Attention。

## 🆘 常见"看不懂公式"急救

| 看到 | 怎么办 |
|---|---|
| 一堆希腊字母 | 大多是常数或固定符号（$\alpha, \beta, \lambda, \mu$） |
| 一堆下标 | 通常是 batch/序列/类别索引（$i, j, t, k$） |
| 一堆 $\sum, \int$ | 对**某维度求和/积分**，看下标知道是哪维 |
| $\mathbb{E}$ | 期望，实际用 N 个样本平均 |
| $\arg\max, \arg\min$ | 让某式最大/最小的**参数值** |
| $\propto$ | "正比于"，常数倍数不重要 |
| $\nabla$ | 梯度算子（对参数求偏导组成的向量） |
| 上标 $T$ | 转置（不是幂） |
| $\lvert \cdot \rvert$ | 绝对值或集合大小或行列式（看上下文） |
| $\lVert \cdot \rVert$ | 范数（默认 L2） |
