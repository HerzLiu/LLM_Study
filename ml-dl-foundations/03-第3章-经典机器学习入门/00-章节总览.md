## 🎬 一句话故事：为什么要学经典 ML？

> "我要做 LLM，干嘛学线性回归？"

因为：

```
线性回归 = 最简单的"模型 + loss + 梯度下降"三件套
       ↓
你能彻底搞懂线性回归
       ↓
你就能彻底搞懂神经网络（神经网络 = 线性回归 ×N + 激活函数）
       ↓
你就能彻底搞懂 SFT loss（SFT loss = next-token 的逻辑回归）
       ↓
你就能彻底搞懂 RM loss（RM loss = pairwise 的逻辑回归）
```

**线性回归 + 逻辑回归 = LLM 训练的"基本粒子"**。其它经典 ML（决策树、SVM）速览即可——**知道存在，看到不慌**。

## 📌 本章一句话小结

> **线性回归 = 加权和 + MSE + SGD**
> **逻辑回归 = 加权和 + sigmoid + CE + SGD**
> **神经网络 = 把上面这套堆 N 层**
>
> 你 SFT 时跑的 `optimizer.step()`，本质上和"训练一个 100 行的逻辑回归"是**一回事**——只是更深、更宽。
