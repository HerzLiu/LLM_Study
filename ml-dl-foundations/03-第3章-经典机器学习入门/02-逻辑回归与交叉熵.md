# 3.2 逻辑回归与交叉熵 ⭐

⬅ [01-线性回归从最小二乘到梯度下降](01-%E7%BA%BF%E6%80%A7%E5%9B%9E%E5%BD%92%E4%BB%8E%E6%9C%80%E5%B0%8F%E4%BA%8C%E4%B9%98%E5%88%B0%E6%A2%AF%E5%BA%A6%E4%B8%8B%E9%99%8D.md) | ➡ [03-决策树与集成（速览）](03-%E5%86%B3%E7%AD%96%E6%A0%91%E4%B8%8E%E9%9B%86%E6%88%90%EF%BC%88%E9%80%9F%E8%A7%88%EF%BC%89.md)

## 🎬 故事比喻：把线性回归改成"分类"

```
线性回归: 输入面积 → 输出房价（连续数值）

  问题:
  - 想做"是垃圾邮件吗？"（0/1 分类）
  - 直接用线性回归输出 → 可能输出 -5 / 100
  - 怎么把任意实数变成 0/1 的概率？

  答: 套个 sigmoid！

线性: ŷ = w·x + b
逻辑: p = sigmoid(w·x + b)

   ŷ ∈ ℝ      →    sigmoid    →    p ∈ (0,1) ← 现在是概率了

最后 p > 0.5 → 预测 1
       p < 0.5 → 预测 0
```

> **逻辑回归 = 线性回归 + sigmoid + 二分类 loss**。
> 这是 LLM **next-token prediction** 的最小原型——本节学透，就懂了 LLM 训练 90%。

---

## 📐 3.2.1 模型定义

**二分类**：

$$\hat{p}(y = 1 \mid \mathbf{x}) = \sigma(\mathbf{w}^T \mathbf{x} + b) = \frac{1}{1 + e^{-(\mathbf{w}^T \mathbf{x} + b)}}$$

| 符号 | 含义 |
|---|---|
| $\mathbf{x}$ | 输入特征 |
| $\hat{p}$ | 模型预测"$y=1$"的**概率** ∈ (0, 1) |
| $\sigma$ | sigmoid 函数 |

**多分类（Multinomial Logistic Regression）**：

$$\hat{\mathbf{p}} = \text{softmax}(\mathbf{W}\mathbf{x} + \mathbf{b})$$

- $\hat{\mathbf{p}}$ 是 C 维概率向量
- C 是类别数

→ **softmax 回归**就是逻辑回归的多类版。**LLM next-token 用这个**。

---

## 📏 3.2.2 损失函数：交叉熵（不是 MSE）

**为什么不用 MSE？**

如果用 MSE，loss 对参数的梯度会**和 sigmoid 导数相乘**——sigmoid 在饱和区导数接近 0，**梯度消失**，训不动。

**用交叉熵**：

**二分类 BCE**：

$$\mathcal{L}_{\text{BCE}} = -[y \log \hat{p} + (1-y) \log (1-\hat{p})]$$

**多分类 CE**：

$$\mathcal{L}_{\text{CE}} = -\log \hat{p}_y$$

（详见 [§4.4](../04-%E7%AC%AC4%E7%AB%A0-%E7%A5%9E%E7%BB%8F%E7%BD%91%E7%BB%9C%E4%B8%8E%E6%B7%B1%E5%BA%A6%E5%AD%A6%E4%B9%A0%E6%A0%B8%E5%BF%83/04-%E6%8D%9F%E5%A4%B1%E5%87%BD%E6%95%B0%E5%A4%A7%E5%85%A8.md)）

**为什么 CE 没有梯度消失？**

数学奇迹：sigmoid + BCE 求导后 **sigmoid 导数被消掉**：

$$\frac{\partial \mathcal{L}_{\text{BCE}}}{\partial z} = \hat{p} - y$$

→ 梯度极简，不会消失！

→ 这就是为什么**分类任务一定用 CE 而不用 MSE**。

---

## 🔢 3.2.3 数值例子（手算一遍）

数据：3 个样本

| $\mathbf{x}$ | $y$ |
|---|---|
| $(1, 2)$ | 1 |
| $(2, 1)$ | 0 |
| $(3, 3)$ | 1 |

**初始**：$\mathbf{w} = (0.5, 0.5), b = 0$

**Step 1: forward**

| $\mathbf{x}_i$ | $z = \mathbf{w}^T\mathbf{x}+b$ | $\hat{p} = \sigma(z)$ | $y$ |
|---|---|---|---|
| (1,2) | 0.5+1 = 1.5 | 0.818 | 1 |
| (2,1) | 1+0.5 = 1.5 | 0.818 | 0 |
| (3,3) | 1.5+1.5 = 3 | 0.953 | 1 |

**Step 2: BCE loss**

$$\mathcal{L} = -\frac{1}{3}[\log 0.818 + \log(1-0.818) + \log 0.953]$$
$$= -\frac{1}{3}[(-0.201) + (-1.705) + (-0.048)] = 0.651$$

**Step 3: 梯度**

$\frac{\partial \mathcal{L}}{\partial z_i} = \hat{p}_i - y_i$:

| 样本 | $\hat{p} - y$ |
|---|---|
| 1 | 0.818 - 1 = -0.182 |
| 2 | 0.818 - 0 = +0.818 |
| 3 | 0.953 - 1 = -0.047 |

第二个样本最"错"（预测高但实际是 0），所以贡献最大梯度。

**Step 4: 更新参数**（略，原理同线性回归）

## 💻 3.2.4 PyTorch 实现（概念示意，未严格验证）

### 二分类

```python
import torch
import torch.nn as nn

model = nn.Linear(in_features=2, out_features=1)   # 输出 1 个 logit
loss_fn = nn.BCEWithLogitsLoss()                    # ← 自带 sigmoid
optimizer = torch.optim.SGD(model.parameters(), lr=0.1)

for epoch in range(100):
    logits = model(X)              # 注意：是 logits，不是概率
    loss = loss_fn(logits, y)      # BCEWithLogitsLoss 内部做 sigmoid + BCE
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()

# 预测
with torch.no_grad():
    probs = torch.sigmoid(model(X_test))
    pred = (probs > 0.5).long()
```

⚠️ 用 `BCEWithLogitsLoss` 而不是 `BCELoss`——**数值稳定**且更高效。

### 多分类（softmax 回归）

```python
model = nn.Linear(in_features=10, out_features=3)   # 3 类
loss_fn = nn.CrossEntropyLoss()                     # ← 自带 softmax
optimizer = torch.optim.SGD(model.parameters(), lr=0.1)

for epoch in range(100):
    logits = model(X)              # [batch, 3]
    loss = loss_fn(logits, y)      # y 是类别 id（不是 one-hot）
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()

# 预测
with torch.no_grad():
    logits = model(X_test)
    pred = logits.argmax(dim=-1)   # 选概率最高的类
```

## 🆚 3.2.5 线性回归 vs 逻辑回归

| 维度 | 线性回归 | 逻辑回归 |
|---|---|---|
| 任务 | 回归（连续输出） | 分类（离散输出） |
| 模型 | $\hat{y} = \mathbf{w}^T\mathbf{x}+b$ | $\hat{p} = \sigma(\mathbf{w}^T\mathbf{x}+b)$ |
| 输出范围 | $\mathbb{R}$ | $(0, 1)$ 或概率分布 |
| Loss | MSE | BCE / CE |
| 输出层激活 | 无 | sigmoid / softmax |

→ 两者**只差一个激活函数 + 不同 loss**。

---

## 🎯 3.2.6 这一节为什么核心？⭐

**逻辑回归 = LLM next-token loss 的最小原型**。

| 概念   | 逻辑回归                   | LLM next-token                 |
| ---- | ---------------------- | ------------------------------ |
| 输入   | 特征 $\mathbf{x}$        | 上下文 token 序列                   |
| 模型   | `nn.Linear` + softmax  | Transformer + 输出投影 + softmax   |
| 类别数  | 几个到几十                  | **词表大小（50000+）**               |
| 输出   | C 类概率分布                | V 维概率分布                        |
| Loss | CE = $-\log \hat{p}_y$ | **完全相同**：$-\log \hat{p}_{y_t}$ |
| 训练   | SGD / Adam             | AdamW                          |

→ **LLM 训练数学上就是一个超大词表的逻辑回归**。
→ 详见 [§7.2](../07-%E7%AC%AC7%E7%AB%A0-%E6%A1%A5%E6%8E%A5%E5%88%B0%E4%BD%A0%E5%B7%B2%E5%AD%A6%E7%9A%84%E4%B8%96%E7%95%8C/02-%E4%BB%8E%E4%BA%A4%E5%8F%89%E7%86%B5%E5%88%B0next-token-loss.md)。

**RM 训练也是逻辑回归的变形**（pairwise Bradley-Terry, 详见 [agentic-rl §2.1](../../agentic-rl-knowledge-base/02-%E7%AC%AC2%E7%AB%A0-%E4%BB%8ERLHF%E5%88%B0Agentic-RL/01-RLHF%E4%B8%89%E9%98%B6%E6%AE%B5%EF%BC%88SFT-RM-PPO%EF%BC%89.md)）。

→ **本节学透 = 学透 LLM 训练核心 + RM 训练核心**。

---

## ⚠️ 3.2.7 常见误解

| 误解 | 真相 |
|---|---|
| "逻辑回归是回归" | **不！** 是**分类**。名字里有"回归"是历史原因 |
| "分类必须用 softmax" | 二分类用 sigmoid，多分类才需要 softmax |
| "BCELoss 和 BCEWithLogitsLoss 一样" | **不！** 后者**输入是 logits**，更稳定 |
| "CrossEntropyLoss 输入是概率" | **不！** 输入是 **logits**，内部做 softmax |
| "标签必须 one-hot" | PyTorch CrossEntropyLoss 接受**类别 id**（整数），自动 one-hot |
| "逻辑回归是线性模型" | **是**——决策边界是直线（XOR 学不会，要 MLP） |

---

## 📌 3.2 节要点

| 要素 | 内容 |
|---|---|
| **模型** | $\hat{p} = \sigma(\mathbf{w}^T\mathbf{x}+b)$ 或 $\hat{\mathbf{p}} = \text{softmax}(\mathbf{Wx}+\mathbf{b})$ |
| **Loss** | BCE / CE（**不用 MSE**） |
| **PyTorch** | `BCEWithLogitsLoss` / `CrossEntropyLoss`（接受 logits） |
| **核心地位** | LLM next-token loss 的最小原型 |
| **训练** | SGD/Adam，同线性回归 |

**最重要的一句**：
> **学透逻辑回归 = 学透 LLM next-token loss + RM loss**。
> 这是 LLM 训练数学上的"基本粒子"。
