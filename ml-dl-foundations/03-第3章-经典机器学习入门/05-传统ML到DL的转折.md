# 3.5 传统 ML 到 DL 的转折

⬅ [04-SVM核方法（速览）](04-SVM%E6%A0%B8%E6%96%B9%E6%B3%95%EF%BC%88%E9%80%9F%E8%A7%88%EF%BC%89.md) | ➡ [00-章节总览](../04-%E7%AC%AC4%E7%AB%A0-%E7%A5%9E%E7%BB%8F%E7%BD%91%E7%BB%9C%E4%B8%8E%E6%B7%B1%E5%BA%A6%E5%AD%A6%E4%B9%A0%E6%A0%B8%E5%BF%83/00-%E7%AB%A0%E8%8A%82%E6%80%BB%E8%A7%88.md)

## 🎬 故事比喻：手工木匠 vs 流水线工厂

```
传统 ML 时代:
  你做"猫狗分类":
  1. 人工设计特征（颜色直方图、HOG、SIFT…）—— 几个月
  2. 喂给 SVM / 决策树 —— 1 天
  3. 拿到结果

深度学习时代:
  你做"猫狗分类":
  1. 把图片直接喂 CNN
  2. CNN 自动学特征
  3. CNN 自动输出分类

  端到端 (end-to-end)，人不参与特征设计。

这就是转折。
```

> 这一节解释 **2012 年发生了什么** —— 为什么你 2025 学的是 LLM 而不是 SVM。
> 是 DL 取代传统 ML 的"分水岭叙事"。

```
你在这里 ──↓

```

→ **2012 是分水岭**——之前传统 ML 主流，之后 DL 接管。

## 🔥 3.5.2 AlexNet (2012) 为什么是引爆点？

**ImageNet 比赛**：120 万张图片，1000 类。

| 年份 | 第一名 | top-5 错误率 | 方法 |
|---|---|---|---|
| 2010 | NEC | 28% | 传统 SIFT + SVM |
| 2011 | XRCE | 26% | 传统 |
| **2012** | **AlexNet** | **16%** | **CNN + GPU + Dropout** ⭐ |
| 2014 | GoogLeNet | 7% | 更深 CNN |
| 2015 | ResNet | 3.6% | 残差连接，152 层 |
| 2017 | (人类水平 5%) | — | — |

**AlexNet 做对了什么**：
1. **更深的 CNN**（8 层，前所未有）
2. **ReLU 激活**（解决梯度消失）
3. **GPU 训练**（10x 加速）
4. **Dropout 防过拟合**

→ **从此 DL 一发不可收**。CV / 语音 / NLP 全部被 DL 颠覆。

## 🆚 3.5.3 核心区别：特征工程 vs 端到端

### 传统 ML 工作流

```
图片
  ↓
[人工特征工程: HOG / SIFT / LBP / 颜色直方图...]   ← 几个月人工
  ↓
特征向量
  ↓
[SVM / Random Forest / Logistic 回归]              ← 训练几小时
  ↓
分类结果
```

**人决定特征**——这是瓶颈。

### 深度学习工作流

```
图片
  ↓
[CNN 第一层: 自动学低级特征（边、角）]              ← 训练几小时-几天
  ↓
[CNN 第二层: 自动学中级特征（纹理、形状）]
  ↓
[CNN 第三层: 自动学高级特征（眼睛、轮子）]
  ↓
[全连接层: 分类]
  ↓
分类结果
```

**模型自己学特征**——完全端到端。
→ 这就是 "**representation learning（表示学习）**"——DL 的根本卖点。

---

## 💡 3.5.4 DL 为什么这 10 年才爆发？

3 个条件同时成熟：

### 1. 大数据

| 时代 | 数据规模 |
|---|---|
| 1990 | MNIST 60K 张 |
| 2000s | CIFAR 60K 张 |
| **2009** | **ImageNet 14M 张** ⭐ |
| 2020s | LLM 训练用万亿 token |

→ 互联网爆发提供数据。

### 2. 算力（GPU）

| 年份 | GPU 算力（FLOPS） |
|---|---|
| 2000 | GeForce 256: 50 MFLOPS |
| 2010 | GeForce GTX 480: 1.3 TFLOPS |
| 2020 | A100: 312 TFLOPS（fp16） |
| 2024 | H100: 989 TFLOPS（fp16） |

→ **NVIDIA CUDA**（2007）让 GPU 可编程，加速矩阵乘 10-100x。

### 3. 算法改进

| 改进 | 解决什么 |
|---|---|
| **ReLU** (2010) | 梯度消失 |
| **Dropout** (2012) | 过拟合 |
| **Adam** (2014) | 调参 |
| **BatchNorm/LayerNorm** (2015/2016) | 训练稳定 |
| **残差连接** (2015) | 深网训练 |
| **Attention/Transformer** (2017) | 长程依赖 |

→ 任一缺失都不会成功。**算法 + 数据 + 算力，三者合力**。

---

## 🌉 3.5.5 但传统 ML 没死

| 场景 | 推荐 |
|---|---|
| **表格数据**（推荐、CTR、风控） | **XGBoost** 常胜 DL |
| **小数据**（< 10k 样本） | 传统 ML |
| **可解释性要求高**（医疗/金融） | 决策树 / 线性模型 |
| **资源受限**（移动设备） | 传统 ML |
| **图像 / 文本 / 语音 / 序列** | **DL 绝对优势** |

→ 不要无脑用 DL。看任务。

---

## 🚀 3.5.6 LLM 是 DL 的现代巅峰

**Transformer + 大数据 + 大算力 = LLM**：

```
2017 Transformer 论文
  ↓
2018 BERT (110M 参数) ─→ NLP 任务大杀器
  ↓
2018 GPT-1 (117M)
2019 GPT-2 (1.5B)
2020 GPT-3 (175B) ⭐ 涌现能力
2022 ChatGPT
2023 GPT-4 / Claude / LLaMA 开源
2024 Sora / o1 / Claude-3.5
2025 你在学（LLM + Agent + RL）
```

→ **DL 的方法论一直没变**：模型 + 数据 + GPU + 反向传播。
→ 只是规模越来越大。

→ 你已学的整本 Happy-LLM，本质上是讲"**Transformer 这个 DL 架构如何成就 LLM**"。

## ⚠️ 3.5.8 常见误解

| 误解 | 真相 |
|---|---|
| "传统 ML 过时了" | **没**——表格数据上仍是 SOTA |
| "DL 学了就够，不用看传统 ML" | 错——表格场景 XGBoost 还是首选 |
| "AlphaGo 是 LLM" | 不！AlphaGo 是 DL + RL，2016 年的事 |
| "GPT 是 2012 才有的" | 错。GPT-1 2018 年。AlexNet 2012 年（CV）才是 DL 引爆点 |
| "ImageNet 2012 之后 SVM 没人用" | 工业界还在用，研究热点转向 DL |

## 📌 3.5 节要点

| 时代 | 主流 |
|---|---|
| 1995-2010 | SVM、决策树、传统 ML |
| **2012-2017** | **CNN 时代**（ImageNet 引爆） |
| **2017-2020** | **Transformer 时代**（NLP 革命） |
| **2020+** | **LLM 时代**（GPT-3、ChatGPT、Agent） |

**3 件事推动了 DL 爆发**：大数据 + GPU + 算法改进（ReLU/Dropout/...）。

**DL 的最大卖点**：**端到端学习** + **自动特征提取**（不用人工特征工程）。
