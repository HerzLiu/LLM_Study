## 🎬 故事比喻：找一条"最宽"的分界线

```
两类点散在平面上，你画一条线分开。

  方法 1（逻辑回归）: 任意一条能分开的线就行
  方法 2（SVM）: 找让两边"间隔最大"的那条线
                 → 抗干扰、泛化好

   类A ○                   类B ●
   ○                            ●
       ○                    ●
              ─ ─ ─ ─ ─       ← SVM 的分界线
   ○         ───────         ●
              ─ ─ ─ ─ ─       ← "间隔" margin
       ○                    ●
   ○                            ●
```

> 这一节速览——你的目标不是 SVM 研究。**知道存在 + 核方法直觉就行**。

---

## 📐 3.4.1 SVM 核心思想

### 最大间隔分类

**目标**：找超平面 $\mathbf{w}^T\mathbf{x} + b = 0$，让两类离它**最近**的点的距离（间隔）**最大**。

最近的那些点叫**支持向量**（Support Vectors）—— SVM 名字的由来。

### Hinge Loss

$$\mathcal{L}_{\text{SVM}} = \max(0, 1 - y \cdot (\mathbf{w}^T\mathbf{x} + b))$$

其中 $y \in \{-1, +1\}$。

**直觉**：
- 分对且离边界远（margin > 1）→ loss = 0
- 分错或离边界太近 → loss > 0

---

## 🪄 3.4.2 核方法（Kernel Trick）⭐ SVM 真正的精髓

**问题**：很多数据**不是线性可分**的（如 XOR）。

**思路**：把数据**映射到高维**，在高维变线性可分。

**问题**：高维映射可能很贵（甚至无限维）。

**核技巧**：**不显式映射**，直接用一个"核函数" $K(\mathbf{x}_1, \mathbf{x}_2)$ 算映射后的内积。

### 常用核

| 核 | 公式 | 用在哪 |
|---|---|---|
| 线性 | $K(\mathbf{x}_1, \mathbf{x}_2) = \mathbf{x}_1^T \mathbf{x}_2$ | 文本分类 |
| 多项式 | $(\mathbf{x}_1^T\mathbf{x}_2 + c)^d$ | 一般 |
| **RBF（高斯）** | $\exp(-\gamma \lVert \mathbf{x}_1 - \mathbf{x}_2 \rVert^2)$ | **最常用** |
| Sigmoid | $\tanh(\alpha \mathbf{x}_1^T\mathbf{x}_2 + c)$ | 类似神经网络 |

→ **不要求记公式**，知道"RBF 核最常用"就行。

---

## 🆚 3.4.3 SVM vs 神经网络

| 维度 | SVM | 神经网络 |
|---|---|---|
| 解 | 全局最优（凸优化） | 局部最优（非凸） |
| 数据需求 | **少量**也能学好 | 海量 |
| 特征工程 | 需要人工 | **自动学**（深度学习的卖点） |
| 训练速度 | 数据多时慢 | GPU 加速 |
| 大数据 | 不擅长 | **擅长** |
| 解释性 | 决策边界清晰 | 黑盒 |

→ **2010 年前 SVM 是王者**，2012 AlexNet 后被 DL 取代。

---

## 🕰 3.4.4 SVM 的历史地位

```
1990s: SVM 引爆机器学习
       - 在小数据上击败神经网络
       - "支持向量机 + 核方法"成为标配

2000s: SVM 全盛
       - LIBSVM 等工具流行
       - NLP / CV / 生物等领域大量应用

2010s: DL 兴起，SVM 退居二线
       - 大数据 + GPU 让 DL 优势显现
       - SVM 仍用在小数据 / 工程项目

2020s: 几乎只剩教学价值（在 LLM 场景里）
```

## 💻 3.4.5 sklearn 代码（一行调用）

```python
from sklearn.svm import SVC

# 线性 SVM
clf = SVC(kernel='linear')
clf.fit(X_train, y_train)

# RBF 核 SVM
clf = SVC(kernel='rbf', C=1.0, gamma='scale')
clf.fit(X_train, y_train)
```

## 📌 3.4 节要点

| 概念 | 一句话 |
|---|---|
| **最大间隔** | 不只是分对，要分得"宽" |
| **支持向量** | 离分界线最近的点 |
| **核技巧** | 不显式映射，直接算高维内积 |
| **RBF 核** | 最常用的非线性核 |
| **历史地位** | 2010 年前王者，现在退居二线 |

**对你的建议**：
- SVM 现在很少用在 LLM 场景
- 知道**核方法的思想**有助于理解 Attention（Attention 本质上也是"加权相似度"，和核方法精神相通）
- 不用深究
