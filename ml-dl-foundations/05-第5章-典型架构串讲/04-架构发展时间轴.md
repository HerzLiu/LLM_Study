## 🔑 4 个关键转折点

### 🔴 1986：反向传播

**意义**：理论上 DL 终于"能训"了。但没数据没算力，没火。

### 🔴 2012：AlexNet 引爆

**意义**：算法 + 数据 + GPU 三者齐备，**CV 革命**。

### 🔴 2017：Transformer

**意义**：抛弃 RNN 的顺序处理，**NLP 革命**。LLM 时代的起点。

### 🔴 2022：ChatGPT

**意义**：LLM 从研究走向**大众产品**。AI 进入新时代。

## 🎯 你应该懂的"3 个史观"

### 1. 算法不是凭空出现，是"问题倒逼"

| 问题 | 解 |
|---|---|
| 单神经元学不会 XOR | MLP |
| 深网梯度消失 | ReLU + 残差 |
| 训练慢 | GPU + Adam |
| 处理序列 | RNN |
| 长程依赖 | LSTM |
| LSTM 仍慢、仍弱 | Transformer |
| LLM 对齐难 | RLHF / DPO / GRPO |
| Reward hacking | Verifier / RLVR |

→ **每个新方法都是为了解决前一代的痛点**。

### 2. 通用规律：**Scaling Wins**

```
小模型 → 加层 / 加宽 → 大模型
小数据 → 加数据    → 大数据
慢算力 → 加 GPU    → 大算力
                  ↓
              效果指数级提升
              （Scaling Law）
```

→ GPT-3 → GPT-4 → o1 → o3 一路印证这条规律。

### 3. **架构在收敛**

CV: CNN → ViT (Transformer)
NLP: RNN → Transformer
语音: RNN → Transformer / Conformer
多模态: 全 Transformer
RL+LLM: Transformer + GRPO

→ **Transformer 成为通用积木**。
