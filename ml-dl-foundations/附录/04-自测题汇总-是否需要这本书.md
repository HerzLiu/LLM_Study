## ⚡ 入门快速自测（5 题）

如果以下 **5 题答不出 ≥ 3 题**，本书是写给你的：

1. **loss 是什么？** 为什么 loss 要最小化？
2. **梯度是什么？** 为什么沿梯度反方向走能下降 loss？
3. **`optimizer.step()` 干了什么？**
4. **`loss.backward()` 干了什么？**
5. **过拟合怎么诊断？** 训练集和验证集为什么要分？

## 🎓 终极测试（毕业）

如果你能**在不查任何资料的情况下**：

### 测试 1：给完全没基础的人讲清楚

```
向一个只会 Python 的人讲清楚:
  "什么是神经网络? loss 是什么? 怎么训练?"

要求: 10 分钟讲完，对方能跟上。
```

### 测试 2：徒手画出 Transformer

```
画出一个 Transformer Block 的所有组件:
  - 输入/输出形状
  - 每个组件来自本书哪一节
  - 数据流向
```

### 测试 3：解释 GRPO 论文

```
打开 DeepSeekMath 论文，向同事解释:
  - GRPO 的公式
  - 每个符号的含义
  - 它和 PPO 的区别
  - 为什么省 critic
```

### 测试 4：诊断训练问题

```
场景: 同事说"我的 LLM SFT 训练，loss 不下降"
你能列出 5 个最可能的原因 + 排查顺序吗？
```
