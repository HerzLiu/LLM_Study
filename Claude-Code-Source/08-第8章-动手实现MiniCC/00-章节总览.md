## 🧭 知识地图

```
MiniCC = 
   Agent Loop (第2章)
 + Tool 系统 (第3章) × 5 个工具
 + Auto-compact (第4章)
 + System Prompt 分节 (第5章)
 + Permission 4 模式 + 危险检测 (第7章)
 + CLI 交互层
```

```
              用户输入
                  │
       ┌──────────▼──────────┐
       │      CLI REPL       │
       │  /plan /default ... │
       └──────────┬──────────┘
                  │
              run_agent()
                  │
       ┌──────────▼──────────┐
       │   auto-compact?     │
       └──────────┬──────────┘
                  │
              call API
              with tools
                  │
           ┌──────┴──────┐
           │             │
       end_turn?     tool_use?
           │             │
        return    check_permission
                       │
                  execute tool
                       │
                  loop back
```
