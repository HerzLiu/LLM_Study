## 🎮 体验 6 个有趣 prompt

### 1. 探索性

```
default> 看一下当前目录有什么 Python 文件
```

预期：模型调 `Glob('**/*.py')`，列出结果。

### 2. 多工具

```
default> 读一下 minicc.py，告诉我它定义了哪些工具
```

预期：模型调 Read 拿内容 → 分析 → 回答（找到 5 个 TOOL 常量）。

### 3. 触发权限

```
default> 把 /tmp/test.txt 写成 "hello"
```

预期：因 Write 是 destructive，**弹"是否允许"对话框**。

### 4. 触发危险检测

```
default> 跑 rm -rf /
```

预期：**被 dangerous pattern 拦下**，模型看到错误信息后会换思路（或老实道歉）。

### 5. 切换 Plan Mode

```
default> /plan
plan> 帮我写一个 hello world 到 /tmp/x.py
```

预期：模型发现 **Write 工具不可用**，会和你讨论方案，建议你 `/default` 后再做。

### 6. 触发 Auto-compact

```
default> 把 /usr/share/dict/words 整个读一遍
```

预期：几轮 Read 后 token 飙升，**触发 auto-compact**，看到 `⚠️ Triggering auto-compact...` 提示。

## 📊 MiniCC vs 真 Claude Code 差距对照

| 维度 | MiniCC | Claude Code |
|---|---|---|
| 代码量 | ~400 行 | ~512,000 行 |
| 工具数 | 5 个 | 40+ 个 |
| 流式 | 否（一次返回） | 是（StreamingToolExecutor） |
| UI | 简陋 print | React/Ink 组件树 |
| 沙箱 | 软件层 + 危险模式 | + seccomp + sandbox-exec |
| 上下文管理 | 单一 auto-compact | 多种 compact 策略 |
| SubAgent | 没实现（练习） | 6+ 内置 + 自定义加载 |
| Prompt cache | 没用 | 用，省 90% 费 |
| Hooks | 没有 | 完整 hooks 系统 |
| MCP | 没有 | 完整 MCP 客户端 |
| Skill | 没有 | Skill 系统 |
| 持久化 | 没有 | 会话存档 + resume |
| 协议适配 | 只 Anthropic | + Bedrock + Vertex + Foundry |

**但核心架构 100% 一样**：
- ✅ `messages` 循环
- ✅ `stop_reason` → tool_use 判断
- ✅ Tool 注册 + 过滤 + 执行
- ✅ Permission 多层过滤
- ✅ System Prompt 分节
- ✅ Auto-compact

## 🛠 进阶练习清单

### ★ 难度低

1. **加 `Grep` 工具**：用 `re.search` 在文件内容里搜
2. **加 `LS` 工具**：列目录
3. **改 system prompt**：加入 "Tasks must be verified" 这条，看模型行为变化

### ★★ 难度中

4. **加 TodoWriteTool**：维护全局任务列表，UI 上每轮渲染当前 todo
5. **流式渲染**：把 `client.messages.create` 换成 `client.messages.stream`，让文本一个字一个字出
6. **配置文件**：从 `~/.minicc/settings.json` 读用户的 allow/deny 规则
7. **CLAUDE.md 支持**：自动加载项目根的 `CLAUDE.md` 到 system prompt

### ★★★ 难度高

8. **加 SubAgent**：实现 `Task` 工具，开独立 messages / 独立 system prompt 的子循环
9. **真 token 计数**：用 `client.beta.messages.count_tokens(...)` 替代估算
10. **Prompt Cache**：用 `cache_control: {"type": "ephemeral"}` 标记 system prompt
11. **持久化会话**：会话退出时存到 `~/.minicc/sessions/`，下次 `--resume`
12. **MCP 客户端**：实现一个简单 MCP 客户端，接外部工具

## 🎯 选 1 个练习深度做

不要全做。**选 1 个真正实现完整**，比浅尝 10 个收获大。

推荐顺序：
1. 第一选择：**加 TodoWriteTool**（覆盖第 4 章核心）
2. 第二选择：**加 SubAgent**（覆盖第 6 章核心）
3. 第三选择：**流式渲染**（提升 UX 体感）

## 💡 一些重要的话

读到这里，你建立了 Agent 工程的完整心智模型。但请记住：

1. **LLM 在快速进化**
   - 本系列基于 Claude 4.5/4.6 时代。模型变强后 prompt 工程和架构也会变
   - 不要把"今天的最佳实践"当成"永恒真理"

2. **不要迷信架构**
   - Claude Code 是一种好实现，**不是唯一答案**
   - LangChain / AutoGen / OpenHands / Aider 都有不同思路

3. **安全永远第一**
   - 你的 Agent 给用户跑命令 → **一切安全机制都不嫌多**
   - 默认拒绝、纵深防御，永远没错

4. **可观测性是续命药**
   - 日志、telemetry、错误追踪，**从第一版就要有**
   - 出 bug 时没日志 = 抓瞎

5. **Prompt 工程是真工程**
   - 不是"调几个字"
   - 是版本化、A/B、内外灰度、变更追踪
