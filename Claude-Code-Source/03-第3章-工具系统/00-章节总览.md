## 🎯 本章学完你将拥有

- [ ] 能解释 Anthropic API 的 `tools` 字段格式
- [ ] 能默写 Tool 接口的 8 个核心字段
- [ ] 知道为什么 `description()` 和 `prompt()` 是两个不同方法
- [ ] 知道 `tool_result` 是用什么 role 发回去的（陷阱题！）
- [ ] 区分 `isReadOnly` / `isConcurrencySafe` / `isDestructive` 三个标志
- [ ] 知道为什么 Read 工具要返回 `<num>: <content>` 格式
- [ ] 跑通一个 Python 工具基类 + 注册表 + 执行器

## 🧭 知识地图

```
                  Tool Use 协议（API 层）
                          │
              tools=[...] 发出去
                          │
              收到 tool_use 块
                          │
              tool_result 塞回（role: user）
                          │
                  ─── 协议结束 ───
                          │
          Claude Code 在协议上加这些：
                          │
       ┌──────────────────┼──────────────────┐
       │                  │                  │
   Tool 接口          注册/过滤         执行器
   (8 个字段)        (Plan Mode 等)    (流式+并发)
       │                  │                  │
   每个工具一个目录  工具白名单/黑名单  权限钩子
   - prompt.ts                            try/catch
   - schema (zod)                         结果截断
   - call(args)
   - UI.tsx
```

## 📝 本章一句话小结

> **工具 = 协议（API 层）+ 接口（CC 层封装）+ 注册（按场景过滤）+ 执行（带权限和并发）。每一层都有自己的设计巧思。**
