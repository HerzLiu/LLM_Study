## ⭐ 加深理解：为什么工具这么多？

40+ 工具看着吓人，但**分工明确**：

| 维度 | 思路 |
|---|---|
| **细粒度** | Read 和 Bash cat 都能读，但 Read 有行号、有限制、有 UI |
| **专用 > 通用** | Glob 比 Bash find 安全 + 易用 |
| **每个工具一个目录** | 容易加工具、容易禁工具、容易测试 |
| **feature gate** | 有些工具默认关闭，特定客户开通 |

**写自己 Agent 时不需要 40 个**。5-10 个常用工具足以应付 80% 场景。

## 🐍 你的 Agent 至少要哪几个？

最小可用集（5 个）：

```python
1. Read     - 读文件
2. Write    - 写文件
3. Edit     - 改文件
4. Bash     - 跑命令
5. Glob     - 找文件
```

进阶（再加 3 个）：
```python
6. Grep     - 搜内容
7. TodoWrite - 任务清单
8. Task     - SubAgent
```
