## 🎯 本章学完你将拥有

- [ ] 能默写 Claude Code system prompt 的 13 个 section
- [ ] 能说出 3 条 Claude Code 的"金句"（NEVER 风格）
- [ ] 知道为什么 prompt 里要解释"后果"（如 "calls will be REJECTED"）
- [ ] 区分 cacheable prefix 和 dynamic suffix
- [ ] 知道 `@[MODEL LAUNCH]` 注释 tag 的作用
- [ ] 能给自己 Agent 写一个合格的 system prompt（用 checklist）
- [ ] 跑通分节式 Prompt 拼装器
