## 🎬 一句话故事

- **自动售货机** = 普通程序：按啥按钮出啥饮料
- **ChatGPT 网页** = Chatbot：会说话，**不会动手**
- **会做事的实习生** = Agent：**会思考、会动手、会观察、会再思考**

**Claude Code = 一个住在终端里的"实习生"**，能读你的代码、改你的文件、跑你的命令。

## 📝 本章一句话小结

> **Agent ≠ 会说话的 LLM。Agent = LLM × 能动手 × 会循环。Claude Code 是这个公式在终端里的工业级实现。**
