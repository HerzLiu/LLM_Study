## 🎬 一句话故事

同样是"做事"，公司不会给每个人一样的权限：
- **临时工**（Plan Mode）：只能看
- **实习生**（Default）：能做小事，大事要老板点头
- **老员工**（Accept Edits）：改代码不用问
- **总监**（Bypass）：几乎啥都能干（但 `rm -rf /` 公司还是禁）

Claude Code 实现了这套**完整的权限分层 + 红线检测 + 物理沙箱**。

## 🧭 知识地图

```
                  工具调用请求
                          │
                          ▼
       ┌─────────────────────────────┐
       │ 第 0 层: 危险模式检测（黑名单）│ → BLOCKED → deny
       ├─────────────────────────────┤
       │ 第 1 层: Mode 检查（Plan?）   │ → 非只读 → deny
       ├─────────────────────────────┤
       │ 第 2 层: 用户 deny 规则       │ → 匹配 → deny
       ├─────────────────────────────┤
       │ 第 3 层: 用户 allow 规则      │ → 匹配 → allow
       ├─────────────────────────────┤
       │ 第 4 层: Destructive 弹窗     │ → user 选择
       ├─────────────────────────────┤
       │ 第 5 层: 默认 allow           │
       └─────────────────────────────┘
                          │
                          ▼
                     执行工具
                          │
                  + 物理沙箱（seccomp / sandbox-exec）
                  + Hooks（用户自定义审计）
```

## 📝 本章一句话小结

> **安全 = 纵深防御。Prompt 约束 + 工具过滤 + 危险检测 + 用户确认 + 物理沙箱 + 远程紧急开关。任何一层失效，下一层还能挡。**
