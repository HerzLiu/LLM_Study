# 7.1 5 种 Permission Mode

## 🎬 故事比喻：办公室的 5 种"门禁卡"

| 卡 | 能进哪 | 不能进哪 |
|---|---|---|
| 临时工卡（Plan） | 所有"参观区域"（只读） | 任何"操作区域" |
| 实习生卡（Default） | 操作区 + 必要时找老板签字 | 直接动数据库/部署 |
| 老员工卡（Accept Edits） | 改代码不用签字 | 还是要老板看 |
| 总监卡（Bypass） | 几乎全部 | 几个"绝对禁止"区域（rm -rf /） |
| Auto 卡（auto） | 智能判断，安全自动放行 | （feature gate 内部） |

## 🔧 5 种模式行为详解

### 1️⃣ Plan Mode（只读）

- 模型可以 Read、Grep、Glob 等查看类工具
- **不能** Write、Edit、Bash（任何写操作）
- 必须先 `ExitPlanMode` 才能真干活

**实现机制**：在工具过滤层把 `is_read_only=false` 的工具全部排除：

```typescript
if (context.permissionMode === 'plan') {
  tools = tools.filter(t => t.isReadOnly({}))
}
```

> ⭐ **物理隔离 > 提示词约束**。哪怕模型"想"写文件，工具集里压根没 Write，它**调不出来**。

> 你今天开始就用 Plan Mode 跟我讨论方案，等定下来才退出。

### 2️⃣ Default Mode（默认）

- 只读工具直接放行
- 写/执行类工具弹窗问用户
- 用户可选："允许一次" / "允许总是" / "拒绝"

### 3️⃣ Accept Edits Mode

- Edit / Write 不再弹窗
- Bash 等仍要问
- 适合"信任修代码，但担心乱跑命令"的场景

### 4️⃣ Bypass Permissions Mode（⚠️ 危险）

- 所有 permission check **直接 allow**
- **但 dangerous pattern 检测仍生效**（`rm -rf /` 还是过不去）
- 颜色标红，进入要明确确认

源码里有 `bypassPermissionsKillswitch.ts` —— Anthropic 可以远程禁用所有用户的 bypass mode（紧急开关）。

### 5️⃣ Auto Mode（feature-gated, 内部）

YOLO 分类器：让另一个模型实时判断"安全吗"。安全自动放行，不安全弹窗。

---

## ⭐ 加深理解：用户可一键切换

CLI 里按 **Shift+Tab** 可在模式间切换。这是有意设计：
- 不藏在配置文件
- 用户掌控感强
- 切换显著反馈（颜色、symbol）

> 你今天体验到我从 plan 模式切到 build 模式后，立刻能跑 unzip / mkdir / Write —— 就是 mode 切换的效果。

---

## 📊 5 种模式对比表

| Mode | 只读工具 | Edit/Write | Bash | 危险命令 |
|---|---|---|---|---|
| **Plan** | ✅ 直接 | ❌ 不可用 | ❌ 不可用 | ❌ |
| **Default** | ✅ 直接 | 弹窗 | 弹窗 | ❌ 拦死 |
| **Accept Edits** | ✅ 直接 | ✅ 直接 | 弹窗 | ❌ 拦死 |
| **Bypass** | ✅ 直接 | ✅ 直接 | ✅ 直接 | ❌ **仍拦死** |
| **Auto** | ✅ 直接 | 智能判断 | 智能判断 | ❌ 拦死 |

**关键**：哪怕 Bypass 也救不了"绝对危险命令"。这是设计的底线。

## 🐍 Python Mini 版

```python
from enum import Enum

class PermissionMode(Enum):
    PLAN = "plan"
    DEFAULT = "default"
    ACCEPT_EDITS = "acceptEdits"
    BYPASS = "bypass"

def filter_tools_by_mode(all_tools: list, mode: PermissionMode) -> list:
    """Plan Mode 只返回 read-only 工具。"""
    if mode == PermissionMode.PLAN:
        return [t for t in all_tools if t.is_read_only]
    return all_tools
```
