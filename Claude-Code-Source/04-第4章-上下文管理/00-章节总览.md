## 🎬 一句话故事

雇了个**短期记忆只有一页 A4 纸**的助理。怎么让他能干长任务？
1. **定期整理 A4** → auto-compact（压缩历史）
2. **小本本记 todo** → TodoWrite（外部任务记忆）
3. **办公桌墙上贴常用规则** → CLAUDE.md（项目长期记忆）

- [ ] 知道 Claude Sonnet 4.5 的 context window 是多少

- [ ] 解释 auto-compact 三种状态（warning/error/trigger）的阈值
- [ ] 能默写 auto-compact 的 prompt 关键部分（NO_TOOLS_PREAMBLE）

- [ ] 区分 CLAUDE.md、`~/.claude/CLAUDE.md`、settings.json 三种"记忆"
- [ ] 跑通一个带 auto-compact 的 Python Agent

## 🧭 知识地图

```
                    Context Window (200K)
                          │
              预留输出 20K + buffer 13K
                          │
                  实际可用 ≈ 167K
                          │
       ┌──────────────────┼──────────────────┐
       │                  │                  │
   长对话历史         工具结果累积        附件（图片/大文件）
       │                  │                  │
       └────────────────┬────────────────────┘
                          │
                  ⚠️ 接近 167K
                          │
              ┌──────────┴──────────┐
              │                     │
        Auto-compact            微压缩
        (整段压缩)              (只压一段)
              │                     │
              └──────────┬──────────┘
                          │
                  替换 messages
                  → 继续工作
                          │
          + 外部记忆：TodoWrite、CLAUDE.md、MemDir
```
