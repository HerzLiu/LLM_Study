## 🎬 一句话故事

**主管**（主 Agent）想做"竞品调研"，但一个人查 10 个网站 → 脑子塞满垃圾信息。
**派 10 个实习生**（SubAgent）各查一个 → 每人**只回报 2 句话总结** → 主管脑子清爽。

这就是 SubAgent 机制的核心：**上下文隔离**。

## 🧭 知识地图

```
              Main Agent context (短)
              ┌───────────────────────┐
              │ user: 审查代码        │
              │ Task(Explore, "找认证")│ ─ spawn ──┐
              │ ← "Summary: 5 文件"   │            ▼
              │ Task(Verify, "测一下")│  SubAgent context (长，独立)
              │ ← "all passing"       │  ┌──────────────────────┐
              │ "审查报告..."          │  │ grep 10 次            │
              └───────────────────────┘  │ read 30 个文件         │
                                          │ 分析综合              │
                                          │ → 200 字摘要         │
                                          └──────────────────────┘
                                             这些细节
                                             ↑ 不进主 Agent
```

## 📝 本章一句话小结

> **SubAgent ≠ "分工"。SubAgent = "上下文隔离"。脏活让小弟干，主 Agent 脑子保持清爽。**
