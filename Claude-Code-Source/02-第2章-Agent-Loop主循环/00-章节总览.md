## 🧭 知识地图

```
                    queryLoop (while true)
                          │
       ┌──────────────────┼──────────────────┐
       │                  │                  │
   流式响应          工具批量收集         状态机
   (async gen)      (toolUseBlocks)     (State 对象)
       │                  │                  │
   yield event       长度=0 → 退出     turnCount++
                     长度>0 → 执行     messages 增长
                          │
              ┌──────────┴───────────┐
              │                       │
        runTools             StreamingToolExecutor
        (批量同步)           (流式并发，模型还在打字就开跑)
              │                       │
              └──────────┬────────────┘
                          ▼
                    工具结果回流
                    messages 追加
                    → 下一轮
```

## 📝 本章一句话小结

> **Claude Code 主循环 = `while(true)` + `async generator` + 5 段标准动作 + 一堆护栏。结构平淡，全是细节。**
