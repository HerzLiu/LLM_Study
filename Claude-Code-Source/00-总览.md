## 📖 怎么用这份笔记

1. **从总览进入** → 选感兴趣的章节
2. **每章先读"章节总览"** → 看全貌和地图
3. **再按顺序读每个小节** → 每节聚焦一个概念
4. **遇到 `[[双链]]` 就点进去**，回头按 `Ctrl+Alt+←` 返回
5. **代码节点单独成文**（编号 `99-代码-xxx`），可以反复来翻
