# 附录 · 术语表

⬅ [00-总览](../00-%E6%80%BB%E8%A7%88.md)

> 🎯 Agent / LLM / Claude Code 常见术语英中对照 + 一句话解释。

---

## A

### **Agent**
> Agent ≠ Chatbot。**Agent = LLM + Tools + Loop**。会"思考-动手-观察-再思考"的程序。详见 [01-Agent是什么](../01-%E7%AC%AC1%E7%AB%A0-Agent%E5%85%A5%E9%97%A8%E4%B8%8ECC%E6%80%BB%E8%A7%88/01-Agent%E6%98%AF%E4%BB%80%E4%B9%88.md)。

### **Agent Loop**
> 主循环。`while(true)` 反复调 LLM、执行工具、塞回结果。详见 [02-queryLoop骨架](../02-%E7%AC%AC2%E7%AB%A0-Agent-Loop%E4%B8%BB%E5%BE%AA%E7%8E%AF/02-queryLoop%E9%AA%A8%E6%9E%B6.md)。

### **AgentTool / Task Tool**
> Claude Code 里派生 SubAgent 的工具。详见 [02-AgentTool与内置Agent](../06-%E7%AC%AC6%E7%AB%A0-%E5%A4%9AAgent%E5%8D%8F%E4%BD%9C/02-AgentTool%E4%B8%8E%E5%86%85%E7%BD%AEAgent.md)。

### **`async generator`**
> Python/JS 中 `async def` + `yield` 组合。让函数能"边算边吐结果"，是流式响应的核心。详见 [03-async-generator与流式](../02-%E7%AC%AC2%E7%AB%A0-Agent-Loop%E4%B8%BB%E5%BE%AA%E7%8E%AF/03-async-generator%E4%B8%8E%E6%B5%81%E5%BC%8F.md)。

### **`asyncio.gather`**
> Python 并发等多个协程的 API。SubAgent 并发派发就靠它。

### **Attachment（附件）**
> Claude Code 把大文件结果包成 attachment，可单独丢弃/去重，不直接塞 messages。详见 [05-高级压缩机制](../04-%E7%AC%AC4%E7%AB%A0-%E4%B8%8A%E4%B8%8B%E6%96%87%E7%AE%A1%E7%90%86/05-%E9%AB%98%E7%BA%A7%E5%8E%8B%E7%BC%A9%E6%9C%BA%E5%88%B6.md)。

### **Auto-Compact**
> 自动压缩。token 超阈值时，让另一个 LLM 总结历史，用 summary 替换 messages。详见 [02-AutoCompact压缩](../04-%E7%AC%AC4%E7%AB%A0-%E4%B8%8A%E4%B8%8B%E6%96%87%E7%AE%A1%E7%90%86/02-AutoCompact%E5%8E%8B%E7%BC%A9.md)。

## B

### **Bash Security**
> Claude Code 对 Bash 命令的危险模式检测，26+ 种正则黑名单。详见 [03-Bash危险模式](../07-%E7%AC%AC7%E7%AB%A0-%E5%AE%89%E5%85%A8%E4%B8%8E%E6%9D%83%E9%99%90/03-Bash%E5%8D%B1%E9%99%A9%E6%A8%A1%E5%BC%8F.md)。

### **Bypass Permissions Mode**
> Claude Code 的"超级权限"模式，所有权限弹窗关闭。**但危险模式仍然拦**。详见 [01-5种权限模式](../07-%E7%AC%AC7%E7%AB%A0-%E5%AE%89%E5%85%A8%E4%B8%8E%E6%9D%83%E9%99%90/01-5%E7%A7%8D%E6%9D%83%E9%99%90%E6%A8%A1%E5%BC%8F.md)。

---

## C

### **`canUseTool`**
> Claude Code 工具执行前的权限拦截器，5 层过滤。详见 [02-canUseTool过滤器](../07-%E7%AC%AC7%E7%AB%A0-%E5%AE%89%E5%85%A8%E4%B8%8E%E6%9D%83%E9%99%90/02-canUseTool%E8%BF%87%E6%BB%A4%E5%99%A8.md)。

### **CLAUDE.md**
> 项目级长期记忆。自动加载到 system prompt。详见 [04-ClaudeMD长期记忆](../04-%E7%AC%AC4%E7%AB%A0-%E4%B8%8A%E4%B8%8B%E6%96%87%E7%AE%A1%E7%90%86/04-ClaudeMD%E9%95%BF%E6%9C%9F%E8%AE%B0%E5%BF%86.md)。

### **ContextWindow**
> LLM 一次能处理的最大 token 数。Claude Sonnet 4.5 ≈ 200K。详见 [01-Token与ContextWindow](../04-%E7%AC%AC4%E7%AB%A0-%E4%B8%8A%E4%B8%8B%E6%96%87%E7%AE%A1%E7%90%86/01-Token%E4%B8%8EContextWindow.md)。

### **Concurrency Safe**
> 工具是否能并发跑。Read 安全（并发），Bash 不安全（串行）。详见 [05-注册过滤执行](../03-%E7%AC%AC3%E7%AB%A0-%E5%B7%A5%E5%85%B7%E7%B3%BB%E7%BB%9F/05-%E6%B3%A8%E5%86%8C%E8%BF%87%E6%BB%A4%E6%89%A7%E8%A1%8C.md)。

## D

### **Dangerous Pattern**
> 任何 mode 下都拦的命令模式（`rm -rf /`、fork bomb 等）。详见 [03-Bash危险模式](../07-%E7%AC%AC7%E7%AB%A0-%E5%AE%89%E5%85%A8%E4%B8%8E%E6%9D%83%E9%99%90/03-Bash%E5%8D%B1%E9%99%A9%E6%A8%A1%E5%BC%8F.md)。

### **Defense in Depth（纵深防御）**
> 安全设计哲学：多层防护，任一层失败下一层兜底。详见 [05-安全设计哲学](../07-%E7%AC%AC7%E7%AB%A0-%E5%AE%89%E5%85%A8%E4%B8%8E%E6%9D%83%E9%99%90/05-%E5%AE%89%E5%85%A8%E8%AE%BE%E8%AE%A1%E5%93%B2%E5%AD%A6.md)。

### **Default Mode**
> Claude Code 默认权限模式。只读直接放行，写/执行类弹窗。详见 [01-5种权限模式](../07-%E7%AC%AC7%E7%AB%A0-%E5%AE%89%E5%85%A8%E4%B8%8E%E6%9D%83%E9%99%90/01-5%E7%A7%8D%E6%9D%83%E9%99%90%E6%A8%A1%E5%BC%8F.md)。

### **Destructive**
> Tool 标志。表示该工具会做不可逆操作（删除/覆盖/发送）。触发权限弹窗。

### **`DYNAMIC_BOUNDARY`**
> Claude Code system prompt 里的边界标记。前面是可缓存内容，后面是动态内容。详见 [05-PromptCache技巧](../05-%E7%AC%AC5%E7%AB%A0-System-Prompt%E5%B7%A5%E7%A8%8B/05-PromptCache%E6%8A%80%E5%B7%A7.md)。

## E

### **Edit Tool**
> 精确字符串替换工具。要求 old_string **唯一匹配**。详见 [06-设计哲学5条](../03-%E7%AC%AC3%E7%AB%A0-%E5%B7%A5%E5%85%B7%E7%B3%BB%E7%BB%9F/06-%E8%AE%BE%E8%AE%A1%E5%93%B2%E5%AD%A65%E6%9D%A1.md)。

### **Explore Agent**
> Claude Code 内置 SubAgent，READ-ONLY 搜索专家。详见 [02-AgentTool与内置Agent](../06-%E7%AC%AC6%E7%AB%A0-%E5%A4%9AAgent%E5%8D%8F%E4%BD%9C/02-AgentTool%E4%B8%8E%E5%86%85%E7%BD%AEAgent.md)。

---

## F

### **Fallback Model**
> 主模型故障时自动切换的备用模型。详见 [05-工业级护栏](../02-%E7%AC%AC2%E7%AB%A0-Agent-Loop%E4%B8%BB%E5%BE%AA%E7%8E%AF/05-%E5%B7%A5%E4%B8%9A%E7%BA%A7%E6%8A%A4%E6%A0%8F.md)。

### **Feature Gate**
> 编译时开关，决定某段代码是否进入打包产物。Claude Code 用 Bun 的 `feature()` 内建函数。

### **Fork**
> 不指定 `subagent_type` 时的派生方式，**继承主 Agent 全部上下文**，共享 prompt cache。详见 [03-Fork与子Agent写法](../06-%E7%AC%AC6%E7%AB%A0-%E5%A4%9AAgent%E5%8D%8F%E4%BD%9C/03-Fork%E4%B8%8E%E5%AD%90Agent%E5%86%99%E6%B3%95.md)。

---

## H

### **Haiku**
> Anthropic 最便宜的 Claude 模型，价格 ≈ Sonnet 的 1/12。常用于 SubAgent / 简单分类任务。

### **Hooks**
> 用户自定义拦截脚本。如 `PreToolUse` 在工具执行前跑用户脚本。详见 [04-物理沙箱与Hooks](../07-%E7%AC%AC7%E7%AB%A0-%E5%AE%89%E5%85%A8%E4%B8%8E%E6%9D%83%E9%99%90/04-%E7%89%A9%E7%90%86%E6%B2%99%E7%AE%B1%E4%B8%8EHooks.md)。

---

## I

### **`is_concurrency_safe`**
> Tool 标志。决定多个工具调用能否并发执行。

### **`is_destructive`**
> Tool 标志。触发权限弹窗确认。

### **`is_read_only`**
> Tool 标志。Plan Mode 下只允许 read-only 工具。

---

## J

### **JSON Schema**
> 描述工具 input 参数的标准格式。`{type, properties, required}`。

---

## K

### **KAIROS**
> Claude Code 内部代号，完全自主代理模式（PR 订阅、心跳、推送通知）。多数 KAIROS 模块在 npm 包中被 feature gate 移除。

### **Killswitch**
> Anthropic 远程紧急开关，能禁用客户端某些功能（如 bypass mode）。详见源码 `bypassPermissionsKillswitch.ts`。

---

## L

### **LLM**
> Large Language Model 大语言模型。Agent 的"大脑"。

---

## M

### **MCP（Model Context Protocol）**
> Anthropic 提出的"模型上下文协议"，让外部工具/资源接入 Agent。

### **`maxResultSizeChars`**
> 工具结果最大字符数。超过持久化到文件，给模型返回路径而不是全内容。

### **`maxTurns`**
> 主循环轮次上限，防死循环烧钱。详见 [05-工业级护栏](../02-%E7%AC%AC2%E7%AB%A0-Agent-Loop%E4%B8%BB%E5%BE%AA%E7%8E%AF/05-%E5%B7%A5%E4%B8%9A%E7%BA%A7%E6%8A%A4%E6%A0%8F.md)。

### **`messages[]`**
> Agent 的短期记忆。"只增不减的录像带"，每轮追加 2 段（模型回复 + 工具结果）。

### **Micro-Compact**
> 微压缩。只压一段特别长的内容（如某条 tool_result），不动整个对话。详见 [05-高级压缩机制](../04-%E7%AC%AC4%E7%AB%A0-%E4%B8%8A%E4%B8%8B%E6%96%87%E7%AE%A1%E7%90%86/05-%E9%AB%98%E7%BA%A7%E5%8E%8B%E7%BC%A9%E6%9C%BA%E5%88%B6.md)。

---

## N

### **`NO_TOOLS_PREAMBLE`**
> Compact prompt 开头的强制声明："CRITICAL: Respond with TEXT ONLY"。防止模型在压缩任务里乱调工具。详见 [02-AutoCompact压缩](../04-%E7%AC%AC4%E7%AB%A0-%E4%B8%8A%E4%B8%8B%E6%96%87%E7%AE%A1%E7%90%86/02-AutoCompact%E5%8E%8B%E7%BC%A9.md)。

---

## O

### **`omitClaudeMd`**
> SubAgent 配置标志。`true` 时不加载项目 CLAUDE.md。Explore Agent 用此节省 token。

---

## P

### **Permission Mode**
> Claude Code 的权限模式。5 种：Plan / Default / Accept Edits / Bypass / Auto。详见 [01-5种权限模式](../07-%E7%AC%AC7%E7%AB%A0-%E5%AE%89%E5%85%A8%E4%B8%8E%E6%9D%83%E9%99%90/01-5%E7%A7%8D%E6%9D%83%E9%99%90%E6%A8%A1%E5%BC%8F.md)。

### **Plan Mode**
> 只读模式。物理过滤掉所有写工具。详见 [01-5种权限模式](../07-%E7%AC%AC7%E7%AB%A0-%E5%AE%89%E5%85%A8%E4%B8%8E%E6%9D%83%E9%99%90/01-5%E7%A7%8D%E6%9D%83%E9%99%90%E6%A8%A1%E5%BC%8F.md)。

### **`PreToolUse` Hook**
> 用户自定义的"工具执行前"钩子脚本。

### **Prompt Cache**
> Anthropic 的 prompt 缓存。命中可省 90% 费用。详见 [05-PromptCache技巧](../05-%E7%AC%AC5%E7%AB%A0-System-Prompt%E5%B7%A5%E7%A8%8B/05-PromptCache%E6%8A%80%E5%B7%A7.md)。

---

## Q

### **`query.ts`**
> Claude Code 主循环的源码文件，1729 行。

### **QueryEngine**
> SDK / 无头模式的查询引擎入口（`src/QueryEngine.ts`）。

---

## R

### **ReAct**
> Reasoning + Acting。Agent 经典模式：思考 → 行动 → 观察 → 再思考。

### **Read Tool**
> 读文件工具。强制返回 `<num>: <content>` 行号格式（为 Edit 服务）。

### **runTools**
> Claude Code 的传统工具执行方式：等流式完才并发执行。详见 [04-工具执行的两种模式](../02-%E7%AC%AC2%E7%AB%A0-Agent-Loop%E4%B8%BB%E5%BE%AA%E7%8E%AF/04-%E5%B7%A5%E5%85%B7%E6%89%A7%E8%A1%8C%E7%9A%84%E4%B8%A4%E7%A7%8D%E6%A8%A1%E5%BC%8F.md)。

---

## S

### **Sandbox（沙箱）**
> 物理隔离。macOS 用 `sandbox-exec`，Linux 用 `seccomp`。详见 [04-物理沙箱与Hooks](../07-%E7%AC%AC7%E7%AB%A0-%E5%AE%89%E5%85%A8%E4%B8%8E%E6%9D%83%E9%99%90/04-%E7%89%A9%E7%90%86%E6%B2%99%E7%AE%B1%E4%B8%8EHooks.md)。

### **Section**
> Claude Code system prompt 的分节。每节由 `getXxxSection()` 函数生成。详见 [01-入职手册的13节](../05-%E7%AC%AC5%E7%AB%A0-System-Prompt%E5%B7%A5%E7%A8%8B/01-%E5%85%A5%E8%81%8C%E6%89%8B%E5%86%8C%E7%9A%8413%E8%8A%82.md)。

### **Sonnet**
> Anthropic 中端 Claude 模型，性价比最高。Claude Code 默认主模型。

### **`stop_reason`**
> Anthropic API 响应字段。`end_turn` / `tool_use` / `max_tokens` / `stop_sequence` 等。**Claude Code 不完全信任它**。

### **StreamingToolExecutor**
> Claude Code 的流式工具执行器：模型还在打字就开始执行工具。详见 [04-工具执行的两种模式](../02-%E7%AC%AC2%E7%AB%A0-Agent-Loop%E4%B8%BB%E5%BE%AA%E7%8E%AF/04-%E5%B7%A5%E5%85%B7%E6%89%A7%E8%A1%8C%E7%9A%84%E4%B8%A4%E7%A7%8D%E6%A8%A1%E5%BC%8F.md)。

### **SubAgent**
> 子代理。主 Agent 派生的独立 context 小 Agent。详见 [00-章节总览](../06-%E7%AC%AC6%E7%AB%A0-%E5%A4%9AAgent%E5%8D%8F%E4%BD%9C/00-%E7%AB%A0%E8%8A%82%E6%80%BB%E8%A7%88.md)。

### **System Prompt**
> 模型每次回答前先读的"入职手册"。详见 [00-章节总览](../05-%E7%AC%AC5%E7%AB%A0-System-Prompt%E5%B7%A5%E7%A8%8B/00-%E7%AB%A0%E8%8A%82%E6%80%BB%E8%A7%88.md)。

## T

### **Task Tool**
> = AgentTool。派生 SubAgent 的工具。

### **TodoWrite**
> Claude Code 的任务清单工具。模型自己维护 todo 列表。详见 [03-TodoWrite外部记忆](../04-%E7%AC%AC4%E7%AB%A0-%E4%B8%8A%E4%B8%8B%E6%96%87%E7%AE%A1%E7%90%86/03-TodoWrite%E5%A4%96%E9%83%A8%E8%AE%B0%E5%BF%86.md)。

### **Token**
> LLM 处理文本的最小单位。英文 ≈ 0.75 单词，中文 ≈ 0.5-0.65 字符。

### **Tool Use Protocol**
> Anthropic API 的工具调用协议。详见 [01-Tool-Use协议基础](../03-%E7%AC%AC3%E7%AB%A0-%E5%B7%A5%E5%85%B7%E7%B3%BB%E7%BB%9F/01-Tool-Use%E5%8D%8F%E8%AE%AE%E5%9F%BA%E7%A1%80.md)。

### **`tool_result`**
> 工具执行后的结果块，用 `role: "user"` 塞回 messages（**不是 role: "tool"**！）。

### **`toolUseBlocks`**
> 本轮模型想用的工具列表。`length === 0` 是循环退出信号。
