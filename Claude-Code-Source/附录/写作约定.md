## 📑 编号约定

| 文件名 | 含义 |
|---|---|
| `00-章节总览.md` | 每章的入口 + 地图 |
| `01-xxx.md` ~ `0N-xxx.md` | 顺序学习的小节 |
| `99-代码-xxx.md` | 代码合集（独立编号，方便复习） |

每章末尾的 99 文件是**该章所有代码的整合可运行版本**。

---

## 🐍 Python 代码注释约定

- **每一段重要逻辑前都有中文注释**
- **新出现的语法**单独在小节末尾"Python 速记"表里讲
- **`⭐` 标记关键行**：
  ```python
  while True:                              # ⭐ 主循环
  ```
- **`# === A. xxx ===`** 标记代码段落
