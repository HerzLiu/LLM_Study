LLM 是现代 Agent 的"**大脑**"。
本章解答 1 个核心问题:**这个大脑是怎么工作的?**

> ⚠️ **本章是"速览版"** —— 因为 LLM 的完整原理在 [Happy-LLM](../../Happy-LLM/00-%E6%80%BB%E8%A7%88.md) 已经讲透了。

> 如果你**没读过 Happy-LLM**,强烈建议**先去补**。

- [ ] 知道 LLM 是 **Decoder-Only Transformer**(细节去 Happy-LLM)

- [ ] 会用 Hugging Face Transformers 调用本地模型
