## 🎬 一句话故事

前 10 章我们做的 Agent 都是**用现成 LLM**。
但现成 LLM 在复杂任务上**经常不够好** —— 推理弱、不会用工具、不会自我改进。

> **怎么办?训练它!**

→ 本章引入 **Agentic-RL**(基于强化学习的智能体训练):
- 用 **SFT** 教 Agent **基本格式 + 推理模式**
- 用 **GRPO** 让 Agent **自主探索更优策略**
- 终极目标:**Agent 自己进化,超越训练数据**

## ⚠️ 学习建议

1. **本章是全书最难的一章**,涉及深度学习训练原理
2. **不必一上来就跑完整训练**,先理解概念
3. **跨书参考**:[Happy-LLM RLHF](../../Happy-LLM/04-%E7%AC%AC4%E7%AB%A0-%E5%A4%A7%E8%AF%AD%E8%A8%80%E6%A8%A1%E5%9E%8B/07-RLHF%E4%BA%BA%E7%B1%BB%E5%8F%8D%E9%A6%88%E5%BC%BA%E5%8C%96%E5%AD%A6%E4%B9%A0.md) 是必读前置
4. **硬件要求**:**至少 8GB GPU 显存**(否则跑不了完整训练)
5. **新手友好路径**:看理论 → 跑快速示例 → 调参 → 再读论文
