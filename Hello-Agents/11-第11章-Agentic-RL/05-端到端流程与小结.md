## 🐍 11.5.1 完整端到端代码

```python
from hello_agents.tools import RLTrainingTool
import json

rl_tool = RLTrainingTool()

# === Phase 1: 加载数据 ===
print("=== Phase 1: 加载 GSM8K 数据 ===")
data_info = rl_tool.run({
    "action": "load_dataset",
    "format": "sft",
    "max_samples": 1000,
})
print(f"数据集大小: {json.loads(data_info)['dataset_size']}")


# === Phase 2: SFT 训练(教格式) ===
print("\n=== Phase 2: SFT 训练 ===")
sft_result = rl_tool.run({
    "action": "train",
    "algorithm": "sft",
    "model_name": "Qwen/Qwen3-0.6B",
    "output_dir": "./models/sft_model",
    "max_samples": 1000,
    "num_epochs": 3,
    "batch_size": 8,
    "learning_rate": 5e-5,
    "use_lora": True,
    "lora_rank": 16,
    "lora_alpha": 32,
})
print(f"✓ SFT 完成: {sft_result['model_path']}")


# === Phase 3: 评估 SFT 模型 ===
print("\n=== Phase 3: 评估 SFT 模型 ===")
sft_eval = rl_tool.run({
    "action": "evaluate",
    "model_path": "./models/sft_model",
    "max_samples": 100,
    "use_lora": True,
})
sft_acc = json.loads(sft_eval)['accuracy']
print(f"SFT 准确率: {sft_acc}")


# === Phase 4: GRPO 训练(优化策略) ===
print("\n=== Phase 4: GRPO 训练 ===")
grpo_result = rl_tool.run({
    "action": "train",
    "algorithm": "grpo",
    "model_name": "./models/sft_model",   # ⭐ 从 SFT 模型开始
    "output_dir": "./models/grpo_model",
    "max_samples": 1000,
    "num_generations": 8,
    "num_epochs": 2,
    "batch_size": 16,
    "learning_rate": 5e-6,                # ⭐ GRPO 用更小学习率
    "use_lora": True,
})
print(f"✓ GRPO 完成: {grpo_result['model_path']}")


# === Phase 5: 评估 GRPO 模型 ===
print("\n=== Phase 5: 评估 GRPO 模型 ===")
grpo_eval = rl_tool.run({
    "action": "evaluate",
    "model_path": "./models/grpo_model",
    "max_samples": 100,
    "use_lora": True,
})
grpo_acc = json.loads(grpo_eval)['accuracy']
print(f"GRPO 准确率: {grpo_acc}")


# === Phase 6: 效果对比 ===
print("\n=== 训练效果对比 ===")
print(f"原始模型:    ~5%")
print(f"SFT 后:     {sft_acc}")
print(f"GRPO 后:    {grpo_acc}")
print(f"提升:        +{(grpo_acc - sft_acc):.1%}")
```

→ **完整 Pipeline 跑完**:从原始模型 → 推理 Agent。

## 📊 11.5.2 典型训练成果

### Qwen3-0.6B + GSM8K(1000 样本)

| 阶段 | 准确率 | 提升 |
|---|---|---|
| **原始模型** | ~5% | – |
| **SFT 后** | ~45% | **+40%** |
| **GRPO 后** | ~65% | **+20%** |

→ **总提升 60%**,**小模型也能见证 RL 的威力**。

### 大模型的"Aha Moment"

```
Qwen2.5-7B + GSM8K + GRPO + 长时间训练
   ↓
模型自发学会:
   "Wait, let me reconsider this step..."
   "Actually, I made a mistake. Let me redo..."
   ↓
这就是 DeepSeek-R1 的"啊哈时刻"
```

→ **小模型不容易出现,但大模型 + 长训练能复现**。

## 🌟 11.5.3 Agentic-RL 的更广前景

### 应用 1:**推理模型**(R1 风格)

```
任务: 数学/物理/代码
GRPO + 答案正确性奖励
   ↓
模型自主学会 长 CoT 推理
```

### 应用 2:**工具使用 Agent**

```
任务: 多步工具调用
奖励 = 任务完成 + 调用效率
   ↓
学会:
- 哪些工具组合最优
- 减少不必要调用
- 错误恢复
```

### 应用 3:**多模态 Agent**

```
任务: 视觉理解 + 推理
奖励 = 视觉判断准确率
   ↓
学会:
- 何时看图
- 看图哪部分
- 视觉 + 文本融合
```

### 应用 4:**自主探索 Agent**

```
任务: 开放域研究
奖励 = 信息收集质量 + 综合能力
   ↓
学会:
- 何时该搜索
- 何时该思考
- 反思 + 迭代
```

## ⚠️ 11.5.4 整章踩坑清单

| 坑 | 解法 |
|---|---|
| 跳过 SFT 直接 GRPO | **必须 SFT 打基础** |
| GRPO 学习率太大 | 降到 5e-6 |
| `batch_size` 不能被 G 整除 | 必须能整除 |
| 奖励函数有 bug | **先独立测试**奖励函数 |
| 小模型不出"aha 时刻" | **正常**,要 7B+ 才见 |
| 显存爆炸 | 减 G / batch / rank |
| Loss 不下降 | 检查数据格式 + 学习率 |
| 评估准确率没上升 | 训得不够久 + 数据太少 |

## 📝 11.6 章节小结

### 核心收获

#### 收获 1:**理论基石**
- LLM 训练 **2 阶段**:预训练 + 后训练
- 后训练 **3 步**:SFT → RM → RL
- **PBRFT vs Agentic-RL** 的 MDP 形式化差异
- Agentic-RL **6 大核心能力**

#### 收获 2:**实战 Pipeline**
```
GSM8K (数据) → SFT (基础) → GRPO (优化) → 评估
```

#### 收获 3:**关键算法**
- **LoRA**:省 256 倍参数
- **GRPO**:比 PPO 更简单更稳

#### 收获 4:**真实效果**
- Qwen3-0.6B + GRPO 在 GSM8K 上**5% → 65%**
- DeepSeek-R1 的 **aha moment** 是 GRPO 的极致体现

## 🎯 11.6.1 设计哲学

### 哲学 1:**站在巨人的肩膀上**
- 不重写 RL 框架,**用 TRL**
- 不训大模型,**用 Qwen3-0.6B + LoRA**
- 不造数据,**用 GSM8K**

### 哲学 2:**简化 + 解耦**
- 数据 / 奖励 / 训练器 **三层解耦**
- 统一接口 `RLTrainingTool` 屏蔽底层
- 支持**自定义扩展**

### 哲学 3:**SFT 优先,RL 优化**
- **永远先 SFT 再 RL**
- 不要跳步骤
