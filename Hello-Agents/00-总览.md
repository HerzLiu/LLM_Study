## 📖 怎么用这份笔记

1. **从总览进入** → 按章节顺序读

4. **遇到 `[[双链]]` 就点进去**，回头按 `Ctrl+Alt+←` 返回

## 🎯 学习路径推荐

### 路径 A：完全新手（推荐）
```
先读 Happy-LLM（LLM 原理）
  ↓
第 1 章（认识 Agent）
  ↓
第 2 章（发展史）
  ↓
第 4 章（经典范式 ReAct / Plan-and-Solve）
  ↓
第 6 章（主流框架）
  ↓
第 8 章（Memory + RAG）
  ↓
第 10 章（MCP 协议）
```

### 路径 B：想低代码搭 Agent
```
第 1 章（基础认知）
  ↓
第 5 章（Coze / Dify / n8n 低代码）
  ↓
直接搭项目
```

### 路径 C：想自建框架
```
第 1, 4 章（理论 + 范式）
  ↓
第 6 章（学主流框架）
  ↓
第 7 章（手撕 HelloAgents 框架）
  ↓
第 9 章（上下文工程）
```

### 路径 D：想训练 Agent 模型
```
回到 Happy-LLM 第 4-6 章（必备）
  ↓
本书第 11 章（Agentic-RL + GRPO）
```
