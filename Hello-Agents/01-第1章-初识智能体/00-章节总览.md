## 🎬 一句话故事

"智能体（Agent）"是当下 AI 圈的**绝对顶流**：从 GitHub Copilot 到 ChatGPT 高级数据分析，背后都是 Agent。
**但什么是 Agent？** 这一章就是回答这个问题——**从"AI 助手"到"会自己办事的 AI"，差的就是 Agent 那一步**。

## 📝 本章一句话小结

**Agent = 能感知 + 能思考 + 能行动 + 有自主性的实体**。
**LLM Agent = 用 LLM 当"大脑"，通过 Thought-Action-Observation 循环办事**。
和死板的 Workflow 不同，**Agent 是"目标-委托"模式，能动态推理决策**。
