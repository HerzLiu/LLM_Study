## 🧭 本章历史时间线

```
1950s ──── 图灵测试,符号主义萌芽
1956 ──── 达特茅斯会议,AI 正式诞生
1966 ──── ELIZA（基于规则的聊天机器人）
1968-70 ── SHRDLU（积木世界自然语言交互）
1970s ──── MYCIN（专家系统巅峰）
1976 ──── 物理符号系统假说（纽厄尔 + 西蒙）
1980s ──── 心智社会理论（明斯基）+ 联结主义复苏
1990s ──── 强化学习理论发展(TD-Gammon)
2012 ──── AlexNet,深度学习突破
2016 ──── AlphaGo 击败李世石
2017 ──── Transformer 论文,Attention is All You Need
2018-22 ── BERT / GPT / ChatGPT,预训练 + 涌现能力
2023+ ──── LLM Agent 时代
            (AutoGPT/BabyAGI → CrewAI/AutoGen/LangGraph)
```

---

## 📝 本章一句话小结

**Agent 的发展 = AI 三大思潮的接力赛**:
- 符号主义教 AI **逻辑推理**(脆弱)
- 联结主义教 AI **感知世界**(黑箱)
- 行为主义教 AI **试错决策**(慢)
- LLM **把三者融合**,成就了今天的 Agent
