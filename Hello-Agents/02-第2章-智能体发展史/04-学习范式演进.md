# 2.4 学习范式的演进与现代智能体

⬅ [03-心智社会](03-%E5%BF%83%E6%99%BA%E7%A4%BE%E4%BC%9A.md)	|	➡ [进入第 3 章](../03-%E7%AC%AC3%E7%AB%A0-%E5%A4%A7%E8%AF%AD%E8%A8%80%E6%A8%A1%E5%9E%8B%E5%9F%BA%E7%A1%80/00-%E7%AB%A0%E8%8A%82%E6%80%BB%E8%A7%88.md)

## 🎬 故事比喻:从"教书"到"自学"

教育孩子有两种思路:

| 方法 | 比喻 |
|---|---|
| **手把手教规则** | "看到红灯就停" —— 死记硬背 |
| **让孩子自己学** | 带他去马路边观察 100 次 —— 自己悟出来 |

→ AI 也是。前一种是 [符号主义](01-%E7%AC%A6%E5%8F%B7%E4%B8%BB%E4%B9%89%E6%97%A9%E6%9C%9F%E6%99%BA%E8%83%BD%E4%BD%93.md),后一种是**学习范式**。

本节看**学习范式 4 大阶段**:**联结主义 → 强化学习 → 预训练 → LLM Agent**。

---

## 🧠 2.4.1 从符号到联结(Connectionism)

### 80 年代的复兴

符号主义遇阻,**联结主义**重新登场。

> **核心理念**:模仿**生物大脑神经网络**结构,**自下而上**地学习。

### 与符号主义的根本对比

| | 符号主义 | **联结主义** |
|---|---|---|
| **思路** | 自上而下 | **自下而上** |
| **知识表示** | 明确的规则 / 符号 | **连接权重**(分布在神经元里) |
| **处理单元** | 复杂的逻辑推理 | **简单的神经元** |
| **能力来源** | 设计者编写 | **从数据中学** |
| **类比** | 图书管理员 | **牙牙学语的孩子** |

### 3 个核心特征

#### 特征 1:知识的分布式表示
- 知识**不存在某个明确地方**
- 而是**分布在大量神经元的连接权重里**
- → 整个网络的连接模式 **本身就是知识**

#### 特征 2:简单的处理单元
- 每个神经元只做**简单计算**:加权输入 + 激活函数 + 输出
- 复杂智能来自**大量神经元的协同**

#### 特征 3:通过学习调整权重
- **不是**手工编程
- **而是**通过样本 + 学习算法(如反向传播)**自动调整权重**
- 训练完后,网络就"会"了

### ⭐ 范式转变

> **符号主义**:把人类知识**显式编码给机器**
> **联结主义**:**创造能像人类一样学习知识的机器**

→ 这是**最根本的思想转变**。

### 联结主义的崛起

| 年份 | 里程碑 |
|---|---|
| 1986 | **反向传播算法**普及(Hinton 等) |
| 2012 | **AlexNet** 在 ImageNet 大胜 → **深度学习时代** |
| 2015+ | CNN / RNN / Transformer 等架构成熟 |

→ 详见 [Happy-LLM 词向量演进](../../Happy-LLM/01-%E7%AC%AC1%E7%AB%A0-NLP%E5%9F%BA%E7%A1%80%E6%A6%82%E5%BF%B5/04-%E6%96%87%E6%9C%AC%E8%A1%A8%E7%A4%BA%E6%BC%94%E8%BF%9B.md)。

### 但还不够

联结主义解决了**感知问题**(图像、声音、文本理解),
但**没解决决策问题** —— "我现在该做什么?"

→ 需要下一个范式:**强化学习**。

## 🎮 2.4.2 基于强化学习的智能体

### 行为主义登场

> **强化学习(Reinforcement Learning, RL)** = 通过**试错**学最优决策
> = 从**与环境的交互**中学,而不是从静态数据集

### 经典案例:AlphaGo

```
AlphaGo 看棋盘(状态)
   ↓
决定落子(行动)
   ↓
游戏结束 → 赢/输(奖励)
   ↓
更新策略 → 下次怎么走更好
```

**关键**:
- **数百万次自我对弈**
- **不依赖人类棋谱**
- 最终**超越人类**

### 强化学习核心 5 要素

| 要素 | 含义 | AlphaGo 例子 |
|---|---|---|
| **智能体**(Agent) | 学习者 | AlphaGo 程序 |
| **环境**(Environment) | 外部世界 | 围棋规则 + 对手 |
| **状态**(State, S) | 当前情况 | 棋盘布局 |
| **行动**(Action, A) | 能采取的操作 | 落子位置 |
| **奖励**(Reward, R) | 反馈信号 | 赢 +1 / 输 -1 |

### 工作循环

```
        ┌────── 智能体 ──────┐
        │                       │
       状态 S_t           行动 A_t
        ↑                       │
        │                       ↓
        └────── 环境 ←───────┘
                  │
              新状态 S_{t+1}
              奖励 R_{t+1}
```

### ⭐ 关键概念:累积奖励(Cumulative Reward)

> **智能体不追求"当前一步最大奖励",而是追求"长期总奖励"。**

例:围棋的"**弃子**"策略
- 当前**主动让出**几个子(短期奖励为负)
- 但能**控制大局**(长期奖励大正)
- → 智能体必须**有远见**

### 强化学习的优势

- **不需要标注数据**(不像监督学习)
- **能学复杂动态环境**(围棋、游戏、机器人控制)
- **能发现人类没想到的策略**(AlphaGo Zero)

### 局限

- **数据需求大**(几百万局对弈)
- **缺乏先验知识**(从零开始学)
- **泛化差**(围棋训练的模型不能玩象棋)

→ 这促使下一个范式:**预训练**。

---

## 📚 2.4.3 基于大规模数据的预训练

### 突破口在 NLP

如何让智能体**在学具体任务前先具备世界常识**?

**预训练-微调(Pre-training, Fine-tuning)** 范式横空出世。

### 旧方式(2018 年之前)

```
任务 1: 情感分类
  ↓ 收集几千条标注数据 → 从零训一个模型 A

任务 2: 机器翻译
  ↓ 收集几十万条平行语料 → 从零训一个模型 B

任务 3: 命名实体识别
  ↓ 收集标注数据 → 从零训一个模型 C
```

**问题**:
- ❌ **知识不共享** —— 模型 A 学到的"猫是动物"模型 B 又得重学
- ❌ **数据标注贵**
- ❌ **每个任务从零开始**

### 新方式:预训练 + 微调

```
Step 1: 预训练(自监督)
  在 **互联网海量文本** 上训一个超大模型
  目标: 预测下一个词(不需要标注)
  ↓
Step 2: 微调
  用**少量任务标注数据**调整模型
  适配具体下游任务
```

### ⭐ 关键变化

|        | 旧方式       | **预训练-微调**    |
| ------ | --------- | ------------- |
| 知识来源   | 任务标注数据    | **海量互联网文本**   |
| 通用性    | 一个模型一个任务  | **一个底模适配多任务** |
| 数据需求   | 每任务几万~几十万 | 微调只需**几百~几千** |
| 知识获取瓶颈 | 严重        | **极大缓解**      |

→ 这**彻底打破了符号主义的"知识获取瓶颈"** —— **互联网文本就是世界知识库**。

### LLM 诞生 + 涌现能力

预训练规模继续放大(参数 / 数据 / 算力),
**当跨越某个阈值,涌现能力(Emergent Abilities)**出现:

| 能力             | 解释                   |
| -------------- | -------------------- |
| **上下文学习**(ICL) | prompt 里给几个例子就能学新任务  |
| **思维链**(CoT)   | 引导 LLM 一步步推理,大幅提升准确性 |

→ 详见 [Happy-LLM LLM 四大能力](../../Happy-LLM/04-%E7%AC%AC4%E7%AB%A0-%E5%A4%A7%E8%AF%AD%E8%A8%80%E6%A8%A1%E5%9E%8B/02-LLM%E5%9B%9B%E5%A4%A7%E8%83%BD%E5%8A%9B.md)。

→ 这标志着 **LLM 不再仅仅是语言模型** —— **它兼具知识库 + 通用推理引擎**。

## 🤖 2.4.4 基于大语言模型的智能体

至此,**几大技术拼图齐了**:

| 拼图 | 来源 |
|---|---|
| **逻辑推理框架** | 符号主义 |
| **学习能力** | 联结主义(神经网络) |
| **决策能力** | 强化学习 |
| **世界知识 + 通用推理** | 预训练 LLM |

→ **LLM Agent** 把这些**融为一体**。

### LLM 驱动 Agent 的核心架构

```
                  ┌─────────────────────┐
                  │    环境 Environment   │
                  └──────────┬──────────┘
                              │ 观察
                              ▼
              ┌──────────────────────────┐
              │     感知模块 Perception     │
              └──────────────┬──────────┘
                              │
                              ▼
   ┌──────────┐    ┌──────────────────┐
   │ 记忆 Memory│ ◀──▶│   规划模块 Planning│
   └──────────┘    │   (反思 + 自我批判)  │
                    └──────────┬──────────┘
                              │
                              ▼
                  ┌──────────────────────┐
                  │    LLM (中枢大脑)      │
                  │   推理 + 决策          │
                  └──────────┬──────────┘
                              │ 工具调用
                              ▼
                  ┌──────────────────────┐
                  │   工具箱 Tool Use      │
                  │  代码 / 搜索 / API      │
                  └──────────┬──────────┘
                              │
                              ▼ 执行
                  ┌──────────────────────┐
                  │   执行模块 Execution    │
                  └──────────┬──────────┘
                              │ 改变环境
                              ▼
                  环境状态变化 → 新观察(循环)
```

### 5 大模块对应历史

| 模块          | 历史源头            |
| ----------- | --------------- |
| **LLM 中枢**  | 联结主义(深度学习)+ 预训练 |
| **规划**      | 符号主义的逻辑推理       |
| **工具调用**    | 符号主义的过程式操作      |
| **记忆**      | 心智社会的"经验存储"     |
| **执行 + 反馈** | 强化学习的"行动-观察"循环  |

→ **LLM Agent = AI 思想史的集大成者**。

## 🗺 2.4.5 智能体发展关键节点(全景图)

### 三大思潮接力赛

```
┌────────────── 符号主义 (Symbolism) ──────────────┐
│  纽厄尔/西蒙/明斯基                                │
│  专家系统、SHRDLU、"深蓝"                           │
│  → 强逻辑推理,但脆弱                                │
└────────────────────────────────────────────────┘

┌────────────── 联结主义 (Connectionism) ───────┐
│  Hinton 等                                        │
│  反向传播 → CNN → Transformer                      │
│  → 强感知,但黑箱                                   │
└────────────────────────────────────────────────┘

┌────────────── 行为主义 (Behaviorism) ─────────┐
│  → 强化学习                                       │
│  TD-Gammon → AlphaGo                              │
│  → 强决策,但慢                                    │
└────────────────────────────────────────────────┘

                        ⬇ 21 世纪 20 年代

┌──────────── LLM Agent (神经符号融合) ─────────┐
│  GPT 系列 + 工具调用 + 多 Agent 协作            │
│  → 集三家之长                                     │
└────────────────────────────────────────────────┘
```

### 关键时间线

```
1956 ── 达特茅斯会议 (AI 正式诞生)
1966 ── ELIZA (规则聊天)
1968 ── SHRDLU (积木世界)
1976 ── 物理符号系统假说 (PSSH)
1980s ─ 专家系统商业化、心智社会理论、联结主义复苏
1992 ── TD-Gammon (RL 战胜人类双陆棋冠军)
2012 ── AlexNet (深度学习突破)
2016 ── AlphaGo 击败李世石
2017 ── Transformer 论文
2018 ── BERT / GPT-1
2020 ── GPT-3 (175B 涌现能力)
2022.11 ─ ChatGPT
2023 ── AutoGPT / BabyAGI / LangChain (Agent 元年)
2024 ── CrewAI / AutoGen / LangGraph
2025+ ─ Agentic-RL / MCP 协议 / 多模态 Agent
```

## ⚠️ 小白避坑

1. **三大思潮不是非此即彼**
   - 现代 AI = **融合**
   - 别把 "符号 vs 神经" 当成对立面
2. **预训练 ≠ 微调**
   - 预训练 = 通用知识
   - 微调 = 任务适配
   - 详见 [Happy-LLM 三阶段](../../Happy-LLM/04-%E7%AC%AC4%E7%AB%A0-%E5%A4%A7%E8%AF%AD%E8%A8%80%E6%A8%A1%E5%9E%8B/04-%E8%AE%AD%E7%BB%83%E4%B8%89%E9%98%B6%E6%AE%B5%E5%85%A8%E6%99%AF.md)
3. **LLM Agent 不是终点**
   - **推理模型**(o1 / R1)、**多模态 Agent**、**Agentic-RL**(本书第 11 章)正在路上
