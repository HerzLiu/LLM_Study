# 2.1 基于符号与逻辑的早期智能体

⬅ [00-章节总览](00-%E7%AB%A0%E8%8A%82%E6%80%BB%E8%A7%88.md)	|	➡ [02-ELIZA与规则系统](02-ELIZA%E4%B8%8E%E8%A7%84%E5%88%99%E7%B3%BB%E7%BB%9F.md)

---

## 🎬 故事比喻：百科全书 + 推理引擎

想象你给一个机器人**装两样东西**：
- **一本超厚的百科全书**(包含"IF 发烧 + 咳嗽 THEN 感冒"这种规则)
- **一个推理引擎**(给它一个症状,它能在百科里查规则并得出结论)

这就是 **符号主义 AI** 的核心思想 —— **智能 = 符号 + 逻辑推理**。

→ 这一节我们看这条路是怎么走通的,又是怎么走死的。

---

## 🧠 2.1.1 物理符号系统假说(PSSH)

### 提出者

**艾伦·纽厄尔(Allen Newell)** + **赫伯特·西蒙(Herbert A. Simon)**,1976 年。
**两位图灵奖得主联手立下的"AI 第一公理"**。

### 假说内容

> **物理符号系统假说(Physical Symbol System Hypothesis, PSSH)**
> **任何一个能展现通用智能行为的系统,本质上必然是一个"物理符号系统"。**

具体两个论断:

| 论断 | 通俗解释 |
|---|---|
| **充分性论断** | 物理符号系统就**够了** —— 用符号操作能做出通用智能 |
| **必要性论断** | 物理符号系统是**必需的** —— 想做出智能,**必须**是符号系统 |

### 什么是"物理符号系统"?

```
一组「可被区分的符号」+ 一系列「对符号操作的过程」
   ↓                          ↓
比如词语、概念        创建、修改、复制、销毁符号结构
```

### ⭐ 这个假说为什么牛?

它把"人类心智"这个**哲学问题**,转化成了"计算机上能不能实现"的**工程问题**。
→ **给了 AI 圈整整 30 年的研究方向**。

→ 但**对不对呢**?这是 AI 界辩论至今的核心 —— 后面我们会看到 LLM 既部分支持又部分挑战这个假说。

---

## 🏥 2.1.2 专家系统 —— 符号主义巅峰

### 什么是专家系统?

> **专家系统 = 模拟人类专家在特定领域的解决问题能力**
> = 知识库 + 推理机 + 用户界面

### 通用架构

```
┌─────────────────────────────────────────┐
│         用户  ←  用户界面                 │
│           ↕                                │
│    ┌──────────────────────┐              │
│    │     推理机             │              │
│    │  (通用程序,负责计算)    │              │
│    └──────────┬───────────┘              │
│               ↕                            │
│    ┌──────────────────────┐              │
│    │     知识库             │              │
│    │  (领域专家的 IF-THEN)   │              │
│    └──────────────────────┘              │
└─────────────────────────────────────────┘
```

### 核心设计:知识与推理分离

| 组件 | 作用 |
|---|---|
| **知识库**(Knowledge Base) | 存"领域知识"(由专家手工写的 IF-THEN 规则) |
| **推理机**(Inference Engine) | 通用的逻辑引擎(算法固定,知识库换换就能做其他领域) |

### 知识表示:产生式规则

最常用的形式 —— **IF-THEN 条件语句**:

```
IF 病人有发烧症状 AND 咳嗽
THEN 可能患有呼吸道感染
```

一个复杂的专家系统可能有 **几百几千条规则**,构成庞大知识网络。

### 推理方式:正向链 vs 反向链

#### 正向链(Forward Chaining)—— 数据驱动

```
已知事实: [发烧, 咳嗽]
   ↓ 匹配规则
触发: [发烧+咳嗽 → 呼吸道感染]
   ↓ 新事实加入
事实: [发烧, 咳嗽, 呼吸道感染]
   ↓ 继续匹配...
```

**比喻**: "我有这些线索,能推出什么?"

#### 反向链(Backward Chaining)—— 目标驱动

```
假设目标: "病人是否患肺炎?"
   ↓ 找能推出"肺炎"的规则
规则: [发烧+咳嗽+胸痛+X 光异常 → 肺炎]
   ↓ 子目标: 是否有这些症状?
向医生提问 → 收集证据
```

**比喻**: "我想证明 X,需要哪些证据?"

→ MYCIN 用的是**反向链**。

---

### 🔬 案例:MYCIN —— 用专家系统看病

| 项 | 内容 |
|---|---|
| 出品 | 斯坦福大学,1970 年代 |
| 用途 | 辅助医生诊断**细菌性血液感染** + 推荐抗生素 |
| 知识库 | 约 **600 条**医学 IF-THEN 规则 |
| 推理方式 | 反向链(从"诊断"目标反推证据) |
| **创新点** | **置信因子(CF)** —— -1 到 1 的"可信度",**处理不确定性** |

#### 工作流程示意

```
医生输入: 病人症状、化验结果
   ↓
MYCIN 反向链推理: "想确定细菌种类,需要哪些证据?"
   ↓
向医生提问: "病人最近是否接触过家畜?"
   ↓
推理 + CF 加权
   ↓
输出: "70% 概率是细菌 X,推荐抗生素 Y"
```

#### ⭐ 历史意义

- 评估中,MYCIN **超过了非专业医生,达到人类专家水平**
- **证明了 PSSH 假说在某些领域的有效性**
- 为后续 AI 在医疗、金融、法律的应用**铺路**

→ **可惜**:由于法律和责任问题,MYCIN **从未真正用于临床**。

## 🧱 2.1.3 SHRDLU —— 积木世界的"全能 AI"

### 出品

**特里·威诺格拉德(Terry Winograd)**,1968-70,**MIT** 出品。

### 目标

> 在一个**积木世界**(虚拟 3D 空间 + 不同形状颜色的积木 + 虚拟机械臂)里,
> 用**自然语言**和人类流畅交互。

### 革命性突破

SHRDLU **首次**把多个 AI 模块**集成在一个系统**里:

| 模块 | 能干啥 |
|---|---|
| **自然语言理解** | 解析复杂英语句子,包括**指代消解** |
| **规划** | 自主规划动作序列 |
| **记忆 + 问答** | 记住自己干过什么,能回答"为什么" |

### 真实对话片段

```
User: Find a block which is taller than the one you are holding
       and put it into the box.
SHRDLU: [理解 "the one you are holding" 指当前抓的物体]
         OK. [执行规划:释放当前积木 → 找更高的 → 抓 → 放入盒子]

User: Why did you pick up the red block?
SHRDLU: BECAUSE YOU ASKED ME TO.
```

→ **70 年代就能这样!**当时震惊了整个 AI 圈。

### 三大历史意义

| 意义 | 解释 |
|---|---|
| **综合智能典范** | 首次集成语言/推理/规划/记忆,**奠定现代 Agent 架构基础** |
| **微观世界研究法** | 在简化环境验证复杂智能体原理,影响深远 |
| **AGI 乐观情绪** | 让 70 年代研究者相信"AGI 不远了" |

### ⚠️ 但是...

SHRDLU 的能力**严格局限在积木世界**。
出了这个世界,它**什么都不懂**。
→ 引发"**符号处理 ≠ 真正理解**"的长期争论。

---

## ❌ 2.1.4 符号主义的根本性挑战

80 年代起,符号主义在走向**真实开放世界**时遇到无法克服的难题。

### 挑战 1:知识获取瓶颈(Knowledge Acquisition Bottleneck)

> **专家系统的智能全靠知识库,但知识库太难造了!**

| 痛点 | 解释 |
|---|---|
| 成本高 | 需要专家 + 知识工程师**手工编码** |
| 慢 | 一个领域要几年 |
| 无法规模化 | 每个新领域都得**从头来** |
| **内隐知识** | 专家的"直觉"**很难写成规则** |

→ **想把整个世界知识手工符号化**?**几乎不可能**。

### 挑战 2:常识问题(Common-sense Problem)

人类的"常识"——比如:
- "水是湿的"
- "绳子能拉不能推"
- "桌子下面通常没鬼"

符号系统**除非显式编码,否则一无所知**。
→ Cyc 项目从 80 年代搞到现在,花了**几十年**也没搞定。

### 挑战 3:框架问题(Frame Problem)

> **动作执行后,如何知道哪些事物没变?**

例:你拿起一个苹果。
- 苹果在你手里 ✓ (变了)
- 桌子还在原位 ✓
- 天空还是蓝的 ✓
- 隔壁邻居还在睡觉 ✓
- 月球还在转 ✓
- ... **要显式列出所有"没变的"是不可能的**

但人类**毫不费力就能忽略不相关的变化**。

### 挑战 4:系统脆弱性(Brittleness)

符号系统**完全依赖预设规则**:
- 遇到规则之外的情况 → **系统直接崩**
- 规则有冲突 → **难以维护**
- SHRDLU 在积木世界完美,**出来就死**

→ **真实世界充满例外**,符号主义抓瞎了。

---

## ⭐ 符号主义的遗产

虽然符号主义被时代超越,但它留下了**深刻遗产**:

| 遗产         | 影响                                     |
| ---------- | -------------------------------------- |
| **逻辑推理框架** | 今天 LLM Agent 的 Thought-Action 仍是"符号操作" |
| **知识表示**   | 知识图谱、本体论                               |
| **可解释性**   | LLM 时代努力追求的目标,符号系统天生具备                 |
| **专家系统思想** | 在确定性强的领域(税务、法务规则引擎)仍在使用                |

→ **不是死了,而是融入了新范式**(神经符号融合)。

---

## ⚠️ 小白避坑

1. **专家系统不等于规则引擎**
   - 专家系统**有推理机** —— 能链式推理
   - 简单 if-else 不算
2. **MYCIN 没真正用于临床**
   - 法律责任、伦理问题阻挡
   - 这教训影响了所有"AI 医疗"产品
3. **正向链 vs 反向链根据场景选**
   - 数据已知,问能推出啥 → **正向链**
   - 目标已知,问要啥证据 → **反向链**

| 知识点 | 一句话 |
|---|---|
| **物理符号系统假说** | 智能 = 符号操作 |
| **专家系统** | 知识库 + 推理机 + IF-THEN |
| **MYCIN** | 600 条规则诊断细菌感染,引入置信因子 |
| **SHRDLU** | 积木世界的"全能 AI",首次集成多模块 |
