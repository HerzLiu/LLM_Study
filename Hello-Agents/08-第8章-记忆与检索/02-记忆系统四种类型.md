# 8.2 记忆系统:四种记忆类型 + MemoryTool

⬅ [01-人类记忆系统启发](01-%E4%BA%BA%E7%B1%BB%E8%AE%B0%E5%BF%86%E7%B3%BB%E7%BB%9F%E5%90%AF%E5%8F%91.md)	|	➡ [03-RAG基础与原理](03-RAG%E5%9F%BA%E7%A1%80%E4%B8%8E%E5%8E%9F%E7%90%86.md)

## 🎬 故事比喻:大脑的四种"档案柜"

| 档案柜 | 内容 | 时长 | 例子 |
|---|---|---|---|
| **抽屉**(WorkingMemory) | 当前在用的 | 短(分钟级) | "刚才用户问了 Python 函数" |
| **日记本**(EpisodicMemory) | 经历的事件 | 长(月级) | "2024-03-15 用户完成 Python 项目" |
| **百科**(SemanticMemory) | 抽象知识 | 终生 | "Python 是面向对象语言" |
| **相册**(PerceptualMemory) | 图/音/视频 | 长 | "用户上传的代码截图" |

→ HelloAgents 的 4 种记忆**精准对应** 4 种档案柜。

---

## 🧠 8.2.1 记忆形成的认知过程

> 借鉴认知科学的 5 阶段:

```
1. 编码 (Encoding)      → 把感知转换为可存储格式
2. 存储 (Storage)        → 保存到记忆系统
3. 检索 (Retrieval)      → 按需提取
4. 整合 (Consolidation)  → 工作记忆 → 长期记忆
5. 遗忘 (Forgetting)     → 删除不重要 / 过时
```

→ HelloAgents 的 MemoryTool **5 大操作**(`add/search/forget/consolidate/...`)直接对应这 5 阶段。

---

## 🛠 8.2.2 MemoryTool 统一接口

### 设计:**统一入口 + 分发处理**

```python
class MemoryTool(BaseTool):
    """记忆工具 - Agent 的记忆能力"""

    def execute(self, action: str, **kwargs) -> str:
        """执行记忆操作

        支持的 action:
        - add: 添加记忆(支持 4 种类型)
        - search: 搜索记忆
        - summary: 获取记忆摘要
        - stats: 统计信息
        - update: 更新记忆
        - remove: 删除记忆
        - forget: 遗忘记忆(多种策略)
        - consolidate: 整合(短期 → 长期)
        - clear_all: 清空
        """
        if action == "add":         return self._add_memory(**kwargs)
        if action == "search":      return self._search_memory(**kwargs)
        if action == "summary":     return self._get_summary(**kwargs)
        if action == "forget":      return self._forget(**kwargs)
        if action == "consolidate": return self._consolidate(**kwargs)
        # ...
```

→ **一个工具,九种操作**,**极简心智模型**。

## 🔑 8.2.3 四个核心操作详解

### 操作 1:**`add`(添加记忆)**

```python
memory_tool.execute(
    "add",
    content="用户张三是 Python 开发者,专注于机器学习",
    memory_type="semantic",       # ⭐ 关键:指定记忆类型
    importance=0.8,                # ⭐ 重要性 0~1
)
```

#### 关键参数

| 参数 | 含义 | 默认值 |
|---|---|---|
| `content` | 记忆内容 | – |
| `memory_type` | 类型:working/episodic/semantic/perceptual | working |
| `importance` | 重要性 0~1 | 0.5 |
| `file_path` | (感知记忆)文件路径 | None |
| `modality` | (感知记忆)模态:text/image/audio | 自动推断 |

#### 4 种类型的使用示例

```python
# 1. 工作记忆 - 临时信息
memory_tool.execute("add",
    content="用户刚才问了 Python 函数",
    memory_type="working",
    importance=0.6,
)

# 2. 情景记忆 - 具体事件
memory_tool.execute("add",
    content="2024-03-15,用户张三完成第一个 Python 项目",
    memory_type="episodic",
    importance=0.8,
    event_type="milestone",
)

# 3. 语义记忆 - 抽象知识
memory_tool.execute("add",
    content="Python 是解释型、面向对象的编程语言",
    memory_type="semantic",
    importance=0.9,
)

# 4. 感知记忆 - 多模态
memory_tool.execute("add",
    content="用户上传了 Python 代码截图",
    memory_type="perceptual",
    importance=0.7,
    modality="image",
    file_path="./uploads/code.png",
)
```

---

### 操作 2:**`search`(搜索记忆)**

```python
result = memory_tool.execute(
    "search",
    query="Python 编程",
    limit=5,                       # 返回数量
    memory_type="semantic",        # 限定类型(可选)
    min_importance=0.5,             # 重要性下限
)
```

#### 三种用法

```python
# 基础搜索(所有类型)
memory_tool.execute("search", query="Python 编程", limit=5)

# 指定单类型
memory_tool.execute("search", query="学习进度", memory_type="episodic")

# 多类型同时搜
memory_tool.execute("search",
    query="函数定义",
    memory_types=["semantic", "episodic"],
    min_importance=0.5,
)
```

#### ⭐ 智能评分公式

```
最终得分 = (向量相似度 × 0.7 + 关键词得分 × 0.3) × 时间衰减 × 重要性权重
                                                              ↑
                                              重要性权重 = 0.8 + 重要性 × 0.4
                                                          (范围: 0.8 ~ 1.2)
```

→ **不仅"语义相似",还考虑"时间近因"和"重要性"** —— 模仿人类记忆。

---

### 操作 3:**`forget`(遗忘记忆)** —— 最具认知色彩的功能

> **模拟人类大脑的选择性遗忘**。

#### 3 种遗忘策略

```python
# 策略 1: 基于重要性 — 删除重要性低于阈值的
memory_tool.execute("forget",
    strategy="importance_based",
    threshold=0.2,
)

# 策略 2: 基于时间 — 删除超过 N 天的
memory_tool.execute("forget",
    strategy="time_based",
    max_age_days=30,
)

# 策略 3: 基于容量 — 接近上限时删最不重要的
memory_tool.execute("forget",
    strategy="capacity_based",
    threshold=0.3,
)
```

→ **为啥要"遗忘"?** 防止记忆爆炸,提高检索效率,贴近人类心智模型。

---

### 操作 4:**`consolidate`(整合记忆)**

> 模拟神经科学中的"记忆固化":**工作记忆 → 长期记忆**。

```python
# 把重要的工作记忆 → 情景记忆
memory_tool.execute(
    "consolidate",
    from_type="working",
    to_type="episodic",
    importance_threshold=0.7,   # 只有重要性 > 0.7 的才整合
)

# 把重要的情景记忆 → 语义记忆(沉淀为知识)
memory_tool.execute(
    "consolidate",
    from_type="episodic",
    to_type="semantic",
    importance_threshold=0.8,
)
```

→ **自动 + 选择性**,**真正像人类大脑**。

## 🧬 8.2.4 四种记忆类型深入

### 类型 1:**WorkingMemory(工作记忆)**

| 维度 | 设计 |
|---|---|
| **存储** | **纯内存**(快) |
| **生命周期** | 会话级(结束自动清) |
| **容量** | 50 条上限(默认) |
| **TTL** | 60 分钟自动过期 |
| **检索** | TF-IDF + 关键词混合 |
| **类比** | 人类"现在脑子里想的" |

**关键设计**:**TTL + 容量管理**
```python
def add(self, memory_item):
    self._expire_old_memories()   # 先清过期
    if len(self.memories) >= self.max_capacity:
        self._remove_lowest_priority_memory()   # 满了就删最不重要的
    self.memories.append(memory_item)
```

### 类型 2:**EpisodicMemory(情景记忆)**

| 维度 | 设计 |
|---|---|
| **存储** | **SQLite + Qdrant 混合** |
| **生命周期** | 长期 |
| **特点** | 按时间序列 + 会话级检索 |
| **检索** | 结构化过滤 + 向量检索 |
| **评分** | (向量 × 0.8 + 时间近因 × 0.2) × 重要性 |
| **类比** | "昨天的会议内容" |

### 类型 3:**SemanticMemory(语义记忆)** ⭐ **最复杂**

| 维度 | 设计 |
|---|---|
| **存储** | **Qdrant + Neo4j 双库** |
| **特点** | 知识图谱 + 实体 + 关系 |
| **检索** | 向量检索 + 图检索(混合) |
| **NLP** | spaCy 自动抽实体 |
| **评分** | (向量 × 0.7 + 图 × 0.3) × 重要性 |
| **类比** | "Python 是面向对象语言"(可推理关联) |

**关键流程**:
```
添加记忆
  ↓
1. 嵌入向量化
2. spaCy 自动抽实体 + 关系
3. 实体存 Neo4j 图库
4. 向量存 Qdrant 向量库
```

→ **既能语义搜索,又能图关系推理**。

### 类型 4:**PerceptualMemory(感知记忆)**

| 维度 | 设计 |
|---|---|
| **存储** | Qdrant(多模态向量库) |
| **特点** | 文本 / 图像 / 音频 |
| **编码器** | text-embedder / CLIP / CLAP |
| **检索** | 同模态 + 跨模态 |
| **类比** | "用户上传的截图" |

**关键设计**:**按模态分离的向量存储**
```python
self.vector_stores = {
    "text":  Qdrant(collection="perceptual_text",  vector_size=text_dim),
    "image": Qdrant(collection="perceptual_image", vector_size=image_dim),
    "audio": Qdrant(collection="perceptual_audio", vector_size=audio_dim),
}
```

→ 避免**维度不匹配**,**支持跨模态语义对齐**。

## 📊 四种记忆类型对比

| 维度 | Working | Episodic | **Semantic** | Perceptual |
|---|---|---|---|---|
| **存储** | 纯内存 | SQLite+Qdrant | **Qdrant+Neo4j** | Qdrant(多模态) |
| **生命周期** | 会话级 | 长期 | 长期 | 长期 |
| **容量** | 50 条 | 无限 | 无限 | 无限 |
| **检索** | TF-IDF+关键词 | 向量+结构化 | **向量+图谱** | 多模态向量 |
| **复杂度** | 低 | 中 | **高** | 高 |
| **典型用途** | 当前对话 | 用户经历 | 知识沉淀 | 图片/音频 |

## 🤖 8.2.5 MemoryManager 协作

> MemoryTool 只是**用户接口**,真正的核心是 `MemoryManager`。

```python
class MemoryTool(BaseTool):
    def __init__(self, user_id="default_user", memory_types=None):
        # ⭐ 创建 MemoryManager
        self.memory_manager = MemoryManager(
            user_id=user_id,
            enable_working=    "working"    in memory_types,
            enable_episodic=   "episodic"   in memory_types,
            enable_semantic=   "semantic"   in memory_types,
            enable_perceptual= "perceptual" in memory_types,
        )
```

### 分层设计

```
MemoryTool          ← 用户接口(参数校验、格式化)
   ↓
MemoryManager       ← 核心管理(分发到具体类型)
   ↓
WorkingMemory / EpisodicMemory / SemanticMemory / PerceptualMemory   ← 具体类型
   ↓
QdrantStore / Neo4jStore / SQLiteStore   ← 存储后端
```

→ **关注点分离**,**易扩展**。

## 🎮 8.2.6 完整体验代码

```python
from hello_agents import SimpleAgent, HelloAgentsLLM, ToolRegistry
from hello_agents.tools import MemoryTool

# 创建 Agent + Memory
llm = HelloAgentsLLM()
agent = SimpleAgent(name="记忆助手", llm=llm)

memory_tool = MemoryTool(user_id="user123")
tool_registry = ToolRegistry()
tool_registry.register_tool(memory_tool)
agent.tool_registry = tool_registry

# === 添加多个记忆 ===
memory_tool.execute("add",
    content="用户张三是 Python 开发者,专注机器学习",
    memory_type="semantic", importance=0.8)

memory_tool.execute("add",
    content="李四是前端工程师,擅长 React 和 Vue",
    memory_type="semantic", importance=0.7)

# === 搜索 ===
result = memory_tool.execute("search", query="前端工程师", limit=3)
print(result)
# 🔍 找到 1 条相关记忆:
# 1. [语义记忆] 李四是前端工程师,擅长 React 和 Vue (重要性: 0.70)

# === 记忆摘要 ===
result = memory_tool.execute("summary")
print(result)
```

## ⚠️ 小白避坑

1. **`memory_type` 别忘传**
   - 默认是 `working`,会话结束自动清
   - 想长期存要传 `semantic` / `episodic`
2. **`importance` 区分度要大**
   - 都设 0.5 → 失去过滤意义
   - 系统性给重要事 ≥ 0.7,普通事 0.3~0.5
3. **`forget` 用前慎重**
   - 删了**找不回**
   - 重要场景先备份(用 `summary` 导出)
4. **不要把所有事都塞 SemanticMemory**
   - 临时信息用 Working 更高效
5. **多用户场景必须用 `user_id` 隔离**
   - 不传 `user_id` → 默认共用,**数据串台**
