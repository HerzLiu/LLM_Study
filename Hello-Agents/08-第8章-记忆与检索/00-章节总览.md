## 🎬 一句话故事

[第 7 章](../07-%E7%AC%AC7%E7%AB%A0-%E6%9E%84%E5%BB%BA%E4%BD%A0%E7%9A%84%E6%99%BA%E8%83%BD%E4%BD%93%E6%A1%86%E6%9E%B6/00-%E7%AB%A0%E8%8A%82%E6%80%BB%E8%A7%88.md) 我们造好了 HelloAgents 框架,但有一个**致命缺陷**:

> **Agent 没有记忆**!
> 上一句你说"我叫张三",下一句问"你还记得我叫啥吗?" → "**不好意思,我不知道**"

→ 这一章给 HelloAgents **加上 2 大核心能力**:
- **Memory**(记忆系统):让 Agent 记住对话和经验
- **RAG**(检索增强生成):让 Agent 调用外部知识库

并且,**两者都设计成 Tool**(贯彻第 7 章"万物皆为工具"哲学)。

```
                    Agent 记忆与检索

        ┌─────────────────┼─────────────────┐

   Memory(记忆)        RAG(检索)         融合

        │              ├─ MQE (查询扩展)
   MemoryTool         └─ HyDE (假设答案)
   (统一接口)
```

## 💡 核心设计原则

### 原则 1:**万物皆为工具**(继承第 7 章)
```
Memory  → MemoryTool
RAG     → RAGTool
```
→ Agent 用统一的 `tool_registry` 调用,**心智模型极简**。

### 原则 2:**借鉴人类认知科学**
```
人类记忆       →  Agent 记忆
─────────       ─────────
工作记忆        →  WorkingMemory (TTL 自动清理)
情景记忆        →  EpisodicMemory (事件序列)
语义记忆        →  SemanticMemory (知识图谱)
感知记忆        →  PerceptualMemory (多模态)
```

### 原则 3:**RAG 解决幻觉**
- 不让 LLM 凭记忆答题
- **先检索真实文档** → 基于文档答 → **可追溯**

## ⚠️ 学习建议

1. **理论 + 实战结合**
   - 理论:理解为什么这么设计
   - 实战:`pip install "hello-agents[all]==0.2.0"`
2. **不必所有 4 种记忆都试**
   - **工作记忆 + 语义记忆** 是 80% 场景的核心
3. **本章基础设施依赖较多**
   - 完整跑要装 Qdrant(向量库) + Neo4j(图库) + spaCy
   - **入门可以用 Hello-Agents 默认的轻量版**

## 📝 本章一句话小结

**记忆让 Agent 持续学习,RAG 让 Agent 答得准确**。
HelloAgents 用 "**Memory + RAG 都是 Tool**" 的极简设计,**让 Agent 一键拥有这两大能力**。
