## 🎬 故事比喻:金鱼 7 秒记忆 vs 人类终身记忆

| | LLM | 人类 |
|---|---|---|
| 比喻 | **金鱼**(7 秒记忆) | **拥有终身记忆的大脑** |
| 上一句 | "我叫张三" | "我叫张三" |
| 下一句 | "你记得我叫啥?" → "**不知道**" | "你叫张三" ✓ |

→ 这就是为啥 LLM 需要 **Memory 系统**。

## 🧠 8.1.1 人类记忆系统的启发

> 给 Agent 造记忆,**最好的老师是人类大脑**。

### 人类记忆 3 大层次(认知心理学经典模型)

```
   感官输入(看/听/触)
        ↓
   ┌─────────────────┐
   │ 感觉记忆          │   0.5-3 秒,容量巨大
   │ Sensory Memory   │   "瞬间留影"
   └────────┬────────┘
            ↓ 注意力筛选
   ┌─────────────────┐
   │ 工作记忆          │   15-30 秒,容量 7±2
   │ Working Memory   │   "现在脑子里想的"
   └────────┬────────┘
            ↓ 重要的固化
   ┌─────────────────┐
   │ 长期记忆          │   终生,容量无限
   │ Long-term Memory │
   └─────────────────┘
        │
   ┌────┴────────────┐
   │                  │
程序性记忆       陈述性记忆
(技能/习惯)      (可表达的知识)
                  │
            ┌─────┴─────┐
            │            │
        语义记忆      情景记忆
        (一般知识)    (个人经历)
        "巴黎是法国首都"  "昨天的会议"
```

→ HelloAgents 的 4 种记忆类型**直接对应这个模型**(见 [下一节](02-%E8%AE%B0%E5%BF%86%E7%B3%BB%E7%BB%9F%E5%9B%9B%E7%A7%8D%E7%B1%BB%E5%9E%8B.md))。

## ❌ 8.1.2 LLM 的 2 大根本局限

### 局限 1:**无状态导致的对话遗忘**

#### LLM 的本质:**无状态**

```
每次 API 调用 = 独立的、无关联的计算
模型本身不会"记住"上一次说了啥
```

#### 后果

| 问题 | 解释 |
|---|---|
| **上下文丢失** | 长对话中早期信息因窗口限制被丢弃 |
| **个性化缺失** | Agent 不记得用户偏好/习惯 |
| **学习能力受限** | 无法从过往成败经验中改进 |
| **一致性问题** | 多轮对话**前后矛盾** |

#### 具体例子

```python
from hello_agents import SimpleAgent, HelloAgentsLLM

agent = SimpleAgent(name="学习助手", llm=HelloAgentsLLM())

# 第一次对话
agent.run("我叫张三,正在学 Python,目前掌握了基础语法")
# → "很好!Python 基础语法是编程的重要基础..."

# 第二次对话(新会话)
agent.run("你还记得我的学习进度吗?")
# → "❌ 抱歉,我不知道您的学习进度..."
```

→ **必须引入 Memory 系统**。

---

### 局限 2:**模型内置知识的局限性**

#### 4 大子问题

| 问题 | 解释 |
|---|---|
| **知识时效性** | 训练数据有截止日期,**不知道之后的事** |
| **专业领域知识不足** | 通用模型在细分领域**深度不够** |
| **事实准确性** | 容易**幻觉**,编出看似合理但虚假的信息 |
| **缺乏可解释性** | 答案没有来源,**用户无法验证** |

#### 解法:**RAG**(检索增强生成)

```
传统 LLM:
   用户问 → LLM 凭记忆答 → 可能错

RAG:
   用户问 → 先从知识库检索相关文档 → 把文档喂给 LLM → 基于文档答
   ↓
   答案更准确 + 可追溯
```

→ **见 [8.3 节](03-RAG%E5%9F%BA%E7%A1%80%E4%B8%8E%E5%8E%9F%E7%90%86.md)**。

## 🏗 8.1.3 HelloAgents Memory + RAG 架构设计

### 设计理念:**继承第 7 章"万物皆为工具"**

```
其他框架:
   Memory 是独立模块
   RAG 是独立模块
   → 学习 2 个新概念

HelloAgents:
   MemoryTool ← Memory 是 Tool
   RAGTool    ← RAG 是 Tool
   → 还是只学 Agent + Tools
```

### 完整架构(分层)

#### Memory 系统(4 层)

```
HelloAgents 记忆系统
├── 基础设施层 (Infrastructure)
│   ├── MemoryManager    # 统一调度
│   ├── MemoryItem       # 记忆数据结构
│   ├── MemoryConfig     # 配置
│   └── BaseMemory       # 基类
│
├── 记忆类型层 (Types)
│   ├── WorkingMemory     # 工作记忆(TTL)
│   ├── EpisodicMemory    # 情景记忆(时间序列)
│   ├── SemanticMemory    # 语义记忆(图谱)
│   └── PerceptualMemory  # 感知记忆(多模态)
│
├── 存储后端层 (Storage)
│   ├── QdrantVectorStore   # 向量(语义检索)
│   ├── Neo4jGraphStore     # 图(知识图谱)
│   └── SQLiteDocumentStore # 结构化持久化
│
└── 嵌入服务层 (Embedding)
    ├── DashScopeEmbedding       # 通义千问
    ├── LocalTransformerEmbedding # 本地
    └── TFIDFEmbedding           # 轻量兜底
```

#### RAG 系统(4 层)

```
HelloAgents RAG 系统
├── 文档处理层
│   ├── DocumentProcessor  # 多格式解析(PDF/MD/TXT)
│   ├── Document           # 文档对象 + 元数据
│   └── Pipeline           # 端到端
│
├── 嵌入表示层
│   └── 复用记忆系统的嵌入服务  # 统一,不重复造
│
├── 向量存储层
│   └── QdrantVectorStore   # 命名空间隔离
│
└── 智能问答层
    ├── 多策略检索          # 向量 + MQE + HyDE
    ├── 上下文构建          # 智能片段合并
    └── LLM 增强生成        # 基于上下文准确问答
```

## 🚀 8.1.4 30 秒体验

### 安装

```bash
pip install "hello-agents[all]==0.2.0"
python -m spacy download zh_core_web_sm
python -m spacy download en_core_web_sm
```

### 配置 `.env`(关键)

```bash
# Qdrant 向量库(注册免费: https://cloud.qdrant.io/)
QDRANT_URL=https://your-cluster.qdrant.tech:6333
QDRANT_API_KEY=your_qdrant_api_key

# Neo4j 图库(注册免费: https://neo4j.com/cloud/aura/)
NEO4J_URI=neo4j+s://your-instance.databases.neo4j.io
NEO4J_USERNAME=neo4j
NEO4J_PASSWORD=your_neo4j_password

# Embedding(阿里云: https://dashscope.aliyun.com/)
EMBED_MODEL_TYPE=dashscope
EMBED_API_KEY=your_dashscope_key
```

→ 入门**只用 Qdrant 即可**,Neo4j 可选。

### 最小可跑示例

```python
from hello_agents import SimpleAgent, HelloAgentsLLM, ToolRegistry
from hello_agents.tools import MemoryTool, RAGTool

# 1. 创建 Agent
llm = HelloAgentsLLM()
agent = SimpleAgent(
    name="智能助手",
    llm=llm,
    system_prompt="你是一个有记忆和知识检索能力的 AI 助手",
)

# 2. 创建工具
memory_tool = MemoryTool(user_id="user123")
rag_tool = RAGTool(knowledge_base_path="./knowledge_base")

# 3. 注册到 Agent
tool_registry = ToolRegistry()
tool_registry.register_tool(memory_tool)
tool_registry.register_tool(rag_tool)
agent.tool_registry = tool_registry

# 4. 对话(自带记忆 + RAG)
response = agent.run("你好!请记住我叫张三,我是 Python 开发者")
print(response)
# → "你好张三!很高兴认识你。作为 Python 开发者..."
```

→ **3 步加 2 大能力**。

## ⚠️ 小白避坑

1. **Memory ≠ 对话历史**
   - 对话历史是**短期** + **会话级**
   - Memory 是**长期** + **跨会话** + **可检索**
2. **RAG ≠ Memory**
   - Memory:存 Agent 自己经历的事
   - RAG:存外部知识库(用户给的文档)
   - 二者**互补**
3. **不是所有任务都需要 Memory + RAG**
   - 单步查询:不需要
   - 多轮对话 / 个性化:需要 Memory
   - 知识问答 / 客服:需要 RAG
4. **Qdrant / Neo4j 是可选**
   - 入门可用 Hello-Agents 默认的本地存储
   - 生产环境再上专业数据库

## 📌 8.1 节要点

| 知识点 | 一句话 |
|---|---|
| **人类记忆 3 层** | 感觉 → 工作 → 长期(语义/情景) |
| **LLM 2 大局限** | **对话遗忘 + 知识局限** |
| **Memory** | 解决对话遗忘 |
| **RAG** | 解决知识局限 |
| **设计哲学** | **Memory/RAG 都是 Tool** |
| **架构** | 基础设施 + 类型 + 存储 + 嵌入 4 层 |
