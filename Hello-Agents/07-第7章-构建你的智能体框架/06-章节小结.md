## ⭐ 必背设计哲学

### 哲学 1:**轻量级 + 教学友好**
- 极简依赖
- 代码可读
- 任何开发者**合理时间内能完全理解**

### 哲学 2:**基于标准 API**
- OpenAI 兼容接口已是行业标准
- **不重复发明轮子**
- 学完无缝迁移到任何主流框架

### 哲学 3:**渐进式学习路径**
- 每章一个 pip 可装版本
- **边学边用**,不会有断层

### 哲学 4:**万物皆为工具**(🌟 最核心)
- Memory / RAG / RL / MCP 都是 Tool
- **统一抽象**,**只学 Agent + Tools 两个概念**

---

## 🎯 与其他框架的对比

| 框架 | 抽象层 | 学习曲线 | 适合 |
|---|---|---|---|
| **LangChain** | 多(Chain/Agent/Tool/Memory/Retriever...) | 陡 | 通用 |
| **LangGraph** | 中(Node/Edge/State) | 中 | 复杂控制流 |
| **AutoGen** | 中(Agent/Team) | 中 | 多 Agent 协作 |
| **HelloAgents** | **极少(Agent + Tools)** | **平** | **学习 + 入门 + 教学** |

→ HelloAgents 不与生产框架竞争,**它的定位是"最好的学习框架"**。

### 收获 1:**能造自己的框架**
- 简历:**"独立设计和实现了一个 Agent 框架"**
- 面试谈"为什么这么设计" → 加分点

### 收获 2:**看穿任何 Agent 框架**
- LangChain / AutoGen / LangGraph / CrewAI...
- 万变不离其宗:**Agent 基类 + 工具系统 + LLM 适配**

### 收获 3:**深度定制能力**
- 任何需求 → 知道怎么扩展
- 不依赖框架作者的更新

### 收获 4:**为后续章节打基础**

## 🛠 关键代码模板(可直接复用)

### 模板 1:**自定义 LLM Provider**

```python
class MyLLM(HelloAgentsLLM):
    def __init__(self, provider=None, **kwargs):
        if provider == "your_provider":
            # 自定义逻辑
            ...
        else:
            super().__init__(provider=provider, **kwargs)
```

### 模板 2:**自定义 Agent**

```python
from hello_agents import Agent, HelloAgentsLLM

class MyCustomAgent(Agent):
    def __init__(self, name, llm, **kwargs):
        super().__init__(name=name, llm=llm, **kwargs)

    def run(self, input_text: str, **kwargs) -> str:
        # 你的 Agent 逻辑
        messages = [
            {"role": "system", "content": self.system_prompt},
            {"role": "user", "content": input_text},
        ]
        return self.llm.invoke(messages)
```

### 模板 3:**自定义工具**

```python
from hello_agents.tools import BaseTool

class MyCustomTool(BaseTool):
    name = "my_tool"
    description = "用一句话描述这个工具做什么(LLM 通过这个判断何时调用)"

    def run(self, input_arg: str) -> str:
        # 你的工具逻辑
        return "执行结果字符串"
```
