## 📨 7.3.1 Message 类

### 设计目标

> **统一消息格式** → 智能体与 LLM 之间信息传递标准化。

### 完整实现

```python
"""消息系统"""
from typing import Optional, Dict, Any, Literal
from datetime import datetime
from pydantic import BaseModel

# ⭐ 严格限制角色取值
MessageRole = Literal["user", "assistant", "system", "tool"]


class Message(BaseModel):
    """消息类"""

    content: str
    role: MessageRole
    timestamp: datetime = None
    metadata: Optional[Dict[str, Any]] = None

    def __init__(self, content: str, role: MessageRole, **kwargs):
        super().__init__(
            content=content,
            role=role,
            timestamp=kwargs.get("timestamp", datetime.now()),
            metadata=kwargs.get("metadata", {}),
        )

    def to_dict(self) -> Dict[str, Any]:
        """转换为 OpenAI API 兼容的字典格式"""
        return {
            "role": self.role,
            "content": self.content,
        }

    def __str__(self) -> str:
        return f"[{self.role}] {self.content}"
```

### 设计要点

#### 🔑 1. **类型安全**:`Literal` 限制 role

```python
MessageRole = Literal["user", "assistant", "system", "tool"]
```

→ **只允许 4 种 role**,**和 OpenAI API 标准一致**。
→ 传错 role IDE 会报错,**避免运行时 bug**。

#### 🔑 2. **预留扩展字段**:`timestamp` + `metadata`

```python
timestamp: datetime = None
metadata: Optional[Dict[str, Any]] = None
```

| 字段 | 用途 |
|---|---|
| `timestamp` | 日志记录 / 事件追踪 |
| `metadata` | 未来扩展(token 数 / 工具调用 ID 等) |

→ **"对内丰富,对外兼容"**:内部数据丰富,但 `to_dict()` 只输出 OpenAI 标准字段。

#### 🔑 3. **基于 Pydantic**

- 自动类型验证
- 自动序列化
- IDE 友好

## ⚙️ 7.3.2 Config 类

### 设计目标

> **集中管理所有配置参数** + **支持环境变量覆盖**。

### 完整实现

```python
"""配置管理"""
import os
from typing import Optional, Dict, Any
from pydantic import BaseModel


class Config(BaseModel):
    """HelloAgents 配置类"""

    # ===== LLM 配置 =====
    default_model: str = "gpt-3.5-turbo"
    default_provider: str = "openai"
    temperature: float = 0.7
    max_tokens: Optional[int] = None

    # ===== 系统配置 =====
    debug: bool = False
    log_level: str = "INFO"

    # ===== 其他配置 =====
    max_history_length: int = 100

    @classmethod
    def from_env(cls) -> "Config":
        """⭐ 从环境变量创建配置"""
        return cls(
            debug=os.getenv("DEBUG", "false").lower() == "true",
            log_level=os.getenv("LOG_LEVEL", "INFO"),
            temperature=float(os.getenv("TEMPERATURE", "0.7")),
            max_tokens=int(os.getenv("MAX_TOKENS")) if os.getenv("MAX_TOKENS") else None,
        )

    def to_dict(self) -> Dict[str, Any]:
        return self.dict()
```

### 设计要点

#### 🔑 1. **配置分类**

```python
# LLM 配置 / 系统配置 / 其他 → 清晰分类
```

→ **看一眼就知道有啥配置**。

#### 🔑 2. **合理默认值**

```python
default_model: str = "gpt-3.5-turbo"
debug: bool = False
log_level: str = "INFO"
```

→ **零配置也能跑**,**新手友好**。

#### 🔑 3. **`from_env()` 类方法**

```python
config = Config.from_env()
```

→ **不改代码 + 通过环境变量调参**,部署友好。

## 🧬 7.3.3 Agent 抽象基类(最重要)

### 设计目标

> **顶层抽象** —— 定义所有 Agent 的通用行为和接口规范。

### 完整实现

```python
"""Agent 基类"""
from abc import ABC, abstractmethod
from typing import Optional, Any
from .message import Message
from .llm import HelloAgentsLLM
from .config import Config


class Agent(ABC):
    """Agent 基类"""

    def __init__(
        self,
        name: str,
        llm: HelloAgentsLLM,
        system_prompt: Optional[str] = None,
        config: Optional[Config] = None,
    ):
        self.name = name
        self.llm = llm
        self.system_prompt = system_prompt
        self.config = config or Config()
        self._history: list[Message] = []

    # ⭐ 强制子类必须实现
    @abstractmethod
    def run(self, input_text: str, **kwargs) -> str:
        """运行 Agent"""
        pass

    # ⭐ 通用历史管理(所有子类共享)
    def add_message(self, message: Message):
        self._history.append(message)

    def clear_history(self):
        self._history.clear()

    def get_history(self) -> list[Message]:
        return self._history.copy()

    def __str__(self) -> str:
        return f"Agent(name={self.name}, provider={self.llm.provider})"
```

### 设计要点

#### 🔑 1. **`ABC` + `@abstractmethod` = 抽象类**

```python
class Agent(ABC):                          # 不能直接实例化
    @abstractmethod
    def run(self, input_text):              # 子类必须实现
        pass
```

→ 试图 `Agent(...)` → **Python 报错**:不能实例化抽象类。
→ **强制规范**:所有子类**必须**有 `run` 方法。

#### 🔑 2. **统一构造参数**

```python
def __init__(self, name, llm, system_prompt=None, config=None):
```

→ 所有 Agent(SimpleAgent / ReActAgent / ReflectionAgent...)**用同样的初始化**。
→ **学一个,会一片**。

#### 🔑 3. **基类提供通用方法**

```python
def add_message(...): ...
def clear_history(...): ...
def get_history(...): ...
```

→ **历史管理是所有 Agent 共有的**,不要每个 Agent 都重写。
→ 这是**DRY 原则**(Don't Repeat Yourself)。

#### 🔑 4. **`get_history()` 返回 copy**

```python
def get_history(self) -> list[Message]:
    return self._history.copy()
```

→ 外部修改返回的列表 **不会污染内部状态**。
→ **防御式编程**。

## ⭐ 7.3.5 抽象基类的设计哲学

### 哲学 1:**接口 vs 实现 分离**

| 层 | 关注点 |
|---|---|
| 抽象基类(Agent) | **"做什么"** —— 接口定义 |
| 具体子类(SimpleAgent) | **"怎么做"** —— 实现细节 |

→ **接口稳定,实现可变**。

### 哲学 2:**强制规范**

```python
@abstractmethod
def run(self, input_text: str, **kwargs) -> str: pass
```

→ 子类**必须**实现 `run`,**统一调用方式**。
→ 用户**学一个 Agent 会用所有 Agent**。

### 哲学 3:**复用代码**

```python
# 基类提供通用历史管理
# 子类不用重复写
```

→ 改基类 → **所有子类自动获益**。

### 哲学 4:**可观测性**

```python
def __str__(self) -> str:
    return f"Agent(name={self.name}, provider={self.llm.provider})"
```

→ `print(agent)` **直观看到 Agent 信息**,调试友好。

## ⚠️ 小白避坑

1. **`ABC` 必须用**
   - 漏了 `from abc import ABC` → 抽象类失效
2. **`@abstractmethod` 必须装饰**
   - 不装饰 → 子类不实现也不报错
3. **`Optional[X]` ≠ `X = None`**
   - `Optional[X] = None` 才是正确写法
   - 单写 `X = None` 类型检查器会警告
4. **`.copy()` 别忘**
   - `return self._history` 会暴露内部状态
   - `return self._history.copy()` 才安全
