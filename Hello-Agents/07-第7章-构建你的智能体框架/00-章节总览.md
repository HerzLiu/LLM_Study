## 🧭 HelloAgents 架构地图

```
hello-agents/
├── core/                # 核心层
│   ├── agent.py         # Agent 抽象基类
│   ├── llm.py           # HelloAgentsLLM 统一接口
│   ├── message.py       # Message 类
│   ├── config.py        # Config 类
│   └── exceptions.py    # 异常体系
│
├── agents/              # Agent 实现层
│   ├── simple_agent.py
│   ├── react_agent.py
│   ├── reflection_agent.py
│   ├── plan_solve_agent.py
│   └── function_call_agent.py
│
└── tools/               # 工具系统层
    ├── base.py          # BaseTool 工具基类
    ├── registry.py      # ToolRegistry 工具注册
    ├── chain.py         # 工具链管理
    └── builtin/         # 内置工具集
        ├── calculator.py
        └── search.py
```

→ **3 层分层架构**:Core(核心) → Agents(范式) → Tools(工具)。

## 💡 HelloAgents 4 大设计理念

```
1. 轻量级 + 教学友好
   → 任何有编程基础的开发者都能在合理时间内完全理解

2. 基于标准 API (OpenAI 兼容)
   → 不重复发明轮子,直接复用行业标准

3. 渐进式学习路径
   → 每章一个 pip 可装版本,边学边用

4. 万物皆为工具 (统一抽象)
   → Memory/RAG/RL/MCP 都是 "工具" → 极简心智模型
```

## ⚠️ 学习建议

1. **本章是"造轮子",不是"用轮子"**
   - 重点在**理解设计哲学**
   - 不必逐行抄代码
2. **配合第 4 章一起看**
   - 第 4 章是从零手撕(无框架)
   - 第 7 章是同样的范式,**框架化重构**
3. **快速上手用 pip**
   ```bash
   pip install "hello-agents==0.1.1"
   ```
