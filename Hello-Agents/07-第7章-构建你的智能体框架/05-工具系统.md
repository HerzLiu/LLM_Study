## 🎬 故事比喻:统一插头标准

家里电器五花八门:
- 冰箱 / 微波炉 / 手机充电器 / 电脑 / ...

**但插座是统一的标准**(国标 / 欧标 / 美标)。
→ **任何电器只要满足插头标准,就能接到任何插座**。

**HelloAgents 的工具系统就是 Agent 的"插座标准"**:
- 任何外部能力(搜索 / 计算 / Memory / RAG / MCP)
- **只要满足 BaseTool 接口,就能接到任何 Agent**

## 🧱 7.5.2 BaseTool(工具基类)

### 设计目标

> 所有工具的**统一接口** —— 让 Agent 不用关心具体工具,只关心"调用工具"这件事。

### 关键骨架

```python
"""工具基类"""
from abc import ABC, abstractmethod
from typing import Any, Dict

class BaseTool(ABC):
    """工具基类:所有自定义工具必须继承"""

    # ⭐ 工具元信息(子类必须定义)
    name: str = "base_tool"
    description: str = "工具基类,不可直接使用"

    @abstractmethod
    def run(self, *args, **kwargs) -> str:
        """执行工具,返回字符串结果"""
        pass

    def get_openai_schema(self) -> Dict[str, Any]:
        """转 OpenAI Function Calling schema"""
        return {
            "type": "function",
            "function": {
                "name": self.name,
                "description": self.description,
                "parameters": self._get_parameters_schema(),
            },
        }

    def _get_parameters_schema(self) -> Dict[str, Any]:
        """子类可重写以定义参数 schema"""
        return {"type": "object", "properties": {}, "required": []}
```

### 关键设计

#### 🔑 1. **`name` + `description`**

```python
name: str = "base_tool"
description: str = "工具基类,不可直接使用"
```

→ **LLM 通过 description 决定何时调用这个工具**!
→ `description` 写得好坏 = 工具能不能被正确调用。

#### 🔑 2. **`@abstractmethod` 强制实现 `run`**

→ 所有子类**必须**实现 `run`,**接口统一**。

#### 🔑 3. **`get_openai_schema()` 桥接 Function Calling**

→ 内部用 HelloAgents 自己的格式,**外部对接 OpenAI 标准**。

## 📦 7.5.3 ToolRegistry(工具注册中心)

```python
"""工具注册中心"""
from typing import Dict, Optional, List
from .base import BaseTool

class ToolRegistry:
    """统一管理所有工具"""

    def __init__(self):
        self.tools: Dict[str, BaseTool] = {}

    def register_tool(self, tool: BaseTool):
        """注册工具"""
        if tool.name in self.tools:
            print(f"⚠️ 工具 '{tool.name}' 已存在,将覆盖")
        self.tools[tool.name] = tool
        print(f"✓ 工具 '{tool.name}' 已注册")

    def unregister(self, name: str):
        """注销工具"""
        if name in self.tools:
            del self.tools[name]

    def get_tool(self, name: str) -> Optional[BaseTool]:
        """获取工具"""
        return self.tools.get(name)

    def execute_tool(self, name: str, *args, **kwargs) -> str:
        """执行工具"""
        tool = self.get_tool(name)
        if not tool:
            return f"❌ 未找到工具 '{name}'"
        try:
            return tool.run(*args, **kwargs)
        except Exception as e:
            return f"❌ 工具执行错误: {e}"

    def list_tools(self) -> List[str]:
        """列出所有工具名"""
        return list(self.tools.keys())

    def get_tools_description(self) -> str:
        """格式化所有工具描述(给 LLM 看)"""
        if not self.tools:
            return "暂无可用工具"
        return "\n".join([
            f"- {name}: {tool.description}"
            for name, tool in self.tools.items()
        ])

    def get_openai_tools_schema(self) -> List[Dict]:
        """获取所有工具的 OpenAI Function Calling schema"""
        return [tool.get_openai_schema() for tool in self.tools.values()]
```

### 核心 5 个方法

| 方法 | 用途 |
|---|---|
| `register_tool(tool)` | 注册 |
| `unregister(name)` | 注销 |
| `get_tool(name)` | 查询 |
| `execute_tool(name, ...)` | 执行(含错误处理) |
| `get_tools_description()` | **给 LLM 看的描述** |
| `get_openai_tools_schema()` | **OpenAI Function Calling 格式** |

→ **一个 Registry,覆盖所有工具管理需求**。

## 🛠 7.5.4 自定义工具开发(实战)

### 例 1:**计算器工具**

```python
from hello_agents.tools import BaseTool

class CalculatorTool(BaseTool):
    """计算器工具:支持基本数学运算"""

    name = "calculator"
    description = "用于计算数学表达式,如 '2 + 3 * 4' 或 '(10 + 5) / 3'"

    def run(self, expression: str) -> str:
        """执行计算"""
        try:
            # ⚠️ 生产环境用 ast.literal_eval 或专门的表达式解析库
            result = eval(expression)
            return f"计算结果: {expression} = {result}"
        except Exception as e:
            return f"计算错误: {e}"
```

### 例 2:**天气工具**(实战示意)

```python
import requests

class WeatherTool(BaseTool):
    """查询天气工具"""

    name = "weather"
    description = "查询指定城市的实时天气。参数:城市名(如'北京')"

    def run(self, city: str) -> str:
        url = f"https://wttr.in/{city}?format=j1"
        try:
            data = requests.get(url, timeout=5).json()
            current = data["current_condition"][0]
            return (
                f"{city}当前天气:"
                f"{current['weatherDesc'][0]['value']},"
                f"气温 {current['temp_C']}°C"
            )
        except Exception as e:
            return f"查询失败: {e}"
```

### 使用 3 步

```python
from hello_agents import HelloAgentsLLM, SimpleAgent, ToolRegistry

# 1. 创建 Registry
registry = ToolRegistry()

# 2. 注册工具
registry.register_tool(CalculatorTool())
registry.register_tool(WeatherTool())

# 3. 给 Agent 用
agent = SimpleAgent(
    name="助手",
    llm=HelloAgentsLLM(),
    tool_registry=registry,
)

response = agent.run("北京今天天气怎么样?")
# Agent 自动选 WeatherTool 调用
```

→ **3 步加任意工具**,**优雅极简**。

## 🔍 7.5.5 多源搜索工具(实战案例)

### 需求

> 搜索引擎可能挂,**需要多个 fallback**。

### 设计

```python
class MultiSourceSearchTool(BaseTool):
    """多源搜索工具:依次尝试 SerpAPI → Tavily → DuckDuckGo"""

    name = "search"
    description = "搜索网页信息,自动 fallback 多个搜索源"

    def __init__(self):
        self.sources = [
            self._search_serpapi,
            self._search_tavily,
            self._search_duckduckgo,
        ]

    def run(self, query: str) -> str:
        for source in self.sources:
            try:
                result = source(query)
                if result:
                    return result
            except Exception as e:
                print(f"⚠️ {source.__name__} 失败: {e},尝试下一个...")
        return "❌ 所有搜索源都失败了"

    def _search_serpapi(self, query): ...
    def _search_tavily(self, query): ...
    def _search_duckduckgo(self, query): ...
```

→ **生产级"防御式设计"** —— 一个 API 挂了,自动换下一个。

## 🌟 7.5.7 "万物皆为工具" 的极致应用

### 应用 1:Memory 作为工具

```python
class MemoryTool(BaseTool):
    name = "memory"
    description = "存取长期记忆。action=store/recall/search"

    def run(self, action: str, content: str = None, query: str = None) -> str:
        if action == "store":
            self._vector_db.add(content)
            return f"✓ 已记忆: {content[:30]}..."
        elif action == "recall":
            return self._vector_db.get(query)
        elif action == "search":
            return self._vector_db.search(query, top_k=3)
```

→ **Memory 不是独立模块,就是个 Tool**。
→ Agent 通过统一的 `[TOOL_CALL:memory:...]` 调用。

### 应用 2:RAG 作为工具

```python
class RAGTool(BaseTool):
    name = "rag"
    description = "从私有知识库检索信息"

    def run(self, query: str) -> str:
        return self._retriever.retrieve(query)
```

→ **RAG 也是个 Tool**,**统一抽象**。

### 应用 3:MCP 作为工具

```python
class MCPTool(BaseTool):
    name = "mcp"
    description = "调用 MCP 协议的远程工具"

    def run(self, server: str, tool: str, params: dict) -> str:
        return self._mcp_client.call(server, tool, params)
```

→ MCP 协议(第 10 章)也是个 Tool。

### 终极简化:**所有外部能力 = Tool**

```
Memory     → MemoryTool
RAG        → RAGTool
MCP        → MCPTool
RL 训练数据  → DatasetTool
搜索/计算   → SearchTool / CalculatorTool
```

→ **学习者只需要理解一个核心模型**:**Agent 调用 Tool**。
→ 极致简化心智模型。

## ⚠️ 小白避坑

1. **`description` 至关重要**
   - LLM **完全靠这个判断何时调用**
   - 写不好 → 工具调不上 / 乱调
2. **`name` 不要有特殊字符**
   - 用 snake_case(`my_tool`)
   - 不要用空格 / 中文
3. **`run` 必须返回 `str`**
   - LLM 只能处理文本
   - 复杂数据 → 转 JSON 字符串
4. **错误处理一定要做**
   - 工具挂了 → 返回错误信息字符串
   - **不要 throw Exception**(会让 Agent 崩)
5. **生产环境别用 `eval()`**
   - 安全风险大
   - 用 `ast.literal_eval` 或专门库
