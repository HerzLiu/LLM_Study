## 🎬 一句话故事

前 9 章我们造了**单体 Agent**(自带 Memory/RAG/工具/上下文工程)。
但单兵作战有 3 大限制:

> **工具集成困境** + **能力扩展瓶颈** + **协作缺失**

→ 本章引入**3 大通信协议** —— **Agent 圈最前沿的话题**:

| 协议 | 作用 | 出品 |
|---|---|---|
| **MCP** | 智能体 ↔ **工具/数据** | Anthropic |
| **A2A** | 智能体 ↔ **智能体** | Google |
| **ANP** | 智能体 ↔ **网络发现** | 社区 |

                  智能体通信协议
                          │
        ┌─────────────────┼─────────────────┐
        │                 │                 │
       MCP               A2A               ANP

---

## ⚖️ 三协议速选

```
你想干啥?
   ├── Agent 用外部工具(文件/数据库/API)     → MCP ⭐
   ├── 多 Agent 协作完成任务                   → A2A
   └── 构建大规模 Agent 网络(服务发现)         → ANP
```

→ **MCP 当前生态最成熟,优先学**。

---

## 📝 本章一句话小结

**MCP 让 Agent 接入万物**(工具/数据)。
**A2A 让 Agent 互相协作**(对等通信)。
**ANP 让 Agent 组建网络**(服务发现)。
**三者协同 = Agent 的"互联网协议栈"**。
