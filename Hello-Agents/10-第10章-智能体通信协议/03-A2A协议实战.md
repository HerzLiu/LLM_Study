# 10.3 A2A 协议实战

⬅ [02-MCP协议详解](02-MCP%E5%8D%8F%E8%AE%AE%E8%AF%A6%E8%A7%A3.md)	|	➡ [04-ANP协议简介](04-ANP%E5%8D%8F%E8%AE%AE%E7%AE%80%E4%BB%8B.md)

> **A2A**(Agent-to-Agent)—— **智能体之间**的直接通信协议,由 Google 提出。

---

## 🎬 故事比喻:Slack 工作群

```
MCP:Agent → 工具(USB-C 充电)
A2A:Agent ↔ Agent(Slack 工作群里互相 @)
```

→ **A2A 让 Agent 像人类同事一样对话协作**。

---

## 🎯 10.3.1 设计动机

### 中央协调器(星型架构)的 3 大问题

```
        ┌─ Agent A
        │
协调器 ─┼─ Agent B
        │
        └─ Agent C
```

| 问题 | 解释 |
|---|---|
| **单点故障** | 协调器挂 → 全瘫 |
| **性能瓶颈** | 所有通信经过中心 → 并发受限 |
| **扩展困难** | 加 Agent 需改中心逻辑 |

### A2A 的解法:**P2P 对等架构**

```
       Agent A ↔ Agent B
            ↘ ↙
          Agent C
            ↕
       Agent D ↔ Agent E
```

→ **Agent 直接对话**,**无单点 + 并发好 + 易扩展**。

---

## 🧱 10.3.2 核心抽象:Task + Artifact

> 这是 A2A 与 MCP **最大的区别**。

| 概念 | 描述 |
|---|---|
| **Task(任务)** | 一个**有状态、可追踪**的协作单元 |
| **Artifact(工件)** | Task 产出的**结构化产物**(代码/文档/数据) |

### Task 的标准生命周期

```
   创建 (Created)
      ↓
   协商 (Negotiating)
      ↓
   代理 (Delegated)
      ↓
   执行中 (In Progress)
      ↓
   完成 (Completed) / 失败 (Failed)
```

→ **不是简单的请求-响应**,而是**完整的任务管理**。

---

## 🔄 10.3.3 A2A 请求生命周期(4 步)

```
1. 代理发现 (Agent Discovery)
   找到能干这事的 Agent

2. 身份验证 (Authentication)
   通过认证服务器

3. 发送消息 API (Send Message)
   主请求

4. 流式 API (Send Message Stream)
   实时进度
```

→ **比 MCP 更"重"**,但**适合复杂协作**。

## 🛠 10.3.4 创建 A2A 服务端

> A2A 用 `@skill` 装饰器定义能力。

### 计算器 Agent 示例

```python
from hello_agents.protocols.a2a.implementation import A2AServer

# 创建 A2A 服务器
calculator = A2AServer(
    name="calculator-agent",
    description="专业数学计算智能体",
    version="1.0.0",
    capabilities={
        "math": ["addition", "subtraction", "multiplication", "division"],
        "advanced": ["power", "sqrt", "factorial"],
    },
)

# ⭐ 用 @skill 装饰器定义技能
@calculator.skill("add")
def add_numbers(query: str) -> str:
    """加法计算"""
    parts = query.replace("加", "+").replace("加上", "+")
    if "+" in parts:
        numbers = [float(x.strip()) for x in parts.split("+")]
        return f"计算结果: {' + '.join(map(str, numbers))} = {sum(numbers)}"
    return "请使用格式: 计算 5 + 3"


@calculator.skill("multiply")
def multiply_numbers(query: str) -> str:
    """乘法计算"""
    parts = query.replace("乘以", "*").replace("×", "*")
    if "*" in parts:
        numbers = [float(x.strip()) for x in parts.split("*")]
        result = 1
        for num in numbers:
            result *= num
        return f"计算结果: {' × '.join(map(str, numbers))} = {result}"
    return "请使用格式: 计算 5 * 3"


@calculator.skill("info")
def get_info(query: str) -> str:
    """获取智能体信息"""
    return f"我是 {calculator.name},支持的技能: {list(calculator.skills.keys())}"
```

### 启动服务

```python
import threading

def start_server():
    calculator.run(host="localhost", port=5000)

server_thread = threading.Thread(target=start_server, daemon=True)
server_thread.start()
print("✅ 计算器 Agent 已启动: http://localhost:5000")
```

## 📞 10.3.5 创建 A2A 客户端

```python
from hello_agents.protocols import A2AClient

# 连接到 Agent 服务端
client = A2AClient("http://localhost:5000")

# 调用技能
response = client.execute_skill("add", "计算 10 + 5")
print(f"结果: {response.get('result')}")
# → 计算结果: 10.0 + 5.0 = 15.0

response = client.execute_skill("info", "你是谁?")
print(response.get('result'))
# → 我是 calculator-agent,支持的技能: ['add', 'multiply', 'info']
```

## 🌐 10.3.6 多 Agent 协作示例

> 真实场景:**研究员 + 撰写员** 协作完成文章。

### 服务端:启动两个 Agent

```python
from hello_agents.protocols import A2AServer

# 1. 研究员 Agent
researcher = A2AServer(name="researcher", description="研究员")

@researcher.skill("research")
def do_research(text: str) -> str:
    import re
    match = re.search(r'research\s+(.+)', text, re.IGNORECASE)
    topic = match.group(1).strip() if match else text
    return str({"topic": topic, "findings": f"{topic}的研究结果..."})


# 2. 撰写员 Agent
writer = A2AServer(name="writer", description="撰写员")

@writer.skill("write")
def write_article(text: str) -> str:
    import re
    match = re.search(r'write\s+(.+)', text, re.IGNORECASE)
    content = match.group(1).strip() if match else text
    try:
        data = eval(content)
        topic = data.get("topic", "未知主题")
        findings = data.get("findings", "无")
        return f"# {topic}\n\n{findings}\n\n这是基于研究的文章..."
    except:
        return "解析失败"
```

### 客户端:**Agent 链式调用**

```python
from hello_agents.protocols import A2AClient

# 1. 调研究员
researcher_client = A2AClient("http://localhost:5000")
research_result = researcher_client.execute_skill(
    "research", "research AI 在医疗领域的应用"
)

# 2. 把研究结果传给撰写员
writer_client = A2AClient("http://localhost:5001")
article = writer_client.execute_skill(
    "write", f"write {research_result['result']}"
)

print(article['result'])
```

→ **两个 Agent 链式协作**,产出完整文章。

## ⚖️ 10.3.7 A2A 实际状况:**生态早期**

> ⚠️ **务实评估**

| 维度 | A2A 现状 |
|---|---|
| 协议成熟度 | 早期 |

## 🆚 10.3.8 A2A vs 第 6 章多 Agent 框架

| | **A2A 协议** | **AutoGen/AgentScope/CAMEL** |
|---|---|---|
| 性质 | **通信协议**(标准) | **多 Agent 框架** |
| 实现 | 协议规范 | 完整框架 |
| 关系 | **底层** | 框架可基于 A2A 实现 |
| 当前推荐 | 学概念 | **生产用框架** |

→ **类比**:**A2A 像 HTTP 协议**,**AutoGen 像 React 框架**。

---

## ⚠️ 小白避坑

1. **不要全面替代框架**
   - 生产用框架(AutoGen / CrewAI)更稳
2. **A2A 协议本身在演进**
   - 跟着 Google 官方动态走
3. **Agent 之间的认证别忘**
   - 真实生产必须做(否则任意 Agent 都能调用)
4. **错误处理要鲁棒**
   - 网络调用 → 必须 try/except + 超时

## 📌 10.3 节要点

| 知识点 | 一句话 |
|---|---|
| **A2A 定位** | 智能体↔智能体的 P2P 通信协议 |
| **解决问题** | 中心化协调器的单点故障/瓶颈/扩展难 |
| **核心抽象** | Task(任务)+ Artifact(工件) |
| **生命周期** | 创建→协商→代理→执行→完成 |
| **@skill 装饰器** | 定义 Agent 的技能 |
