## ⭐ 必须记住的"全书核心十二条"

1. **Agent = LLM + 工具 + 规划 + 记忆 + 反思** —— 缺一不可
2. **Thought → Action → Observation 循环**是所有 Agent 的核心骨架
3. **ReAct 是最基础范式**,Plan-and-Solve 适合复杂任务,Reflexion 适合需迭代
4. **多 Agent 协作**用"角色分工 + 共享状态"
5. **HelloAgents 五大模块**:LLM / Tool / Agent / Memory / Workflow
6. **记忆分短长期**:短期靠 buffer,长期靠向量库 + RAG
7. **上下文工程 = prompt 设计 + 压缩 + 路由**,直接决定 Agent 上限
8. **MCP 协议** = Anthropic 推动的 Tool 标准,Claude / Cursor 都在用
9. **Agent 通信三层**:MCP(工具)/ A2A(协作)/ ANP(身份)
10. **Agentic-RL**:SFT 冷启 + GRPO 提升,奖励函数是灵魂
11. **BFCL 评工具调用**,**GAIA 评通用能力**,**LLM Judge 评数据质量**
12. **训练 + 评估 = Agent 开发的完整闭环**,不评估的 Agent 等于盲飞

## 🌅 写在最后

Agent 是一个**比 LLM 更年轻**的领域。本书覆盖的是**截至 2026 年初**的核心知识,但:

- **新协议每月发布**(MCP → A2A → ANP → ...)
- **新框架每周出现**(从 LangChain 到 LangGraph 到 ...)
- **新范式每季度更迭**(从 ReAct 到 Multi-Agent 到 Agentic-RL)

**真正重要的不是"学完这本书",而是建立"Agent 思维"**:

> **Agent 思维 = 把任何任务拆成 → 感知 + 决策 + 行动 + 反思**

掌握了这个思维:
- 看到新论文能快速理解(范式都差不多)
- 看到新框架能快速上手(架构都类似)
- 看到新应用能快速复现(工具链你都会)
- 看到新协议能快速接入(MCP 你已经懂了)
