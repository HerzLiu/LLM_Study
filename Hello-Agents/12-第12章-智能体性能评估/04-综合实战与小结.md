## ⭐ 三大评估横向对比

| 维度 | **BFCL** | **GAIA** | **数据质量** |
|---|---|---|---|
| **评什么** | 工具调用能力 | 通用 AI 能力 | 生成数据质量 |
| **数据集** | 1.6K 条工具调用样本 | 466 道真实世界问题 | 自定义(本章 AIME) |
| **评估算法** | AST 匹配 | 准精确匹配 | LLM Judge + Win Rate |
| **难度** | 中(单步/多步/并行) | 极高(多模态/长链路) | 中(领域相关) |
| **输入类型** | 文本 | 文本 + 图 + PDF + Excel | 文本(题目) |
| **关键指标** | Accuracy / AST Match | Exact Match Rate | 平均分 / Win Rate |
| **官方榜单** | [Gorilla Leaderboard](https://gorilla.cs.berkeley.edu/leaderboard.html) | [GAIA Leaderboard](https://huggingface.co/spaces/gaia-benchmark/leaderboard) | 无(自评) |
| **适用场景** | 评工具型 Agent | 评全能 AI 助手 | 评数据生成系统 |
| **HelloAgents 工具** | `BFCLEvaluationTool` | `GAIAEvaluationTool` | `LLMJudgeTool` + `WinRateTool` |

## 🐍 综合实战:一个 Agent 三套评估

```python
from helloagents import HelloAgentsLLM, SimpleAgent
from helloagents.evaluation import (
    BFCLEvaluationTool,
    GAIAEvaluationTool,
    LLMJudgeTool,
    WinRateTool
)

# Step 1: 创建你的 Agent
llm = HelloAgentsLLM()
agent = SimpleAgent(
    name="MyAgent",
    llm=llm,
    system_prompt="你是一个全能 AI 助手"
)

# Step 2: BFCL 评估(工具调用能力)
print("=" * 80)
print("📊 评估 1: BFCL 工具调用能力")
bfcl_tool = BFCLEvaluationTool()
bfcl_result = bfcl_tool.run({
    "agent": agent,
    "categories": ["simple", "multiple", "parallel", "irrelevance"],
    "max_samples": 100  # 先跑 100 个测试
})
print(f"BFCL 总体准确率: {bfcl_result['accuracy']:.2%}")

# Step 3: GAIA 评估(通用能力)
print("=" * 80)
print("🌍 评估 2: GAIA 通用能力")
gaia_tool = GAIAEvaluationTool()
gaia_result = gaia_tool.run({
    "agent": agent,
    "level": 1,         # 先从 Level 1 开始
    "max_samples": 50
})
print(f"GAIA Level 1 精确匹配率: {gaia_result['exact_match_rate']:.2%}")

# Step 4: 用 Agent 生成数据,再评估生成质量
print("=" * 80)
print("📝 评估 3: 数据生成质量")
# (假设 Agent 已经生成了一批 AIME 题目)
judge_tool = LLMJudgeTool()
judge_result = judge_tool.run({
    "generated_data_path": "./generated_aime.json",
    "judge_model": "gpt-4o"
})
print(f"LLM Judge 平均分: {judge_result['metrics']['avg_score']:.2f}/5.0")

winrate_tool = WinRateTool()
winrate_result = winrate_tool.run({
    "generated_data_path": "./generated_aime.json",
    "reference_year": 2025
})
print(f"Win Rate (vs AIME 2025): {winrate_result['win_rate']:.1%}")

# Step 5: 综合报告
print("\n" + "=" * 80)
print("🏆 综合评估报告")
print(f"  - 工具调用能力 (BFCL): {bfcl_result['accuracy']:.2%}")
print(f"  - 通用能力 (GAIA L1):  {gaia_result['exact_match_rate']:.2%}")
print(f"  - 生成质量 (LLM Judge): {judge_result['metrics']['avg_score']:.2f}/5.0")
print(f"  - 生成质量 (Win Rate):  {winrate_result['win_rate']:.1%}")
```

## 📊 评估指标全景速查

### BFCL 指标

| 指标 | 公式 | 含义 |
|---|---|---|
| Accuracy | 正确数 / 总数 | 总体准确率 |
| AST Match Rate | AST 匹配数 / 总数 | 工具签名匹配率 |
| Category Accuracy | 按类别拆分 | 各类别准确率 |
| Weighted Score | 按难度加权 | 综合分 |
| Error Rate | 错误数 / 总数 | 错误率 |

### GAIA 指标

| 指标 | 含义 |
|---|---|
| Exact Match Rate | 准精确匹配率 |
| Level Metrics | L1 / L2 / L3 分级准确率 |
| Avg Steps | 平均推理步数 |
| Tool Usage | 工具调用次数分布 |

### 数据质量指标

| 指标 | 健康线 |
|---|---|
| LLM Judge 平均分 | ≥ 4.0 / 5.0 |
| LLM Judge 通过率 | ≥ 80% |
| LLM Judge 优秀率 | ≥ 40% |
| Win Rate | 45% ~ 55% |
| 人工通过率 | ≥ 90% |

## 🎯 评估三大核心组件(架构层)

HelloAgents 评估系统的**统一架构**:

```
┌──────────────────────────────────────────────────────┐
│              EvaluationTool(对外接口)                │
│         (一键评估 / 生成报告 / 提交榜单)               │
└──────────────────────┬───────────────────────────────┘
                       │
        ┌──────────────┼──────────────┐
        ↓              ↓              ↓
   ┌─────────┐   ┌──────────┐   ┌─────────┐
   │ Dataset │   │Evaluator │   │ Metrics │
   │ 数据加载 │  │  评估器   │   │ 指标计算 │
   └─────────┘   └──────────┘   └─────────┘
        │              │              │
   BFCLDataset  BFCLEvaluator  BFCLMetrics
   GAIADataset  GAIAEvaluator  GAIAMetrics
    AIDataset   LLMJudgeEvaluator  …
```

**统一架构带来的好处**:
- 新增评估基准 → 只需实现 3 个类
- 各基准复用相同接口 → 学一遍会一片
- CI/CD 集成简单 → 调用同一套 API

## 💡 扩展方向

基于本章的评估系统,你可以在 **4 个方向** 扩展:

### 1. 添加新的评估基准

参考 BFCL/GAIA 的模式,实现:
```python
class MyBenchmarkDataset(Dataset): ...
class MyBenchmarkEvaluator(Evaluator): ...
class MyBenchmarkMetrics(Metrics): ...
class MyBenchmarkEvaluationTool(Tool): ...
```

参考资料:
- API-Bank(工具调用)
- AgentBench(综合 Agent 能力)
- WebArena(Web 操作)
- SWE-bench(代码修复)

### 2. 自定义评估指标

在 `Metrics` 类中加新指标:
```python
def compute_efficiency(self, results):
    """评估工具调用效率"""
    avg_steps = sum(r['steps'] for r in results) / len(results)
    return 1.0 / avg_steps  # 步数越少效率越高
```

### 3. 集成到 CI/CD

```yaml
# .github/workflows/agent-eval.yml
name: Agent Evaluation
on: [push]
jobs:
  evaluate:
    runs-on: ubuntu-latest
    steps:
      - run: |
          python -m helloagents.evaluation bfcl \
            --agent my_agent.py \
            --max-samples 50
      # 性能阈值检查
      - run: |
          python -c "
          import json
          r = json.load(open('eval_result.json'))
          assert r['accuracy'] >= 0.80, f'性能退化!{r[\"accuracy\"]}'
          "
```

### 4. 扩展数据生成评估

支持更多数据类型:
- 代码生成质量(LeetCode 风格)
- 对话生成质量(多轮一致性)
- 文档生成质量(摘要 ROUGE)

## 📝 本章核心要点

| # | 要点 |
|---|---|
| 1 | **评估 = Agent 开发的"高考"**,不评不知道好坏 |
| 2 | **BFCL** 评工具调用,**GAIA** 评通用能力,**LLM Judge** 评数据质量 |
| 3 | HelloAgents 统一架构:**Dataset + Evaluator + Metrics + Tool** |
| 4 | AST 匹配 vs 准精确匹配 vs LLM 评分 —— **针对不同任务选不同评估方式** |
| 5 | LLM Judge 要警惕 **bias**,Win Rate 要 **双盲**,人工验证不可少 |
| 6 | 一切评估都要支持 **断点续跑** + **检查点保存**(几千道题不能白跑) |
| 7 | 评估能 **集成 CI/CD**,自动监控性能退化 |

## ⚠️ 全章避坑清单

1. **不要只看一个指标** —— BFCL 高不代表 GAIA 高
2. **小样本先跑通** —— 1.6K 全量跑前先跑 10 个验证流程
3. **保存中间结果** —— API 调用很贵,中断要能恢复
4. **多评委交叉验证** —— LLM Judge 单评委可能偏差大
5. **关注子指标** —— 总分 80% 但 irrelevance 类别 0% 还是有问题
6. **GAIA 多模态不要漏** —— 没装 PDF / 图像解析能力直接 0 分
7. **小心评估"作弊"** —— 训练时用了评估集 = 数据泄漏
