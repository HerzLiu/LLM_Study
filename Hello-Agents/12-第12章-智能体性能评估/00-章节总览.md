## 🎬 一句话故事

> 第 11 章我们**训了 Agent**,但 —— **训得好不好,怎么知道?**

→ 本章引入**评估** —— Agent 开发的"**最后一公里**":

| 评估目的 | 重要性 |
|---|---|
| **客观衡量能力** | 不被自己"感觉良好"骗 |
| **横向对比** | 知道和顶尖 Agent 差多远 |
| **指导优化** | 知道哪里要改 |
| **可发表 / 提交榜单** | 学术 + 商业价值 |

→ **训练 + 评估 = Agent 开发的完整闭环**。

## 🎯 本章学完你将拥有

- [ ] 理解 **BFCL 评估流程**(AST 匹配 + 4 大类别)
- [ ] 能用 **HelloAgents BFCLEvaluationTool** 一键评估工具调用
- [ ] 知道 BFCL **5 大评估指标**(Accuracy / AST Match / Category / Weighted / Error Rate)
- [ ] 理解 **GAIA 评估基准**(通用 AI 能力 + 3 个难度级别)
- [ ] 知道 GAIA 的**准精确匹配(Quasi Exact Match)**
- [ ] 能用 **HelloAgents GAIAEvaluationTool** 评估通用能力
- [ ] 会**提交结果到 BFCL / GAIA 官方排行榜**
- [ ] 理解 **LLM Judge / Win Rate / 人工验证** 三大数据质量评估法
- [ ] 能用 LLM Judge 从**4 个维度**给数据打分(正确性/清晰度/难度/完整性)
- [ ] 会用 **Gradio 搭人工验证 Web 界面**

## ⚖️ BFCL vs GAIA 速选

| 维度 | **BFCL** | **GAIA** |
|---|---|---|
| 关注点 | **工具调用** | **通用能力** |
| 难度 | 中 | **高** |
| 输入 | 文本 | 文本 + 图 + PDF + Excel |
| 评估算法 | AST 匹配 | 准精确匹配 |
| 适合 | 评估工具型 Agent | 评估全能 AI 助手 |
| 排行榜 | https://gorilla.cs.berkeley.edu/leaderboard.html | https://huggingface.co/spaces/gaia-benchmark/leaderboard |

## 📝 本章一句话小结

**BFCL 评估"用工具的能力"**,**GAIA 评估"做事的能力"**。
HelloAgents 把两者都**一键化** —— 让你 5 分钟看到 Agent 的真实水平。
**评估是 Agent 开发的最后一公里,也是上榜的入场券**。
