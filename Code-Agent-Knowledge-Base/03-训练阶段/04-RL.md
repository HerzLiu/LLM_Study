# RL

⬅ [03-SFT](03-SFT.md) | ➡ [Reward-Hacking与Sandbox安全](../05-Reward%E4%B8%8E%E7%A8%B3%E5%AE%9A%E6%80%A7/Reward-Hacking%E4%B8%8ESandbox%E5%AE%89%E5%85%A8.md)

## 🎬 故事比喻：让新人进模拟车间独立接单

SFT 是看师傅录像，RL 是让新人进模拟车间自己修。

每张工单都有真实车辆、工具、检测仪和验收标准。新人可以走弯路，可以第一次修错，但每次点火测试都会给反馈。训练的目标不是模仿师傅每一步，而是提高未来工单的真实修复率。

## 目标

让模型在真实可验证环境中自己探索，用测试和执行反馈提升修 bug 成功率。

## 喂什么数据

参考 [04-RL任务与验证器数据](../02-%E6%95%B0%E6%8D%AE%E5%B7%A5%E7%A8%8B/04-RL%E4%BB%BB%E5%8A%A1%E4%B8%8E%E9%AA%8C%E8%AF%81%E5%99%A8%E6%95%B0%E6%8D%AE.md)：

- problem statement。
- repo 与 base commit。
- FAIL_TO_PASS / PASS_TO_PASS。
- docker image。
- scaffold 配置。

没有教师答案轨迹。

## 训练信号

沙箱执行后的 reward：

- F2P 是否通过。
- P2P 是否保持。
- 工具是否合法。
- patch 是否合理。
- 是否触发安全审计。

## 🔧 技术拆解：一个 RL step

```text
1. 取一批 task
2. 每个 task 采样多条 trajectory
3. scaffold 通过 proxy 调 rollout 模型
4. sandbox 执行工具并返回 observation
5. submit 后跑 F2P/P2P
6. reward -> advantage -> policy update
7. actor 权重同步到 rollout engine
```

## 训练环境

```text
Actor / Policy
  -> vLLM Rollout Engine
  -> Proxy 拦截 scaffold 的 LLM 调用
  -> Sandbox 执行工具和测试
  -> Reward
  -> GRPO / KL 更新 Actor
  -> 同步权重回 Rollout
```

## 关键工程 trick

- 代理层劫持 scaffold API，保证 rollout 来自正在训练的模型。
- 每个 prompt 采样多条轨迹，用组内相对 reward 做 GRPO。
- rollout 和训练尽量异步，避免长轨迹阻塞。
- horizon 从短到长课程放开。
- 用 KL 锚、KL-Cov、序列级重要性比率稳定长轨迹训练。

## 🧪 例子：F2P/P2P 如何变成 reward

```text
FAIL_TO_PASS:
  tests/test_timeout.py::test_zero_timeout

PASS_TO_PASS:
  tests/test_timeout.py::test_normal_timeout
  tests/test_requests.py::test_regular_request

reward:
  F2P 全过 +0.7
  P2P 全保留 +0.2
  没改测试文件 +0.1
  非法命令 / 超时 / 修改隐藏文件 扣分
```

真实工程里不会只看一个 0/1。否则模型很容易学会“改测试、skip 测试、硬编码样例”这类 [reward hacking](../05-Reward%E4%B8%8E%E7%A8%B3%E5%AE%9A%E6%80%A7/Reward-Hacking%E4%B8%8ESandbox%E5%AE%89%E5%85%A8.md)。

## ⚠️ 工程坑

| 坑 | 表现 | 处理 |
|---|---|---|
| 长轨迹阻塞 | batch 等最慢任务 | 异步 rollout 队列 |
| reward 太稀疏 | 大部分轨迹 0 分 | partial tests / progress reward |
| on-policy 破坏 | scaffold 调到外部模型 | proxy 统一转发到当前 rollout |
| policy 漂移 | 工具格式突然变坏 | KL anchor / reference model |

## 产物

Coder Model：

- 能在自己的轨迹里试错。
- 能利用测试反馈修正 patch。
- 对没见过的 bug 有更高解决率。
