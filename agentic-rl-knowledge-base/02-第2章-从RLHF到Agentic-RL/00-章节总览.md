## 🎬 一句话故事：算法谱系图

在 GPT-3 之前，大家用 PPO 训练机器人走路。
ChatGPT 出来后，PPO 被搬来训 LLM：

> 「人类标 chosen/rejected → 训 reward model → PPO 优化 LLM」 → 这就是 **RLHF**。

然后社区一路简化、改造、扩展：

```
RLHF (2022, InstructGPT)
   ↓ 嫌 RM + PPO 太重
DPO (2023)          ─── 直接用偏好对优化，不要 RM、不要在线 rollout
   ↓ 嫌 critic 太贵
GRPO (2024, DeepSeekMath) ─── 同 prompt 多采样，用组内相对奖励代替 critic
   ↓ 嫌人类反馈太贵 + 数学/代码任务有客观答案
RLVR (2025, DeepSeek-R1) ─── 用可验证奖励（答案对错、测试通过）训练
   ↓ 嫌最终 reward 太稀疏
PRM (Let's Verify Step-by-Step) ─── 给中间每一步打分
```

> **本章把这条线讲清楚**：每个算法解决了上一个算法的什么问题，缺点是什么，适合什么场景。
> 这条线就是你进入 Code Agentic RL 的"算法工具箱"——SWE-RL、CodeRL 用的都是这些。

## 🧭 本章知识地图

```
                      LLM 上的 RL 谱系
                            │
        ┌───────────────────┼──────────────────────┐
        │                   │                      │
   【偏好驱动】          【可验证奖励驱动】     【奖励粒度】
        │                   │                      │
   RLHF (SFT+RM+PPO)    RLVR (规则/单测/        ORM (结果奖励)
        │               执行/答案校验)          PRM (过程奖励)
   DPO  (省RM+离线)         │
        │               DeepSeek-R1
   GRPO (省critic+组内    DeepSeekMath
        相对优势)
        │
   ✦ Agentic RL 里最常用：
     GRPO + RLVR + 偶尔 PRM
```

## 🎯 对你目标的重要性

你要做 Code Agentic RL，本章对应的实际用法：

| 算法 | 你会在 Code 专题哪里遇到 |
|---|---|
| **RLHF（PPO 部分）** | 几乎所有 LLM RL 框架（TRL / verl / OpenRLHF）的算法底座 |
| **DPO** | Toy Bug-Fix Agent Gym 里的"通过 patch > 未通过 patch"偏好对 |
| **GRPO** | DeepSeek-R1、open-r1、SWE-RL 等核心方法 |
| **RLVR** | 用 pytest 通过率作 reward 的本质就是 RLVR |
| **PRM** | 给「localization 对 / patch 对 / 测试跑通」每一步打分 |

## ⚠️ 学习建议

1. **2.1 RLHF 必须先读**：是后面所有算法的"母版"。
2. **不要陷入数学**：DPO 的推导很优雅但很烧脑，第一遍只看直觉和实验结论。
3. **GRPO 是当前 SOTA 高频词**：DeepSeek-R1、SWE-RL、open-r1 全是它，**重点理解**。
4. **跨章配合**：本章学完，回 [Hello-Agents 11.4](../../Hello-Agents/11-%E7%AC%AC11%E7%AB%A0-Agentic-RL/04-GRPO%E8%AE%AD%E7%BB%83%E5%AE%9E%E6%88%98.md) 看真实代码会一通百通。

## 📝 本章一句话小结

> **RLHF 是起点，DPO 是绕过 RM，GRPO 是绕过 critic，RLVR 是绕过人类标注。**
> 每一步都是为了**「更便宜、更可验证、更适合工具/代码/数学任务」**。
> Code Agentic RL = GRPO 算法骨架 + RLVR 奖励来源 + 多步 trajectory 训练。
