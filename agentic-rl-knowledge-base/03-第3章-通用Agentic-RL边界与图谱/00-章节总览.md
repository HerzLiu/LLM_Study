## 📌 与第 4 章 Code 专题的关系

第 3 章是**通用视角**，第 4 章是**Code 垂直视角**。两者关系：

| 维度 | 第 3 章 | 第 4 章 |
|---|---|---|
| **覆盖任务** | Web / Tool / 数学 / 代码 / APP / 多 agent 全覆盖 | 只看代码（issue / patch / test） |
| **论文重叠** | SWE-bench 在第 3 章是"强推"，第 4 章是"必学" | 第 4 章新增 SWE-agent / Agentless / CodeRL / SWE-Gym 等 |
| **Repo 重叠** | TRL / verl / Agent Lightning 是通用训练框架 | SWE-bench / SWE-agent / Aider / OpenHands 是 code-specific |
| **算法** | PPO / DPO / GRPO / RLVR 通用 | 同 + 强调 execution feedback / 测试 reward |

→ **如果你时间紧，第 3 章只需读 3.1（边界）+ 3.2（论文卡的前 5 篇）**，剩下的随时回查。

---

## ⚠️ 学习建议

1. **3.1 边界 必读**：分不清 Agentic RL 和 workflow agent，后面所有讨论都会偏。
2. **3.2 论文卡只读"必学"前 5 篇**：ReAct → PPO → InstructGPT → DPO → DeepSeekMath。其它按需。
3. **3.4 Repo 不要急着装**：先按角色分类（训练框架 / agent scaffold / benchmark / sandbox），有 GPU 才考虑跑。
4. **3.5 路线参考即可**：你的目标是 Code，6 周通用路线只是兜底，不要被它捆绑。
