## 🪪 必读卡 1 — PPO

| 字段 | 内容 |
|---|---|
| 标题 | Proximal Policy Optimization Algorithms |
| 作者 / 机构 | John Schulman et al., OpenAI |
| 年份 | 2017 |
| 状态 | arXiv |
| 链接 | https://arxiv.org/abs/1707.06347 |
| 解决的问题 | 普通 policy gradient 更新步长难控制，容易崩 |
| 方法核心 | **Clipping** 限制概率比 + KL 约束 |
| 和 Agentic RL 关系 | **算法底座**：RLHF、GRPO、绝大多数 LLM RL 都基于它 |
| 阶段 | 初学者 |
| 前置知识 | MDP、policy gradient |
| 是否现在精读？ | ✅ **必精读**（看摘要、目标函数、clip 直觉，推导可后补） |

→ 详细在 [04-PPO与KL约束](../01-%E7%AC%AC1%E7%AB%A0-RL%E6%9C%80%E5%B0%8F%E5%BF%85%E8%A6%81%E5%9F%BA%E7%A1%80/04-PPO%E4%B8%8EKL%E7%BA%A6%E6%9D%9F.md)

|---|---|

| 作者 / 机构 | Shunyu Yao et al., Princeton / Google |

## 🧭 3.2.1 论文之间的关系图

```
                            【算法层】
              PPO ────────→ InstructGPT (RLHF) ────→ DPO
              (2017)        (PPO 训 LLM 2022)        (2023)
                  │                                    │
                  └──→ DeepSeekMath/GRPO ←─── 简化     │
                       (2024)              (省 critic)
                  │
                  └──→ DeepSeek-R1/RLVR ←─── 简化
                       (2025)              (省 RM)

                            【监督层】
              Let's Verify Step-by-Step (PRM 2023)

                          【Agent 基础层】
              ReAct ─→ Toolformer ─→ AgentBench
              (轨迹格式) (工具学习) (评测)

                          【Agent RL 训练框架】
              ArCHer (层次 RL) → Agent Lightning (任意 agent 接入) → GiGPO (fine-grained)
```
