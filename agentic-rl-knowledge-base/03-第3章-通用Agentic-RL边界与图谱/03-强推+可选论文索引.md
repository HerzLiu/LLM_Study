## 🌟 3.3.0 强烈推荐 8 篇（索引）

来自原始资料 §"强烈推荐" 表格：

| # | 论文 | 年份 | 状态（资料原标注） | 链接 | 一句话价值 | 推荐阶段 |
|---|---|---:|---|---|---|---|
| 1 | **WebGPT**: Browser-assisted question-answering with human feedback | 2021 | arXiv | https://arxiv.org/abs/2112.09332 | **早期"浏览器环境 + human feedback"的 Agentic RL 雏形** | 进阶 |
| 2 | **Reflexion**: Language Agents with Verbal Reinforcement Learning | 2023 | NeurIPS 2023（CCF-A **需确认**） | https://papers.neurips.cc/paper_files/paper/2023/hash/1b44b878bb782e6954cd888628510e90-Abstract-Conference.html | **不更新参数**，把反馈写入 verbal memory；理解 self-improvement 的**非梯度版本** | 初学者 / 进阶 |
| 3 | **ToolLLM**: Facilitating Large Language Models to Master 16000+ Real-world APIs | 2024 | ICLR 2024（CCF-A **需确认**） | https://proceedings.iclr.cc/paper_files/paper/2024/hash/28e50ee5b72e90b50e7196fde8ea260e-Abstract-Conference.html | 大规模 API 工具学习；理解 **tool-use 数据构造** | 进阶 |
| 4 | **SWE-bench**: Can Language Models Resolve Real-world Github Issues? | 2024 | ICLR 2024（CCF-A **需确认**） | https://proceedings.iclr.cc/paper_files/paper/2024/hash/edac78c3e300629acfe6cbe9ca88fb84-Abstract-Conference.html | **软件工程 agent 的真实环境 benchmark** | 进阶 |
| 5 | **AppWorld**: A Controllable World of Apps and People for Benchmarking Interactive Coding Agents | 2024 | ACL 2024 **Best Resource Paper** | https://aclanthology.org/2024.acl-long.850/ | 函数调用 + APP 世界 + 可控环境 | 进阶 |
| 6 | **tau-bench**: A Benchmark for Tool-Agent-User Interaction in Real-World Domains | 2024 | arXiv | https://arxiv.org/abs/2406.12045 | 多轮**用户模拟器** + 工具交互，贴近实际客服 / 业务 agent | 进阶 |
| 7 | **DAPO**: An Open-Source LLM Reinforcement Learning System at Scale | 2025 | arXiv | https://arxiv.org/abs/2503.14476 | 理解 GRPO/PPO 之后的**工程化变体**和大规模 RL recipe | 研究者 |
| 8 | **Tool-Star**: Empowering LLM-Brained Multi-Tool Reasoner via Reinforcement Learning | 2025 | arXiv | https://arxiv.org/abs/2505.16410 | 多工具 reasoning 的 RL 框架 | 研究者 |

### 这 8 篇按"我什么时候需要看"分类

| 你的需求 | 看哪几篇 |
|---|---|
| 想理解 agentic RL 的早期 root | **WebGPT** |
| 不想训练模型也能改进 agent | **Reflexion**（verbal RL） |
| 做工具调用 / API 学习 | **ToolLLM** |
| 做 Code Agent（**你的目标**） | **SWE-bench** ⭐⭐⭐⭐⭐ |
| 做 APP / function-calling agent | **AppWorld** |
| 做客服 / 业务对话 agent | **tau-bench** |
| 做大规模 RL 训练系统 | **DAPO** |
| 做多工具 reasoning | **Tool-Star** |

> 💡 **你方向是 Code Agentic RL**，所以 **SWE-bench 是其中最重要的**。它同时也是 [Code 必读 10 篇](../04-%E7%AC%AC4%E7%AB%A0-Code-Agentic-RL%E4%B8%93%E9%A2%98/05-%E5%BF%85%E8%AF%BB%E8%AE%BA%E6%96%8710%E7%AF%87%E7%B2%BE%E8%AF%BB%E5%8D%A1%EF%BC%88SWE-bench%E7%BA%BF%EF%BC%89.md) 的第 1 篇。
