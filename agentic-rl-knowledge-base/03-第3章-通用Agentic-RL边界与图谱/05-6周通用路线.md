# 3.5 6 周通用学习路线

⬅ [04-Repo地图与运行成本](04-Repo%E5%9C%B0%E5%9B%BE%E4%B8%8E%E8%BF%90%E8%A1%8C%E6%88%90%E6%9C%AC.md) | ➡ [00-章节总览](../04-%E7%AC%AC4%E7%AB%A0-Code-Agentic-RL%E4%B8%93%E9%A2%98/00-%E7%AB%A0%E8%8A%82%E6%80%BB%E8%A7%88.md)

---

## 🎬 故事比喻：6 周从"听过 RL"到"能设计 toy 实验"

```
第 1 周: 补 RL 基础（你最薄弱）
第 2 周: 学 RLHF + PPO for LLM
第 3 周: 学 DPO / GRPO / RLVR
第 4 周: Agent 基础 + 评测
第 5 周: Agentic RL 核心论文与训练框架
第 6 周: 做一个 toy project
```

> **本节是"通用版"路线**——覆盖整个 Agentic RL 方向。
> 如果你目标只是 Code Agentic RL，**优先看** [02-Code-Agentic-RL-6周路线](../06-%E7%AC%AC6%E7%AB%A0-%E5%AD%A6%E4%B9%A0%E8%B7%AF%E5%BE%84%E9%80%9F%E6%9F%A5/02-Code-Agentic-RL-6%E5%91%A8%E8%B7%AF%E7%BA%BF.md)（更 Code-focused）。

---

## 📅 3.5.1 全 6 周路线总览

| 周 | 主题 | 必读 | 产出物 |
|---|---|---|---|
| 第 1 周 | RL 最小必要基础 | Sutton & Barto Ch 3、PPO 摘要、CleanRL PPO | 1 页 MDP 笔记 + RL loop 伪代码 |
| 第 2 周 | RLHF / PPO for LLM | InstructGPT、PPO 完整、TRL 文档 | 流程图 + RLHF vs SFT 对比表 |
| 第 3 周 | DPO / GRPO / RLVR | DPO、DeepSeekMath、DeepSeek-R1、Let's Verify | 算法对比表 + 3 个可验证 reward 例子 |
| 第 4 周 | Agent 基础与评测 | ReAct、Toolformer、AgentBench | 跑一个 agent eval；写 task 的 state/action/reward |
| 第 5 周 | Agentic RL 论文与框架 | ArCHer、Agent Lightning、GiGPO、verl-agent | trajectory → RL transition 设计草图 |
| 第 6 周 | Toy Project | TRL / Agent Lightning / verl / open-r1 | README + trajectories.jsonl + 失败模式表 |

## 📖 3.5.2 各周详细安排

### 第 1 周：RL 最小必要基础

**学习目标**：

- 用 MDP/POMDP 语言描述 agent 任务
- 理解 policy / value / advantage / return
- 看懂 PPO 核心目标，不要求推导熟练

**必读材料**：

- Sutton & Barto, RL: An Introduction，**Ch 3 MDP**
- Sutton & Barto **Ch 13 policy gradient**（选读）
- OpenAI Spinning Up PPO：https://spinningup.openai.com/en/latest/algorithms/ppo.html
- CleanRL PPO 代码：https://github.com/vwxyzjn/cleanrl

**可选**：

- David Silver RL Course（MDP / Policy Gradient / Actor-Critic 部分）
- Gymnasium 文档

**应掌握**：

- state、action、reward、done、trajectory
- return、discount factor
- policy、value function、advantage
- policy gradient、actor-critic、PPO clipping
- sparse reward、credit assignment

**练习 / 产出物**：

```
1 页笔记：为什么一个 tool-use agent 可以被看成 MDP/POMDP？
伪代码：reset → observe → act → reward → update 的 RL loop
```

→ 本库对应：[00-章节总览](../01-%E7%AC%AC1%E7%AB%A0-RL%E6%9C%80%E5%B0%8F%E5%BF%85%E8%A6%81%E5%9F%BA%E7%A1%80/00-%E7%AB%A0%E8%8A%82%E6%80%BB%E8%A7%88.md)

---

### 第 2 周：RLHF 与 PPO for LLM

**学习目标**：

- 理解 RLHF 三阶段：SFT、reward model、PPO
- 理解 KL regularization 为啥关键
- 区分 "token-level action" 和 "sequence-level reward"

**必读**：

- InstructGPT
- PPO paper
- TRL 文档与示例

**可选**：WebGPT、OpenRLHF 文档

**应掌握**：

- preference data / reward model / reference model
- KL penalty / rollout / value head
- PPO for language models

**产出物**：

```
画一张 prompt → response → reward model → PPO update 流程图
写一个表格比较 RLHF 和 SFT
```

→ 本库对应：[01-RLHF三阶段（SFT-RM-PPO）](../02-%E7%AC%AC2%E7%AB%A0-%E4%BB%8ERLHF%E5%88%B0Agentic-RL/01-RLHF%E4%B8%89%E9%98%B6%E6%AE%B5%EF%BC%88SFT-RM-PPO%EF%BC%89.md)

---

### 第 3 周：DPO / GRPO / RLVR

**学习目标**：

- 理解 DPO 为什么省 RM 和在线 PPO
- 理解 GRPO 怎么用 group-relative reward 估 advantage
- 理解 RLVR 为什么适合数学 / 代码 / 工具 / agent 环境

**必读**：

- DPO
- DeepSeekMath
- DeepSeek-R1
- Let's Verify Step by Step

**可选**：DAPO、PRM800K、open-r1

**应掌握**：

- DPO objective 直觉
- GRPO group sampling
- RLVR / ORM vs PRM / verifier-based reward
- reward hacking

**产出物**：

```
对比表: PPO / DPO / GRPO / RLVR 的 数据 / reward / 是否 online / 优缺点
3 个可验证 reward 例子: 数学 / SQL / 代码测试
```

→ 本库对应：[06-五大算法对比表](../02-%E7%AC%AC2%E7%AB%A0-%E4%BB%8ERLHF%E5%88%B0Agentic-RL/06-%E4%BA%94%E5%A4%A7%E7%AE%97%E6%B3%95%E5%AF%B9%E6%AF%94%E8%A1%A8.md)

---

### 第 4 周：Agent 基础与评测

**学习目标**：

- 把 ReAct trajectory 映射到 RL 术语
- 理解 tool-use agent 的 action space 和 observation
- 了解主流 agent benchmark 评测指标

**必读**：

- ReAct
- Toolformer
- AgentBench
- AgentBench repo

**可选**：ToolLLM、SWE-bench、tau-bench、AppWorld

**应掌握**：

- thought / action / observation trajectory
- tool selection vs parameter generation
- environment feedback
- task success rate / pass@k / success@k
- simulated user

**产出物**：

```
跑一个 AgentBench 或 tau-bench 的最小 eval
(暂时不跑→ 手动阅读一个任务环境并写出它的 state/action/reward)
```

→ 本库对应：[03-Observation-Action-Reward定义](../04-%E7%AC%AC4%E7%AB%A0-Code-Agentic-RL%E4%B8%93%E9%A2%98/03-Observation-Action-Reward%E5%AE%9A%E4%B9%89.md)

---

### 第 5 周：Agentic RL 核心论文与训练框架

**学习目标**：

- 理解多轮 agent 的 credit assignment 为什么比单轮 RLHF 难
- 理解 trainer-agent 解耦、trajectory slicing、hierarchical RL 的动机
- 看懂一个 agent RL 框架如何收集 rollout

**必读**：

- ArCHer
- Agent Lightning + repo
- GiGPO
- verl-agent

**可选**：Tool-Star、Reflexion、AutoGen

**应掌握**：

- multi-turn rollout
- trajectory-level reward
- step-level reward
- credit assignment
- hierarchical policy
- tool-call action
- trainer-agent disaggregation

**产出物**：

```
"agent trajectory 如何转 RL transition" 设计草图
标出哪些字段是 observation / action / reward / done / info
```

→ 本库对应：[02-必学论文12篇精读卡](02-%E5%BF%85%E5%AD%A6%E8%AE%BA%E6%96%8712%E7%AF%87%E7%B2%BE%E8%AF%BB%E5%8D%A1.md) #10 (ArCHer) / #11 (Agent Lightning) / #12 (GiGPO)

---

### 第 6 周：Toy Project

**学习目标**：

- 做一个最小但闭环的 tool-use agent experiment
- 至少实现 baseline evaluation；条件允许再接 TRL/Agent Lightning/verl 做训练

**推荐项目（选 1 个）**：

| 项目 | 任务 | reward |
|---|---|---|
| Calculator agent | 多步算术 / 单位转换 | exact match |
| SQL agent | 自然语言查询 | SQLite execution 一致 |
| Code test agent | 小函数修复 | unit test |

→ **你（Code 方向）应直接选 Code test agent** = [Toy Bug-Fix Agent Gym](../05-%E7%AC%AC5%E7%AB%A0-%E5%8A%A8%E6%89%8B%E9%A1%B9%E7%9B%AE/02-Toy-Bug-Fix-Agent-Gym%EF%BC%88%E6%A0%B8%E5%BF%83%EF%BC%89.md)

**必读**：

- TRL
- Agent Lightning
- verl
- open-r1

**应掌握**：

- environment wrapper / deterministic reward
- rollout logging
- baseline vs trained model
- failure analysis

**产出物**：

```
README: 任务定义 / 环境 / 动作空间 / 奖励函数 / baseline / 实验结果
trajectories.jsonl: 每行一次 episode
小表格: success rate / 平均步数 / 常见失败模式
```

## 🎯 3.5.4 路线 vs 你的目标对齐度

| 你的目标 = Code Agentic RL | 通用 6 周路线的覆盖度 |
|---|---|
| 第 1 周 RL 基础 | ✅ 完全相关 |
| 第 2 周 RLHF/PPO | ✅ 完全相关 |
| 第 3 周 DPO/GRPO/RLVR | ✅ **极相关**（GRPO+RLVR 是 Code 主流） |
| 第 4 周 Agent 基础 | ⚠️ 部分相关（ReAct/AgentBench 通用，SWE-bench 在第 4 章详讲） |
| 第 5 周 Agentic RL 框架 | ⚠️ 部分相关（Agent Lightning 有用，ArCHer/GiGPO 可跳） |
| 第 6 周 Toy Project | ✅ 你做 Bug-Fix Gym 即可 |

→ **建议**：通用 6 周路线 + 替换第 4-5 周为 Code 专题 = Code Agentic RL 6 周路线。
