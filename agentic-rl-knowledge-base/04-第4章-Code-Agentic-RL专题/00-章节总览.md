## 🎬 一句话故事：从「会写函数的模型」到「修 GitHub issue 的开发者」

```
Level 1: Code LLM       ─── 给 prompt 写一个函数（HumanEval、MBPP）
Level 2: Code Agent     ─── 读 issue → 找文件 → 改代码 → 跑测试 → 修改 → 提 patch
Level 3: Code Agentic   ─── Level 2 + 用「测试通过率」作 reward 反过来训练 agent
        RL
```

**第 3 步就是本章的全部内容。**

> 这是 Anthropic Claude Code、Devin、SWE-agent、OpenHands、Aider 这条产品线背后的研究方向。

## 📝 本章一句话小结

> **Code Agent 的优势是「可执行 = 客观 reward」**：
> pytest 通过就是过，编译失败就是错，不需要请人类标注。
> 这让代码任务成为 **RLVR 最自然的战场**。
> 但同时也是 **reward hacking 最严重的地方**——agent 可能学会改测试、hard-code 隐藏 pattern、让测试 skip。
> **能力栈 + OAR + 5 种 reward + reward hacking 防护**，这 4 件事是本章的全部。
