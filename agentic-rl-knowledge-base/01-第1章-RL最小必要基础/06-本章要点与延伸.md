## 🎬 故事比喻：你现在拥有的 RL 词典

读完前 5 节，你应该能"用 RL 黑话"描述一个 Code Agent 任务：

> 「修 SWE-bench issue 是一个 **POMDP**。
> **policy** π 是 LLM，**action space** 是 `{search, read, edit, run_tests, final}`，
> **state** 是 repo + 历史，**observation** 是 context 里的压缩视图。
> **reward** 是 sparse outcome（pytest pass=1, else=0），
> **horizon** 通常 30-50 步。
> 训练用 **GRPO**：同一 issue sample K 个 trajectory，**组内相对奖励**做 advantage，
> 加 **KL penalty** 防止 π 偏离 SFT model 太远。」

如果上面这段话你能复述（不用记公式，但每个词知道在指啥），**第 1 章就算过关了**。

## 🚫 1.6.3 可以先跳过的内容（资料原文）

来自原始资料 `01-boundaries.md` §"可以先跳过"：

> 这些不是不重要，而是对入门 Agentic RL 的**边际收益较低**：

| 跳过项 | 说明 |
|---|---|
| **DQN 全家桶** | Deep Q-Network 系列，离散小动作空间用，**LLM RL 用不上** |
| **SAC / TD3 / DDPG** | 连续控制专用（机器人）算法，**LLM RL 用不上** |
| **复杂 Bellman 收敛证明** | 理论分析，工程实践基本不用 |
| **经典 MARL 博弈理论** | 多智能体博弈深水区，LLM multi-agent 不一定走这条 |
| **Model-based RL 深水区** | 学环境模型再 planning，**LLM RL 实践很少** |
| **Offline RL 理论** | 纯离线训 RL 的理论，LLM RL 实践偏 SFT/DPO |
| **Control theory 背景** | 控制论基础，**完全不用** |

> 💡 **什么时候补这些？**
> 当你准备做 RL 算法研究（不是应用）或大规模训练系统工程时再补。
> 目前你的目标是 Code Agentic RL，**前 5 节够用了**。

## 🎯 1.6.5 进入第 4 章前的桥接

如果你急着去 Code 专题（不看第 2/3 章），最少要记住：

1. **Code Agent = POMDP**（观察不全，是压缩 context）
2. **Trajectory 是优化对象**（不是单步）
3. **Sparse reward + Credit assignment** 是核心难题
4. **PPO/GRPO 通过 advantage 训练**，但具体形式不同
5. **KL 约束保护语言能力**，没它会崩
6. **Reward hacking** 在 Code 任务里**极常见**

→ 然后跳到 [00-章节总览](../04-%E7%AC%AC4%E7%AB%A0-Code-Agentic-RL%E4%B8%93%E9%A2%98/00-%E7%AB%A0%E8%8A%82%E6%80%BB%E8%A7%88.md)，需要回查时再翻第 2-3 章。

## 📝 1.6.6 一句话小结

> **RL 不是新东西**——你写的每个 ReAct agent 都隐式在跑一个 MDP loop。
> RL 只是把这个 loop **数学化**，让你能用"梯度"反过来改进 π。
> Agentic RL = 把 MDP 时间轴拉长 + 用 LLM 当 π + 用 PPO/GRPO 当 update。
>
> **第 1 章给你的不是"会做 RL 研究"，是"看懂 GRPO/RLVR 论文里的每个词"**。
