## 🎬 一句话故事：从「prompt engineer」到「RL engineer」的思维切换

你之前写 agent 是这样：

> 「给一个好的 prompt，再加几个 tool，agent 就会干活了。」

进入 Agentic RL 之后你需要这样想：

> 「agent 是一个 **policy π(a|s)**，它在 **state s** 下选 **action a**，
> 环境给它 **reward r**，多步之后我用 **PPO/GRPO** 优化这个 π。」

这不是换汤不换药——**这是把"行为"看成可优化的统计量**，而不再是"prompt 调对了就完事"。

> 本章不会让你成为 RL 专家。它只让你看得懂第 2~4 章里所有公式和黑话。

---

## 🎯 本章学完你将拥有

- [ ] 能用 MDP 五元组 `(S, A, P, R, γ)` 描述一个 tool-use agent 任务
- [ ] 看懂 policy π / value V / Q / advantage A 四个核心量
- [ ] 理解 policy gradient 的直觉：**"提高获得高奖励动作的概率"**
- [ ] 理解 actor-critic 为什么需要 critic：**减小梯度方差**
- [ ] 看懂 PPO 的 clip 公式和 KL 惩罚是干嘛的
- [ ] 知道什么是 sparse reward / credit assignment / reward hacking
- [ ] 看到 GRPO、RLVR、PRM 时不再一脸懵

## 📏 本章深度声明

本章按"**中等深度 + 详细讲解**"组织：

- **每个概念配故事比喻**（让 LLM 背景的人秒懂）
- **保留核心公式**（看得懂含义，不强求会推导）
- **每个概念都映射到 LLM/Agent 里对应什么**（你最熟的锚点）
- ❌ 不做 Bellman 收敛证明
- ❌ 不做 PPO clipping 的几何推导
- ✅ 给最小可跑的伪代码片段（来自资料 / 概念示意，不保证可运行）

如果想更深：
- 读 Sutton & Barto 第 3、13 章（资料里 `04-six-week-roadmap.md` 第 1 周必读）
- 看 OpenAI Spinning Up PPO：https://spinningup.openai.com/en/latest/algorithms/ppo.html
- CleanRL 单文件 PPO 实现：https://github.com/vwxyzjn/cleanrl

---

## ⚠️ 学习建议

1. **不要追求"理解 100%"**：第一遍读完能复述故事比喻就够了。
2. **用 ReAct 当锚点**：每个 RL 概念都问自己"这在 ReAct trajectory 里对应什么"。
3. **跳过 DQN / SAC / TD3**：原始资料 `01-boundaries.md` 明确说这些"可以先跳过"。
4. **公式看不懂不要停**：第 2 章重新讲一遍 PPO 时还会用到，那时再回来。

---

## 📝 本章一句话小结

> **RL 在 Agentic RL 里只是个"工具语言"**：用它来描述「agent 在多轮环境里行动，根据奖励调整策略」这件事。
> 你不需要变成 RL 研究员，你需要的是**用 MDP/policy/PPO 的话语体系，看懂 GRPO/RLVR 论文里在说什么**。
