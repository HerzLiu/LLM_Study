## 🎬 这份速查表的用途

> 看论文 / 写代码 / 写报告时，不想翻整本书查某个公式怎么写——回这一节。
> 每个公式 1 行写法 + 1 句用途 + 同 section 顶部一个跳转链接到详讲。

**约定**：

- 上标 $^\pi$ 表示"在策略 $\pi$ 下"
- $\theta$ 表示要训的策略参数，$\phi$ 表示 RM/PRM/verifier 参数
- $\tau$ 表示一条轨迹 $(s_0, a_0, r_0, \dots, s_T)$
- $\hat{\cdot}$ 表示"估计值"

## 🧮 A.4.1 RL 基础（第 1 章）

### MDP / Return

📍 详讲：[01-MDP与轨迹（用Agent语言讲RL）](../01-%E7%AC%AC1%E7%AB%A0-RL%E6%9C%80%E5%B0%8F%E5%BF%85%E8%A6%81%E5%9F%BA%E7%A1%80/01-MDP%E4%B8%8E%E8%BD%A8%E8%BF%B9%EF%BC%88%E7%94%A8Agent%E8%AF%AD%E8%A8%80%E8%AE%B2RL%EF%BC%89.md)

| 公式 | 名字 | 含义 | 详讲段号 |
|---|---|---|---|
| $(S, A, P, R, \gamma)$ | MDP 五元组 | RL 任务的数学描述 | §1.1.1 |
| $P(s_{t+1} \mid s_t, a_t)$ | 马尔可夫性质 | 未来只依赖当前 state | §1.1.1 |
| $\tau = (s_0, a_0, r_0, \dots, s_T, a_T, r_T)$ | Trajectory | 一条完整 episode | §1.1.4 |
| $G_t = \sum_{k=0}^{T-t} \gamma^k r_{t+k}$ | Return（回报） | 从 $t$ 起累积折扣奖励 | §1.1.4 |
| $G_t = r_t + \gamma G_{t+1}$ | Return 递归 | Bellman 的起点 | §1.1.4 |
| $J(\pi) = \mathbb{E}_{\tau \sim \pi}[G_0]$ | RL 目标函数 | 要最大化的量 | §1.1.4 |

### Value / Q / Advantage

📍 详讲：[02-Policy-Value-Advantage](../01-%E7%AC%AC1%E7%AB%A0-RL%E6%9C%80%E5%B0%8F%E5%BF%85%E8%A6%81%E5%9F%BA%E7%A1%80/02-Policy-Value-Advantage.md)

| 公式 | 名字 | 含义 | 详讲段号 |
|---|---|---|---|
| $V^\pi(s) = \mathbb{E}_\pi[G_0 \mid s_0=s]$ | State value | 从 $s$ 起按 $\pi$ 玩平均拿多少 | §1.2.2 |
| $Q^\pi(s,a) = \mathbb{E}_\pi[G_0 \mid s_0=s, a_0=a]$ | Action value | 在 $s$ 选 $a$ 后按 $\pi$ 玩平均拿多少 | §1.2.3 |
| $V^\pi(s) = \mathbb{E}_{a \sim \pi}[Q^\pi(s,a)]$ | V vs Q 关系 | V 是 Q 在 π 下的加权平均 | §1.2.3 |
| $V^\pi(s) = \mathbb{E}[R(s,a) + \gamma V^\pi(s')]$ | Bellman 方程 | 现在 = 即刻 + 折扣未来 | §1.2.2 |
| $A^\pi(s,a) = Q^\pi(s,a) - V^\pi(s)$ | Advantage | 这个动作比平均好多少 | §1.2.4 |
| $\delta_t = r_t + \gamma V(s_{t+1}) - V(s_t)$ | TD 残差 | 1 步 advantage 估计 | §1.2.4 |
| $\hat{A}_t^{\text{GAE}} = \sum_{l=0}^{T-t} (\gamma\lambda)^l \delta_{t+l}$ | GAE | 实战 advantage 估计 | §1.2.4 |

### Policy Gradient / Actor-Critic

📍 详讲：[03-Policy-Gradient与Actor-Critic](../01-%E7%AC%AC1%E7%AB%A0-RL%E6%9C%80%E5%B0%8F%E5%BF%85%E8%A6%81%E5%9F%BA%E7%A1%80/03-Policy-Gradient%E4%B8%8EActor-Critic.md)

| 公式 | 名字 | 含义 | 详讲段号 |
|---|---|---|---|
| $\nabla_\theta J = \mathbb{E}_\pi[\sum_t \nabla \log \pi_\theta(a_t \mid s_t) \cdot G_t]$ | PG 定理 | 策略梯度的核心公式 | §1.3.1 |
| $\nabla_\theta J = \mathbb{E}_\pi[\sum_t \nabla \log \pi_\theta(a_t \mid s_t) \cdot (G_t - b(s_t))]$ | PG + baseline | 减 baseline 降方差 | §1.3.3 |
| $\nabla_\theta J = \mathbb{E}_\pi[\sum_t \nabla \log \pi_\theta(a_t \mid s_t) \cdot A^\pi(s_t,a_t)]$ | Actor-Critic | 用 advantage 当信号 | §1.3.4 |

### PPO + KL

📍 详讲：[04-PPO与KL约束](../01-%E7%AC%AC1%E7%AB%A0-RL%E6%9C%80%E5%B0%8F%E5%BF%85%E8%A6%81%E5%9F%BA%E7%A1%80/04-PPO%E4%B8%8EKL%E7%BA%A6%E6%9D%9F.md)

| 公式 | 名字 | 含义 | 详讲段号 |
|---|---|---|---|
| $r_t(\theta) = \pi_\theta(a_t \mid s_t) / \pi_{\theta_{old}}(a_t \mid s_t)$ | importance ratio | 新旧策略概率比 | §1.4.2 |
| $L^{\text{CLIP}} = \mathbb{E}[\min(r_t \hat{A}_t,\, \text{clip}(r_t, 1\!\pm\!\epsilon) \hat{A}_t)]$ | PPO clip loss | 限制更新幅度 | §1.4.2 |
| $\text{KL}(P \,\Vert\, Q) = \sum_x P(x) \log \frac{P(x)}{Q(x)}$ | KL 散度 | 两分布的差距 | §1.4.3 |
| $L^{\text{LLM-PPO}} = L^{\text{CLIP}} - \beta \cdot \text{KL}(\pi_\theta \,\Vert\, \pi_{ref})$ | LLM PPO | 加 KL 防漂移 | §1.4.3 |
| $\tilde{r}_t = r_t - \beta (\log \pi_\theta - \log \pi_{ref})$ | Shaped reward | KL 塞进 reward | §1.4.3 |
| $\beta_{new} = \beta_{old} \cdot 1.5 \text{ if KL} > 1.5 \text{KL}_{target}$ | Adaptive KL | 动态调 β | §1.4.3 |

### On-Policy vs Off-Policy

📍 详讲：[04b-On-Policy-vs-Off-Policy](../01-%E7%AC%AC1%E7%AB%A0-RL%E6%9C%80%E5%B0%8F%E5%BF%85%E8%A6%81%E5%9F%BA%E7%A1%80/04b-On-Policy-vs-Off-Policy.md)

| 公式 | 名字 | 含义 | 详讲段号 |
|---|---|---|---|
| $\mathbb{E}_{x \sim p}[f] = \mathbb{E}_{x \sim q}[\frac{p(x)}{q(x)} f]$ | Importance sampling | 换分布求期望 | §1.4b.3 |
| $\mu = \pi_\theta$ | On-policy 条件 | 数据必须来自当前策略 | §1.4b.1 |
| $\mu \ne \pi_\theta$ | Off-policy 条件 | 数据可来自任何策略 | §1.4b.1 |

### Sparse Reward / Reward Shaping

📍 详讲：[05-Sparse-Reward与信用分配](../01-%E7%AC%AC1%E7%AB%A0-RL%E6%9C%80%E5%B0%8F%E5%BF%85%E8%A6%81%E5%9F%BA%E7%A1%80/05-Sparse-Reward%E4%B8%8E%E4%BF%A1%E7%94%A8%E5%88%86%E9%85%8D.md)

| 公式 | 名字 | 含义 | 详讲段号 |
|---|---|---|---|
| $F(s, a, s') = \gamma \Phi(s') - \Phi(s)$ | Potential-based shaping | **不改变最优策略**的安全 shaping | §1.5.3 A.1 |

## 🤖 A.4.2 LLM 上的 RL 算法（第 2 章）

### SFT / RM (RLHF)

📍 详讲：[01-RLHF三阶段（SFT-RM-PPO）](../02-%E7%AC%AC2%E7%AB%A0-%E4%BB%8ERLHF%E5%88%B0Agentic-RL/01-RLHF%E4%B8%89%E9%98%B6%E6%AE%B5%EF%BC%88SFT-RM-PPO%EF%BC%89.md)

| 公式 | 名字 | 含义 | 详讲段号 |
|---|---|---|---|
| $\mathcal{L}_{SFT} = -\sum_i \sum_t \log P_\theta(y_{i,t} \mid x_i, y_{i,<t})$ | SFT loss | autoregressive NLL | §2.1.3 |
| $\mathcal{L}_{RM} = -\mathbb{E}[\log \sigma(r_\phi(x, y_w) - r_\phi(x, y_l))]$ | RM loss (BT) | Bradley-Terry 偏好学习 | §2.1.4 |
| $P(y_w \succ y_l \mid x) = \sigma(r(x, y_w) - r(x, y_l))$ | Bradley-Terry 模型 | 偏好对的概率模型 | §2.1.4 |
| $R_{total} = r_\phi(x, y) - \beta \cdot \text{KL}(\pi_\theta(y \mid x) \,\Vert\, \pi_{ref}(y \mid x))$ | PPO RM-shaped reward | RM 分数减 KL | §2.1.5 |

### DPO

📍 详讲：[02-DPO（偏好直接优化）](../02-%E7%AC%AC2%E7%AB%A0-%E4%BB%8ERLHF%E5%88%B0Agentic-RL/02-DPO%EF%BC%88%E5%81%8F%E5%A5%BD%E7%9B%B4%E6%8E%A5%E4%BC%98%E5%8C%96%EF%BC%89.md)

| 公式 | 名字 | 含义 | 详讲段号 |
|---|---|---|---|
| $\pi^*(y \mid x) = \frac{1}{Z(x)} \pi_{ref}(y \mid x) \exp(\frac{r(x,y)}{\beta})$ | RLHF 闭式最优解 | 拉格朗日乘子推出 | §2.2.2 Step 1 |
| $r(x, y) = \beta \log \frac{\pi^*(y \mid x)}{\pi_{ref}(y \mid x)} + \beta \log Z(x)$ | 隐式 reward | reward 反推自 policy | §2.2.2 Step 2 |
| $\mathcal{L}_{DPO} = -\mathbb{E}[\log \sigma(\beta \log\frac{\pi_\theta(y_w \mid x)}{\pi_{ref}(y_w \mid x)} - \beta \log\frac{\pi_\theta(y_l \mid x)}{\pi_{ref}(y_l \mid x)})]$ | DPO loss | 直接训 policy，无 RM | §2.2.2 Step 4 |

### GRPO

📍 详讲：[03-GRPO（组内相对优势）](../02-%E7%AC%AC2%E7%AB%A0-%E4%BB%8ERLHF%E5%88%B0Agentic-RL/03-GRPO%EF%BC%88%E7%BB%84%E5%86%85%E7%9B%B8%E5%AF%B9%E4%BC%98%E5%8A%BF%EF%BC%89.md)

| 公式 | 名字 | 含义 | 详讲段号 |
|---|---|---|---|
| $\mu_g = \frac{1}{K}\sum_i R_i$ | 组均值 | 同 prompt sample K 个的均值 | §2.3.2 |
| $\sigma_g = \sqrt{\frac{1}{K}\sum_i (R_i - \mu_g)^2 + \epsilon}$ | 组标准差 | 防除 0 加 $\epsilon$ | §2.3.2 |
| $\hat{A}_i = (R_i - \mu_g) / \sigma_g$ | 组内相对 advantage | 替代 critic V | §2.3.2 |
| $\rho_{i,t} = \pi_\theta(y_{i,t} \mid q, y_{i,<t}) / \pi_{\theta_{old}}(y_{i,t} \mid q, y_{i,<t})$ | token 级 importance ratio | PPO 风格 | §2.3.3 |
| $L^{GRPO} = \mathbb{E}[\frac{1}{K}\sum_i \frac{1}{T_i}\sum_t \min(\rho_{i,t} \hat{A}_i,\, \text{clip}(\rho_{i,t}) \hat{A}_i)] - \beta \cdot \text{KL}$ | GRPO 完整 loss | 长度归一化 + 组内 advantage | §2.3.3 |

### RLVR

📍 详讲：[04-RLVR（可验证奖励）](../02-%E7%AC%AC2%E7%AB%A0-%E4%BB%8ERLHF%E5%88%B0Agentic-RL/04-RLVR%EF%BC%88%E5%8F%AF%E9%AA%8C%E8%AF%81%E5%A5%96%E5%8A%B1%EF%BC%89.md)

| 公式 | 名字 | 含义 | 详讲段号 |
|---|---|---|---|
| $R_{\text{RLVR}}(x, y) = V(x, y) = \mathbb{1}[y \text{ 通过验证}]$ | RLVR reward | verifier 函数（无可学参数） | §2.4.2 |
| 同 GRPO loss + $R \leftarrow V$ | GRPO+RLVR | RLVR 替代 RM，GRPO 替代 critic | §2.4.5 |

### PRM / ORM

📍 详讲：[05-PRM与ORM（过程vs结果奖励）](../02-%E7%AC%AC2%E7%AB%A0-%E4%BB%8ERLHF%E5%88%B0Agentic-RL/05-PRM%E4%B8%8EORM%EF%BC%88%E8%BF%87%E7%A8%8Bvs%E7%BB%93%E6%9E%9C%E5%A5%96%E5%8A%B1%EF%BC%89.md)

| 公式 | 名字 | 含义 | 详讲段号 |
|---|---|---|---|
| $\text{ORM}_\phi(x, y) \to r$ | ORM 函数 | 整段 response 给 1 分 | §2.5.2 |

## ⚠️ 常见公式陷阱

| 公式 | 容易写错的地方 |
|---|---|
| $A = G - V$ | $G$ 是**实际跑到的** return（一次采样），不是 $\mathbb{E}[G]$ |
| GAE 递归 | 必须**倒序**累加：`gae = δ + γλ·gae` |
| PPO clip | 取 $\min$**不是 $\max$**——这是悲观下界 |
| $\text{KL}(\pi_\theta \,\Vert\, \pi_{ref})$ | 顺序重要！$\pi_\theta$ 在前 |
| DPO loss | 两个 ratio**相减**不是相除 |
| GRPO advantage | 必须**同 prompt**才能组（不同 prompt $\mu_g$ 无意义） |
| Pass@k | 用**unbiased estimator**，不要直接 $c/k$ |
| Potential shaping | $\Phi$ **只能依赖 state**，不能依赖 action |
