## 🎬 一句话故事

**NLP = 教外星人说人话**。
外星人只懂 0 和 1，你想让他读懂《红楼梦》、回你微信、写英文邮件。整个 NLP 史就是教学方法的演进：
- **发字典**（规则时代） → 死板，不懂语境
- **统计经验**（统计学习） → 有直觉，但不懂语义
- **接神经网络**（深度学习） → 自己悟，今天 GPT 的前身

## 📝 本章一句话小结

**文本表示是 NLP 的灵魂**：从 One-Hot 的稀疏向量 → Word2Vec 的稠密静态词向量 → ELMo 的动态上下文词向量，每一步都是为了让计算机更"懂"语义。这条进化线**直接通向 Transformer**（第 2 章）。
