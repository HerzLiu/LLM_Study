# 1.2 NLP 发展的三个时代

⬅ [01-NLP是什么](01-NLP%E6%98%AF%E4%BB%80%E4%B9%88.md)　|　➡ [03-NLP九大任务](03-NLP%E4%B9%9D%E5%A4%A7%E4%BB%BB%E5%8A%A1.md)

---

## 🎬 故事比喻：教外星人的三种教学法

| 时代 | 教学方法 | 类比 |
|---|---|---|
| **早期** | 发字典 + 词序规则 | 给外星人字典 |
| **统计学习** | 让他统计文本里哪些词常一起出现 | 让他做大量阅读笔记 |
| **深度学习** | 给他接神经网络，自己悟规律 | 让他像人脑一样思考 |

---

## 🔧 三个时代速览

### ① 早期探索（1940s – 1960s）

- **背景**：二战后，机器翻译需求兴起
- **代表事件**：
  - **1950 图灵测试**：艾伦·图灵提出"机器能否被认为会思考"
  - **乔姆斯基生成语法**：对机器翻译影响深远
- **技术特点**：依赖**字典查找 + 词序规则**
- **结局**：效果很差，遇到 "It's raining cats and dogs" 翻译成"天上下猫和狗"

### ② 符号主义 vs 统计方法（1970s – 1990s）

- **两大流派**：
  - **符号主义**：手写大量语言规则（规则越来越多越复杂）
  - **统计方法**：从大语料里统计概率
- **1980 年代**：算力提升 + 机器学习引入，**统计模型逐渐取代手写规则**
- **代表**：HMM（隐马尔可夫模型）、N-gram

### ③ 机器学习 / 深度学习（2000s – 至今）

| 年份 | 里程碑 | 意义 |
|---|---|---|
| 2000s | RNN/LSTM 引入 NLP | 神经网络处理序列 |
| **2013** | **Word2Vec** | 词向量革命 → [看这里](04-%E6%96%87%E6%9C%AC%E8%A1%A8%E7%A4%BA%E6%BC%94%E8%BF%9B.md#%E6%96%B9%E6%A1%88-b%E6%80%A7%E6%A0%BC%E7%94%BB%E5%83%8Fword2vec) |
| 2017 | **Transformer** | 注意力机制取代 RNN → [第 2 章](../02-%E7%AC%AC2%E7%AB%A0-Transformer%E6%9E%B6%E6%9E%84/00-%E7%AB%A0%E8%8A%82%E6%80%BB%E8%A7%88.md) |
| 2018 | **BERT / GPT** | 预训练-微调范式 |
| 2022 | **ChatGPT** | LLM 进入大众视野 |
| 2024+ | GPT-4 / LLaMA / DeepSeek | 多模态 + 推理 |

---

## ⭐ 加深理解：核心趋势

**贯穿三个时代的一条主线**：
> **从"人工写规则"→"让机器自己从数据里学"**

这条主线最终催生了 LLM —— 不再有人手写一条"if 看到 X 就回答 Y"的规则，全部交给海量数据 + 强大算力。

---

## ⚠️ 小白避坑

- **不用死记年份**，记住三个时代的"教学方法"就够了
- **三个时代不是替代关系，而是叠加关系**：现代 LLM 里也有统计成分（如词频、采样温度），只是底层主力换成了神经网络
- **"深度学习"≠ 万能**：在小数据场景，统计方法或规则系统仍然有用
