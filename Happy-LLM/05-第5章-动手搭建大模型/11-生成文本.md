## 🐍 完整推理代码

```python
import os, torch
from contextlib import nullcontext
from k_model import ModelConfig, Transformer
from transformers import AutoTokenizer

class TextGenerator:
    def __init__(self,
                 checkpoint='./base_model_215M/pretrain_1024_18_6144.pth',
                 tokenizer_model_path='./tokenizer_k/',
                 seed=42,
                 device=None,
                 dtype="bfloat16"):
        """初始化文本生成器"""
        self.checkpoint = checkpoint
        self.tokenizer_model_path = tokenizer_model_path
        self.seed = seed
        self.device = device or ('cuda:0' if torch.cuda.is_available() else 'cpu')
        self.dtype = dtype
        self.device_type = 'cuda' if 'cuda' in self.device else 'cpu'

        # 设置随机种子
        torch.manual_seed(seed)
        torch.cuda.manual_seed(seed)
        torch.backends.cuda.matmul.allow_tf32 = True
        torch.backends.cudnn.allow_tf32 = True

        # 设置混合精度推理
        ptdtype = {'float32': torch.float32,
                   'bfloat16': torch.bfloat16,
                   'float16': torch.float16}[self.dtype]
        self.ctx = nullcontext() if self.device_type == 'cpu' else \
                   torch.amp.autocast(device_type=self.device_type, dtype=ptdtype)

        # 加载模型
        checkpoint_dict = torch.load(self.checkpoint, map_location=self.device)
        self.model = Transformer(ModelConfig(dim=1024, n_layers=18))

        # 兼容性处理
        sunwanted_prefix = '_orig_mod.'
        for k, v in list(checkpoint_dict.items()):
            if k.startswith(sunwanted_prefix):
                checkpoint_dict[k[len(sunwanted_prefix):]] = checkpoint_dict.pop(k)
        self.model.load_state_dict(checkpoint_dict, strict=False)

        num_params = sum(p.numel() for p in self.model.parameters() if p.requires_grad)
        print(f"Model has {num_params / 1e6:.3f} M parameters.")

        # 切换到评估模式
        self.model.eval()
        self.model.to(self.device)

        # 加载 tokenizer
        self.tokenizer = AutoTokenizer.from_pretrained(self.tokenizer_model_path)

    def chat_template(self, prompt):
        """套上聊天模板"""
        message = [
            {"role": "system", "content": "你是一个 AI 助手，你的名字叫小明。"},
            {"role": "user", "content": prompt}
        ]
        return self.tokenizer.apply_chat_template(
            message, tokenize=False, add_generation_prompt=True
        )

    def sft_sample(self, start="Hello!", num_samples=3, max_new_tokens=256,
                   temperature=0.7, top_k=300):
        """SFT 模型生成（用聊天模板）"""
        start = self.chat_template(start)
        start_ids = self.tokenizer(start).data['input_ids']
        x = torch.tensor(start_ids, dtype=torch.long, device=self.device)[None, ...]

        generated_texts = []
        with torch.no_grad():
            with self.ctx:
                for k in range(num_samples):
                    y = self.model.generate(
                        x, self.tokenizer.eos_token_id,
                        max_new_tokens, temperature=temperature, top_k=top_k
                    )
                    generated_texts.append(self.tokenizer.decode(y[0].tolist()))
        return generated_texts

    def pretrain_sample(self, start="Hello!", num_samples=3, max_new_tokens=256,
                        temperature=0.7, top_k=300):
        """预训练模型生成（不用聊天模板，直接续写）"""
        start_ids = self.tokenizer(start).data['input_ids']
        x = torch.tensor(start_ids, dtype=torch.long, device=self.device)[None, ...]

        generated_texts = []
        with torch.no_grad():
            with self.ctx:
                for k in range(num_samples):
                    y = self.model.generate(
                        x, self.tokenizer.eos_token_id,
                        max_new_tokens, temperature=temperature, top_k=top_k
                    )
                    generated_texts.append(self.tokenizer.decode(y[0].tolist()))
        return generated_texts
```

## 📝 关键解读

### 1. 推理 vs 训练的几个不同

| 项                 | 训练              | **推理**               |
| ----------------- | --------------- | -------------------- |
| 模式                | `model.train()` | `model.eval()`       |
| 梯度                | 计算              | `torch.no_grad()` 关闭 |
| Dropout           | 开启              | 自动关闭（eval 模式）        |
| BatchNorm/RMSNorm | 使用 batch 统计     | 用累积统计                |

### 2. `chat_template` + `add_generation_prompt=True`

```python
message = [
    {"role": "system", "content": "..."},
    {"role": "user", "content": prompt},
]
self.tokenizer.apply_chat_template(message, tokenize=False, add_generation_prompt=True)
```

输出：
```
<|im_start|>system
你是一个 AI 助手<|im_end|>
<|im_start|>user
你好<|im_end|>
<|im_start|>assistant
                ↑ 模型从这里开始续写
```

→ `add_generation_prompt=True` **多加了 `<|im_start|>assistant\n`** 这一行，提示模型"该你说了"。

### 3. 调用 `model.generate(...)` 自回归生成

```python
y = self.model.generate(
    x,                                        # 起始 token
    stop_id=self.tokenizer.eos_token_id,      # 遇到 <|im_end|> 就停
    max_new_tokens=256,                       # 最多生成 256 个
    temperature=0.7,                          # 温度
    top_k=300                                 # top-k 采样
)
```

`generate` 的内部逻辑见 [完整 LLaMA2 模型代码](06-%E5%AE%8C%E6%95%B4LLaMA2%E6%A8%A1%E5%9E%8B.md#-%E5%AE%8C%E6%95%B4%E4%BB%A3%E7%A0%81)。

## 🎛 采样策略详解

### 策略 1：贪心（Greedy）

```python
temperature = 0.0
```

每步选**概率最大**的 token。
- ✅ 完全确定
- ❌ 容易重复，无创造性

### 策略 2：温度采样（Temperature Sampling）

```python
logits = logits / temperature
probs = softmax(logits)
next_token = sample from probs
```

| 温度 | 效果 | 适用 |
|---|---|---|
| 0.1 | 几乎贪心 | 数学、代码（要确定答案） |
| **0.7** | **平衡**（常用） | 通用对话 |
| 1.0 | 标准随机 | 创意写作 |
| 1.5 | 高度随机 | 头脑风暴 |

**直觉**：温度越大，softmax 越平滑 → 越可能选低概率 token → 越随机。

### 策略 3：Top-k 采样

```python
top_k = 50
```

只在**概率前 k 个 token** 里采样，其他都设 -inf。
- ✅ 避免选到非常离谱的低概率词
- ❌ k 固定，不灵活

### 策略 4：Top-p 采样（Nucleus）

```python
top_p = 0.9
```

按概率从大到小累加，直到累计概率 ≥ p，**只在这个动态集合里采样**。
- ✅ 比 top-k 灵活（候选数自适应）
- ✅ 当前最主流

> 本书的 `generate` 实现只有 top-k，生产代码通常 top-k + top-p + temperature 三者结合。

## 🎮 推理示例

### 用预训练模型续写

```python
gen = TextGenerator(checkpoint='./base_model_215M/pretrain_1024_18_6144.pth')
results = gen.pretrain_sample(
    start="北京的秋天",
    num_samples=2,
    max_new_tokens=100
)
for r in results:
    print(r)
```

## ⚡ 加速推理的常用技巧

| 技巧 | 作用 | 复杂度 |
|---|---|---|
| **KV-Cache** | 缓存历史 K/V，避免重复计算 | 中（本章未实现） |
| **Flash Attention** | 推理时也用 | 简单（PyTorch 2.0+ 自动） |
| **量化**（int8 / int4） | 模型权重压缩 | 中 |
| **批处理推理** | 多请求一起算 | 简单 |
| **vLLM / TGI** | 专用推理框架 | 工程化 |

→ 本章是**学习版**，没做这些优化。生产部署用 vLLM 等专用框架。

## ⚠️ 小白避坑

1. **`model.eval()` 必须调用**
   - 否则 dropout 还开着，输出不稳定
2. **`torch.no_grad()` 别忘**
   - 否则推理时还在算梯度，速度慢、占显存
3. **温度别太大**
   - > 1.5 容易胡言乱语
4. **`max_new_tokens` 别设太大**
   - 200~500 通常够，太大耗时
5. **SFT 和 Pretrain 用不同 sample 方法**
   - SFT 用 `chat_template`，Pretrain 直接续写
