## 🎬 故事比喻：一个完整的训练日

```
☀️ 清晨：起床 = 初始化模型 / 优化器 / 数据加载器
📚 上课：一节课 = 一个 batch
   ├── 听课 = forward 前向传播
   ├── 反思 = 算 loss
   ├── 记错题 = backward 反向传播
   └── 改正 = optimizer.step 更新参数
🌙 晚上：放假 = 保存模型 checkpoint
```

→ 这就是一个 epoch（轮）的完整循环。

---

## 🏗 训练循环全景

```
┌─────────────────────────────────────────────────┐
│  for epoch in range(epochs):                     │
│      for step, (X, Y, mask) in train_loader:     │
│          1. 更新学习率（warmup + cosine）         │
│          2. forward（在 autocast 上下文里）       │
│          3. 算 loss（× loss_mask）                │
│          4. backward（× grad scaler 防 fp16 下溢）│
│          5. 梯度累积（每 N 步才 step 一次）        │
│          6. 梯度裁剪（防爆炸）                    │
│          7. optimizer.step()                     │
│          8. 定期 log + save                       │
└─────────────────────────────────────────────────┘
```

## 🐍 核心代码（拆解版）

### Part 1：学习率调度（Warmup + Cosine）

```python
def get_lr(it, all):
    """
    学习率调度：先 warmup 后 cosine 衰减
    """
    warmup_iters = args.warmup_iters
    lr_decay_iters = all
    min_lr = args.learning_rate / 10

    # 阶段 1：Warmup —— 线性从 0 增长到目标 lr
    if it < warmup_iters:
        return args.learning_rate * it / warmup_iters

    # 阶段 3：超过总步数 —— 保持最小 lr
    if it > lr_decay_iters:
        return min_lr

    # 阶段 2：Cosine 衰减
    decay_ratio = (it - warmup_iters) / (lr_decay_iters - warmup_iters)
    coeff = 0.5 * (1.0 + math.cos(math.pi * decay_ratio))
    return min_lr + coeff * (args.learning_rate - min_lr)
```

#### 📝 学习率曲线

```
lr ↑
   │     ╱╲
   │    ╱  ╲___
   │   ╱       ╲___
   │  ╱            ╲___
   │ ╱                 ╲___
   │╱                       └─────── min_lr
   └──────────────────────────────► step
   warmup    cosine 衰减
```

| 阶段 | 公式 | 作用 |
|---|---|---|
| **Warmup** | 线性增长 | 防止刚开始大学习率把模型崩了 |
| **Cosine** | 余弦衰减 | 平滑降低，精细调整 |

→ 现代 LLM 的**标准学习率调度方案**。

### Part 2：训练一个 epoch

```python
def train_epoch(epoch):
    start_time = time.time()

    for step, (X, Y, loss_mask) in enumerate(train_loader):
        # 数据搬到 GPU
        X = X.to(args.device)
        Y = Y.to(args.device)
        loss_mask = loss_mask.to(args.device)

        # 1. 更新学习率
        lr = get_lr(epoch * iter_per_epoch + step, args.epochs * iter_per_epoch)
        for param_group in optimizer.param_groups:
            param_group['lr'] = lr

        # 2. 前向传播（自动混合精度）
        with ctx:   # ctx = torch.cuda.amp.autocast()
            out = model(X, Y)
            loss = out.last_loss / args.accumulation_steps

            # 应用 loss_mask（只算有效位置）
            loss_mask = loss_mask.view(-1)
            loss = torch.sum(loss * loss_mask) / loss_mask.sum()

        # 3. 反向传播（用 scaler 防 fp16 数值下溢）
        scaler.scale(loss).backward()

        # 4. 梯度累积：每 N 步才更新一次
        if (step + 1) % args.accumulation_steps == 0:
            scaler.unscale_(optimizer)                  # 取消缩放
            torch.nn.utils.clip_grad_norm_(             # 梯度裁剪防爆炸
                model.parameters(), args.grad_clip
            )
            scaler.step(optimizer)                       # 更新参数
            scaler.update()                              # 更新 scaler 缩放因子
            optimizer.zero_grad(set_to_none=True)        # 清零梯度

        # 5. 日志
        if step % args.log_interval == 0:
            Logger(f'Epoch:[{epoch+1}/{args.epochs}] '
                   f'({step}/{iter_per_epoch}) '
                   f'loss:{loss.item() * args.accumulation_steps:.3f} '
                   f'lr:{lr:.7f}')

        # 6. 保存
        if (step + 1) % args.save_interval == 0:
            model.eval()
            ckp = f'{args.save_dir}/pretrain_{lm_config.dim}_{lm_config.n_layers}.pth'
            state_dict = model.module.state_dict() if isinstance(model, torch.nn.DataParallel) \
                         else model.state_dict()
            torch.save(state_dict, ckp)
            model.train()
```

## 📝 关键技巧深度解读

### 🔑 技巧 1：自动混合精度（AMP）

```python
ctx = torch.cuda.amp.autocast()
scaler = torch.cuda.amp.GradScaler(enabled=(args.dtype in ['float16', 'bfloat16']))

with ctx:
    out = model(X, Y)              # 内部自动用 fp16/bf16
    loss = out.last_loss / ...
scaler.scale(loss).backward()      # 反向传播也是低精度
```

**为什么？**
- fp32 计算慢、占显存大
- fp16/bf16 计算快、占显存小一半
- 但 fp16 数值范围小，**梯度可能下溢成 0**
- → **GradScaler** 把 loss 放大 N 倍，反向传播后再除回去

| 精度 | 适用场景 | 速度 | 显存 |
|---|---|---|---|
| fp32 | 老 GPU、调试 | 慢 | 大 |
| fp16 | V100/A100 | 快 | 小 |
| **bf16** | **A100/H100（推荐）** | 快 | 小 |

`bf16` 比 `fp16` 范围大，**不需要 scaler 也不容易下溢**，是现代 LLM 训练首选。

### 🔑 技巧 2：梯度累积

```python
loss = out.last_loss / args.accumulation_steps   # 提前除
scaler.scale(loss).backward()                     # 累积梯度

if (step + 1) % args.accumulation_steps == 0:    # 每 N 步才更新
    scaler.step(optimizer)
    optimizer.zero_grad(set_to_none=True)
```

**为什么？**
- 想要 effective batch_size = 512，但单卡只能装 64
- → 累积 8 步再更新一次 = 等效 batch_size 512
- **训练效果几乎一样，但单卡能跑大 batch**

公式：`effective_batch = batch_size × accumulation_steps × num_gpus`

### 🔑 技巧 3：loss_mask 应用

```python
loss_mask = loss_mask.view(-1)
loss = torch.sum(loss * loss_mask) / loss_mask.sum()
```

- `loss` 形状 `(B*L,)`，每个位置一个 loss 值
- `loss_mask` 形状 `(B*L,)`，1 表示算、0 表示不算
- **只对有效位置求平均**，padding 位置不参与

→ 这就是为什么模型 forward 里用 `reduction='none'`，把决策权交给训练循环。

### 🔑 技巧 4：梯度裁剪

```python
scaler.unscale_(optimizer)
torch.nn.utils.clip_grad_norm_(model.parameters(), args.grad_clip)  # grad_clip=1.0
```

- 如果某些 batch 的梯度特别大（异常样本），会"一脚踢翻"模型
- 梯度裁剪：**把梯度的总 L2 范数限制在 grad_clip 内**
- → 防止训练发散

### 🔑 技巧 5：`optimizer.zero_grad(set_to_none=True)`

- `set_to_none=True`：把梯度设为 None（不分配新内存）
- 比 `set_to_none=False`（设为 0）**省内存**
- 是 PyTorch 1.7+ 的推荐做法

## 🛠 启动训练

```bash
# 4 卡训练 215M 模型
python pretrain.py \
    --data_path seq_monkey_datawhale.jsonl \
    --gpus 0,1,2,3 \
    --batch_size 64 \
    --accumulation_steps 8 \
    --epochs 1 \
    --use_swanlab
```

### 关键参数

| 参数 | 默认 | 含义 |
|---|---|---|
| `--epochs` | 1 | 训几轮（LLM 一般 1 轮） |
| `--batch_size` | 64 | 单卡 batch |
| `--learning_rate` | 2e-4 | 初始学习率 |
| `--accumulation_steps` | 8 | 梯度累积 |
| `--grad_clip` | 1.0 | 梯度裁剪阈值 |
| `--warmup_iters` | 0 | warmup 步数 |
| `--dtype` | bfloat16 | 训练精度 |
| `--gpus` | 0,1,2,3 | 用哪些 GPU |

## ⚠️ 小白避坑

1. **loss 不下降？**
   - 学习率太大 → 调小 lr
   - 学习率太小 → 加 warmup
   - 数据有问题 → print 几个样本看看
2. **OOM（显存爆炸）？**
   - 调小 batch_size
   - 调小 max_seq_len
   - 用更小精度（fp16/bf16）
   - 用梯度累积模拟大 batch
3. **loss 突然变 NaN？**
   - 加大 grad_clip 限制
   - 切换到 bf16（fp16 易溢出）
   - 降低 lr
4. **训练太慢？**
   - 用 Flash Attention（[代码里已开](03-GQA%E4%B8%8ERoPE.md)）
   - 多卡训练
   - 用 `torch.compile()`（PyTorch 2.0+）
