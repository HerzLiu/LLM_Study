## 🎬 故事比喻：手工 vs 流水线

[第 5 章](../05-%E7%AC%AC5%E7%AB%A0-%E5%8A%A8%E6%89%8B%E6%90%AD%E5%BB%BA%E5%A4%A7%E6%A8%A1%E5%9E%8B/00-%E7%AB%A0%E8%8A%82%E6%80%BB%E8%A7%88.md) 我们像**老木匠**：
- 自己刨木头（写模型）
- 自己打磨（写训练循环）
- 自己上漆（写 Tokenizer）

→ 做出来的东西品质好，但**慢、累、难规模化**。

**第 6 章升级到工业流水线**：
- 用现成模型架构（HuggingFace 几十万个模型任意挑）
- 用 Trainer 类（封装训练循环）
- 用 DeepSpeed（封装分布式）

→ 同样的活，**几行代码 + 几小时**搞定。

---

## 🏗 手写实现 vs HuggingFace 框架对比

| 维度 | 第 5 章 手写 | **第 6 章 HF 框架** |
|---|---|---|
| 模型架构 | 自己写 RMSNorm/Attention/MLP | `AutoModelForCausalLM.from_pretrained()` |
| 加载权重 | `torch.load(...)` 手动处理 | `from_pretrained()` 一键搞定 |
| Tokenizer | 自己训 BPE | `AutoTokenizer.from_pretrained()` |
| 数据处理 | 自己写 Dataset | `datasets` 库 + `map()` |
| 训练循环 | 自己写 `for` 循环 | `Trainer.train()` 一行 |
| 多卡分布式 | `DataParallel` 简陋 | DeepSpeed / Accelerate |
| 兼容 LLM 生态 | ❌ 无法用预训练权重 | ✅ 直接加载 Qwen/LLaMA |
| 代码量 | 数百行 | **几十行** |

## 🛠 HuggingFace 三件套

### 1. Transformers 库（模型 + 训练）

> 由 HuggingFace 开发，统一支持 BERT / GPT / LLaMA / T5 / ViT 等 **上百种主流模型**。

**核心类**：
- `AutoConfig`：加载模型配置（`config.json`）
- `AutoModelForCausalLM`：加载 LLM 模型
- `AutoTokenizer`：加载 Tokenizer
- `Trainer`：封装训练循环
- `TrainingArguments`：超参配置

### 2. datasets 库（数据加载）

> HF 配套的数据处理库，集成 25 万+ 公开数据集。

```python
from datasets import load_dataset
ds = load_dataset('json', data_files='train.jsonl')
```

### 3. PEFT 库（高效微调）

> 封装了 LoRA / Adapter / Prefix Tuning 等高效微调方法。
> ⭐ 本章 6.3 节重点讲。

## 🐍 三大组件代码速览

### 加载模型（从零 vs 加载预训练）

```python
from transformers import AutoConfig, AutoModelForCausalLM, AutoTokenizer

# 方式 A：从零初始化（仅用配置）
config = AutoConfig.from_pretrained("Qwen/Qwen2.5-1.5B")
model = AutoModelForCausalLM.from_config(config, trust_remote_code=True)

# 方式 B：加载预训练权重（最常用）⭐
model = AutoModelForCausalLM.from_pretrained(
    "Qwen/Qwen2.5-1.5B",
    trust_remote_code=True
)

# Tokenizer 一行加载
tokenizer = AutoTokenizer.from_pretrained("Qwen/Qwen2.5-1.5B")
```

→ **就这 3 行**，替代了第 5 章里几百行模型代码。

### 数据加载

```python
from datasets import load_dataset

ds = load_dataset('json', data_files='/path/to/train.jsonl')
# ds 是 DatasetDict，默认在 ds["train"] 里
```

### Tokenize + 拼接成训练样本

```python
# 1. 分词
def tokenize_function(examples):
    return tokenizer([item for item in examples["text"]])

tokenized = ds.map(tokenize_function, batched=True, num_proc=10,
                   remove_columns=["text"])

# 2. 拼接成固定长度（CLM 训练标准做法）
block_size = 2048

def group_texts(examples):
    # 把多段文本拼接起来
    concatenated = {k: list(chain(*examples[k])) for k in examples.keys()}
    total_length = (len(concatenated[list(examples.keys())[0]]) // block_size) * block_size
    result = {
        k: [t[i:i+block_size] for i in range(0, total_length, block_size)]
        for k, t in concatenated.items()
    }
    # ⭐ CLM 训练里 labels == input_ids（模型内部自动错位）
    result["labels"] = result["input_ids"].copy()
    return result

train_dataset = tokenized.map(group_texts, batched=True)["train"]
```

#### ⭐ 关键技巧：把多段文本拼成 block_size

**为什么不直接用原始样本？**
- 原始样本长度不一（有的 100 字、有的 5000 字）
- 训练时需要**统一长度**，否则 batch 拼不起来
- **解法**：把所有文本拼成一条超长序列，再切成等长的 2048 块
- 这样每条训练样本都是 2048 个 token，效率最高

**和第 5 章手写的差异**：
- 第 5 章：每条样本 padding 到固定长度（浪费空间）
- 第 6 章：**拼接后切块**（不浪费一个 token）

## 📌 完整训练代码（速览）

```python
from transformers import (
    AutoConfig, AutoModelForCausalLM, AutoTokenizer,
    Trainer, TrainingArguments, default_data_collator,
)
from datasets import load_dataset

# 1. 加载模型 + Tokenizer
config = AutoConfig.from_pretrained("Qwen/Qwen2.5-1.5B")
model = AutoModelForCausalLM.from_config(config, trust_remote_code=True)
tokenizer = AutoTokenizer.from_pretrained("Qwen/Qwen2.5-1.5B")

# 2. 加载并处理数据（省略 tokenize 和 group_texts）
ds = load_dataset('json', data_files='train.jsonl')
train_dataset = ... # 上面的 tokenized + grouped

# 3. 配置训练超参
training_args = TrainingArguments(
    output_dir="output",
    per_device_train_batch_size=4,
    gradient_accumulation_steps=4,
    num_train_epochs=1,
    learning_rate=1e-4,
    logging_steps=10,
    save_steps=100,
    gradient_checkpointing=True,  # 省显存
)

# 4. 训练
trainer = Trainer(
    model=model,
    args=training_args,
    train_dataset=train_dataset,
    tokenizer=tokenizer,
    data_collator=default_data_collator,
)
trainer.train()
```

→ **40 行**代码就能跑通 1.5B 模型的预训练。

## ⚠️ 小白避坑

1. **`trust_remote_code=True` 必须加**
   - 否则自定义模型架构（如 ChatGLM）无法加载
2. **`Trainer` 默认用的是 MLM data_collator**
   - 训 CLM 必须传 `default_data_collator`
3. **预训练数据要拼接成 block_size**
   - 不要直接用 padding，浪费算力
4. **`gradient_checkpointing=True` 大幅省显存**
   - 但训练慢 ~25%，时间换空间
