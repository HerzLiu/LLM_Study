# 6.3.2-6.3.3 LoRA 原理深入

⬅ [04-高效微调三大流派](04-%E9%AB%98%E6%95%88%E5%BE%AE%E8%B0%83%E4%B8%89%E5%A4%A7%E6%B5%81%E6%B4%BE.md)	|	➡ [06-LoRA代码与peft](06-LoRA%E4%BB%A3%E7%A0%81%E4%B8%8Epeft.md)

> ⭐ **本章核心理论**：本节是面试高频考点，必懂数学原理。

---

## 🎬 故事比喻：高维世界里的小角落

想象 LLM 是一个**超复杂的工厂**，能加工各种产品（解各种任务）。
当你只需要它做"某个细分小任务"时（比如只回答医学问题）：
- **不需要动整个工厂的所有机器**
- **只需要在某个角落加几台小机器**

→ 这就是 LoRA 的核心假设：
> **微调时，参数变化是"低维的"**（只占整个高维空间的一个小角落）。

---

## 🧠 核心假设 1：本征秩（Intrinsic Rank）

### 什么是本征秩？

**直觉解释**：
> 一个任务"真正需要的参数自由度"通常**远远小于**模型实际的参数量。
> 这个"真正需要的自由度"叫**本征秩**（intrinsic rank）。

### 关键论文发现（2020）

论文 _Intrinsic Dimensionality Explains the Effectiveness of Language Model Fine-Tuning_ 实验证明：

| 模型 | 全参数 | 实际只需训 | 比例 |
|---|---|---|---|
| BERT-large | 340M | **~200 个参数**就能做某些任务 | 极低 |
| 现代 LLM | 7B+ | 几 M 参数搞定下游任务 | < 0.1% |

→ **预训练已经把模型"压"到了低维流形**，微调只是在这个流形上微小调整。

### LoRA 论文的核心断言

> **微调时，权重的变化 ΔW 也是低秩的。**

数学表示：
$$\Delta W \approx B \cdot A$$
其中：
- $W \in \mathbb{R}^{d \times k}$：原权重矩阵
- $A \in \mathbb{R}^{r \times k}$：低秩分解之一
- $B \in \mathbb{R}^{d \times r}$：低秩分解之二
- $r \ll \min(d, k)$：**秩**（rank），通常 4/8/16

→ **不需要训 $\Delta W$（$d \times k$ 个参数），只需训 $A$ 和 $B$（$r \times (d+k)$ 个参数）**。

---

## 🔧 LoRA 数学公式

### 微调前

原模型某一层权重为 $W_0$，前向传播：
$$h = W_0 x$$

### 微调后

**全参数微调**：
$$h = (W_0 + \Delta W) x$$
（直接更新 $\Delta W$，$d \times k$ 个参数）

**LoRA 微调** ⭐：
$$h = W_0 x + B A x$$

其中：
- $W_0$ **冻结不更新**
- $A$ 和 $B$ **训练**
- $\Delta W = BA$ 是低秩近似

### 参数量对比

假设 $d = k = 1024$，$r = 8$：

| | 全参数 | **LoRA** | 节省 |
|---|---|---|---|
| 参数量 | $d \times k = 1{,}048{,}576$ | $r \times (d + k) = 16{,}384$ | **64×** |

→ 单层就省 64 倍参数，整个 7B 模型省 **数百倍**。

---

## 🎨 LoRA 数据流可视化

```
输入 x
   ↓
   ├──────────────────────┐
   │                       ↓
   │                  A (训练)
   │                       ↓
   │                       r 维
   │                       ↓
   │                  B (训练)
   │                       ↓
   │            ΔW·x = B(A·x)
   │                       ↓
   ↓                       ↓
 W₀·x  ────────► + ◄──────┘
                 ↓
              h = W₀·x + B·A·x
```

**初始化技巧**：
- $A$ 用**随机高斯初始化**
- $B$ **全零初始化**
- → **初始时 $\Delta W = BA = 0$**，模型行为和未微调时完全一样，训练稳定

---

## 🔧 LoRA 应用在 Transformer 哪里？

### 原论文经验

> **只在注意力模块的 $W_Q$、$W_K$、$W_V$、$W_O$ 上加 LoRA**，FFN 不加。

实验发现：
- 单加 $W_Q$ → 效果一般
- 单加 $W_V$ → 效果稍好
- **同时加 $W_Q + W_V$** → ⭐ 效果最佳

### 现代实践

| `target_modules` 选择 | 效果 | 参数量 |
|---|---|---|
| 只 `["q_proj", "v_proj"]` | 中 | 最少 |
| `["q_proj", "k_proj", "v_proj", "o_proj"]` | 好 | 中 |
| **包含 MLP 的 `gate_proj`, `up_proj`, `down_proj`** | **最好** | 多 |

→ **MLP 层加 LoRA 现在也很常见**（虽然原论文不建议）。

---

## 📐 可训练参数量公式

$$\text{Params} = 2 \times L_{\text{LoRA}} \times d_{\text{model}} \times r$$

其中：
- $L_{\text{LoRA}}$：应用 LoRA 的权重矩阵**总数**
- $d_{\text{model}}$：模型隐藏维度
- $r$：LoRA 秩

### 具体例子：LLaMA-7B + LoRA

| 参数 | 值 |
|---|---|
| 层数 | 32 |
| 每层 LoRA 矩阵数 | 4（q_proj + k_proj + v_proj + o_proj） |
| $d_{\text{model}}$ | 4096 |
| $r$ | 8 |
| **总训练参数** | $2 \times 32 \times 4 \times 4096 \times 8 \approx 8.4M$ |
| 占比 | $8.4M / 7B \approx 0.12\%$ |

→ **训 7B 模型，只需要训 8M 参数**。

## ⭐ LoRA 5 大优势（必背）

### 优势 1：**模块化** —— 多任务热切换

```
基座模型（冻结）+ LoRA 模块 A → 法律助手
基座模型（冻结）+ LoRA 模块 B → 医疗助手
基座模型（冻结）+ LoRA 模块 C → 代码助手
```

→ **同一基座 + 切换 LoRA**，部署一份 7B 模型即可服务多场景。

### 优势 2：**训练高效** —— 硬件门槛低

- 不需要优化器状态保存大模型的参数 → 显存极省
- Adam 状态只针对 A、B 计算

### 优势 3：**零推理延迟**

训练完后，直接合并到原权重：
$$W_{\text{merged}} = W_0 + BA$$

→ 推理时的计算图**和原模型一模一样**。

### 优势 4：**简单线性设计**

- 没有非线性
- 没有改变计算图结构
- 易实现、易优化

### 优势 5：**与其他方法正交**

- LoRA + ZeRO ✅
- LoRA + DPO ✅
- LoRA + 量化（QLoRA）✅
- LoRA + 多任务（MoE-LoRA）✅

## ⚠️ LoRA 的局限性

### 局限 1：不适合"知识注入"任务

> **划重点**：LoRA **只能学下游任务的"格式 / 风格"**，**学不会大量新知识**。

| 任务 | 是否适合 LoRA |
|---|---|
| 学某个角色对话风格 | ✅ |
| 学某种代码风格 | ✅ |
| 让模型遵循特定输出格式 | ✅ |
| **学某领域的大量新知识** | ❌ **效果差** |
| **预训练 / 后训练 CPT** | ❌ **效果差** |

**为什么？**
- 知识存储主要在**权重的高秩分量**
- LoRA 只调低秩矩阵 → **没法影响高秩分量**
- 想注入知识，**必须全参数继续预训练**

### 局限 2：效果略低于全参数微调

- 一般低 1~3%
- 大部分场景**可接受**

### 局限 3：r 调参敏感

- r 太小 → 表达能力不足
- r 太大 → 过拟合 + 失去 LoRA 优势
- 经验值：4 / 8 / 16

---

## 🚀 进阶：QLoRA（突破性优化）

### 思路

> **LoRA + 4bit 量化**：把基座模型权重量化到 4bit，再加 LoRA 训练。

### 效果

| 模型 | 全参数微调显存 | LoRA 显存 | **QLoRA 显存** |
|---|---|---|---|
| 7B | ~112 GB | ~20 GB | **~7 GB** |
| 13B | ~208 GB | ~28 GB | **~12 GB** |
| 65B | ~1100 GB | ~80 GB | **~48 GB** |

→ **单卡 24G（RTX 3090/4090）可以微调 33B 模型！**
→ **单卡 48G（A6000）可以微调 65B 模型！**

### 关键技术

| 技术 | 作用 |
|---|---|
| **4-bit NormalFloat (NF4)** | 比 INT4 更精准的量化方案 |
| **Double Quantization** | 量化常数本身也量化 |
| **Paged Optimizer** | 显存爆掉时自动 swap 到 CPU |

→ **QLoRA 让"个人开发者微调大模型"成为可能**。

## 📌 6.3.2-6.3.3 节要点（必背）

| 知识点 | 一句话 |
|---|---|
| 核心假设 | 微调时 ΔW 是低秩的 |
| 数学公式 | $h = W_0 x + B A x$，$r \ll d$ |
| 初始化 | A 高斯，**B 零初始化**（保证训练初始等价原模型） |
| 应用位置 | 主要在 Attention 的 W_Q, W_K, W_V, W_O |
| 5 大优势 | 模块化、训练高效、零推理延迟、简单、正交 |
| **致命局限** | **不适合知识注入** |
| 进阶 | **QLoRA**（4bit 量化 + LoRA），单卡可训 33B |
