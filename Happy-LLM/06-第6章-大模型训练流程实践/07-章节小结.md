## ⭐ 必背知识清单

### 工业框架

- [ ] HuggingFace 三件套：**Transformers / datasets / PEFT**
- [ ] `AutoConfig + AutoModelForCausalLM + AutoTokenizer` 三个 Auto 类
- [ ] **Trainer 封装训练循环**：只关心模型、数据、超参
- [ ] **DeepSpeed ZeRO 配置文件**：`stage=1/2/3`、`offload_optimizer`
- [ ] **预训练数据拼接成 block_size**（不是 padding）

### SFT 关键

- [ ] **labels 中 IGNORE = -100**（PyTorch 默认 ignore_index）
- [ ] **Chat Template 不能错配**

### PEFT 三大流派对比

- [ ] **Adapter**：每层插模块，❌ 推理延迟
- [ ] **Prefix**：加虚拟前缀，❌ 占序列长度
- [ ] **LoRA** ⭐：低秩分解旁路，✅ 零延迟 + 不占长度

### LoRA 原理（面试高频）

- [ ] **核心假设**：微调时 ΔW 是低秩的
- [ ] **数学公式**：$h = W_0 x + B A x$，$r \ll d$
- [ ] **A 高斯初始化、B 零初始化**（保证训练初始等价原模型）
- [ ] **5 大优势**：模块化、训练高效、零推理延迟、简单、正交
- [ ] **致命局限**：不适合知识注入
- [ ] **QLoRA = LoRA + 4bit 量化**，单卡可训 33B

## 🎯 选型决策树

### 我有什么资源？

```
有上千张 A100，要训新基座模型？
  → 全参数 Pretrain（HF + DeepSpeed ZeRO-3）

有 4~8 张 A100，要训自己的 Chat 模型？
  → 加载开源 Base + 全参数 SFT（HF + DeepSpeed ZeRO-2）

只有 1 张 RTX 4090（24G），想微调 7B/13B？
  → ⭐ QLoRA（4bit + LoRA）

只有 1 张 RTX 3060（12G），想微调 1.5B/3B？
  → LoRA（bf16 + LoRA）

只想用 API，不想本地训练？
  → 不微调，做 Prompt Engineering / RAG
```

### 我要做什么任务？

```
学某种对话风格 / 角色扮演？
  → LoRA ✅

学某领域的输出格式 / 任务结构？
  → LoRA ✅

让模型遵循特定指令？
  → SFT（全参数 or LoRA）

让模型学大量新知识（如医学专业知识）？
  → 必须全参数 CPT + SFT，LoRA 效果差 ❌

让模型对齐人类偏好？
  → DPO / PPO（可配合 LoRA）
```
