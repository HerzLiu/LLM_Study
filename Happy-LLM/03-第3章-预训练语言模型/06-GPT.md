# 3.3.1 GPT —— LLM 的奠基者

⬅ [05-T5](05-T5.md)　|	➡ [07-LLaMA](07-LLaMA.md)

> 📅 OpenAI 2018 年发布 GPT-1，2020 年发布 GPT-3（**LLM 时代正式开启**）
> 🎯 核心信息：**Decoder-only + 极致规模化 + CLM = 通往 AGI 之路**

---

## 🎬 故事比喻：写小说大师

[BERT](02-BERT.md) 是高考语文选手（擅长完形填空 / 阅读理解）。
**GPT 是小说家** —— 给你一个开头，它能一直写下去。

而 OpenAI 的信念很简单：
> "**只要会预测下一个词，且数据和模型够大，就能产生智能。**"

历经 5 年，被 BERT 压制、被忽视、被嘲笑……
最终 GPT-3 引爆 LLM 时代，**ChatGPT** 让全球认识 LLM。

## 🔧 模型架构：Decoder Only

### 整体结构

```
输入文本 ──→ Tokenizer ──→ Embedding ──→ 加位置编码
                                              │
                                              ▼
                                ┌─────────────────────────┐
                                │ Decoder Block × N        │
                                │  ┌────────────────────┐  │
                                │  │ Pre-LayerNorm     │  │
                                │  │ Masked Self-Attn  │  │
                                │  │ + 残差            │  │
                                │  │ Pre-LayerNorm     │  │
                                │  │ MLP（或卷积）     │  │
                                │  │ + 残差            │  │
                                │  └────────────────────┘  │
                                └─────────────────────────┘
                                              │
                                              ▼
                                       线性层 → 词表概率
                                              │
                                              ▼
                                       生成下一个 token
```

### 与原版 Transformer Decoder 的差异

| 原版 Transformer Decoder | **GPT Decoder**                 |
| ---------------------- | ------------------------------- |
| 两个注意力层（掩码自注意力 + 交叉注意力） | **只有掩码自注意力**（没有 Encoder 给的 K/V） |
| Post-Norm              | **Pre-Norm**（GPT-2 起改用）         |
| FFN 用线性层               | GPT-1 用一维卷积（效果差不多）              |

→ 简化后的 GPT Decoder Layer 其实**更像 BERT 的 Encoder Layer**，但加了**掩码**。

### 位置编码

GPT 用的是 [sin/cos 绝对位置编码](../02-%E7%AC%AC2%E7%AB%A0-Transformer%E6%9E%B6%E6%9E%84/09-%E4%BD%8D%E7%BD%AE%E7%BC%96%E7%A0%81.md)（与 [BERT](02-BERT.md) 的可学习位置编码不同）。

## 🎯 预训练任务：CLM（因果语言建模）

### 思路

> **看前面所有 token，预测下一个 token**。

```
输入：今天天气
输出：今天天气很

输入：今天天气很
输出：今天天气很好

输入：今天天气很好
输出：今天天气很好。
...
```

这就是 **Causal Language Model（CLM）** —— 也叫"自回归语言模型"。

### CLM vs MLM 对比

| | **CLM**（GPT） | **MLM**（BERT） |
|---|---|---|
| **思路** | 看前面，预测下一个 | 挖空，让模型填 |
| **方向** | 单向（左→右） | 双向 |
| **训练-推理一致性** | ✅ 完全一致 | ❌ 推理时没 `[MASK]` |
| **天然支持生成** | ✅ | ❌ 需要魔改 |
| **理解能力** | 弱（小模型时） / 强（大模型时） | 强 |

### ⭐ 加深理解：CLM 凭什么击败 MLM？

虽然 BERT-MLM 在 NLU 上更强，但 GPT-CLM 在大规模化时有 3 大优势：

1. **训练-推理一致** —— MLM 推理时根本没 `[MASK]`，迁移有损失
2. **直接生成** —— LLM 的核心能力是对话生成，CLM 天然适合
3. **数据效率** —— CLM 每个 token 都能产生训练信号，MLM 只有 15% 能产生

## 📈 GPT 系列模型演进（核心表格）

| 模型 | 年份 | Decoder 层数 | 隐藏维度 | 头数 | 参数量 | 预训练语料 |
|---|---|---|---|---|---|---|
| **GPT-1** | 2018 | 12 | 768 | 12 | **0.12B** | 5 GB |
| **GPT-2** | 2019 | 48 | 1600 | 25 | **1.5B** | 40 GB |
| **GPT-3** | 2020 | 96 | 12288 | 96 | **175B** | 570 GB |
| GPT-4 | 2023 | 未公开 | 未公开 | 未公开 | 估计 1T+ | 未公开 |

→ **每代参数量 ~10× 增长，数据量也水涨船高**。

### GPT-1（2018）：被忽视的开拓者

- 首次提出**预训练 + 微调**思想（**比 BERT 早 4 个月！**）
- 但参数太小（0.12B），效果略输 BERT-base
- → 被学界忽视

### GPT-2（2019）：迈向 zero-shot

#### 关键改动
- 模型变大：48 层 / 1.5B 参数
- **Post-Norm → Pre-Norm**：训练更稳（详见 [Pre-Norm vs Post-Norm](../02-%E7%AC%AC2%E7%AB%A0-Transformer%E6%9E%B6%E6%9E%84/08-%E6%AE%8B%E5%B7%AE%E8%BF%9E%E6%8E%A5.md#-pre-norm-vs-post-norm)）

#### 重大思想：**zero-shot**
不微调，直接用自然语言描述任务让模型解决：

```
请你判断"这真是一个绝佳的机会"的情感是正向还是负向，
如果是正向，输出 1；否则输出 0。
```

但当时模型还不够大，zero-shot 效果一般。

### GPT-3（2020）：LLM 时代正式开启

#### 关键数字
- **175 B 参数**（千亿级）
- **570 GB 训练数据**（清洗后）
- 训练成本：**1024 块 A100（80G）跑 1 个月** ≈ 数千万美元

#### 重大思想：**few-shot / In-context Learning**

few-shot = 在 prompt 里给几个示例，让模型"现学现用"：

```
请判断情感（正向输出 1，负向输出 0）：

示例：
  "你的表现非常好" → 1
  "太糟糕了" → 0
  "真是一个好主意" → 1

现在判断：
  "这真是一个绝佳的机会" → ?
```

**这就是 In-context Learning（ICL）**：模型不更新参数，只看 prompt 里的示例就能学习。

#### ⭐ 加深理解：In-context Learning 为什么改变一切？

| 旧范式（BERT 等） | **新范式（GPT-3）** |
|---|---|
| 每个任务收集几百上千标注 → 微调 | 写 3~5 个示例放 prompt 里 |
| 每个任务一个模型 | **一个模型搞定一切** |
| 训练成本高 | 零成本 |
| 部署复杂 | 一个 API 搞定 |

→ 这就是 GPT-3 引爆 LLM 时代的根本原因。

## 🎯 涌现能力（Emergent Ability）

GPT-3 的最大惊喜是**涌现能力**：

> 某些能力**只有模型大到一定规模**才会突然出现，**小模型完全没有**。

典型涌现能力：
- **few-shot learning**
- **链式推理（CoT）**
- **指令遵循**
- **代码生成**

下图概念示意：

```
能力 ↑
  │           ┌───── 大模型涌现
  │          /
  │         /
  │  ──────/   ← 小模型完全没有这些能力
  └─────────────────→ 参数量
       涌现阈值
```

→ 详见 [第 4 章 LLM 概念](../04-%E7%AC%AC4%E7%AB%A0-%E5%A4%A7%E8%AF%AD%E8%A8%80%E6%A8%A1%E5%9E%8B/00-%E7%AB%A0%E8%8A%82%E6%80%BB%E8%A7%88.md)

## 🎯 GPT 系列的成功秘诀

1. **坚定的信念** —— 在被 BERT 压制的 3 年里，OpenAI 始终没改 Decoder-only 路线
2. **力大砖飞** —— 不断堆数据、堆参数、堆算力
3. **架构最小改动** —— 没有花哨的预训练任务，就是 CLM
4. **抓住涌现机会** —— GPT-3 175B 成为关键转折点

→ **印证了那句"Scaling is all you need"**

---

## ⚠️ 小白避坑

1. **GPT 不是简单的"反着用 BERT"** —— 是完全不同的训练范式
2. **GPT-1 没火 ≠ Decoder-only 不行** —— 只是当时规模不够
3. **不是所有模型都遵循"越大越好"** —— 在小规模上 BERT 系仍占优
4. **GPT-3 没开源，但 GPT-2 开源了** —— 学术圈很多研究基于 GPT-2
