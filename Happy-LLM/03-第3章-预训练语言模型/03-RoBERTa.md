# 3.1.2 RoBERTa —— 把 BERT 训得更狠

⬅ [02-BERT](02-BERT.md)　|	➡ [04-ALBERT](04-ALBERT.md)

> 📅 Facebook 2019 年发布
> 🎯 核心信息：**BERT 没训够！** 用同样的架构，把训练做对就能继续涨点。

---

## 🎬 故事比喻：同一辆赛车，换个老司机

[BERT](02-BERT.md) 是辆超跑，但 Google 觉得"差不多了就好"。
Facebook 看了一眼说："这车性能还能拉，给我！" —— 然后**没改架构**，只是把训练流程拉满，刷出了新 SOTA。

→ **RoBERTa 证明了一件事：BERT 的预训练远没饱和**。
这也是后来 **LLM 一路堆数据堆算力**的灵感来源。

---

## 🆚 RoBERTa vs BERT 速览

| 维度               | BERT-large         | **RoBERTa**     | 提升点      |
| ---------------- | ------------------ | --------------- | -------- |
| **架构**           | 24 层 Encoder       | 24 层 Encoder    | 完全一样     |
| **预训练任务**        | MLM + NSP          | **只用 MLM**      | 去掉 NSP   |
| **遮蔽策略**         | 静态（数据预处理时遮蔽）       | **动态**（训练时实时遮蔽） | Mask 更多样 |
| **训练数据**         | 13 GB / 3.3B token | **160 GB**（10×） | 数据爆炸     |
| **Batch size**   | 256                | **8 K**（32×）    | 大 batch  |
| **训练步数**         | 1M                 | 500K            | 但每步学得更多  |
| **序列长度**         | 多数 128，少数 512      | **全 512**       | 长序列稳定    |
| **Tokenizer 词表** | WordPiece 30K      | **BPE 50K**     | 更大词表     |
| **硬件**           | 64 TPU × 4 天       | 1024 V100 × 1 天 | 算力翻倍     |

→ 一句话：**架构没变，训练彻底升级**。

---

## 🔧 三大核心优化详解

### 优化 1：去掉 NSP，改进 MLM

#### 实验对比四组设置

| 组 | 设置 | 结果 |
|---|---|---|
| 1 | 段落对 + MLM + NSP（BERT 原版） | 基线 |
| 2 | 文档对 + MLM + NSP | 差不多 |
| 3 | 跨文档 + 只用 MLM | **更好** |
| 4 | 单文档 + 只用 MLM | **最好** |

**结论**：NSP 任务**没用**，去掉反而更好。可能是因为：
- NSP 太简单（判断两句是否相邻），模型很快就学会
- 占用了训练资源，不如让模型多学 MLM

#### 动态遮蔽 vs 静态遮蔽

| 策略 | BERT 做法 | RoBERTa 做法 |
|---|---|---|
| **静态** | 数据预处理时遮蔽一次 → 4 次重复掩码 → 训练 40 epoch | – |
| **动态** | – | 每个 epoch 训练时**实时随机遮蔽** |

**效果差异**：动态遮蔽**略有优势**，但更重要的是：
- 实现更简单
- 训练样本多样性大幅提升
- → 后续所有 MLM 模型都用动态遮蔽

### 优化 2：更大规模的数据和 batch

#### 数据扩充

| 数据集                    | 大小         | 来源               |
| ---------------------- | ---------- | ---------------- |
| BookCorpus + Wikipedia | 13 GB      | BERT 用过          |
| CC-NEWS                | –          | CommonCrawl 新闻部分 |
| OPENWEBTEXT            | –          | 高质量网页            |
| STORIES                | –          | 故事风格子集           |
| **总计**                 | **160 GB** | **10× BERT**     |

#### 大 batch 实验

| 设置 | Batch | Steps | 总 token | 性能 |
|---|---|---|---|---|
| BERT 风格 | 256 | 1M | 3.3B | 基线 |
| RoBERTa 风格 | **8K** | 31K | 3.3B | **更好** |

**结论**：在**相同总 token 数**下，**大 batch + 少步数 > 小 batch + 多步数**。

> ⭐ **加深理解：为什么大 batch 更好？**
> - 大 batch 让梯度估计更稳定（噪声小）
> - 可以用更高的学习率
> - 训练效率高（GPU 利用率高）
> - → 这是后来 LLM 普遍用 4K+ batch 的原因

### 优化 3：更大的 BPE 词表

#### WordPiece vs BPE

| 算法 | 代表用户 | 切分思路 |
|---|---|---|
| **WordPiece** | BERT | 基于最大似然合并 |
| **BPE** | GPT / RoBERTa / LLaMA | 基于词频合并字节对 |

#### 词表大小影响

| 模型 | 词表 | 影响 |
|---|---|---|
| BERT | 30K | OOV 较多 |
| **RoBERTa** | **50K** | 覆盖更广，**Embedding 层参数增加** |

**权衡**：词表越大覆盖越好，但 Embedding 参数也越大（`vocab_size × hidden_size`）。
**结论**：50K 是个不错的平衡点。

---

## 📈 RoBERTa 的历史意义

1. **证明了"训练流程"和"架构"同样重要** —— 同样的 BERT，会训和不会训差很多
2. **奠定了 LLM 时代的训练范式**：
   - 更大数据 ✅
   - 更大 batch ✅
   - 动态遮蔽 ✅
   - 大词表 ✅
3. **NSP 被钉死在历史的耻辱柱** —— 后续模型基本都不用了
4. **RoBERTa 至今仍是 BERT 系最强的轻量级理解模型** —— 很多 embedding 模型基于它

---

## ⚠️ 小白避坑

1. **RoBERTa 不是新架构**，是 BERT 的"训练优化版"
   - 这反映了深度学习的一个真理：**工程细节往往决定生死**
2. **去掉 NSP ≠ NSP 思想完全错** —— [ALBERT](04-ALBERT.md) 改进成了 SOP
3. **大 batch 不是越大越好**：超过某个阈值后边际收益递减，还可能掉点
