## 🎯 选型决策树

### 问题 1：你要解决什么任务？

```
┌─ 文本分类、相似度、检索召回（输入→标签）
│     → BERT 系（RoBERTa、DeBERTa）
│       小、快、精度高
│
├─ 翻译、摘要等明确的 Seq2Seq
│     → T5、BART、Flan-T5
│
├─ 对话、生成、问答、Agent
│     → LLM（GPT、LLaMA、Qwen、Claude…）
│
└─ 多模态（图文、语音）
      → 多模态 LLM（GPT-4V、Qwen-VL、LLaVA…）
```

### 问题 2：要不要本地部署？

```
要本地部署 / 商用 / 数据保密
   ↓
开源 LLM：
   - LLaMA-2/3（英文优势，需自己加强中文）
   - Qwen 2/2.5（中文 + 多语言强）
   - ChatGLM4-9B（中文优秀，工具能力强）
   - DeepSeek（性价比高）

不本地部署，只要效果好
   ↓
商用 API：
   - GPT-4 / Claude（最强但贵）
   - GPT-3.5-turbo（便宜够用）
   - 国内：通义、文心、智谱、DeepSeek API
```

### 问题 3：算力够吗？

| 算力级别                   | 推荐                                    |
| ---------------------- | ------------------------------------- |
| 笔记本 CPU                | BERT-base（量化后甚至 LLaMA-7B int4）        |
| 单张 8G GPU              | BERT-large / RoBERTa / Qwen-1.8B int4 |
| 单张 24G GPU（如 RTX 4090） | LLaMA-13B fp16 / Qwen-7B fp16         |
| 单张 80G A100            | LLaMA-70B int4 / LLaMA-30B fp16       |
| 多卡集群                   | 全参数微调 LLaMA-70B、训练自己的模型               |

## ⭐ 三大流派的"赢家通吃" 现象

```
BERT 时代（2018-2020）              LLM 时代（2022-）
─────────────────────             ─────────────────────
Encoder-only 称王                  Decoder-only 称王
↓                                  ↓
3 派各有发展                      其他派被边缘化
↓                                  ↓
学界研究多样                      工业界基本只用 Decoder-only
```

**为什么这样？**

| 原因 | 解释 |
|---|---|
| **架构简单** | Decoder-only 易规模化、易工程优化 |
| **任务统一** | CLM + Instruction Tuning 一招解千题 |
| **涌现能力** | 大模型下 Decoder-only 能力突变 |
| **生态完善** | LLaMA 开源 → 工具链全 → 良性循环 |

→ 详细分析见 [为什么 Decoder-only 赢了](01-PLM%E4%B8%89%E5%A4%A7%E6%B5%81%E6%B4%BE%E5%AF%B9%E6%AF%94.md#-%E5%8A%A0%E6%B7%B1%E7%90%86%E8%A7%A3%E4%B8%BA%E4%BB%80%E4%B9%88-decoder-only-%E6%9C%80%E7%BB%88%E8%B5%A2%E4%BA%86)

## 🧠 关键预训练任务对比

| 任务                  | 模型          | 思路            | 优势          | 劣势          |
| ------------------- | ----------- | ------------- | ----------- | ----------- |
| **MLM**             | BERT 系      | 遮单 token 让模型填 | 双向理解强       | 预训练-推理不一致   |
| **NSP**             | BERT        | 判断两句是否连续      | 学句间关系       | 太简单，常被去掉    |
| **SOP**             | ALBERT      | 判断两句顺序        | 比 NSP 更难    | 没被广泛采用      |
| **Span Corruption** | T5          | 遮 span，输出生成   | 适合 Seq2Seq  | 实现复杂        |
| **CLM**             | GPT / LLaMA | 看前面预测下一个      | 训练-推理一致、生成强 | 单向          |
| **GLM 任务**          | GLM-1       | CLM + MLM 融合  | 兼顾两者        | 大模型下不如纯 CLM |

## 🔬 哪些技术是"现代 LLM 标配"？

经过 BERT → T5 → GPT → LLaMA 的演进，沉淀下来的**最佳实践组合**：

| 组件      | 选择                      | 原因            |
| ------- | ----------------------- | ------------- |
| 架构      | Decoder-only            | 规模化最容易        |
| 注意力     | Masked Multi-Head + GQA | 速度和质量平衡       |
| 位置编码    | **RoPE**                | 长度外推 + 相对位置   |
| 归一化     | **RMSNorm**             | 比 LayerNorm 快 |
| Norm 位置 | **Pre-Norm**            | 训练稳定          |
| 激活函数    | **SwiGLU**              | 比 GELU 好      |
| 预训练任务   | **CLM**                 | 简单 + 大规模友好    |
| 后训练     | **SFT + RLHF / DPO**    | 对齐人类偏好        |
