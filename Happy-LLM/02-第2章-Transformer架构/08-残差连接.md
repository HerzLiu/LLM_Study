# 2.2.4 残差连接（Residual Connection）

⬅ [07-LayerNorm与BatchNorm](07-LayerNorm%E4%B8%8EBatchNorm.md)　|	➡ [09-位置编码](09-%E4%BD%8D%E7%BD%AE%E7%BC%96%E7%A0%81.md)

---

## 🎬 故事比喻：电梯直达，不必爬楼梯

100 层楼的酒店，如果只有楼梯（信息层层传递），到顶楼时早累垮（**梯度消失**）。

装个**直达电梯**（残差连接），底层信息可以一步到顶层。

---

## 🔧 技术拆解

### 普通层

$$y = F(x)$$

下一层只看到加工后的 `F(x)`，原始 `x` 丢了。

### 残差层

$$y = x + F(x)$$

下一层**既看到加工后的 `F(x)`，也看到原始 `x`**。

---

## ⭐ 加深理解：为什么残差能解决梯度消失？

反向传播时，对残差层求梯度：

$$\frac{\partial y}{\partial x} = 1 + \frac{\partial F(x)}{\partial x}$$

> **关键**：无论 `∂F/∂x` 多小（哪怕接近 0），那个 **+1** 都保证梯度不会归零。

### 对比：没有残差时

$$\frac{\partial y}{\partial x} = \frac{\partial F(x)}{\partial x}$$

如果 `∂F/∂x` 很小（如 0.1），多层叠加后：
- 10 层：`0.1^10 = 10⁻¹⁰` → 梯度消失
- 50 层：基本归零，模型学不动

### 有残差时

- 10 层：`(1 + 0.1)^10 ≈ 2.6` → 梯度健康
- 50 层：依然可控

**这就是 ResNet 能训练 1000 层、Transformer 能堆几十层的关键。**

---

## 🐍 代码（一行的事）

```python
# Pre-Norm 残差连接（现代 LLM 标准做法）
h = x + self.attention(self.attention_norm(x))      # 注意力子层
out = h + self.feed_forward(self.fnn_norm(h))       # FFN 子层
```

注意结构：
```
x ──┬─── LayerNorm ── Attention ──┐
    │                              +───→ h
    └──────────────────────────────┘
        （直接跳过去）
```

## ⭐ Pre-Norm vs Post-Norm

> 这是 Transformer 实现的一个**关键工程细节**，很多人没注意到。

### Post-Norm（原论文）

$$y = \text{LayerNorm}(x + \text{Sublayer}(x))$$

```
x ──┬─── Sublayer ──┐
    │                +── LayerNorm ──→ y
    └────────────────┘
```

归一化放在**残差后**。

### Pre-Norm（现代 LLM 标准）

$$y = x + \text{Sublayer}(\text{LayerNorm}(x))$$

```
x ──┬─── LayerNorm ── Sublayer ──┐
    │                              +───→ y
    └──────────────────────────────┘
```

归一化放在**残差前**。

### 对比

| 项 | Post-Norm | **Pre-Norm** |
|---|---|---|
| 训练稳定性 | 差（深层时 loss 容易炸） | ✅ 好 |
| 收敛速度 | 慢 | ✅ 快 |
| 是否需要 warmup | 必须 | 可选 |
| 现代采用 | ❌ | ✅ GPT / LLaMA / Qwen 都用 |

### 为什么 Pre-Norm 更稳？

Pre-Norm 让残差路径上**始终保持恒等映射**（最坏情况下网络等价于浅层），梯度流更顺。
Post-Norm 在残差路径上加了 LayerNorm，可能扰动梯度流。

---

## ⚠️ 小白避坑

1. **残差连接要求输入和输出 shape 完全一样**
   - 这就是为什么 [多头注意力的输入输出 shape 相同](05-%E5%A4%9A%E5%A4%B4%E6%B3%A8%E6%84%8F%E5%8A%9B.md#tensor-shape-%E5%85%A8%E7%A8%8B%E8%B7%9F%E8%B8%AA%E5%BF%85%E8%AE%B0)
   - 也是 FFN 升维后必须降回来的原因
2. **残差不是简单地"复制粘贴"**，是**加法**
3. **Pre-Norm 是现代 LLM 的事实标准**，写代码时记得用这个

---

## 📐 知识小结

| 救星 | 作用 |
|---|---|
| [LayerNorm](07-LayerNorm%E4%B8%8EBatchNorm.md) | 让每层输入分布稳定 |
| **残差连接** | 让梯度直达底层 |
| **Pre-Norm 组合** | 训练超深网络的稳定方案 |

→ 这三个加起来 = 现代 Transformer 能堆 100+ 层（如 GPT-3 有 96 层）的工程基础
