# 2.3.2 位置编码（Positional Encoding）

⬅ [08-残差连接](08-%E6%AE%8B%E5%B7%AE%E8%BF%9E%E6%8E%A5.md)　|	➡ [10-完整Transformer拼装](10-%E5%AE%8C%E6%95%B4Transformer%E6%8B%BC%E8%A3%85.md)

## 🎬 故事比喻：开会的人不知道彼此谁先到

[自注意力](03-%E8%87%AA%E6%B3%A8%E6%84%8F%E5%8A%9B.md) 里所有 token 是"平等"参与计算的，**模型无法区分**：
- "我喜欢你"
- "你喜欢我"

两句话里词集合一样、注意力机制看起来完全相同。
但意思完全相反！

**位置编码就是给每个位置贴一个"位置身份证"，加到词向量上，让模型知道顺序。**

---

## 🔧 技术拆解：正弦/余弦位置编码

### 公式

$$\text{PE}(pos, 2i) = \sin\left(\frac{pos}{10000^{2i/d}}\right)$$

$$\text{PE}(pos, 2i+1) = \cos\left(\frac{pos}{10000^{2i/d}}\right)$$

| 符号         | 含义                            |
| ---------- | ----------------------------- |
| `pos`      | token 在序列里的位置（0, 1, 2, ...）   |
| `2i, 2i+1` | 向量维度索引（**偶数维用 sin，奇数维用 cos**） |
| `d`        | 词向量维度（如 512）                  |
| `10000`    | 人为选定的"基数"                     |

### 例子：序列长 4，d_model = 4

```python
import numpy as np

def PositionEncoding(seq_len, d_model, n=10000):
    P = np.zeros((seq_len, d_model))
    for k in range(seq_len):
        for i in range(d_model // 2):
            denom = np.power(n, 2*i/d_model)
            P[k, 2*i]   = np.sin(k/denom)
            P[k, 2*i+1] = np.cos(k/denom)
    return P

P = PositionEncoding(seq_len=4, d_model=4, n=100)
print(P)
```

输出：
```
[[ 0.          1.          0.          1.        ]   # pos=0
 [ 0.84147098  0.54030231  0.09983342  0.99500417]   # pos=1
 [ 0.90929743 -0.41614684  0.19866933  0.98006658]   # pos=2
 [ 0.14112001 -0.9899925   0.29552021  0.95533649]]  # pos=3
```

每一行就是该位置的"身份证向量"。

---

## ⭐ 加深理解：为什么用 sin/cos 而不是简单整数？

### 好处 1：能外推到训练时没见过的长度

- 训练时最长 100，推理时来了 200 长度的句子
- sin/cos 公式直接能算出位置 100~199 的编码
- 而简单整数 `[1, 2, 3, ...]` 会让模型遇到 200 时懵掉（**外推困难**）

### 好处 2：能让模型轻松算出相对位置

根据三角恒等式：
$$\sin(A+B) = \sin A \cos B + \cos A \sin B$$
$$\cos(A+B) = \cos A \cos B - \sin A \sin B$$

→ `PE(pos+k)` 可以由 `PE(pos)` **线性变换得到**
→ 模型不用专门学相对位置，从 sin/cos 中**自然能解出来**

### 好处 3：不同维度对应不同频率

```
低维度 (i 小): 高频  → 刻画细粒度位置变化
高维度 (i 大): 低频  → 刻画粗粒度位置变化
```

类似**傅里叶变换的多尺度表示**。

### 好处 4：数值范围有界

sin/cos 输出始终在 `[-1, 1]`，不会随位置增大而无界扩张（整数编码会）。

## 🐍 PyTorch 实现

```python
import math
import torch

class PositionalEncoding(nn.Module):
    """位置编码模块"""

    def __init__(self, args):
        super().__init__()
        # 预先算好所有位置的编码，存起来（节省每次 forward 的计算）
        pe = torch.zeros(args.block_size, args.n_embd)
        position = torch.arange(0, args.block_size).unsqueeze(1)  # (block_size, 1)

        # 计算分母项 10000^(2i/d)
        # 用 exp(log) 实现避免溢出（log 域计算更稳）
        div_term = torch.exp(
            torch.arange(0, args.n_embd, 2) * -(math.log(10000.0) / args.n_embd)
        )

        # 偶数维用 sin，奇数维用 cos
        pe[:, 0::2] = torch.sin(position * div_term)  # 0, 2, 4, ... 维度
        pe[:, 1::2] = torch.cos(position * div_term)  # 1, 3, 5, ... 维度

        pe = pe.unsqueeze(0)  # (1, block_size, n_embd)，第 0 维留给 batch
        self.register_buffer("pe", pe)  # 注册为 buffer（不训练，但跟模型走）

    def forward(self, x):
        # 把位置编码加到词嵌入上
        # x.size(1) 是当前实际序列长度，可能小于 block_size
        x = x + self.pe[:, :x.size(1)].requires_grad_(False)
        return x
```

### 📝 代码解读

**关键 1：`unsqueeze(1)`**
- 在第 1 维插入 1，把 `(L,)` 变成 `(L, 1)`
- 方便后续广播（`position * div_term`）

**关键 2：`0::2` 和 `1::2`**
- Python 切片，分别取**偶数索引**和**奇数索引**
- 等价于：`pe[:, [0,2,4,...]]` 和 `pe[:, [1,3,5,...]]`

**关键 3：`register_buffer`**
- 位置编码是**固定值**，不参与梯度
- 但需要跟模型一起 save/move device → 用 `register_buffer` 而不是普通 attribute

**关键 4：`requires_grad_(False)`**
- 双保险，确保不参与梯度

## 🆚 各代位置编码对比

| 类型 | 代表 | 特点 |
|---|---|---|
| **绝对位置编码（sin/cos）** | Transformer 原论文 | 可外推、固定不学 |
| **可学习位置编码** | BERT | 简单，但只能用训练时长度内 |
| **相对位置编码** | T5、DeBERTa | 直接编码"两词距离" |
| **RoPE（旋转位置编码）** ⭐ | **LLaMA / Qwen** | 把位置信息融入 Q/K，效果好 |
| ALiBi | BLOOM | 线性偏置，外推强 |

> 第 5 章实现 LLaMA2 时会详细讲 **RoPE**。

---

## ⚠️ 小白避坑

1. **位置编码是"加"到词嵌入上的**，不是拼接
2. **现代 LLM 不用绝对位置编码了**，但思想都一样：**通过某种方式注入位置信息**
3. **位置编码不是必需的吗？** —— 是的，如果你的模型有顺序敏感性（如 RNN），可以不用。但纯注意力模型必须有
