## 🎬 一句话故事

旧时代：**传话游戏（RNN）** —— 30 人排成一排，一个传一个，**慢 + 健忘 + 失真**。
新时代：**全员开会（Transformer）** —— 30 人围圆桌，**同时**互相看，每人自己决定该关注谁。

**Transformer = 工业化实现的"全员开会"机制**，是所有现代 LLM（GPT、LLaMA、BERT、Claude…）的祖宗架构。

                          │
        ┌─────────────────┼─────────────────┐
        │                 │                 │
      Input            Encoder           Decoder
    ┌───┴────┐       ┌───┴────┐       ┌───┴─────┐

                       │                 │
                  EncoderLayer       DecoderLayer

                  │                          │

## 📝 本章一句话小结

**注意力让任意两个 token 直接对话（O(1) 距离），多头让模型从多个视角同时看，LayerNorm+残差保证深层可训练，位置编码注入顺序信息**。这五块拼起来 = Transformer = 现代 LLM 的发动机。
