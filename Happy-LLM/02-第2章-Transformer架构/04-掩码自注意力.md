# 2.1.4 掩码自注意力（Masked Self-Attention）

⬅ [03-自注意力](03-%E8%87%AA%E6%B3%A8%E6%84%8F%E5%8A%9B.md)　|	➡ [05-多头注意力](05-%E5%A4%9A%E5%A4%B4%E6%B3%A8%E6%84%8F%E5%8A%9B.md)

---

## 🎬 故事比喻：考试不许看后面的题

训练语言模型时，任务是「看前面的词，预测下一个词」。
**如果模型能偷看到未来的词，那就是作弊。**

### 例子：训练序列 `[BOS] I like you [EOS]`

模型应该按顺序完成：

| Step | 输入 | 应预测 |
|---|---|---|
| 1 | `[BOS]` | `I` |
| 2 | `[BOS] I` | `like` |
| 3 | `[BOS] I like` | `you` |
| 4 | `[BOS] I like you` | `[EOS]` |

如果不做处理，[自注意力](03-%E8%87%AA%E6%B3%A8%E6%84%8F%E5%8A%9B.md) 里"预测 like 的位置"会偷看到 "you"，**作弊！**

---

## 🔧 技术拆解：上三角 Mask

### 我们要的效果

第 i 个位置**只能看到位置 1 ~ i**，不能看到 i+1 之后。

### 做法：构造上三角矩阵

对角线**以上**设为 `-inf`，其他为 `0`：

```
位置:        1     2     3     4
1   [   0,  -inf, -inf, -inf]    ← 第 1 个词只能看自己
2   [   0,   0,  -inf, -inf]    ← 第 2 个词能看前 2 个
3   [   0,   0,   0,  -inf]    ← 第 3 个词能看前 3 个
4   [   0,   0,   0,   0   ]    ← 第 4 个词能看全部
```

### 把 mask 加到 scores 上

```
scores = scores + mask   # 加法
scores = softmax(scores) # 再 softmax
```

**效果**：
- `0 + score = score`（保留）
- `-inf + score = -inf` → softmax 后变成 **0**（屏蔽）

---

## 🐍 代码实现

```python
import torch
import torch.nn.functional as F

# 创建一个 (1, seq_len, seq_len) 的全 -inf 矩阵
mask = torch.full((1, args.max_seq_len, args.max_seq_len), float("-inf"))

# torch.triu 把对角线以下的元素设为 0，保留上三角
# diagonal=1 表示从主对角线往上偏 1 行开始保留（主对角线本身也设为 0）
mask = torch.triu(mask, diagonal=1)

# 在注意力计算中应用 mask
scores = scores + mask[:, :seqlen, :seqlen]  # 加 mask
scores = F.softmax(scores.float(), dim=-1)   # -inf 经 softmax → 0
```

### 📝 代码解读

**关键 1：`torch.full((shape), -inf)`**
- 创建一个全 `-inf` 的张量
- 为啥不是 `float("-inf")` 直接 `torch.zeros`？因为后面要做加法

**关键 2：`torch.triu(mask, diagonal=1)`**
- `triu` = upper triangular，保留上三角
- `diagonal=1` 表示从主对角线**上方 1 行**开始保留（主对角线本身设为 0）
- 这样第 i 个位置可以看到位置 i（含自己）

**关键 3：`mask[:, :seqlen, :seqlen]`**
- 预先生成 `max_seq_len` 大小的 mask
- 实际推理时如果序列短，**切片取出实际需要的部分**

---

## ⭐ 加深理解：训练 vs 推理的关键区别

### 训练时（并行）

一句话一次性输入，**靠 mask 假装看不到未来**。
所有位置的预测在**同一次 forward** 里完成。

```
输入:    [BOS]  I    like  you  [EOS]
            ↓    ↓    ↓     ↓    ↓
预测:      I   like  you  [EOS]  ?
（全部并行，mask 保证每个位置只看前面）
```

### 推理时（串行）

**真的看不到未来**（因为未来还没生成）。
一个 token 一个 token 地生成：

```
Step 1: 输入 [BOS]              → 预测 I
Step 2: 输入 [BOS] I            → 预测 like
Step 3: 输入 [BOS] I like       → 预测 you
Step 4: 输入 [BOS] I like you   → 预测 [EOS]
```

→ 通常用 **KV-Cache** 加速：每步只算新位置的 Q，K/V 复用历史结果。

### 这就是为什么……

> GPT 训练得很快（并行），但生成时却是逐 token 吐出来的。
> ChatGPT 那个"打字机效果"是真的在一个个生成，不是动画。

---

## 🆚 三种注意力对比

| 类型 | Q 来自 | K, V 来自 | 是否 mask 未来 | 用在哪 |
|---|---|---|---|---|
| 普通注意力 | 序列 A | 序列 B | ❌ | 跨序列建模 |
| [自注意力](03-%E8%87%AA%E6%B3%A8%E6%84%8F%E5%8A%9B.md) | 序列 X | 序列 X | ❌ | Encoder（如 BERT） |
| **掩码自注意力** | 序列 X | 序列 X | ✅ | Decoder（如 GPT） |
| 交叉注意力 | Decoder | Encoder | ❌ | Encoder-Decoder 桥梁 |

---

## ⚠️ 小白避坑

1. **mask 是"加"上去再 softmax**，不是直接乘 0
   - 因为 softmax(0) ≠ 0，但 softmax(-inf) = 0
2. **掩码自注意力 = Causal Attention = 因果注意力** —— 不同书叫法不同，是同一个东西
3. **训练和推理的输入顺序不同**：
   - 训练：一次性给完整序列 + mask
   - 推理：一个个加新 token
