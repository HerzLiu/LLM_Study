# 2.1.3 自注意力（Self-Attention）

⬅ [02-注意力机制QKV](02-%E6%B3%A8%E6%84%8F%E5%8A%9B%E6%9C%BA%E5%88%B6QKV.md)　|	➡ [04-掩码自注意力](04-%E6%8E%A9%E7%A0%81%E8%87%AA%E6%B3%A8%E6%84%8F%E5%8A%9B.md)

---

## 🎬 故事比喻：自己跟自己开会

普通注意力是"两个序列之间互相看"（比如翻译时，目标语言看源语言）。

**自注意力是同一个序列里所有 token 互相看**：每个词都问"这句话里其他词对我有多重要？"

### 例子：句子"这只猫在追它的尾巴"

每个词都问自己：
- "它" → 高度关注 "猫"（**指代关系**）
- "尾巴" → 高度关注 "猫"（**属于关系**）
- "追" → 关注 "猫" 和 "尾巴"（**动作的施受关系**）

---

## 🔧 技术拆解：QKV 都来自同一个输入

| 类型 | Q 来自 | K, V 来自 | 用途 |
|---|---|---|---|
| 普通注意力 | 序列 A | 序列 B | 跨序列建模（如翻译） |
| **自注意力** | 序列 X | 序列 X | **序列内部建模** |
| 交叉注意力 | Decoder 输入 | Encoder 输出 | Encoder-Decoder 桥梁 |

### 自注意力公式

输入 `X`，通过**三个不同的权重矩阵**得到 Q、K、V：

$$Q = X W_Q, \quad K = X W_K, \quad V = X W_V$$

然后套用 [标准注意力公式](02-%E6%B3%A8%E6%84%8F%E5%8A%9B%E6%9C%BA%E5%88%B6QKV.md)：

$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{Q K^T}{\sqrt{d_k}}\right) V$$

### 代码层面

自注意力的实现极其简单 —— **把同一个输入传 3 次**：

```python
# attention 是上一节定义的注意力函数
attention(x, x, x)  # 这就是自注意力
```

> ⚠️ 这里的 `x` 在真实代码里会先各自过一个线性层（`W_Q`, `W_K`, `W_V`），见 [完整代码](99-%E4%BB%A3%E7%A0%81-MultiHeadAttention.md)。

## ⭐ 加深理解：自注意力为什么这么强？

### 优势 1：任意两个位置 O(1) 距离

| 架构 | 第 1 词到第 N 词的距离 |
|---|---|
| RNN | O(N) —— 必须一步步传 |
| CNN | O(log N) —— 多层叠加 |
| **自注意力** | **O(1)** —— 一次性直连 |

→ 长距离依赖问题**彻底解决**。

### 优势 2：完全可并行

所有位置的 Q、K、V **一次性算出来**，矩阵乘法天然适合 GPU，硬件利用率拉满。

### 优势 3：灵活的依赖建模

每个词**自动学会**该看哪里，不受固定窗口（CNN）或顺序（RNN）限制。

### 代价：O(N²) 复杂度

| 序列长度 N | 注意力计算量 |
|---|---|
| 100 | 10,000 |
| 1,000 | 1,000,000 |
| 10,000 | 100,000,000（炸了） |

→ 这是后来很多 **Efficient Transformer**（Longformer、Linformer、Flash Attention）想优化的点。

## 🎨 自注意力的可视化（直觉）

想象一个 5×5 的方阵，行是 query 位置，列是 key 位置：

```
              这    只    猫    在    追
        ┌───────────────────────────────┐
   这   │ 0.6  0.1  0.1  0.1  0.1     │
   只   │ 0.1  0.5  0.3  0.05 0.05    │
   猫   │ 0.1  0.2  0.5  0.1  0.1     │
   在   │ 0.1  0.1  0.2  0.4  0.2     │
   追   │ 0.1  0.05 0.45 0.1  0.3     │  ← "追"高度关注"猫"
        └───────────────────────────────┘
```

**每一行加起来 = 1**（softmax 性质）
**每一格表示 query 该给 key 多少注意力**

---

## ⚠️ 小白避坑

1. **"自"是指 Q、K、V 来自同一序列**，不是说只关注自己
2. **每个位置都会关注所有位置**（包括自己），权重由 softmax 自动分配
3. **自注意力本身不知道顺序** —— 需要 [位置编码](09-%E4%BD%8D%E7%BD%AE%E7%BC%96%E7%A0%81.md) 来注入
