# 2.1.5 多头注意力（Multi-Head Attention）

⬅ [04-掩码自注意力](04-%E6%8E%A9%E7%A0%81%E8%87%AA%E6%B3%A8%E6%84%8F%E5%8A%9B.md)　|	➡ [06-Encoder-Decoder](06-Encoder-Decoder.md)

---

## 🎬 故事比喻：8 个专家联合会诊

一次注意力 = **一种相关性视角**。
但语言里有多种关系：

| 关系类型 | 例子 |
|---|---|
| 语法关系 | 主谓宾结构 |
| 语义关系 | 猫 ↔ 动物 |
| 指代关系 | 它 ↔ 猫 |
| 位置关系 | "昨天" 在 "今天" 前面 |

让一个人同时关注这些太难。

**解法**：让 `h` 个"专家头"各自独立做一次注意力，每人盯一个视角，最后把结果拼起来。
→ 这就是**多头注意力**。

> 原论文里 8 头注意力可视化显示：不同头确实学会了关注不同信息（语法 vs 语义 vs 远距离…）

---

## 🔧 技术拆解

### 参数设置（典型）

- `d_model = 512`（模型维度）
- `h = 8`（头数）
- `d_k = d_v = d_model / h = 64`（每个头的维度）

### 计算流程（5 步）

```
1. 输入 X: shape (B, L, 512)
2. 经 W_Q, W_K, W_V（每个都是 512×512）→ Q, K, V: (B, L, 512)
3. 拆头: (B, L, 512) → (B, L, 8, 64) → transpose → (B, 8, L, 64)
4. 8 头并行做注意力: (B, 8, L, 64)
5. 拼头: (B, 8, L, 64) → (B, L, 8, 64) → reshape → (B, L, 512)
6. 输出投影 W_O: (B, L, 512)
```

### 公式表示

$$\text{MultiHead}(Q, K, V) = \text{Concat}(\text{head}_1, ..., \text{head}_h) \, W_O$$

其中每个头：
$$\text{head}_i = \text{Attention}(Q W_Q^i, K W_K^i, V W_V^i)$$

---

## ⭐ 加深理解：为什么 d_model / h 而不是每头都 d_model？

> 这是面试常考的"设计动机"题。

**假设**：每个头都用 `d_model` 维（而不是 `d_model/h` 维）

| 设计 | 单头维度 | 总参数（QKV） | 问题 |
|---|---|---|---|
| 每头都 d_model | 512 | 8 × 3 × 512² ≈ **6.3M** | 参数爆炸 |
| **每头 d_model/h（实际方案）** | 64 | 1 × 3 × 512² ≈ **0.79M** | 同单头预算 |

**结论**：
> 拆维度后，**总参数和单头一样**，但获得了 **h 倍的视角多样性** —— 零成本升级。

### 工程小技巧

实际代码里**不是真的有 8 个独立矩阵**，而是用 1 个大矩阵（`512×512`）一次性算 8 头的 QKV，然后 reshape。
→ GPU 上一次大矩阵乘 >> 8 次小矩阵乘。

## 🐍 代码实现

完整 `MultiHeadAttention` 类见 [代码-MultiHeadAttention](99-%E4%BB%A3%E7%A0%81-MultiHeadAttention.md)，这里只看核心 forward 流程：

```python
def forward(self, q, k, v):
    bsz, seqlen, _ = q.shape

    # Step 1: 线性投影
    xq, xk, xv = self.wq(q), self.wk(k), self.wv(v)
    # shape: (B, L, dim)

    # Step 2: 拆头 (view + transpose)
    xq = xq.view(bsz, seqlen, self.n_heads, self.head_dim).transpose(1, 2)
    xk = xk.view(bsz, seqlen, self.n_heads, self.head_dim).transpose(1, 2)
    xv = xv.view(bsz, seqlen, self.n_heads, self.head_dim).transpose(1, 2)
    # shape: (B, n_heads, L, head_dim)

    # Step 3: 注意力计算（多头并行）
    scores = torch.matmul(xq, xk.transpose(2, 3)) / math.sqrt(self.head_dim)
    if self.is_causal:
        scores = scores + self.mask[:, :, :seqlen, :seqlen]
    scores = F.softmax(scores.float(), dim=-1).type_as(xq)
    output = torch.matmul(scores, xv)
    # shape: (B, n_heads, L, head_dim)

    # Step 4: 拼头
    output = output.transpose(1, 2).contiguous().view(bsz, seqlen, -1)
    # shape: (B, L, dim)

    # Step 5: 输出投影
    return self.wo(output)
```

### Tensor shape 全程跟踪（必记）

```
输入:                (B, L, dim)
QKV after wq:        (B, L, dim)
拆头后:               (B, n_heads, L, head_dim)
scores:              (B, n_heads, L, L)
加权后:               (B, n_heads, L, head_dim)
拼头后:               (B, L, dim)
输出:                 (B, L, dim)
```

> ⭐ **多头注意力的输入和输出 shape 完全一样**，所以可以无限堆叠成深层网络。

## 🎨 多头的可视化（直觉）

```
输入 X
  │
  ├── Head 1 ── 学语法关系 ──┐
  ├── Head 2 ── 学指代关系 ──┤
  ├── Head 3 ── 学远距离 ────┤
  ├── ...                  ├── Concat ── W_O ── 输出
  ├── Head 7 ── 学情感倾向 ──┤
  └── Head 8 ── 学位置邻近 ──┘
```

---

## ⚠️ 小白避坑

1. **头数必须能整除模型维度**：`assert d_model % n_heads == 0`
2. **`view + transpose` 是 PyTorch 多头实现的标准套路**，背下来
3. **`transpose` 后必须 `contiguous()` 才能 `view`**：因为 transpose 不改内存布局
4. **训练时一定要加 dropout**（在 attention 权重上、在残差连接上）
5. **多头不是模型变深，是变宽** —— 实际深度由 EncoderLayer 数量决定
