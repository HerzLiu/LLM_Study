## ⭐ 必背知识点

### 1. LLM = 参数大 + 数据多 + 涌现能力

### 2. 四大能力（区分 LLM 和 PLM）
- **涌现**：大到某阈值突然就会了
- **ICL**：prompt 给几个示例就能学
- **指令遵循**：听人话办事
- **CoT 推理**：会"一步步想"

### 3. 三阶段训练
- **Pretrain**：CLM 任务、海量无监督文本
- **SFT**：指令微调、多任务、多轮对话
- **RLHF**：RM + PPO（或 DPO 简化）

### 4. Scaling Law
- OpenAI：`C ≈ 6ND`，D ≈ 1.7N
- Chinchilla：D ≈ 20N（更合理）

### 5. RLHF 4 个模型
- Actor（更新）+ Ref（冻结）+ Reward（冻结）+ Critic（更新）
- 显存爆炸 → DPO 简化成 2 个模型

---

## 💰 三阶段训练成本对比

| 阶段 | LLaMA-65B 级别 | 估算成本 |
|---|---|---|
| Pretrain | 2048 张 A100 × 21 天 | **数百万美元** |
| SFT | 8 卡 × 数小时~数天 | **几千~几万美元** |
| RLHF (PPO) | 数十卡 × 数天 | **数万美元** |
| RLHF (DPO) | 8 卡 × 数天 | **几千美元** |

→ Pretrain 是**绝对大头**，所以普通研究者基本都是基于**开源 Base 模型**做后训练。

## 🎯 训练 LLM 的现实路线推荐

### 路线 A：完全从零（**几乎不可行**）

只有大厂能玩：
- OpenAI / Google / Meta / Anthropic
- 国内：阿里、百度、字节、华为、智谱、深度求索等

### 路线 B：基于开源 Base 二次训练（**主流**）

```
开源 Base 模型（LLaMA-3、Qwen-2、ChatGLM-4）
   ↓ 继续预训练（可选，用领域数据）
   ↓ SFT（用你的指令数据）
   ↓ DPO（可选，让回答更对齐你的需求）
   ↓ 部署！
```

### 路线 C：只做 SFT（**最常见**）

```
开源 Chat 模型（已经过 SFT + RLHF）
   ↓ LoRA 微调（你的少量数据）
   ↓ 部署！
```

→ 详见 [第 6 章 LoRA 微调实战](../06-%E7%AC%AC6%E7%AB%A0-%E5%A4%A7%E6%A8%A1%E5%9E%8B%E8%AE%AD%E7%BB%83%E6%B5%81%E7%A8%8B%E5%AE%9E%E8%B7%B5/05-LoRA%E5%8E%9F%E7%90%86%E6%B7%B1%E5%85%A5.md)

## 🧠 LLM 的现状与未来

### 现在已经很强
- ChatGPT、GPT-4、Claude 3.5、DeepSeek-R1 等
- 通用知识、推理、编程、写作都不错

### 仍待解决的问题
- ⚠️ [幻觉](03-LLM%E5%9B%9B%E5%A4%A7%E7%89%B9%E7%82%B9.md#%EF%B8%8F-%E7%89%B9%E7%82%B9-4%E6%8C%A5%E4%B9%8B%E4%B8%8D%E5%8E%BB%E7%9A%84%E5%B9%BB%E8%A7%89hallucination)
- ⚠️ 实时知识更新（一旦训完就"过期"）
- ⚠️ 复杂推理（多步骤、严格逻辑）
- ⚠️ 长期记忆（对话超过上下文窗口就忘）
- ⚠️ 多模态对齐
- ⚠️ 安全性、价值观对齐

### 未来方向
- 推理模型（o1、R1）
- 多模态统一
- Agent 化（[第 7 章 Agent](../07-%E7%AC%AC7%E7%AB%A0-%E5%A4%A7%E6%A8%A1%E5%9E%8B%E5%BA%94%E7%94%A8/04-LLM-Agent%E5%8E%9F%E7%90%86.md)）
- 更高效的训练方法（MoE、SSM）
- 端侧部署（小 LLM）

## 📝 本章一句话总结

**LLM = 大规模 Decoder-only + Pretrain + SFT + RLHF**
**四大能力**（涌现、ICL、指令、CoT）让 LLM 从"NLP 工具"升级为"通用智能助手"
**三阶段训练**（预训练 → SFT → RLHF）分别赋予 LLM **知识、指令遵循、价值对齐**
