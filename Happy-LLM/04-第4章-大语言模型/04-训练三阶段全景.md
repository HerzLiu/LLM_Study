# 4.2.0 训练 LLM 的三阶段全景

⬅ [03-LLM四大特点](03-LLM%E5%9B%9B%E5%A4%A7%E7%89%B9%E7%82%B9.md)　|	➡ [05-Pretrain预训练](05-Pretrain%E9%A2%84%E8%AE%AD%E7%BB%83.md)

> 在深入每个阶段前，先建立"鸟瞰视角"。

---

## 🎬 故事比喻：培养一个学生的三个阶段

把 LLM 想象成一个**学生**，从"婴儿"养成"全能助理"要走三步：

| 阶段                 | 类比             | 让模型学到什么              |
| ------------------ | -------------- | -------------------- |
| **Pretrain（预训练）**  | 让他**博览群书**     | 海量知识（语法、事实、模式）       |
| **SFT（有监督微调）**     | 教他**怎么解题**     | 听懂指令 + 给出格式化回答       |
| **RLHF（人类反馈强化学习）** | 让他**反复练习挨改作业** | 答得**让人喜欢**（安全、有用、无害） |

---

## 🗺 三阶段全景图

```
                    互联网海量文本（数 T token）
                              │
                              ▼ 数千 GPU × 数月
                ┌─────────────────────────┐
                │      ① Pretrain         │
                │   学知识 + 学语言模式      │
                │   CLM 任务（无监督）      │
                └────────────┬────────────┘
                              │
                              ▼ Base Model（如 LLaMA-Base）
                  人工标注的指令-回复对
                              │
                              ▼ 数十 GPU × 数天
                ┌─────────────────────────┐
                │       ② SFT            │
                │  学指令格式 + 多任务泛化   │
                │  指令微调（监督学习）      │
                └────────────┬────────────┘
                              │
                              ▼ Chat/Instruct Model
                  人工标注的偏好对（chosen vs rejected）
                              │
                              ▼ 数十~数百 GPU × 数天
                ┌─────────────────────────┐
                │       ③ RLHF           │
                │  对齐人类价值观（安全、礼貌、有用）│
                │  RM + PPO（或 DPO）       │
                └────────────┬────────────┘
                              │
                              ▼
                        最终 ChatGPT/Claude
```

## 📊 三阶段对比表

| 维度        | Pretrain                                               | SFT               | RLHF             |
| --------- | ------------------------------------------------------ | ----------------- | ---------------- |
| **目的**    | 学知识                                                    | 学指令               | 学价值观             |
| **数据来源**  | 互联网无监督文本                                               | 人工标注指令-回复         | 人工标注偏好对          |
| **数据规模**  | 数 T token                                              | 数百万条              | 数十万对             |
| **标注成本**  | 几乎 0                                                   | 高                 | 极高               |
| **训练任务**  | [CLM](../03-%E7%AC%AC3%E7%AB%A0-%E9%A2%84%E8%AE%AD%E7%BB%83%E8%AF%AD%E8%A8%80%E6%A8%A1%E5%9E%8B/06-GPT.md#-%E9%A2%84%E8%AE%AD%E7%BB%83%E4%BB%BB%E5%8A%A1clm%E5%9B%A0%E6%9E%9C%E8%AF%AD%E8%A8%80%E5%BB%BA%E6%A8%A1) | CLM（仅算回复部分的 loss） | RM 训练 + PPO 强化学习 |
| **算力消耗**  | 极大（千卡×数月）                                              | 中等（数十卡×数天）        | 较大（数百卡×数天）       |
| **训练时长**  | 几个月                                                    | 几天                | 几天到几周            |
| **是否能跳过** | ❌ 必须                                                   | ⚠️ 几乎必须（否则不会"对话"） | ⚠️ 可选但推荐         |

## ⭐ 加深理解：为什么是这三阶段？

### 阶段间的"分工"

```
Pretrain ── 赋予能力（capability）
            "你能做什么"

SFT ────── 激发能力（usability）
            "你怎么用这些能力"

RLHF ───── 对齐能力（alignment）
            "用得让人满意"
```

### 没有 SFT 会怎样？

直接用 GPT-3 Base：
```
用户：请告诉我今天的天气
GPT-3：请告诉我今天的天气
       请告诉我今天的温度
       请告诉我今天的湿度
       ...（一直接话茬）
```
→ 不会"对话"，只会"续写"。

### 没有 RLHF 会怎样？

只到 SFT：
- 能听懂指令了
- 但可能输出**不安全、不礼貌、有害**的内容
- 无法精细控制回答风格

### 三阶段 = 现代 LLM 标准训练流程

OpenAI（InstructGPT 论文）、Anthropic（Claude）、Meta（LLaMA-2-Chat）等头部 LLM 都遵循这个范式。
甚至现在已经扩展为 **5 阶段**：

```
Pretrain → SFT → RM → PPO/DPO → 持续对齐（RLAIF / Constitutional AI）
```

## 💰 训练成本对比（粗略估算）

| 阶段 | 例子 | 算力 | 估算成本 |
|---|---|---|---|
| **Pretrain** | LLaMA-65B | 2048 张 A100 × 21 天 | **数百万美元** |
| **SFT** | Alpaca | 8 卡 × 3 小时 | **数百美元** |
| **RLHF** | InstructGPT | 数十卡 × 数天 | **数万~数十万美元** |
| 总和 | ChatGPT 级别 | – | **千万~亿美元** |

→ Pretrain 是大头，**这就是为什么大多数公司只能"基于开源底模做后训练"**。

---

## 🛠 阶段对应的"底模"概念

业界常说的"底模"指的是 **Pretrain 出来的 Base 模型**：

| 模型类型 | 阶段 | 用法 |
|---|---|---|
| **Base / Foundation Model** | Pretrain 完成 | 用于二次开发（继续训练） |
| **Instruct / Chat Model** | SFT + RLHF 完成 | 直接用作对话产品 |

例子：
- **LLaMA-2-7B-Base**（只预训练，不能对话）
- **LLaMA-2-7B-Chat**（含 SFT + RLHF，可直接对话）

## ⚠️ 小白避坑

1. **三阶段不是绝对的**
   - 有的模型不做 RLHF，只做 SFT（如早期 LLaMA-2-Base 派生）
   - 有的用 DPO 替代 RLHF
   - 有的把 SFT 拆成多轮（按主题分阶段微调）
2. **数据质量 > 数据数量**（尤其在 SFT 和 RLHF 阶段）
3. **不要试图自己 Pretrain**
   - 普通研究者 / 小公司根本玩不起
   - 99% 的情况是**基于开源 Base 做后训练**
4. **RLHF 难度高**
   - 工程复杂、调参敏感
   - 建议优先尝试 DPO
