## 🎬 一句话故事

前 6 章我们学会了**怎么造 / 怎么训** LLM。
**第 7 章终于轮到"怎么用"** ：

| 主题 | 解决什么问题 |
|---|---|
| **7.1 LLM 评测** | 如何科学衡量"哪个模型更好"？ |
| **7.2 RAG** | 如何让 LLM **不胡说八道**？（缓解 [幻觉](../04-%E7%AC%AC4%E7%AB%A0-%E5%A4%A7%E8%AF%AD%E8%A8%80%E6%A8%A1%E5%9E%8B/03-LLM%E5%9B%9B%E5%A4%A7%E7%89%B9%E7%82%B9.md#%EF%B8%8F-%E7%89%B9%E7%82%B9-4%E6%8C%A5%E4%B9%8B%E4%B8%8D%E5%8E%BB%E7%9A%84%E5%B9%BB%E8%A7%89hallucination)） |
| **7.3 Agent** | 如何让 LLM **真正办事**？（不只是聊天） |

→ 这三个模块**支撑了今天 90% 的 LLM 应用**。

## 🎯 本章学完你将拥有

- [ ] 知道 MMLU / GSM8K / HumanEval / BFCL 等主流评测集干嘛用
- [ ] 知道 Open LLM Leaderboard / Lmsys Arena / OpenCompass 三大榜单

- [ ] **理解 ReAct 框架**（Reason + Act）
- [ ] 能用 OpenAI `tool_calls` 写一个简单 Agent

## 📝 本章一句话小结

**评测**给 LLM 打分、**RAG**让 LLM 不胡说、**Agent**让 LLM 会办事。
这三块是 LLM 从"玩具"走向"生产力工具"的关键一跃。

## ⚠️ 学习建议

1. **7.1 速读**：知道有这些评测集和榜单即可，不必背
2. **7.2 RAG 精读**：当下最热的应用范式，必懂
3. **7.3 Agent 精读**：通往 AGI 的核心方向，未来几年最重要
