## ⭐ 必背知识清单

### LLM 评测
- [ ] 三大榜单：**Open LLM Leaderboard / Lmsys Arena / OpenCompass**
- [ ] 通用：**MMLU**；数学：**GSM8K**；代码：**HumanEval**
- [ ] **小心 Benchmark Hacking**（刷榜作弊）

### RAG
- [ ] **三步原理**：索引（切分+向量化）→ 检索（余弦相似度）→ 生成（基于上下文）
- [ ] **核心组件**：Embedding 模型 + 向量数据库 + LLM
- [ ] **解决的痛点**：幻觉、知识过时、领域专业
- [ ] **vs 微调**：RAG 管知识，微调管风格
- [ ] **进阶**：Rerank、Query Rewrite、Agentic RAG

### Agent
- [ ] **5 大核心能力**：目标理解、规划、记忆、工具使用、反思迭代
- [ ] **4 大类型**：任务型、规划推理型、多 Agent、探索学习型
- [ ] **ReAct 框架**：Thought → Action → Observation 循环
- [ ] **关键技术**：Function Calling / Tool Calling
- [ ] **主流框架**：LangChain / AutoGen / CrewAI / Dify

## 🆚 三大应用范式对比

| 维度 | **评测** | **RAG** | **Agent** |
|---|---|---|---|
| 目的 | 衡量能力 | 提供知识 | 完成任务 |
| 复杂度 | 低 | 中 | 高 |
| 是否调用工具 | ❌ | 仅检索 | ✅ 多种 |
| 是否能规划 | ❌ | ❌ | ✅ |
| 工业成熟度 | 高 | **高（最火）** | 中（快速发展） |
| 典型应用 | 选型 + 训练优化 | 客服 / 文档问答 / 知识库 | 自动办公 / 自主任务 |

## 🎯 实战选型决策树

### 我想做什么应用？

```
要让 LLM 回答某领域专业问题？
   → ⭐ RAG（建领域知识库）

要让 LLM 实际完成任务（如订票、发邮件、控制设备）？
   → ⭐ Agent（Function Calling）

要让 LLM 既懂知识又会办事？
   → RAG + Agent 组合（Agentic RAG）

要选哪个 LLM 做底座？
   → 看评测榜单 + 自己业务样本验证

要让 LLM 学某种风格 / 角色？
   → SFT 微调（[[../06-第6章-大模型训练流程实践/05-LoRA原理深入|第 6 章 LoRA]]）

要让 LLM 安全、礼貌、对齐价值观？
   → RLHF / DPO（[[../04-第4章-大语言模型/07-RLHF人类反馈强化学习|第 4 章 RLHF]]）
```

## 💼 现实生产中的"组合拳"

实际产品通常**多种技术组合**：

```
                ┌────────────────────────────┐
                │      用户问题                │
                └─────────────┬──────────────┘
                              │
                              ▼
                     ┌────────────────┐
                     │   Agent 规划    │  ← 决定下一步
                     └────────┬───────┘
                              │
              ┌───────────────┼───────────────┐
              │               │                │
              ▼               ▼                ▼
         调 RAG 查知识     调工具 API       调计算器
         (向量数据库)      (天气/订票)     (数学)
              │               │                │
              └───────────────┼───────────────┘
                              │
                              ▼
                     ┌────────────────┐
                     │   LLM 整合回答   │
                     └────────────────┘
```

→ 这就是**今天典型 LLM 产品的架构**（ChatGPT Plus、Claude、Kimi 等）。
