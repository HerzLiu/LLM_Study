## ⭐ 必须记住的"全书核心十条"

1. **Transformer 的核心是注意力机制** —— 让任意两个 token O(1) 距离交互
2. **现代 LLM 都是 Decoder-only** —— GPT/LLaMA 流派赢了 BERT/T5
3. **CLM 任务无监督友好** —— 任何文本都能训
4. **Scaling Law / Chinchilla 法则** —— D ≈ 20×N 是最佳数据量
5. **三阶段训练**：Pretrain（学知识）→ SFT（学指令）→ RLHF（学价值观）
6. **LoRA 的本质**：微调时 ΔW 是低秩的，只需训 BA
7. **幻觉无法根除**：必须用 RAG 缓解
8. **RAG = 索引 + 检索 + 生成**：让 LLM 开卷考
9. **Agent = LLM + 工具 + 规划 + 记忆 + 反思**：让 LLM 会办事
10. **LLM 评测要看多个榜单 + 自己业务样本验证**

## 🛤 后续学习路线

### 路线 A：深入理论
- **强化学习**：PPO / GRPO / DAPO（推理模型的核心）
- **多模态**：CLIP / LLaVA / Qwen-VL
- **MoE 架构**：Mixtral / DeepSeek-V3 的稀疏专家
- **长上下文**：Flash Attention / Ring Attention / 线性注意力
- **推理模型**：o1 / R1 / 慢思考 + 强化学习

### 路线 B：工程实战
- **训练**：DeepSpeed Megatron-LM 大规模训练
- **推理**：vLLM / TGI / SGLang 高性能推理
- **微调**：TRL 库（SFT/DPO/PPO/KTO）
- **应用**：LangChain / LangGraph / LlamaIndex 工业级框架
- **模型部署**：量化、剪枝、知识蒸馏

### 路线 C：应用产品
- **垂直 RAG**：法律、医疗、金融知识库
- **垂直 Agent**：客服、办公自动化、代码生成
- **多模态产品**：图文理解、视频生成
- **AI 编程助手**：Cursor / Copilot 风格
- **AI Agent 平台**：Dify / Coze / FastGPT

### 路线 D：研究方向
- **AGI 探索**：自主规划、世界模型
- **可控生成**：RLHF / RLAIF / Constitutional AI
- **可解释性**：注意力可视化、概念探针
- **效率优化**：稀疏化、动态计算
- **安全对齐**：越狱防御、价值观对齐
